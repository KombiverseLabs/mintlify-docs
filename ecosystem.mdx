## Complete Workflow

```mermaid
sequenceDiagram
    participant You
    participant StackKits as StackKits
    participant Sim as Sim
    participant Stack as Stack

    Note over You,Infra: Phase 1: Design
    You->>StackKits: Choose blueprint (e.g., Basement Kit)
    StackKits->>You: stack-spec.yaml template
    You->>You: Customize configuration
    
    Note over You,Infra: Phase 2: Test
    You->>Sim: Test configuration
    Sim->>Sim: Create simulated nodes
    You->>Sim: SSH & verify
    Sim->>You: ✓ Configuration works!
    
    Note over You,Infra: Phase 3: Deploy
    You->>Stack: Deploy configuration
    Stack->>Stack: Validate with CUE
    Stack->>Stack: Generate OpenTofu
    Stack->>Infra: Provision infrastructure
    Infra->>Stack: Report status
    Stack->>You: ✓ Deployment complete!
    
    Note over You,Infra: Phase 4: Operate
    loop Continuous
        Infra->>Stack: Heartbeat & metrics
        Stack->>You: Dashboard updates
    end
```

## Architecture Layers

### Layer 1: Open Core (Self-Hosted)

These tools follow the open-core model and are designed to run entirely on your infrastructure. ## How They Connect

### The stack-spec.yaml File

All tools share a common configuration format:

```yaml
# stack-spec.yaml - The universal config
stackkit: basement-kit       # ← StackKit to use
version: "1.0.0"

domain: homelab.local
email: you@example.com

nodes:
  - name: server-1
    ip: 192.168.1.10
    role: primary

services:
  traefik:
    enabled: true
  portainer:
    enabled: true
```

This single file works with:

| Tool | Usage |
|------|-------|
| **StackKits** | Validates against CUE schemas |
| **Sim** | Creates simulated test environment |
| **Stack** | Generates & deploys infrastructure |
| **Cloud** | Stores & version-controls configs |

## Technology Stack

| Component | Technology | Purpose |
|-----------|------------|---------|
| **Backend** | Go 1.25+ | High-performance, single binary |
| **Frontend** | SvelteKit 2 / Svelte 5 | Modern, reactive UI |
| **Database** | PostgreSQL 17 (Cloud), PocketBase (TechStack) | Production persistence |
| **IaC** | OpenTofu | Infrastructure provisioning |
| **Validation** | CUE | Schema definition & validation |
| **Agent Comm** | gRPC + mTLS | Secure, efficient RPC |
| **Auth** | Auth0 (OIDC) | Enterprise SSO |
| **Billing** | Stripe | Subscription management |
