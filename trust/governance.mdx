## Who is responsible

kombify is operated by Kombiverse Labs. The legal details are in the imprint on
[kombify.io](https://kombify.io). Product decisions are made by the operator.

## Open source and open core

- StackKits, Techstack, SpeechKit and the kombify Sites framework are
  available as open source. When you run them yourself, the licence of the
  repository applies, not the Terms of the hosted services.
- Each repository states its own licence in the file `LICENSE`. The licences
  differ between products, so read the one that belongs to the product you use.
  Some products allow a choice between licences.
- The open core works without a kombify account, without Techstack and without a
  hosted kombify endpoint. kombify earns money with convenience around it, such
  as hosting, monitoring, managed placement and support, and not by locking
  features of the open-source products.
- Operating several servers, provider actions and the server agent belong to
  Techstack. The standalone StackKits command line has no such part.

## How the code is published

Development happens in a private repository. A cleaned export is published to
the public repository, where releases, tags and issues live. Public releases
are built there. Downloads carry checksums so you can verify them, and
StackKits releases also carry software bills of materials and signed build
attestations.

## How releases reach you

A merged change is not live yet. Stable releases ship through a regular
release process, and every product page states which release it describes and
how far the product has come. Pre-1.0 products can change between versions, so
pin the version you tested.

## Contribute and report

- Contributions and the code of conduct are described in each repository.
- Documentation errors: use "Edit this file" on the page or write to
  [info@kombify.io](mailto:info@kombify.io).
- Vulnerabilities: see [Security](/trust/security#report-a-vulnerability).

## Commitments and limits

- No service-level agreement during the beta, including on paid plans.
- Support is by e-mail on working days and answered asynchronously.
- The operating status is at [status.kombify.io](https://status.kombify.io).
- This documentation excludes internal infrastructure and unsupported claims.
