## homelab api stackkits get

جلب تفاصيل StackKit محدد.

```bash
homelab api stackkits get <name> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/stackkits/{name}` |
| يغيّر الحالة | لا |
| أداة MCP | `get_stack_kit` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<name>` | string | **مطلوب.** |

## homelab api stackkits list

عرض StackKits المتاحة.

```bash
homelab api stackkits list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/stackkits` |
| يغيّر الحالة | لا |
| أداة MCP | `list_stack_kits` |
