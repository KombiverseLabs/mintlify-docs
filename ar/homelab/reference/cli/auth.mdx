## homelab api auth methods

عرض طرق المصادقة المحلية وعبر المتصفح المتاحة.

```bash
homelab api auth methods [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/auth/methods` |
| يغيّر الحالة | لا |
| أداة MCP | لا شيء |
