<Note>مولَّد من إصدار Homelab v0.32.8 (المصدر `4c7d219a5d56`). بالنسبة إلى إصدار مثبَّت، فإن `homelab api <command> --help` هو المرجع.</Note>

يستدعي `homelab api` واجهة Homelab API تماماً كما يصفها [مرجع API](#مرجع-api): أمر واحد لكل عملية عامة، مولَّد من عقد API الخاص بالإصدار. يطبع كل أمر JSON على stdout بعد إزالة غلاف الاستجابة؛ وتذهب الأخطاء إلى stderr ككائن خطأ منظَّم.

## المصادقة

| المتغير | المعنى |
| --- | --- |
| `HOMELAB_API_URL` | عنوان URL الأساسي لـ API. القيمة الافتراضية `https://api.kombify.io/v1/homelab`؛ اضبطه على عنوان مثيل Homelab الخاص بك لاستدعاء ذلك المثيل مباشرة. |
| `HOMELAB_API_TOKEN` | رمز Bearer المميز المُرسل مع كل طلب. بدونه يستخدم CLI الجلسة المخزنة بواسطة `homelab login`، ويفشل برمز الخروج 3 عندما لا توجد جلسة أو تكون قد انتهت صلاحيتها. |

## الخيارات العامة

| الخيار | ينطبق على | الوصف |
| --- | --- | --- |
| `--fields <paths>` | كل أمر | مسارات منقوطة مفصولة بفواصل للإبقاء عليها في الإخراج؛ وتُطبَّق على كل عنصر في المصفوفات. |
| `--ndjson` | كل أمر | طباعة المصفوفات كقيمة JSON مضغوطة واحدة في كل سطر. |
| `--dry-run` | الأوامر المعدِّلة | طباعة الطلب المحلول بصيغة JSON دون تفويضه أو إرساله. |
| `--idempotency-key <key>` | الأوامر المعدِّلة | ترويسة Idempotency-Key؛ والقيمة الافتراضية UUID جديد. |
| `--body <json\|@path\|->` | الأوامر ذات جسم JSON | جسم الطلب الأساسي كقيمة حرفية أو ملف أو stdin؛ وتتجاوز خيارات الوسائط خصائصه. |
| `--file <path\|->` | الأوامر ذات جسم ملف | ملف جسم الطلب المُرسل بنوع المحتوى المُعلَن. |
| `--yes` | الأوامر التي تتطلب تأكيداً | التأكيد دون مطالبة؛ مطلوب عند التشغيل غير التفاعلي. |

الأوامر الموسومة بأنها تتطلب تأكيداً تطلب `yes` في الطرفية. وبدون طرفية ترفض إرسال الطلب ما لم يُضبط `--yes`، وتطبع الخطأ `CONFIRMATION_REQUIRED` وتخرج بالرمز 9.

## رموز الخروج

| الرمز | المعنى |
| --- | --- |
| 0 | نجاح. |
| 1 | أي فشل آخر. |
| 2 | إدخال غير صالح (HTTP 400/422). |
| 3 | غير مصادَق عليه (HTTP 401). |
| 4 | مرفوض أو يتطلب الدفع أو محدود المعدل (HTTP 402/403/429). |
| 5 | غير موجود (HTTP 404). |
| 6 | تعارض (HTTP 409). |
| 7 | فشل في الخادم أو النقل (HTTP 5xx). |
| 9 | التأكيد مطلوب أو مرفوض. |

## سياق الوكيل

يطبع `homelab api agent-context` كتالوج الأوامر هذا لوكلاء الذكاء الاصطناعي بصيغة Markdown، أو بصيغة JSON مع `--json`: كل أمر مع طريقة استخدامه ووسائطه وتأكيده وتوفره واسم أداة MCP الخاصة به، إضافة إلى الخيارات العامة ورموز الخروج أعلاه.
