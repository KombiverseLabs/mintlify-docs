<Note>مولَّد من إصدار Homelab v0.32.8 (المصدر `4c7d219a5d56`). بالنسبة إلى إصدار مثبَّت، فإن `homelab api <command> --help` هو المرجع.</Note>

## homelab api instance enrollment

جلب سجل التسجيل المحلي.

```bash
homelab api instance enrollment [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/enrollment` |
| يغيّر الحالة | لا |
| أداة MCP | `get_enrollment_record` |

## homelab api instance get

جلب هوية المثيل المحلية الثابتة.

```bash
homelab api instance get [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/instance` |
| يغيّر الحالة | لا |
| أداة MCP | `get_instance_identity` |
