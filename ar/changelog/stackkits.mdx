## StackKits moves Coolify workloads between servers and adds an Early Access channel

أصدر StackKits الإصدارات من [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) إلى [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) ، مع نقل أحمال Coolify، وقناة إصدارات اختيارية تُسمّى الآن Early Access، وحزم ذكاء اصطناعي خاصة، والاحتفاظ بالبيانات عند إزالة التطبيق.

### New features

- **Move Coolify workloads to another server.** [StackKits v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) adds `stackkit relocate plan`, `check`, `drain`, `send`, and `receive`. Drain stops your apps before the final send, so the backup is consistent, and `drain --undo` rolls the move back. See [`stackkit relocate` (English)](https://docs.kombify.io/stackkits/reference/cli/relocate).
- **قناة Early Access.** أضاف [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) قناة إصدارات اختيارية. أوقف StackKits هذه القناة منذ ذلك الحين، ويُصدر الآن إصدارات Stable فقط.
- **Preview footprint and capacity before you install.** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) shows the footprint and capacity of your selected use cases on the target with `stackkit use-cases pick --kit`. See [`stackkit use-cases`](/ar/stackkits/reference/cli/use-cases).
- **Private AI bundles by goal.** [v0.53.8](https://github.com/kombifyio/stackKits/releases/tag/v0.53.8) groups Private AI into bundles such as My private Chat and My local AI. It adds the LiteLLM model router for API access and a model manager setup action, and shows memory and GPU fit for each choice. See [Personal AI](/ar/guides/stackkits/use-cases/personal-ai).
- **OpenCloud for Files and an MQTT add-on.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) adds OpenCloud as a Files alternative and an MQTT add-on with authenticated messaging. See [Documents and files](/ar/guides/stackkits/use-cases/documents-and-files).
- **Household access per app.** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) adds per-app household access groups on your node, and completes native owner setup for Navidrome and Audiobookshelf. See [Media](/ar/guides/stackkits/use-cases/media).

### Updates

- **Removing an app keeps its data.** [StackKits v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) retains application volumes on ordinary removal. Deletion is an explicit choice.
- **Clearer install and upgrade guidance.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) resumes interrupted installs and explains unsupported Cloud or Modern upgrades with a supported route before anything changes.
- **Private DNS with AdGuard Home.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) activates private-client DNS through AdGuard Home, and [v0.53.8](https://github.com/kombifyio/stackKits/releases/tag/v0.53.8) backs up its configuration. See [Network](/ar/guides/stackkits/use-cases/network).
- **Smart Home notifications and MQTT.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) connects Home Assistant to kombify notify, [v0.53.6](https://github.com/kombifyio/stackKits/releases/tag/v0.53.6) installs ntfy live notifications, and [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) configures Home Assistant MQTT from your plan. See [Smart Home](/ar/guides/stackkits/use-cases/smart-home).
- **Bring your own AI provider.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) connects Private AI to an external OpenAI-compatible provider with a key from the kombify Wallet, and pulls selected model packs into Ollama during Apply.
- **Coolify and Dokploy are back.** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) restores Coolify and Dokploy as optional application platforms. The default core still uses no PaaS. See [Coolify](/ar/stackkits/apps/coolify).

### Bug fixes

- **Coolify restores recover.** [StackKits v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) recovers interrupted Coolify application restores, and [v0.53.8](https://github.com/kombifyio/stackKits/releases/tag/v0.53.8) restores signed Coolify application data.
- **Restores are checked.** [v0.53.6](https://github.com/kombifyio/stackKits/releases/tag/v0.53.6) reads back restored volume content during live restore. See [Back up and restore](/ar/guides/stackkits/back-up-and-restore).
- **Friendlier install refusals.** [v0.53.6](https://github.com/kombifyio/stackKits/releases/tag/v0.53.6) fixes the non-root install path and explains a low-memory refusal. [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) adds recovery guidance when a stored plan is rejected.
- **Stable capacity on Windows.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) keeps Windows host capacity stable across working drives.

</Update>

## مختبر Private AI وخوادم ألعاب وMCP في كل تثبيت من StackKits

- **خوادم ألعاب.** يضيف [v0.41.0](https://github.com/kombifyio/stackKits/releases/tag/v0.41.0) حالة استخدام Game اختيارية مع Pterodactyl Panel. ينشئ `stackkit setup game` خوادم Minecraft Java وBedrock بإعدادات افتراضية آمنة، ويضيف [v0.43.0](https://github.com/kombifyio/stackKits/releases/tag/v0.43.0) Paper وTerraria وValheim. يتحقق الإعداد من الجاهزية بانضمام عميل حقيقي ويرفض خادمًا لا تتسع له ذاكرة المضيف. راجع [Game](/ar/guides/stackkits/use-cases/game).
- **مزيد من التطبيقات لكل حالة استخدام.** يثبّت [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) Nextcloud وForgejo وEmby وPassbolt بدائلَ للإعدادات الافتراضية. وتُثبّت إضافات بجانب حالة الاستخدام: Paperless-ngx وEuro-Office وNavidrome وAudiobookshelf وESPHome. راجع [فهرس حالات الاستخدام](/ar/stackkits/reference/use-case-catalog).

## مثبّت StackKits يختار الـ Kit بنفسه

StackKits الإصدارات من [v0.25.1](https://github.com/kombifyio/stackKits/releases/tag/v0.25.1) إلى [v0.32.1](https://github.com/kombifyio/stackKits/releases/tag/v0.32.1) : مثبّت يكتشف المضيف ويقترح الـ Kit المناسب، وبوابات تسجيل دخول أمام مسارات الـ homelab، ومستخدمو المنزل عبر PocketID.

## StackKits v0.15.0 – v0.18.1: مثبّت موجَّه، وطرح قابل للتحكم على مستوى الخدمة، ونواة Cloud محايدة للمزوّد

انتقل StackKits من v0.14.28 إلى [v0.18.1](https://github.com/kombifyio/stackKits/releases/tag/v0.18.1) هذا الأسبوع. يأخذ مثبّت موجَّه جديد جهازًا غير مُعَدّ إلى homelab عامل بثلاثة أوضاع. واكتسب Cloud Kit نواة Cloud محايدة للمزوّد وملكية مسارات TLS العامة ونسخًا احتياطيًا خارجيًا اختياريًا. وأصبحت `apply` و`status` و`verify` و`logs` قابلة للقراءة الآلية بالكامل في كل نتيجة، وأمر `stackkit service` جديد يتحكم في الخدمات الفردية بين عمليات apply الكاملة.

### ميزات جديدة

- **نواة Cloud محايدة للمزوّد مع مسارات TLS عامة.** يحلّ [StackKits v0.15.0](https://github.com/kombifyio/stackKits/releases/tag/v0.15.0) حملًا مطلوبًا `cloud-core` لـ `base` و`auth` و`id` و`coolify`، ويُنتج مشروع Compose واحدًا مثبَّتًا بالـ digest، وينفّذه عبر مالك بيئة تشغيل محلي مغلق على مضيف يُقدَّم من الخارج. ويجعل [v0.18.0](https://github.com/kombifyio/stackKits/releases/tag/v0.18.0) Cloud Kit يملك مسارات TLS العامة ويجسّدها من البداية إلى النهاية. ولا يخزّن حفظ بيئة تشغيل Cloud سوى مواد PocketID وTinyAuth وCoolify الخاصة بكل خدمة. أما بيانات اعتماد المزوّد وبيانات اعتماد الخادم وعقود الإيجار (leases) والمخزون فتبقى خارج StackKits. راجع [Cloud Kit](/ar/stackkits/kits/cloud-kit).
- **أمر `stackkit service` للتحكم بعد الطرح.** يضيف [v0.16.0](https://github.com/kombifyio/stackKits/releases/tag/v0.16.0) الأمرين `stackkit service start|stop|restart <service-key>` و`stackkit service logs <service-key>` لخدمات نواة Cloud التي تديرها StackKits. تتطلب التعديلات `--owner-approve`، ويعيد `--json` نتيجة إجراء مُرقَّمة الإصدار. استخدمه لإعادة تشغيل خدمة واحدة أو فحصها بين عمليات apply الكاملة. راجع [عمليات اليوم الثاني](/ar/stackkits/reference/day-2-operations).

```bash
stackkit service restart coolify --owner-approve --json
stackkit service logs auth --tail 100
```

- **مخرجات آلية كاملة في apply وstatus وverify وlogs.** يُبقي [v0.15.8](https://github.com/kombifyio/stackKits/releases/tag/v0.15.8) الأوامر `stackkit apply --json` و`stackkit status --json` و`stackkit verify --json` قابلة للتحليل عند النجاح والرفض والفشل. ويعيد `stackkit logs` صفحات منقَّحة ومحدودة بمؤشرات مرتبطة بالـ digest وبيانات وصفية صريحة عن الاقتطاع. ويعرض موصّل MCP الأدلة المنظَّمة نفسها. راجع [موصّل MCP](/ar/stackkits/reference/mcp-connector) و[تشغيل StackKit](/ar/stackkits/reference/day-2-operations).
- **مستمعو بيئة تشغيل Architecture v2 لتسليم التطبيقات المملوك للمنتج.** يعرض [v0.15.3](https://github.com/kombifyio/stackKits/releases/tag/v0.15.3) مستمعي بيئة التشغيل على إسقاطات فهرس Architecture v2 كي تتمكن التطبيقات من قيادة تسليمها دون نقل سلطة دورة الحياة خارج StackKits. راجع [تسليم التطبيقات](/ar/guides/stackkits/application-delivery).
