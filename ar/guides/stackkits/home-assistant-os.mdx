توفّر kombify طريقتين لتشغيل Home Assistant. وكلتاهما جزء من سيناريو
استخدام المنزل الذكي. يصف
[دليل المنزل الذكي](/ar/guides/stackkits/use-cases/smart-home) الإعداد
والاستخدام اليومي.

<Warning>
كلا المسارين قيد التطوير. تسجيل الدخول الموحد منفّذ، ولم يكتمل بعد إقلاع
فعلي لـ Home Assistant مع تسجيل الدخول عبر المتصفح والتطبيق. تعامل مع
التفاصيل أدناه بوصفها نطاق معاينة.
</Warning>

## الخيار 1: Home Assistant OS كضيف جهاز

يعمل Home Assistant OS في جهاز افتراضي خاص به على عقدة Proxmox VE تملكها
بالفعل. ينشئ Homelab الجهاز الافتراضي، ولا يُثبّت StackKits أبداً داخل
Home Assistant OS. ويمكن لخادم منزلي مختلط أن يضم ضيف Ubuntu للخدمات
الأساسية وضيف Home Assistant OS منفصلاً.

| العنصر | القيمة |
| --- | --- |
| إصدار Home Assistant OS المثبّت | 18.2 (صورة KVM رسمية، محقّقة بمجموع التدقيق) |
| المعمارية | amd64 |
| الحد الأدنى للحجم | نواتا معالج (CPU)، 4 GiB ذاكرة، 32 GiB قرص |
| مساحة تخزين العقدة | نشطة، وتسمح بالصور والاستيرادات وقوالب الحاويات |

يعرض المعالج هذا الضيف عندما تختار Smart Home وتختار Home Assistant OS
وتكون النسخة جديدة. وتحديث الإصدار المثبّت في إصدار جديد لا يغيّر أبداً ضيفاً
موجوداً بالفعل.

اقرأ [تشغيل kombify على Proxmox VE](/ar/guides/stackkits/proxmox) أولاً. فهو
يغطي الاتصال والتفويض وما لم يُتحقق منه بعد.

## الخيار 2: Home Assistant كحاوية

يضم دليل StackKits وحدة اختيارية باسم `home-assistant`. وهي تشغّل Home
Assistant Container دون Supervisor أو تطبيقات، إلى جانب بقية خدمات حزمتك.
يثبّت الدليل Home Assistant 2026.9.4 وامتداد `auth_oidc` بالإصدار 1.2.1
لتسجيل الدخول. ولا يثبّت التطبيق أي امتداد عبر الشبكة.

يعمل هذا المسار على مضيف تديره بنفسك، مع Homelab أو دونه. ويمكن تمرير
مهايئ USB لاسلكي لـ Zigbee أو Z-Wave مباشرة إلى عبء العمل.

## ما يعمل وما لا يزال معلقاً

- منفّذ: تسجيل الدخول عبر Pocket ID، مقيّد بمجموعات owner وadmin
  وhousehold. ويظل تسجيل الدخول المحلي في Home Assistant متاحاً. يرتبط حساب
  المالك بهويته في Pocket ID ولا يُنشأ أي حساب بصمت.
- منفّذ: تبنّي حاوية Home Assistant مدعومة موجودة مسبقاً دون إعادة إنشائها أو
  تغيير حساباتها. وتُسجّل النسخة القائمة أولاً كمرصودة.
- لم يكتمل بعد: إقلاع فعلي لـ Home Assistant مع تسجيل الدخول في المتصفح
  والتطبيق الأصلي، والثقة في هيئة شهادات خاصة، وتأهيل الاستعادة.
- لم يكتمل بعد: تشغيل مباشر كامل لضيف الجهاز على إصدار حالي.

استعادة نسخة احتياطية لا تعيد إقران الأجهزة المادية. تحقق من ارتباطات الأجهزة
قبل استئناف الإجراءات المادية. راجع
[النسخ الاحتياطي والاستعادة](/ar/guides/stackkits/back-up-and-restore).

## الاختيار بينهما

يمنحك Home Assistant OS نظام Home Assistant الكامل بنموذج التحديثات
والتطبيقات الخاص به. أما الحاوية فهي أخف وتشارك المضيف مع بقية خادمك
المنزلي. وهما بديلان؛ يمكنك اختيار أيهما في المعالج أو في ملف StackSpec
الخاص بك.
