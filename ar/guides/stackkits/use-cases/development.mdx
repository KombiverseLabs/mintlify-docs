يجمع Dev نتائج المستودعات ومساحة عمل التطوير وسطح المكتب البعيد تحت حالة استخدام واحدة: تابع مشروعاً من حاسوب آخر دون أن تجمّع بنفسك خادم Git ومساحة عمل ومسار وصول. تبقى المستودعات وسطح المكتب البعيد قابلين للاختيار بشكل مستقل، وتُعدّ مشغّلات CI خياراً منفصلاً لا يأتي مع استخدام Dev العادي.

## المستودعات اليوم

- يعمل Git عبر HTTPS فقط. لا يُكشف SSH، ولا يُثبَّت مشغّل CI.
- يحتاج كل عميل إلى اسم DNS لمضيف Git ويجب أن يثق بشهادة CA الداخلية لذلك المضيف.
- يحتاج الاسترداد إلى وحدتي تخزين Gitea معاً، تُلتقطان أثناء إيقاف الكتابة.

## سطح المكتب البعيد ومساحة العمل، قيد التخطيط

- **سطح المكتب البعيد** يعمل في المتصفح: [Apache Guacamole](https://guacamole.apache.org/) هو المرشح القائم، وتُفتح الجلسة عبر أي متصفح دون تثبيت عميل سطح مكتب. يرتبط بهدف سطح مكتب صريح مدعوم بالفعل؛ ولا يوفّر بنفسه سطح مكتب لنظام تشغيل.
- **مساحة عمل التطوير** (افتح مشروعاً وحرّره واستأنفه مع سلسلة أدواته المعلنة) تحتاج إلى اختيار صريح لبيئة التشغيل ولم تُعتمد بعد.
- يبقى كلاهما قيد التقييم. لا يغيّر أي منهما ما تفعله المستودعات اليوم، ولا يتطلب اختيار أحدهما الآخر: مالك يريد Git فقط لا يحتاج سطح مكتب، ومالك يريد سطح المكتب فقط لا يحتاج خادم Git.

## احصل على الأدوات

- **عملاء Git**: استخدم عميل Git الأصلي لديك أو تكامل IDE مع مسار HTTPS المولّد.
- **tea، واجهة سطر أوامر Gitea**: لعمليات المستودعات والمشكلات وطلبات الدمج المبرمجة من الطرفية، راجع [gitea.com/gitea/tea](https://gitea.com/gitea/tea).
- **Guacamole**: لا عميل لتثبيته بعد إصداره — فهو يعمل بالكامل في متصفحك.

## أعدّه

اتبع صفحة [Gitea](/ar/stackkits/apps/gitea) من مساحة عمل مالك فارغة. ادفع إلى مستودع اختبار من عميل حقيقي قبل أن تعتمد عليه.
