يتضمن إصدار StackKits العام Basement Kit وCloud Kit وتعريف معاينة Modern Homelab. اختر مساراً للمضيفات التي تشغّلها بالفعل. أدلة التشغيل الحي لـ Cloud Kit خاصة بكل إصدار؛ أما Modern فليس له بعد مسار تثبيت كامل مدعوم.

| إذا كنت تشغّل... | اختر | السبب |
| --- | --- | --- |
| عتاداً محلياً على شبكة منزلية أو خاصة | [Basement Kit](/ar/stackkits/kits/basement-kit) | هو الملف المحلي المُصدَر الذي يعتمد الشبكة المحلية أولاً. |
| VPS أو مضيف سحابي قائم مع نطاق تتحكم به | [Cloud Kit](/ar/stackkits/kits/cloud-kit) | هو ملف النطاق العام المُصدَر لذلك المضيف. |
| بيئتي Home وCloud تريد استكشاف الربط بينهما | [Modern Homelab (alpha)](/ar/stackkits/kits/modern-homelab) | يصف التعريف المُصدَر الموقعين معاً؛ ودعم التشغيل الكامل لا يزال قيد الانتظار. |

لأدلة التثبيت الحالية، ابدأ ببيئة واحدة. لا يوفّر StackKits الخوادم ولا يتولى حيازة بيانات اعتماد المزوّد، فاختر kit فقط بعد أن تعرف أي مضيف ونطاق تتحكم بهما.

أول مسار Basement ناجح هو [البدء السريع](/ar/stackkits/quickstart). ولـ VPS تشغّله بالفعل، استخدم [Cloud Kit](/ar/stackkits/kits/cloud-kit). ويمكن أيضاً لـ [موقع StackKits](https://stackkit.cc/getting-started) أن يساعدك في الاختيار.

<span id="install-only-the-toolchain"></span>
## تثبيت أدوات التشغيل فقط

لتثبيت CLI والكتالوج العام الكامل دون أمر Basement المختصر:

```bash
curl -sSL https://install.stackkit.cc | sh
```

ولتثبيت تعريفات kit واحد فقط إلى جانب CLI، مرّر اسمه:

```bash
curl -sSL https://install.stackkit.cc | sh -s -- basement-kit
```

يمكنك تمرير `cloud-kit` أو `modern-homelab` بالطريقة نفسها.

<Note>
  الاسم المتقاعد `base-kit` مرفوض. حدّث السكربتات التي لا تزال تمرّره لتستخدم `basement-kit`.
</Note>

تحلّ مثبّتات shell الإصدار العام الحالي وتدعم Linux وmacOS على `amd64` و`arm64`. ويمكن لمستخدمي Windows تنزيل ملف ZIP الخاص بـ `windows_amd64` من [أحدث إصدار](https://github.com/kombifyio/StackKits/releases/latest).

بعد تثبيت أدوات التشغيل فقط، هيّئ مساحة العمل على [Basement Kit](/ar/stackkits/kits/basement-kit) أو [إعداد StackSpec](/ar/guides/stackkits/configure-stack-spec).
