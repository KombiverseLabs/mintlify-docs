يدعم عميل سطح المكتب SpeechKit نظامي Windows 10 وWindows 11 على أنظمة x64. Windows هو الهدف
الكامل: الأوضاع الثلاثة وHands-Free وMeeting. نزّل الأصول من إصدار `kombifyio/SpeechKit`
الرسمي فقط.

{/* speechkit-release:begin */}
الإصدار العام الحالي هو [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1)، نُشر في 2026-09-20.
{/* speechkit-release:end */}

## التحقق من التنزيل

1. نزّل ملف
   [SHA256SUMS.txt](https://github.com/kombifyio/SpeechKit/releases/latest/download/SHA256SUMS.txt)
   المطابق.
2. احسب تجزئة SHA-256 للمثبّت أو لأرشيف ZIP بأداة تثق بها.
3. قارن التجزئة الكاملة مع المدخل في `SHA256SUMS.txt` قبل فتح الحزمة.
4. اقرأ
   [إشعار الإصدار غير الموقّع](https://github.com/kombifyio/SpeechKit/releases/latest/download/UNSIGNED-WINDOWS-RELEASE.txt).

<Warning>
إصدار Windows المجاني غير موقّع. قد يعرض Windows تحذير سمعة. تحقق من المجموع الاختباري
ومصدر الإصدار قبل أن تقرر المتابعة.
</Warning>

## الاستخدام الأول

1. شغّل SpeechKit واختر الميكروفون الذي تريد أن يستخدمه.
2. اختر Network Scope. يسمح All networks بالمزودين الخارجيين؛ ويقيّد local network only
   وthis device only ما يجوز للواجهة الخلفية الاتصال به.
3. اختر مزوداً محلياً أو خارجياً مناسباً للوضع.
4. اختبر Dictation قبل تفعيل Assist أو Voice Agent أو Meeting.
5. راجع ما يغادر الجهاز عند اختيار مزود خارجي.

مفاتيح الاختصار الافتراضية هي `Ctrl+Win` لـ Dictation، و`Win+Alt` لـ Assist، و`Ctrl+Shift` لـ
Voice Agent. داخل الاجتماع، يلتقط `Ctrl+Alt+S` لقطة للشاشة.
