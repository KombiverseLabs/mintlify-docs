SpeechKit هو إطار عمل ووقت تشغيل الصوت من kombify الذي يعمل محلياً أولاً. يقدّم مشروع عام واحد
نواة الصوت بلغة Go، وخادماً مستضافاً ذاتياً، وأدوات للوكلاء، ووحدات Android، وعملاء سطح
مكتب لنظامي Windows وmacOS.

{/* speechkit-release:begin */}
الإصدار العام الحالي هو [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1)، نُشر في 2026-09-20.
{/* speechkit-release:end */}

SpeechKit برنامج تجريبي (Beta): قد تتغير واجهات API العامة ومفاتيح التهيئة والقيم الافتراضية
بين الإصدارات الفرعية، لذا ثبّت النسخة التي اختبرتها.

## ثلاثة أوضاع وخدمة تسجيل واحدة

| السطح | الغرض |
| --- | --- |
| Dictation | تحويل الكلام إلى نص دون إعادة صياغة بنموذج لغوي. |
| Assist | تحويل الكلام أو النص إلى نتيجة واحدة محدودة، يمكن نطقها اختيارياً. |
| Voice Agent | إجراء محادثة صوتية في الوقت الفعلي للعمل التفاعلي. |
| Meeting | تسجيل مكالمة على قناتين وكتابة ملخص لها بعد ذلك. |

Hands-Free طبقة تفعيل وإخراج فوق الأوضاع الثلاثة، وليس وضعاً رابعاً. أما Meeting فخدمة تسجيل
منفصلة لا تشارك Dictation إلا في محوّل الكلام إلى نص.

## أين يعمل SpeechKit

| الهدف | التوفر |
| --- | --- |
| عميل سطح المكتب لـ Windows 10/11 x64 | Beta عامة؛ الأوضاع الثلاثة وHands-Free وMeeting |
| macOS 14+ على Apple Silicon | Beta للإملاء فقط، موقّعة ad-hoc، مع ثغرات معروفة |
| إطار Go | وحدة عامة؛ ضمّن النواة في مضيف Go الخاص بك |
| الخادم المستضاف ذاتياً | هدف Linux يُبنى من المصدر العام |
| Android | وحدات Gradle بترخيص Apache-2.0 مع تطبيق مرجعي داخل المستودع |
| المتصفح | عميل TypeScript وحزم واجهة الصوت في المستودع العام |
| سطح مكتب Linux | غير متاح؛ Linux وقت تشغيل للخادم |

## حدود الخصوصية التي تحددها

يحدد إعدادان مستقلان ما يُسمح لـ SpeechKit بفعله:

- **Network Scope** يجيب عن المكان الذي يجوز للعملية الوصول إليه: كل الشبكات، أو الشبكة
  المحلية فقط، أو هذا الجهاز فقط. تفرض الواجهة الخلفية هذا الحد على مزودي الكلام وتنزيلات
  النماذج والتحديثات والقياس عن بُعد واتصالات الخادم والتكاملات. ويعلّق النطاق الأشد
  الإعدادات غير المتوافقة بدلاً من حذفها.
- **Retention Scope** يجيب عمّا يبقى بعد العمل الذي أنتجه: الاحتفاظ، أو عدم الاحتفاظ. يمسح
  عدم الاحتفاظ المواد الخام عند انتهاء الجلسة ويُبقي النتيجة المولَّدة فقط.

الإعدادان متعامدان. يظل التثبيت المقتصر على الجهاز يكتب النصوص المفرغة على القرص ما لم
تختر أيضاً عدم الاحتفاظ.
