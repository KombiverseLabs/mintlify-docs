Voice Agent محادثة منطوقة حية. يمكنك طرح أسئلة متابعة والمقاطعة. ولا يكتب في
تطبيقاتك. استخدم Dictation أو Assist لذلك. Voice Agent ميزة في Windows. على macOS لم
يجرِ التحقق منه في النسخة التجريبية الحالية.

## قبل أن تبدأ

- SpeechKit مثبّت ويعمل Dictation.
- Voice Agent معطّل في التثبيت الجديد. تفعّله أدناه.
- يحتاج Voice Agent إلى مزوّد للمحادثة الحية، محلي أو سحابي. اختره مع مراعاة
  [إعدادات الخصوصية](/ar/speechkit/privacy-settings). يستقبل المزوّد السحابي صوتك.

## الخطوات

<Steps>
  <Step title="فعّل Voice Agent">
    في **Settings > Overview**، شغّل Voice Agent في قائمة **Modes**. يمكنك أيضًا فتح
    **Voice Agent Mode** وتفعيل اختصاره هناك.
  </Step>
  <Step title="تحقق مما يحتاج إلى انتباه">
    تسرد **Overview** مفاتيح المزوّد المفقودة تحت **Needs attention**. أضف المفتاح أو
    اختر مزوّدًا آخر.
  </Step>
  <Step title="ابدأ محادثة">
    الاختصار الافتراضي هو `Ctrl+Shift`. اضغط عليه باستمرار، وتحدث، ثم اتركه. يمكنك
    أيضًا بدء الوكيل وإيقافه بالزرين **Start voice agent** و**Stop voice agent** في
    نافذة Voice Agent.
  </Step>
  <Step title="اطرح سؤال متابعة">
    تعرض النافذة المحادثة. بعد أن يجيب الوكيل، اطرح سؤال متابعة. مثلًا: "help me
    decide the next release slice". ثم قاطعه بسؤال متابعة.
  </Step>
  <Step title="أنهِ الجلسة">
    أنهِ الجلسة للحصول على ملخص. بعد أن تترك الاختصار يبقى الحوار قابلًا للاستئناف
    لوقت قصير (**Resume window**). يحدث الملخص وإغلاق اللوحة عندما تنتهي تلك النافذة.
  </Step>
</Steps>

## إعدادات يمكنك تغييرها

افتح **Settings > Voice Agent Mode**.

| الإعداد | ما يفعله |
| --- | --- |
| Voice Agent hotkey | التركيبة التي تبدأ المحادثة. |
| Agent profile | يختار ملف الوكيل. |
| Personal refinement prompt | يضيف تفضيلاتك الخاصة، مثل إجابات قصيرة. |
| Resume window (seconds) | المدة التي يبقى فيها الحوار قابلًا للاستئناف. القيمة 0 تنهي الجلسة فورًا. |
| Pause tolerance (ms) | الوقفات القصيرة حتى هذا الطول لا تُطلق إجابة. القيمة 0 تستخدم الافتراضي للمزوّد. |
| Session summary | يحتفظ بملخص للجلسة. |
| Closing the window | اختر **Minimise and keep chat** أو **End chat on close**. |

تظهر المحادثات السابقة في **Library** تحت تبويب الصوت.

## ابدأ بصوتك

يمكن لـ **Hands-Free** بدء وضع بعبارة تنبيه بدلًا من اختصار. فعّله تحت
**Settings > Hands-Free** عبر **Enable hands-free activation**، ثم اختر العبارة
والهدف (**Voice Agent conversation** أو **Assist voice companion** أو **Dictation
(UI-assisted)**). يبقى صوت الميكروفون للكشف عن عبارة التنبيه على الجهاز. Hands-Free
غير متاح على macOS.

## إذا حدث خطأ

- **لا يبدأ الوكيل.** تحقق من أن Voice Agent مفعّل وأن لمزوّده مفتاحًا. انظر **Needs
  attention** في **Overview**.
- **يجيب مبكرًا جدًا.** ارفع **Pause tolerance (ms)**.
- **لا تسمعه.** استخدم عنصر التحكم في إخراج السماعة في نافذة Voice Agent لاختيار
  سماعة أخرى.
- **ما زلت عالقًا.** راجع [أصلح المشكلات الشائعة](/ar/speechkit/fix-common-problems).
