هذه الصفحة مولَّدة من [إصدار v0.50.3](https://github.com/kombifyio/StackKits/releases/tag/v0.50.3) المنشور. وهي تسرد كل حالة استخدام يعلنها ذلك الإصدار، مجمّعة بحسب حالة الاستخدام الرئيسية، مع غرضها ومكوّناتها والتطبيق الافتراضي. المكوّن المعلن ليس دليلًا على تثبيت ولا على تشغيل جرى التحقق منه على مضيف؛ ففي [توافق أنظمة التشغيل](/ar/stackkits/reference/os-compatibility) تقييمات دورة الحياة التي جرى التحقق منها. وفي [حالات الاستخدام](/ar/guides/stackkits/use-cases/overview) نظرة عامة على أدلة الإعداد.

## Mail

### البريد الخاص

بريد ويب خاص عبر Roundcube لصندوق بريد تملكه بالفعل لدى مزوّد خارجي. لا يُنشأ خادم بريد ولا DNS ولا سجل MX.

الدليل: [افتح الدليل](/ar/guides/stackkits/use-cases/mail)

| المكوّن | الدور | النوع | الافتراضي |
| --- | --- | --- | --- |
| kombify Paperwork (`paperwork`) | alternative | connector |  |
| Roundcube Webmail (`roundcube`) | primary | application | ✓ |

### خادم البريد الخاص بك

خادم البريد الخاص بك على عقدة Cloud مخصصة عبر Stalwart: صناديق بريد لنطاقك مع SMTP وIMAP وsubmission. يطبع StackKits سجلات DNS التي تنشرها؛ ولا يغيّر DNS أبدًا.

الدليل: [افتح الدليل](/ar/guides/stackkits/use-cases/mail)

| المكوّن | الدور | النوع | الافتراضي |
| --- | --- | --- | --- |
| mailcow (`mailcow`) | alternative | application |  |
| Stalwart Mail Server (`stalwart`) | primary | application | ✓ |
