أدوات مساعدة أصلية للوكلاء لأتمتة StackKits.

تُصدر الأدوات المساعدة الأصلية للوكلاء خطط التثبيت وفحوصات الجاهزية والتعليمات (prompts) وإعدادات MCP دون تعديل أي عملية نشر.

```bash
stackkit agent [flags]
```

الأوامر الفرعية: [`stackkit agent install-plan`](#stackkit-agent-install-plan)، [`stackkit agent mcp-config`](#stackkit-agent-mcp-config)، [`stackkit agent prompt`](#stackkit-agent-prompt)، [`stackkit agent self-check`](#stackkit-agent-self-check)

## stackkit agent install-plan

طباعة خطة تثبيت StackKits غير تفاعلية.

```bash
stackkit agent install-plan [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--dir` | string | `my-homelab` | مجلد مساحة العمل |
| `--json` | bool | — | إصدار JSON |
| `--kit` | string | `basement-kit` | StackKit المراد التخطيط له |
| `--target` | string | `local` | نوع الهدف: local أو ssh أو vm أو ci |

**أمثلة**

```bash
# Print the install steps for a Basement Kit workspace named my-homelab
stackkit agent install-plan

# A Cloud Kit plan for an agent working over SSH, as JSON
stackkit agent install-plan --kit cloud-kit --target ssh --dir my-cloud --json
```

## stackkit agent mcp-config

طباعة إعداد اتصال واحد لعميل StackKits MCP.

طباعة إعداد عميل MCP جاهز للصق باسم "stackkit".

بالنسبة للمستخدمين هذا اتصال StackKits MCP واحد. محلياً يشغّل محوّل stackkit-mcp؛ وبعد التثبيت يمكن الوصول إلى الموصّل نفسه أيضاً عبر stackkit-server /mcp عند تفعيل نقطة نهاية محمية صراحةً.

```bash
stackkit agent mcp-config [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--client` | string | `generic` | صيغة العميل: generic أو codex أو claude |
| `--mode` | string | `docs,local,server,actions` | أوضاع MCP؛ يضيف actions أدوات دورة الحياة للقراءة فقط، وتظل أدوات الكتابة تتطلب STACKKIT_MCP_ALLOW_WRITE=true |
| `--server-url` | string | `http://localhost:8082` | عنوان stackkit-server |

**أمثلة**

```bash
# Print the connection as Claude mcpServers JSON
stackkit agent mcp-config --client claude

# Print the Codex config.toml block
stackkit agent mcp-config --client codex
```

## stackkit agent prompt

طباعة تعليمات (prompt) وكيل StackKits جاهزة للنسخ.

```bash
stackkit agent prompt [scenario] [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--json` | bool | — | إصدار JSON |
| `--list` | bool | — | عرض سيناريوهات التعليمات المتاحة |

**أمثلة**

```bash
# List the available prompt scenarios
stackkit agent prompt --list

# Print the prompt for diagnosing a failed rollout
stackkit agent prompt diagnose-failed-rollout
```

## stackkit agent self-check

فحص المتطلبات المسبقة المحلية لـ StackKits الموجَّهة للوكلاء.

```bash
stackkit agent self-check [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--json` | bool | — | إصدار JSON |
| `--server-url` | string | `http://localhost:8082` | عنوان stackkit-server |

**أمثلة**

```bash
# Check that stackkit, stackkit-server, and stackkit-mcp are on PATH
stackkit agent self-check

# The same checks as JSON
stackkit agent self-check --json
```
