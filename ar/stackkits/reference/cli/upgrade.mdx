حدّد إصدار StackKit موثَّقًا وثبّته.

حدّد إصدار StackKit عامًا من GitHub، وتحقق من أرشيفه وSPDX SBOM وشهادة GitHub OIDC/Sigstore والجذر الموثوق المخزَّن مؤقتًا، ثم ثبّته بصورة ذرّية تحت .stackkit/releases/.

مع `--dry-run` ينشئ الهدف الموثَّق داخل مساحة عمل ظلّية محدودة فقط ويبلغ عن فرق قانوني بين الخطة والمخرجات. وبدون `--dry-run` يفحص هذا الهدف أولًا، وينشئ لقطة Kopia أصلية إضافةً إلى نقطة استرداد لحالة المنفِّذ موقَّعة من المالك، ويجهّز بيانات التراجع ويتحقق منها دون تفعيلها، ثم يثبّت ويشغّل بعد ذلك فقط معاملة generate/apply/verify للهدف نفسه بالضبط. يمكن لمعاملة هدف فاشلة أن تستعيد المنفِّذ السابق وتتحقق منه قبل قبول Apply للهدف فقط. بعد Apply يبقى إعادة تشغيل وقت التشغيل السابق محظورة حتى يوجد تفعيل موثَّق لبيانات الإصدار السابق؛ ولا يكفي تجهيز Kopia المعزول وحده للسماح بذلك. يحتفظ التزام الهدف المكتمل بإثبات نجاحه لإنهاء صريح. تتطلب الترقيات الجديدة دعمًا في سياسة Kit CUE المضمَّنة؛ أما استرداد عملية قائمة فيتبع سجلها الموقَّع ونقطة استردادها.

```bash
stackkit upgrade [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--dry-run` | bool | — | تحقق من توليد الهدف وافحصه داخل مساحة عمل ظلّية محدودة دون تطبيقه. |
| `--json` | bool | — | أخرج JSON بصيغة stackkit.command-result/v1. |
| `--recover` | string | — | استرد صراحةً معرّف عملية دورة حياة واحدة دقيقة انقطعت. |
| `--to` | string | `latest` | الهدف: latest أو vX.Y.Z أو channel:stable\|beta\|edge. |

**أمثلة**

```bash
# Verify the newest stable release and preview its plan and artifact diff without applying it
stackkit upgrade --dry-run

# Upgrade to the newest stable release
stackkit upgrade

# Upgrade to the newest beta prerelease
stackkit upgrade --to channel:beta

# Recover an interrupted upgrade by its lifecycle operation ID
stackkit upgrade --recover <operation-id>
```
