إدارة حيازة الأسرار المحلية المرتبطة بالمالك.

```bash
stackkit secrets [flags]
```

الأوامر الفرعية: [`stackkit secrets materialize`](#stackkit-secrets-materialize), [`stackkit secrets reveal`](#stackkit-secrets-reveal)

## stackkit secrets materialize

أنشئ الحيازة لمراجع الأسرار في StackSpec الحالية.

أنشئ الحيازة المحلية المرتبطة بالمالك لكل مرجع secret:// في StackSpec القانونية الحالية أو أعد استخدامها.

شغّل هذه الخطوة الصريحة والتي يمكن تكرارها بأمان بعد إضافة حمل عمل إلى مساحة عمل مستقلة قائمة وقبل generate/apply. فهي لا تطبع مراجع الأسرار أو موادها أبدًا، ولا تستبدل حيازة غير صالحة أو أجنبية أبدًا.

```bash
stackkit secrets materialize [flags]
```

**أمثلة**

```bash
# After adding a workload to stack-spec.yaml, create its secrets, then roll out
stackkit secrets materialize
stackkit generate
stackkit apply
```

## stackkit secrets reveal

اطبع سرًّا واحدًا لحمل عمل محدد من حيازة المالك المحلية.

اطبع القيمة الحالية لخانة سر واحدة يعلنها حمل عمل محدد في StackSpec الحالية الصالحة في CUE. يحتوي الإخراج على مادة سرية؛ فاستخدمه فقط في طرفية خاصة أو في أنبوب مقصود. لا تُكتب أي قيمة في سجلات النشر أو الإيصالات.

```bash
stackkit secrets reveal [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--slot` | string | — | **مطلوب.** خانة سر حمل العمل المعلنة |
| `--workload` | string | — | **مطلوب.** معرّف حمل العمل المحدد |

**أمثلة**

```bash
# Print the Photos database password from local owner custody
stackkit secrets reveal --workload photos --slot database-password
```
