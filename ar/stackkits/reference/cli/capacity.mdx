قيّم طلب الوحدات المحددة مقابل سعة المضيف المرصودة.

حلّ التحديد المرتبط بـ CUE الحالي واطبع تقييم السعة الاستشاري الخاص به بصيغة JSON. تبقى القياسات المفقودة غير موثّقة (unverified). لا تتغير أي ملفات أو حالة وقت التشغيل؛ ولا يحل هذا محل قبول Apply.

```bash
stackkit capacity [spec-file] [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--inventory` | string | — | Inventory المرصود؛ تبقى السعة المفقودة غير موثّقة (unverified) |
| `--module-root` | string | — | جذر سلطة Architecture |
