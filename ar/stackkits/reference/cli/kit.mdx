عمليات إصدارات StackKit المنشورة.

اكتشف حِزم إصدارات StackKit المنشورة وتحقق منها وثبّتها.

```bash
stackkit kit [flags]
```

الأوامر الفرعية: [`stackkit kit list`](#stackkit-kit-list), [`stackkit kit prepare-source-generation`](#stackkit-kit-prepare-source-generation)

## stackkit kit list

اعرض إصدارات StackKits المنشورة من GitHub.

حدّد أحدث إصدار منشور لكل StackKit عام على نظام التشغيل والمعمارية الحاليين. يُجلب فهرس الإصدارات من مستودع GitHub Releases العام kombifyio/stackKits.

```text
Channels:
  stable  newest release that is not a prerelease
  beta    newest -beta.* prerelease
  edge    newest -edge.* prerelease
```

```bash
stackkit kit list [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--channel` | string | `stable` | قناة الإصدار: stable أو beta أو edge. |
| `--json` | bool | — | أخرج JSON بصيغة stackkit.command-result/v1. |

**أمثلة**

```bash
# Show the newest stable release of every public StackKit for this OS and architecture
stackkit kit list

# Show beta prereleases as JSON
stackkit kit list --channel beta --json
```

## stackkit kit prepare-source-generation

خزّن الإصدار المشهود الذي أنشأ التوليد المحتفَظ به في الذاكرة المؤقتة وتحقّق منه.

```bash
stackkit kit prepare-source-generation [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--json` | bool | — | أخرج دليل فحص محدودًا لتوليد المصدر بعد تجهيز الذاكرة المؤقتة المصادَق عليه. |
