أعدّ خدماتك الخاصة واعتنِ بها باستخدام StackKits المحمولة. تسرد هذه الصفحات كل أمر `stackkit` مع خياراته وأمثلته. وهي مولَّدة من تعريفات أوامر StackKits؛ وإذا كان إصدارك المثبَّت أقدم، فإن `stackkit <command> --help` هو المرجع له.

## تثبيت CLI

```bash
curl -sSL https://install.stackkit.cc | STACKKIT_CLI_ONLY=1 sh
```

مع `STACKKIT_CLI_ONLY=1` يضع المثبّت `stackkit` و`stackkit-server` و`stackkit-mcp` وOpenTofu المُحزَّم وكتالوج الـ Kit العام في `~/.stackkits` دون تثبيت StackKit. وبدونه يكتشف المثبّت المضيف ويتابع إلى Basement Kit أو Cloud Kit.

## الخيارات العامة

تعمل هذه الخيارات مع كل أمر.

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--chdir, -C` | string | `.` | انتقل إلى الدليل قبل التشغيل |
| `--correlation-id` | string | — | معرّف ارتباط للمستدعي جرى التحقق منه ويُسجَّل في أدلة الطرح المحلية |
| `--no-log` | bool | — | عطّل تسجيل النشر المنظَّم |
| `--progress-jsonl` | string | — | اكتب تقدّم الطرح القابل للقراءة الآلية والمحجوب البيانات الحساسة بصيغة JSONL إلى مسار، أو '-' إلى stdout |
| `--quiet, -q` | bool | — | أخفِ الإخراج غير الأساسي |
| `--spec, -s` | string | `stack-spec.yaml` | مسار ملف مواصفة stack (يُقبل kombination.yaml عندما يغيب الملف الافتراضي) |
| `--verbose, -v` | bool | — | فعّل الإخراج المفصّل |
