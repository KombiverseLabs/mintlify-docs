تجهيز ذاكرة تخزين مؤقت لصورة ذهبية محايدة للمالك وقبولها.

تجهيز ذاكرات تخزين مؤقتة ثابتة لحاويات النواة من فهرس CUE المضمّن. لا يؤدي هذا مطلقًا إلى تهيئة Owner أو بدء الخدمات أو إنشاء وحدات تخزين أو تجهيز VM لدى مزوّد. Ubuntu 26.04 هو الهدف الافتراضي؛ ويظل Ubuntu 24.04 متوافقًا. البيان هو بيانات وصفية غير موقّعة لذاكرة التخزين المؤقت، وليس مطلقًا إثبات امتثال المضيف أو صلاحية Apply. يجري التحقق من مجموعة تبعيات مزوّد OpenTofu القائمة والمضمّنة في الحزمة وإعادة استخدامها. يظل الوصول إلى الشبكة ضروريًا لعمليات تكامل الخدمات عند الإقلاع الأول ولأحمال العمل الاختيارية. يتولى Techstack مسؤولية sysprep للأجهزة وصور VM والتسجيل.

```bash
stackkit image [flags]
```

الأوامر الفرعية: [`stackkit image plan`](#stackkit-image-plan)، [`stackkit image prepare`](#stackkit-image-prepare)، [`stackkit image verify`](#stackkit-image-verify)

## stackkit image plan

طباعة ملف تعريف ذاكرة التخزين المؤقت المحايد والمرجعي للنواة.

```bash
stackkit image plan [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--profile` | string | `cloud-core-compose` | ملف تعريف CUE محايد (cloud-core-compose، basement-core-compose، basement-core-lite-compose) |

## stackkit image prepare

تخزين الإصدار الدقيق الجاري تشغيله والمُصدَّق عليه مؤقتًا وسحب صور النواة فقط.

```bash
stackkit image prepare [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--cache-root` | string | — | **مطلوب.** دليل منفصل ومحايد للبيانات الوصفية للإصدار/ذاكرة التخزين المؤقت |
| `--profile` | string | `cloud-core-compose` | ملف تعريف CUE محايد لذاكرة تخزين النواة المؤقتة |
| `--target` | string | — | **مطلوب.** دليل فارغ لنشر مستقبلي؛ وليس stack تمت تهيئته مطلقًا |

## stackkit image verify

إعادة رصد بايتات الإصدار والهدف الفارغ والمضيف وذاكرة التخزين المؤقت الدقيقة لصور النواة.

```bash
stackkit image verify [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--cache-root` | string | — | **مطلوب.** دليل منفصل ومحايد للبيانات الوصفية للإصدار/ذاكرة التخزين المؤقت |
| `--target` | string | — | **مطلوب.** دليل فارغ لنشر مستقبلي؛ وليس stack تمت تهيئته مطلقًا |
