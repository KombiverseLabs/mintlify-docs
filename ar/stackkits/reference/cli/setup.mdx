إعداد حساب المالك لتطبيق جرى تطبيقه.

شغّل إجراء إعداد تعلنه Plan على التطبيق المحلي الموجود. اقرأ حقول JSON الخاصة ببيانات الاعتماد الخاصة ومسار الملف من دليل الإعداد للتطبيق المحدد أو من إجراء الحالة. لا تُكتب بيانات الاعتماد أبدًا في أدلة دورة الحياة. وإعادة التشغيل بعد انقطاع تعيد رصد التطبيق قبل إكمال عملية الإعداد المعلّقة نفسها.

```bash
stackkit setup <workload> [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--complete-onboarding` | bool | — | أكمل تهيئة مستخدم التطبيق والمسؤول بعد التحقق من تسجيل دخول المالك |
| `--credentials-file` | string | — | ملف JSON خاص ببيانات اعتماد المالك نسبةً إلى مساحة العمل (الافتراضي دليل الإعداد للتطبيق المحدد) |
| `--json` | bool | — | أخرج نتيجة الإعداد الموثَّقة الخالية من الأسرار |
| `--operation-id` | string | — | استأنف عملية إعداد معلّقة؛ والافتراضي هو الإعداد المعلّق الحالي أو معرّف جديد |
| `--owner-approve` | bool | — | وافق على إعداد التطبيق المرتبط بـ Plan هذا |

**أمثلة**

```bash
# Create the Photos owner from the private credentials in .stackkit/setup/owner.json
stackkit setup photos --owner-approve

# Also finish the application's onboarding after the owner login is verified
stackkit setup photos --owner-approve --complete-onboarding

# Create the Files owner from a workspace-relative credentials file of your choice
stackkit setup files --owner-approve --credentials-file private/files-owner.json
```
