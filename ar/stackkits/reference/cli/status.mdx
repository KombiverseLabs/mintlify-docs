عرض حالة النشر.

عرض الحالة الحالية لنشر StackKit.

```text
Shows:
  • Deployment state (running, degraded, error)
  • Service statuses and health
  • Resource usage
  • URLs and endpoints
```

```bash
stackkit status [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--http` | bool | — | فحص مسارات الخدمات المتحقق منها من مضيف التحقق هذا |
| `--inventory` | string | — | Architecture v2 observed Inventory المستخدمة لتحديد وقت تشغيل عملية Standard مهيّأة |
| `--json` | bool | — | الإخراج بصيغة JSON |
| `--resolved-plan` | string | — | Architecture v2 ResolvedPlan القياسية (الافتراضي: deploy/.stackkit/resolved-plan.json) |

**أمثلة**

```bash
# Show status
stackkit status

# Output as JSON
stackkit status --json
```
