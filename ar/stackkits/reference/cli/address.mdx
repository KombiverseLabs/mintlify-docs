تخطيط عناوين الخدمات العامة وربطها دون أسرار.

```bash
stackkit address [flags]
```

Subcommands: [`stackkit address bind`](#stackkit-address-bind), [`stackkit address plan`](#stackkit-address-plan), [`stackkit address session-zone`](#stackkit-address-session-zone)

## stackkit address bind

ربط بادئة مخصصة أو منطقة تثبيت بمسارات عامة قياسية.

```bash
stackkit address bind [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--expected-spec-hash` | string | — | لـ native v2 فقط: تجزئة المواصفة الحالية المطابقة تماماً بعد التطبيع عبر CUE، وهي مطلوبة للاستبدال |
| `--output, -o` | string | — | كتابة StackSpec المربوطة والمتحقق منها في هذا المسار |
| `--prefix` | string | — | بادئة نطاق فرعي مخصصة وآمنة لـ DNS: تصبح المضيفات &lt;prefix&gt;-&lt;service&gt;.&lt;domain&gt; |
| `--zone` | string | — | تسمية منطقة تثبيت مخصصة: تُقدَّم الحزمة من &lt;zone&gt;.&lt;domain&gt; وتصبح المضيفات &lt;service&gt;.&lt;zone&gt;.&lt;domain&gt; |

## stackkit address plan

إصدار خطة تسجيل العناوين التي لا تتطلب حساباً.

```bash
stackkit address plan [flags]
```

## stackkit address session-zone

Resume an installed Cloud session pair in an allocated private zone, preserving PocketID.

```bash
stackkit address session-zone [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--abort` | bool | — | Restore only the signed original session routes and callback after an interrupted transition |
| `--check` | bool | — | Inspect existing custody, component pin and source/runtime closure without writing transition state or changing the callback |
| `--migrate-tinyauth` | bool | — | Migrate the qualified legacy TinyAuth component to the CUE-pinned image with a verified cold original-data snapshot; no whole-kit upgrade |
| `--zone` | string | — | Already allocated private kombify.me zone for Auth and Hub; the existing PocketID origin is retained |
