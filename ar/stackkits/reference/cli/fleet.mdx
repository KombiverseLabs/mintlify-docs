قبول المضيفين الأعضاء في StackInstance واحدة وضمّهم إليها.

ربط مضيف فعلي بعقدة عضو قائمة في StackInstance هذه.

يوقّع مالك Home على Foundation Node قبول عضو لعقدة واحدة مفعّلة وغير متحكمة في Cloud Site. يتحقق المضيف العضو منه باستخدام مفتاح Home المثبّت، ويعيد تجميع الخطة نفسها من StackSpec وInventory المقبولين، ويحتفظ بحيازة عضو للتحقق فقط: لا تسجيل ولا توقيع ولا إصدار لبيانات الاعتماد ولا ControlAuthority. يجب أن يشغّل المضيفان إصدار StackKits نفسه.

ينشئ Join أيضًا مفتاح دليل للعضو ويكتب ملف طلب واحدًا. يصدّقه مالك Home باستخدام certify-member-key؛ وبعد import-member-key يطبّق العضو ويتحقق من صف Site/node/channel الخاص به وحده، ويوقّع ذلك الدليل بالمفتاح المصدّق.

```bash
stackkit fleet [flags]
```

الأوامر الفرعية: [`stackkit fleet admit-member`](#stackkit-fleet-admit-member)، [`stackkit fleet certify-member-key`](#stackkit-fleet-certify-member-key)، [`stackkit fleet import-member-key`](#stackkit-fleet-import-member-key)، [`stackkit fleet join`](#stackkit-fleet-join)

## stackkit fleet admit-member

توقيع قبول عضو من المالك لعقدة طرفية واحدة في Cloud.

```bash
stackkit fleet admit-member [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--inventory` | string | — | Inventory تعلن قناتي التنفيذ كلتيهما (وإلا يُختار ملف Inventory تقليدي واحد) |
| `--node` | string | — | معرّف عقدة العضو من StackSpec (عقدة worker أو edge مفعّلة في Cloud Site) |
| `--output` | string | — | ناتج قبول محصور في مساحة العمل (الافتراضي .stackkit/fleet/member-admissions/&lt;node&gt;.json) |
| `--valid-for` | duration | `24h0m0s` | نافذة Join للقبول (24 ساعة كحد أقصى) |

**أمثلة**

```bash
# On the Foundation Node, admit the Cloud edge declared in the plan
stackkit fleet admit-member --node cloud-edge
```

## stackkit fleet certify-member-key

تصديق مفتاح دليل عضو منضم من المالك لصفّه الخاص.

تصديق مفتاح دليل العضو الذي أنشأه عضو منضم عند Join.

تتيح الشهادة للعضو توقيع أدلة Apply وVerify لصف Site/node/execution-channel الخاص به فقط، ولا شيء غير ذلك: لا تسجيل ولا توقيع هوية ولا إصدار لبيانات الاعتماد ولا ControlAuthority ولا صلاحية Owner. تسجّل Foundation Node كل شهادة تصدرها، ومنذ ذلك الحين تترك أهداف وقت التشغيل المحلية لذلك العضو تحت إدارته.

```bash
stackkit fleet certify-member-key <request-file> [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--inventory` | string | — | Inventory تعلن قناتي التنفيذ كلتيهما (وإلا يُختار ملف Inventory تقليدي واحد) |
| `--output` | string | — | ناتج شهادة إضافي محصور في مساحة العمل لنقله إلى العضو |
| `--valid-for` | duration | `720h0m0s` | صلاحية الشهادة (2160 ساعة كحد أقصى) |

**أمثلة**

```bash
# On the Foundation Node, with the request file the member relayed
stackkit fleet certify-member-key member-evidence-key-request.json --output member-evidence-key.json
```

## stackkit fleet import-member-key

استيراد شهادة مالك Home لمفتاح دليل هذا العضو.

```bash
stackkit fleet import-member-key <certificate-file> [flags]
```

**أمثلة**

```bash
# On the Cloud host, with the certificate the Foundation Node returned
stackkit fleet import-member-key member-evidence-key.json
```

## stackkit fleet join

ضم هذا المضيف بوصفه العضو المخصّص للتحقق فقط والمسمّى في القبول.

```bash
stackkit fleet join <admission-file> [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--home-key-id` | string | — | معرّف مفتاح مالك Home من admit-member، وتُجرى مقارنته خارج النطاق |

**أمثلة**

```bash
# On the Cloud host, in an empty deployment directory
stackkit fleet join member-admission.json --home-key-id <homeKeyId>
```
