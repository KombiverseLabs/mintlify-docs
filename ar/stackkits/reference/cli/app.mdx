فحص تسليم تطبيقات StackKits وإدارة عمليات التسليم v0.6.

فحص مصفوفة تسليم التطبيقات الخاضعة للحوكمة في Architecture v2 لكل من Coolify وKomodo وCompose المستقل.

تبقى بيانات تسليم PaaS الاختيارية للعملاء متاحة فقط على خط التوافق الصريح لـ StackSpec v0.6. لا تتضمن Architecture v2 أي ربط لأحمال عمل العملاء العشوائية؛ فالتطبيقات التي تملكها StackKit تأتي من كتالوج CUE، أما الحالة المطلوبة لأحمال عمل العملاء فتعود إلى Techstack.

```bash
stackkit app [flags]
```

الأوامر الفرعية: [`stackkit app compatibility`](#stackkit-app-compatibility)

## stackkit app compatibility

عرض مصفوفة دعم التطبيقات والمحوّلات الخاضعة للحوكمة.

عرض صفوف الدعم الثابتة التي تملكها CUE لتطبيقات StackKits. يعبّر ذلك عن قدرة المنتج، لا عن الخطة المختارة ولا عن توفر المحوّل الفعلي ولا عن أدلة النشر.

```bash
stackkit app compatibility [flags]
```

| Flag | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--json` | bool | — | طباعة مصفوفة التوافق بصيغة JSON |

**أمثلة**

```bash
# Show which applications each runtime adapter supports
stackkit app compatibility

# The same matrix as JSON
stackkit app compatibility --json
```
