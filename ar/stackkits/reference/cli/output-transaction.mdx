افحص إجراءات دورة حياة معاملة الإخراج الصريحة في Architecture v2.

```bash
stackkit output-transaction [flags]
```

الأوامر الفرعية: [`stackkit output-transaction gc-retired`](#stackkit-output-transaction-gc-retired)

## stackkit output-transaction gc-retired

افحص شاهد قبر لمعاملة إخراج متقاعدة أو نظّفه صراحةً.

```bash
stackkit output-transaction gc-retired [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--action` | string | — | الإجراء الدقيق الذي أبلغ عنه فحص سابق |
| `--apply` | bool | — | نفّذ الإجراء المُعاد ذكره؛ والفحص هو الافتراضي |
| `--transaction-id` | string | — | **مطلوب.** معرّف المعاملة الدقيق بأحرف صغيرة |
