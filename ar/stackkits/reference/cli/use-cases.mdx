اختيار حالات الاستخدام الاختيارية للـ Kit.

```bash
stackkit use-cases [flags]
```

الأوامر الفرعية: [`stackkit use-cases pick`](#stackkit-use-cases-pick)

## stackkit use-cases pick

اختر حالات الاستخدام الاختيارية تفاعليًا.

اعرض حالات الاستخدام الاختيارية للـ Kit وبدّل حالتها في الطرفية.

تحرّك مفاتيح الأسهم أو j/k المؤشر. تبدّل المسافة العنصر المظلّل. يؤكد Enter. تبدأ Files وPhotos وVault محددة (القيم الافتراضية L3 للـ Kit).

يكتب `--print` المعرّفات المحددة في سطر واحد مفصول بفواصل على stdout ليتمكن المثبّتون من تمريرها إلى stackkit init `--use-case`. تذهب المطالبات إلى stderr. وعندما لا يكون stdin طرفية تُعاد القيم الافتراضية الحالية دون مطالبة.

```bash
stackkit use-cases pick [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--print` | bool | — | اكتب معرّفات حالات الاستخدام المحددة في سطر واحد مفصول بفواصل على stdout |

**أمثلة**

```bash
# Choose optional use cases in the terminal
stackkit use-cases pick

# Print the selected IDs as one comma-separated line for stackkit init --use-case
stackkit use-cases pick --print
```
