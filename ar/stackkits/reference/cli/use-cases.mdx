اختيار حالات الاستخدام الاختيارية للـ Kit.

```bash
stackkit use-cases [flags]
```

الأوامر الفرعية: [`stackkit use-cases add`](#stackkit-use-cases-add), [`stackkit use-cases pick`](#stackkit-use-cases-pick)

## stackkit use-cases add

أضف حالة استخدام من الكتالوج إلى تثبيت مستقل قائم.

أضف حالة استخدام باستخدام القيم الافتراضية للبديل وملف تعريف الوحدة التي يملكها CUE في الطقم المثبّت. احتفظ بأحمال العمل والمسارات والمواضع والتخزين القائمة. احفظ المرشح وفق تجزئة spec الحالية وأنشئ فقط خانات الأسرار المحلية لحالة الاستخدام المختارة. يُعاد استخدام الحفظ القائم. لا تُنشر خدمات؛ ولّد النية المحدّثة وطبّقها عبر دورة الحياة المعتادة. يلزم stackkit/v2alpha2 أصلي وتثبيت مستقل بعقدة واحدة وموقع واحد.

```bash
stackkit use-cases add <slug> [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--expected-spec-hash` | string | — | اشترط تجزئة spec الحالية المعتمدة هذه؛ وعند الإغفال تُستخدم التجزئة المقروءة قبل الإنشاء |

**أمثلة**

```bash
stackkit use-cases add mail
stackkit use-cases add mail --expected-spec-hash sha256:<current-hash>
```

## stackkit use-cases pick

اختر حالات الاستخدام الاختيارية تفاعليًا.

اعرض حالات الاستخدام الاختيارية للـ Kit وبدّل حالتها في الطرفية.

تحرّك مفاتيح الأسهم أو j/k المؤشر. تبدّل المسافة العنصر المظلّل. يؤكد Enter. تبدأ Files وPhotos وVault محددة (القيم الافتراضية L3 للـ Kit).

يكتب `--print` المعرّفات المحددة في سطر واحد مفصول بفواصل على stdout ليتمكن المثبّتون من تمريرها إلى stackkit init `--use-case`. تذهب المطالبات إلى stderr. وعندما لا يكون stdin طرفية تُعاد القيم الافتراضية الحالية دون مطالبة.

```bash
stackkit use-cases pick [flags]
```

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `--print` | bool | — | اكتب معرّفات حالات الاستخدام المحددة في سطر واحد مفصول بفواصل على stdout |

**أمثلة**

```bash
# Choose optional use cases in the terminal
stackkit use-cases pick

# Print the selected IDs as one comma-separated line for stackkit init --use-case
stackkit use-cases pick --print
```
