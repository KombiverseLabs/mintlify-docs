تعرض StackKits اتصال MCP واحدًا موجّهًا للمستخدم باسم `stackkit`. المحوّل المحلي هو `stackkit-mcp`؛ وبعد التثبيت يمكن أيضًا أن يخدم `stackkit-server` الموصّل نفسه على نقطة النهاية المحمية `/mcp`.

## إعداد عميل محلي

ولّد مقتطف عميل من الإصدار المثبَّت:

```bash
stackkit agent mcp-config --client codex
```

الصيغة المحلية الافتراضية هي:

```toml
[mcp_servers.stackkit]
command = "stackkit-mcp"
args = ["--mode", "docs,local,server"]
```

## نموذج الأمان

- تتوفر أدوات التوثيق والتشخيص للقراءة فقط افتراضيًا.
- تتطلب الأدوات القادرة على الكتابة وضع كتابة صريحًا وموافقة محلية من المالك خاصة بكل عملية.
- يجب حماية نقطة النهاية القابلة للوصول عن بُعد عمدًا؛ ولا تكشفها مباشرةً على الإنترنت العام.
- يستخدم الموصّل دورة حياة CLI المحلية وعقد الأدلة نفسيهما اللذين تستخدمهما أوامر الطرفية.

## State Console

State Console الاختياري هو محوّل محلي لمراجعة الحالة والموافقة على العمليات. يمكنه عرض مساحة عمل مختارة وخطة وحالة وسجلات وأدلة. وهو لا يوصي بطقم ولا ينفّذ إجراءات دورة الحياة بنفسه.
