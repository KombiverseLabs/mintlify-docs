Cloud Kit مضمَّن في الإصدار العام الحالي (v0.35.x) كمعاينة. لا يغطي أي تشغيل آلي لدورة الحياة خادمًا افتراضيًا عامًا بعد، لذا تسرده [توافق أنظمة التشغيل](/ar/stackkits/reference/os-compatibility) بالحالة `unverified`. يستخدم دورة التأليف المستقلة نفسها التي يستخدمها Basement Kit، لكنه مخصص لمضيف سحابة موجود واحد مع DNS عام وTLS تحت سيطرتك.

<Note>
  يتضمن الإصدار تعريف Cloud Kit ومثبّته. تعامل مع تهيئة الإعدادات وأدلة وقت التشغيل الحي الخاصة بالإصدار كادعاءين منفصلين.
</Note>

## قبل أن تبدأ

جهّز ما يلي خارج StackKits:

- مضيف متاح بالفعل ومصرّح لك بتشغيله
- نطاق وسجلات DNS تتحكم فيها
- وضع مضيف وشبكة مناسب للخدمات العامة

تتحقق StackKits من تعريف نظامها الخاص وتطبّقه على ذلك المضيف. فهي لا تجهّز خادمًا ولا تختار مزوّدًا ولا تحتفظ ببيانات اعتماد المزوّد.

## بدء Cloud Kit

هيّئ مساحة العمل المنشورة على Linux أو macOS:

```bash
curl -sSL https://cloud.stackkit.cc | DOMAIN=example.com sh
cd ~/my-cloud-homelab
```

استخدم نطاقًا تملكه بدلًا من `example.com`. احتفظ بـ StackSpec ومخرجات التحقق مع مساحة العمل، ولا تغيّر سوى StackSpec قبل إعادة توليد الملفات.

إذا كان لديك CLI بالفعل، فـ[اختر طقمًا](/ar/guides/stackkits/choosing-a-kit) و[اضبط StackSpec](/ar/guides/stackkits/configure-stack-spec).
