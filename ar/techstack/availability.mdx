يخضع Techstack لتطوير نشط بوصفه تجربة المشغّل الاختيارية لـ StackKits. نسخة Windows Alpha
مفتوحة المصدر الأولى متاحة للعموم لتلقي ملاحظات الخوادم المحلية؛ أما القدرات المتصلة
والمُدارة فتبقى ضمن نطاق المعاينة.

| السطح | الحالة الحالية |
| --- | --- |
| نظرة عامة على المنتج ونموذج التشغيل | توثيق عام |
| المدخل المستضاف على `techstack.kombify.io` | معاينة؛ قد يكون الوصول محدوداً |
| مثبّت Windows وحزمة سطح المكتب | Alpha عامة غير موقّعة |
| توزيع المصدر العام دون هوية | عام في `kombifyio/TechStack` |
| التشغيل المتصل والمُدار | معاينة؛ وليس ادعاءً بالتوفر العام |
| أسماء HTTPS العامة في kombify.me ومرحّل HTTP الخاص | توثيق Alpha عام |
| دورة حياة StackKits المستقلة | متاحة للعموم عبر StackKits |

<Warning>
حزمة Windows هي نسخة Alpha غير موقّعة، وليست إصداراً مستقراً أو جاهزاً للإنتاج. استخدم
المستودع الرسمي فقط وتحقق من المجموع الاختباري المنشور قبل فتحها.
</Warning>

## ما يمكنك فعله الآن

- ثبّت StackKits وشغّله عبر [البدء السريع العام](/ar/stackkits/quickstart)
- [نزّل Techstack Windows Alpha](/ar/techstack/install-windows) واستخدم وضعه المحلي دون حساب
- اطّلع على [أوضاع تشغيل Techstack](/ar/techstack/operating-modes)
- افتح [المعاينة المستضافة](https://techstack.kombify.io) إذا كان حسابك يملك الوصول
- تواصل مع [دعم kombify](mailto:info@kombify.io) بشأن الوصول إلى المعاينة

[المستودع مفتوح المصدر](https://github.com/kombifyio/TechStack) هو المرجع الحاكم للمصدر
وأصول المثبّت والمجاميع الاختبارية وتحديثات Alpha.
