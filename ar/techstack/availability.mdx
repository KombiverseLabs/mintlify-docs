يخضع Techstack لتطوير نشط بوصفه تجربة المشغّل الاختيارية لـ StackKits. نسخة Windows Alpha
مفتوحة المصدر الأولى متاحة للعموم لتلقي ملاحظات الخوادم المحلية؛ أما القدرات المتصلة
والمُدارة فتبقى ضمن نطاق المعاينة.

## بكلمات بسيطة

بعض أجزاء Techstack عامة اليوم وبعضها ما زال معاينة. تبيّن لك هذه الصفحة أيها هو،
لتختار المسار الذي يناسبك الآن.

| السطح | الحالة الحالية |
| --- | --- |
| نظرة عامة على المنتج ونموذج التشغيل | وثائق عامة |
| المدخل المستضاف في `techstack.kombify.io` | معاينة؛ قد يكون الوصول محدودًا |
| مثبّت Windows وحزمة سطح المكتب | Alpha عامة غير موقّعة |
| توزيع المصدر العام دون هوية | عام في `kombifyio/TechStack` |
| التشغيل المتصل والمُدار | معاينة؛ وليس ادعاءً بالتوفر العام |
| أسماء HTTPS العامة في kombify.me وترحيل HTTP الخاص | وثائق Alpha عامة |
| دورة حياة StackKits المستقلة | متاحة للعموم عبر StackKits |

<Warning>
حزمة Windows هي نسخة Alpha غير موقّعة، وليست إصدارًا مستقرًا أو جاهزًا للإنتاج.
استخدم المستودع الرسمي فقط وتحقق من المجموع الاختباري المنشور قبل فتحها.
</Warning>

## ما تحتاجه أولًا

لتجربة Windows Alpha تحتاج إلى حاسوب Windows وخادم في شبكتك المنزلية. لا يلزم حساب
kombify للمسار المحلي. ويعتمد الوصول إلى المعاينة المستضافة على ما فعّله حساب kombify الخاص بك.

## ما يمكن توقعه

مثبّت Windows غير موقّع، لذا قد يعرض Windows تحذير SmartScreen. قارن المثبّت
بالمجموع الاختباري المنشور قبل المتابعة. لا تظهر الخوادم المُدارة إلا عندما
يفعّلها حسابك، ويبقى الخيار غير متاح خلاف ذلك.

## ما يمكنك فعله الآن

- ثبّت StackKits وشغّله عبر
  [البدء السريع العام](/ar/stackkits/quickstart)
- [نزّل Techstack Windows Alpha](/ar/techstack/install-windows) واستخدم وضعه المحلي
  دون حساب
- راجع [أوضاع تشغيل Techstack](/ar/techstack/operating-modes)
- افتح [المعاينة المستضافة](https://techstack.kombify.io) إذا كان حسابك يملك
  الوصول
- تواصل مع [دعم kombify](mailto:info@kombify.io) بشأن الوصول إلى المعاينة

## إذا حدث خطأ ما

- إذا لم يسمح لك المدخل المستضاف بالدخول، فقد لا يملك حسابك الوصول إلى المعاينة بعد.
  راسل [دعم kombify](mailto:info@kombify.io).
- إذا أردت خادمًا يعمل اليوم، فاستخدم
  [البدء السريع لـ StackKits](/ar/stackkits/quickstart) بدلًا من ذلك.
- لمعرفة الخيارات التي يفتحها حسابك، اقرأ
  [الخوادم المُدارة](/ar/techstack/managed-servers).

[المستودع مفتوح المصدر](https://github.com/kombifyio/TechStack) هو المرجع الرسمي
للمصدر وملفات المثبّت والمجاميع الاختبارية وتحديثات Alpha.
