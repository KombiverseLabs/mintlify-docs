<Note>مولَّد من إصدار Techstack v0.32.8 (المصدر `4c7d219a5d56`). بالنسبة إلى إصدار مثبَّت، فإن `techstack api <command> --help` هو المرجع.</Note>

## techstack api unifier analyze

تحليل المواصفة للحصول على المتطلبات (المرحلة 1).

آمن وغير متغير النتيجة (idempotent). يُرجع متطلبات العتاد والإضافات المكتشفة وبيانات الاعتماد المطلوبة.

```bash
techstack api unifier analyze [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/unifier/analyze` |
| يغيّر الحالة | نعم |
| أداة MCP | `analyze_spec` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `--body` | json | **مطلوب.** جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |

## techstack api unifier pipeline preview

معاينة نتائج خط المعالجة دون آثار جانبية.

آمن وغير متغير النتيجة (idempotent). يعرض ما سيُولَّد. تُرجع حالات فشل التحقق في الواجهة الخلفية أو تحديد StackKit الرمز 200 مع data.valid=false وdata.errors المنظَّمة؛ بينما تبقى المدخلات المشوّهة وحالات فشل المصادقة أخطاء HTTP.

```bash
techstack api unifier pipeline preview [flags]
```

| --- | --- |
| HTTP | `POST /api/v1/unifier/pipeline/preview` |
| يغيّر الحالة | نعم |

| `--body` | json | **مطلوب.** جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |
