## techstack api tunnel install-command

إنشاء أمر تثبيت العامل مع عنوان URL للنفق.

```bash
techstack api tunnel install-command [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/tunnel/install-command` |
| يغيّر الحالة | نعم |
| أداة MCP | لا شيء |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `--token` | string | **مطلوب.** |
| `--body` | json | جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |

## techstack api tunnel subdomains list

عرض نطاقات kombify.me الفرعية الخاصة بالمستدعي لأغراض التشخيص؛ والتسجيل من مسؤولية StackKits.

يتطلب مستدعياً مصادَقاً عليه. مع هوية المنصة المشتركة تُحصر القائمة في ربط المالك الخاص بالمستدعي.

```bash
techstack api tunnel subdomains list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/tunnel/subdomains` |
| يغيّر الحالة | لا |
| أداة MCP | `list_tunnel_subdomains` |

## techstack api tunnel subdomains services

عرض الخدمات تحت أحد نطاقات kombify.me الفرعية الأساسية الخاصة بالمستدعي.

| | |
