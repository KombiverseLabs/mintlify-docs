## techstack api system capabilities

اكتشاف قدرات API للعملاء.

يُرجع قائمة منظَّمة بكل قدرات API للاكتشاف البرمجي. تستخدم تطبيقات العملاء الأصلية نقطة النهاية هذه لتعداد الإجراءات المتاحة والمصادقة المطلوبة والسلوك غير المتزامن.

```bash
techstack api system capabilities [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/capabilities` |
| يغيّر الحالة | لا |
| أداة MCP | لا شيء |

## techstack api system client-bootstrap

إعداد وقت التشغيل العام لـ SPA الثابت.

يُرجع إعداداً عاماً غير سري يختلف حسب وقت التشغيل للواجهة الأمامية الثابتة المضمَّنة (نسخة المنتج، ووضع النشر، ومفاتيح القياس عن بُعد). تكون القيم فارغة ما لم يضبط المشغّل أو القائم بالنشر متغيرات البيئة المقابلة، ما يُبقي عمليات النشر المستضافة ذاتياً والمحلية خالية من القياس عن بُعد افتراضياً.

```bash
techstack api system client-bootstrap [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/client/bootstrap` |
| يغيّر الحالة | لا |
| أداة MCP | لا شيء |
