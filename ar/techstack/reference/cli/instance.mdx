<Note>مولَّد من إصدار Techstack v0.32.8 (المصدر `4c7d219a5d56`). بالنسبة إلى إصدار مثبَّت، فإن `techstack api <command> --help` هو المرجع.</Note>

## techstack api instance enrollment

جلب سجل التسجيل المحلي.

```bash
techstack api instance enrollment [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/enrollment` |
| يغيّر الحالة | لا |
| أداة MCP | `get_enrollment_record` |

## techstack api instance get

جلب هوية المثيل المحلية الثابتة.

```bash
techstack api instance get [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/instance` |
| يغيّر الحالة | لا |
| أداة MCP | `get_instance_identity` |
