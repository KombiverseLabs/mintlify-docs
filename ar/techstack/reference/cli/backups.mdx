## techstack api backups delete

حذف نسخة احتياطية (للمسؤولين فقط).

```bash
techstack api backups delete <name> [flags]
```

<Warning>يتطلب تأكيداً: تحذف هذه العملية أرشيف النسخة الاحتياطية المحلي نهائياً. مرّر `--yes` أو أجب عن المطالبة؛ فالتشغيل غير التفاعلي دون `--yes` يتوقف قبل أي طلب برمز الخروج 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/backups/{name}` |
| يغيّر الحالة | نعم |
| أداة MCP | لا شيء |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<name>` | string | **مطلوب.** |
