## techstack api monitor availability

التوفر وفترات التوقف والحالة اليومية، مشتقة من الخط الزمني للانتقالات.

إسقاط فوق الخط الزمني لانتقالات الخادم القائم على الإلحاق فقط، وليس أداة أخذ عينات: كل فترة محصورة بانتقالين مسجَّلين وتحمل رموز الأسباب التي كُتبا بها. تنشر الاستجابة مفردات الاحتساب الخاصة بها، ليتمكن القارئ من معرفة حالات الاتصال التي احتُسبت توقفاً دون قراءة المصدر.

```bash
techstack api monitor availability [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/monitor/availability` |
| يغيّر الحالة | لا |
| أداة MCP | `get_availability_report` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `--window` | string | مجموعة مغلقة؛ فالنافذة غير المحدودة ستكون منفذاً لهجمات حجب الخدمة. إحدى القيم: `24h`، `7d`، `30d`، `90d`. الافتراضي `"30d"`. |
| `--server-id` | string | حصر التقرير في خادم واحد، لصفحة تفاصيل الخادم. |
