## techstack api discovery cache clear

مسح ذاكرة التخزين المؤقت للاكتشاف (للمسؤولين فقط).

```bash
techstack api discovery cache clear [flags]
```

<Warning>يتطلب تأكيداً: تتجاهل هذه العملية كل نتائج الاكتشاف المخزنة مؤقتاً؛ ويعيد الاكتشاف التالي فحص الشبكة. مرّر `--yes` أو أجب عن المطالبة؛ فالتشغيل غير التفاعلي دون `--yes` يتوقف قبل أي طلب برمز الخروج 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/discovery/cache` |
| يغيّر الحالة | نعم |
| أداة MCP | `clear_discovery_cache` |

## techstack api discovery devices get

جلب جهاز مكتشَف يملكه المستدعي.

```bash
techstack api discovery devices get <id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/discovery/devices/{id}` |
| يغيّر الحالة | لا |
| أداة MCP | `get_device` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<id>` | string | **مطلوب.** معرّف المورد. |

## techstack api discovery devices probe

فحص معمّق لجهاز يملكه المستدعي.

لا يجوز للمستدعين من غير المسؤولين فحص إلا عناوين IP من نتائج اكتشافهم الخاصة؛ ويجوز للمسؤولين فحص أي عناوين IP.

```bash
techstack api discovery devices probe [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/discovery/probe` |
| يغيّر الحالة | نعم |
| أداة MCP | لا شيء |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `--ip` | string | **مطلوب.** |
| `--ssh-key` | string | — |
| `--ssh-user` | string | — |
| `--body` | json | جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |
