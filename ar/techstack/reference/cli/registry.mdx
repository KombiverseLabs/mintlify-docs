## techstack api registry services list

اعرض الخدمات المملوكة مع كتالوجها ومواضعها المعتمدة.

تستخدم سجلات التشغيل إسقاط الحالة والقدرات والإصدار وقفل المالك نفسه المستخدم في تفاصيل الخدمة. تظل السجلات التاريخية قابلة للقراءة مع حالة مرصودة مجهولة، ودون قدرات عمليات لم تُقَس.

```bash
techstack api registry services list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/registry/services` |
| يغيّر الحالة | لا |
| أداة MCP | `list_registry_services` |
