## techstack api monthly-runtimes cleanup-readback

قراءة حقائق حالة تنظيف وقت التشغيل المُدار المحجوبة البيانات الحساسة.

يُرجع حقائق الحالة المحصورة بالمستأجر والمالك لجيل موارد التحكم لدى المزوّد الحالي الدقيق لعقد الإيجار. لا تستدعي نقطة النهاية هذه، وهي للقراءة فقط، أي مزوّد أو وكيل وقت تشغيل أبداً، ولا تُرجع مقابض موارد المزوّد أو الأوامر أو مستندات الأدلة أو بيانات الاعتماد. العملية النهائية لم تعد قيد التشغيل، لكنها ليست بحد ذاتها دليلاً على نجاح التنظيف: فغياب المورد لدى المزوّد يتطلب absence_evidence_ref، وتحرير السعة يتطلب capacity_released.

```bash
techstack api monthly-runtimes cleanup-readback <lease-id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/monthly-runtimes/{lease_id}/cleanup-readback` |
| يغيّر الحالة | لا |
| أداة MCP | `get_monthly_runtime_cleanup_readback` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<lease-id>` | string | **مطلوب.** معرّف عقد إيجار وقت التشغيل الشهري. |

## techstack api monthly-runtimes decommission

إخراج عقد إيجار وقت تشغيل شهري من الخدمة.

```bash
techstack api monthly-runtimes decommission <lease-id> [flags]
```

<Warning>يتطلب تأكيداً: تُخرج هذه العملية وقت التشغيل الشهري من الخدمة وتزيل موارده لدى المزوّد. مرّر `--yes` أو أجب عن المطالبة؛ فالتشغيل غير التفاعلي دون `--yes` يتوقف قبل أي طلب برمز الخروج 9.</Warning>

| | |
| --- | --- |
| HTTP | `POST /api/v1/monthly-runtimes/{lease_id}/decommission` |
| يغيّر الحالة | نعم |
| أداة MCP | `decommission_monthly_runtime` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<lease-id>` | string | **مطلوب.** معرّف عقد إيجار وقت التشغيل الشهري. |
| `--force-query` | boolean | طلب مطابقة دقيقة لدى المزوّد مرتبطة بالجيل عندما يتعذر الوصول إلى وقت التشغيل. لا يُقبل Force إلا عندما يستطيع مستوى التحكم إثبات حيازة دائمة آمنة عند إعادة التشغيل ومسيّجة بـ HA قبل إلغاء عقد الإيجار. ويُقبل أيضاً كجسم JSON بالشكل &#123;"force": true&#125;. الطلب الفارغ يفترض false. الافتراضي `false`. |
| `--expected-resource-generation-digest` | string | مطالبة تزامن متفائلة اختيارية. يُرفض هدم الموارد لدى المزوّد بالرمز 409 ما لم يظل هذا الملخص يحدد جيل موارد عقد الإيجار الحالي. |
| `--force` | boolean | الافتراضي `false`. |
| `--body` | json | جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |

## techstack api monthly-runtimes reconnect

استرداد جلسة Guard لوقت تشغيل مُدار.

يفحص الكيان التجميعي القياسي؛ وعندما يتعذر إثبات اتصال Guard، يعيد تشغيل Guard عبر قناة التنفيذ المثبّتة لمالك مستحق لخادم قيد التشغيل، ويعيد رصد الاتصال خلال نافذة محدودة، ثم يوصل التسجيل إلى الحالة enrolled. يُرفض وقت التشغيل المتوقف (managed_runtime_stopped). ولا يُمسّ أي مورد لدى المزوّد.

## techstack api monthly-runtimes recreate

إعادة إنشاء جيل خادم مُدار واحد محرَّر بالكامل.

يجهّز صراحةً الجيل N+1 لخانة وقت التشغيل نفسها المحايدة للمزوّد بعد أن يبلغ الجيل N حالة نهائية لعقد الإيجار والخادم القياسي، وحالة نهائية لعملية المزوّد، ودليلاً معتماً أصلياً لدى المزوّد على الغياب، وتحريراً دقيقاً للسعة. يُسترد المزوّد والمنطقة والعرض والدور وStackKit ونية الخدمة غير القابلة للتغيير من عقد الإيجار القديم المحصور بالمالك؛ ولا يمكن للعملاء استبدالها. تفوّض نقطة النهاية إلى سلطة توسيع وقت التشغيل المُدار نفسها التي يستخدمها Add Node، لذا يمر التسجيل وأدلة Guard ونقاط النهاية وطرح StackKit عبر مسار Creation الكامل. مفتاح Idempotency-Key القياسي إلزامي ويعيد تشغيل الجيل المقبول بأمان.

```bash
techstack api monthly-runtimes recreate <lease-id> [flags]
```

<Warning>يتطلب تأكيداً: تستبدل هذه العملية خادم المزوّد لوقت التشغيل بخادم مجهَّز حديثاً، وتُحتسب عليها رسوم. مرّر `--yes` أو أجب عن المطالبة؛ فالتشغيل غير التفاعلي دون `--yes` يتوقف قبل أي طلب برمز الخروج 9.</Warning>

| | |
| --- | --- |
| HTTP | `POST /api/v1/monthly-runtimes/{lease_id}/recreate` |
| يغيّر الحالة | نعم |
| أداة MCP | `recreate_monthly_runtime` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<lease-id>` | string | **مطلوب.** معرّف عقد إيجار وقت التشغيل الشهري. |
| `--confirmed` | boolean | **مطلوب.** إقرار صريح بأن Recreate يجهّز جيل خادم مُدار جديداً ويحتسب رسومه. إحدى القيم: `true`. |
| `--body` | json | جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |

## techstack api monthly-runtimes resolve-custody

أرشفة سجل حيازة قديم أو غير مرتبط بعد تنظيف موارد المزوّد.

يزيل عقد إيجار قديماً أو غير مرتبط وغير قابل للتنفيذ من لوحة التحكم النشطة فقط بعد أن يؤكد المالك أن مورده لدى المزوّد قد أُزيل بالفعل. لا تتصل هذه العملية أبداً بأي مورد لدى المزوّد ولا تحذفه، وتُرفض للأجيال التي يتحكم Techstack في مزوّدها.

```bash
techstack api monthly-runtimes resolve-custody <lease-id> [flags]
```

<Warning>يتطلب تأكيداً: تسجّل هذه العملية أن موارد المزوّد قد نُظّفت، وتحرر حيازة عقد الإيجار. مرّر `--yes` أو أجب عن المطالبة؛ فالتشغيل غير التفاعلي دون `--yes` يتوقف قبل أي طلب برمز الخروج 9.</Warning>

| | |
| --- | --- |
| HTTP | `POST /api/v1/monthly-runtimes/{lease_id}/resolve-custody` |
| يغيّر الحالة | نعم |
| أداة MCP | `resolve_monthly_runtime_custody` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `<lease-id>` | string | **مطلوب.** معرّف عقد إيجار وقت التشغيل الشهري. |
| `--provider-cleanup-confirmed` | boolean | **مطلوب.** إحدى القيم: `true`. |

## techstack api monthly-runtimes stop

يقبل عملية مطابقة واحدة للتحكم لدى المزوّد مرتبطة بالجيل نحو الحالة stopped. يستخدم centron إجراء إيقاف تشغيل الضيف السلس الخاص به؛ أما IONOS فيوقف الضيف عبر قناة التنفيذ لأن إيقاف المزوّد IONOS يحرر عنوان DHCP IPv4 المرتبط. يحتفظ الخادم بقرصه وعنوانه وعقد إيجاره وحجز سعته وفوترته الشهرية.
