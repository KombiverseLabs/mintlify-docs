<Note>مولَّد من إصدار Techstack v0.32.8 (المصدر `4c7d219a5d56`). بالنسبة إلى إصدار مثبَّت، فإن `techstack api <command> --help` هو المرجع.</Note>

## techstack api addons detect

الاكتشاف التلقائي للإضافات المناسبة لمواصفة.

```bash
techstack api addons detect [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/addons/detect` |
| يغيّر الحالة | نعم |
| أداة MCP | `detect_addons` |

| الوسيط | النوع | الوصف |
| --- | --- | --- |
| `--body` | json | **مطلوب.** جسم طلب JSON (`application/json`) كقيمة حرفية أو `@path` أو `-` لـ stdin. |

## techstack api addons list

عرض الإضافات المتاحة.

```bash
techstack api addons list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/addons` |
| يغيّر الحالة | لا |
| أداة MCP | `list_addons` |
