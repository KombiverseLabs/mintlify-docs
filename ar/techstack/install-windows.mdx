Techstack Alpha عميل Windows مبكر يعمل محلياً أولاً لتشغيل الخوادم في شبكتك المنزلية. يمكنه
العمل دون حساب kombify مستضاف. ومع ذلك يهيّئ StackKits على الخادم هوية المالك/المسؤول
المحلية المطلوبة.

<Warning>
هذه نسخة Alpha غير موقّعة لتلقي ملاحظات المستخدمين الفعليين، وليست ادعاءً بالاستقرار أو
الجاهزية للإنتاج. قد يعرض Windows تحذير SmartScreen. تحقق من مصدر إصدار GitHub والمجموع
الاختباري قبل أن تقرر المتابعة.
</Warning>

## استخدام Techstack محلياً

1. شغّل Techstack واختر **Use locally**. لا يتطلب هذا الوضع حساب kombify مستضافاً.
2. لخادم Ubuntu جديد، اختر **Give me a one-liner**، ثم حدد **Basement Kit**، واملأ حقول
   تهيئة المالك/المسؤول المحلي.
3. انسخ أمر الاقتران المُولَّد وشغّله مرة واحدة على خادم Ubuntu. أبقِ عميل Windows يعمل ويمكن
   الوصول إليه على الشبكة الفرعية المحلية بينما يثبّت الخادم kombify Guard ويرسل Guard أول نبضة له.
4. انتظر حتى يغيّر Techstack حالة الخادم من **Not connected yet** إلى حالة الاتصال، ثم تابع
   نشر StackKit.
5. لخادم يشغّل Basement Kit بالفعل، اختر **Connect my server** بدلاً من ذلك وأدخل تفاصيل SSH
   المحلية الخاصة به.

<Note>
تضم نسخة Windows Alpha كتالوج Basement Kit مثبّت الإصدار، ومدقق Windows الخاص به، وحمولة
النشر لنظام Linux؛ وتذكر ملاحظات الإصدار نسخة StackKits الدقيقة التي تحملها كل بنية. ينشئ
المثبّت أيضاً استثناءً في جدار حماية Windows للمنفذ TCP `5264` مقيداً بالشبكة الفرعية المحلية،
ليتمكن الأمر المُولَّد من الوصول إلى العميل حتى عندما يصنّف Windows الشبكة المنزلية على أنها
عامة.
</Note>

<Note>
تتطلب المزامنة السحابية والتشغيل المتصل حساباً منفصلاً لاحقاً. وليست شرطاً مسبقاً لمسار
Alpha المحلي.
</Note>

<Note>
في هذا الوضع المحلي، يبلّغ [kombify Guard](/ar/techstack/kombify-guard) على خادمك إلى Techstack
الذي تشغّله بنفسك. ولا تتلقى kombify أي بيانات من Guard ما لم تربط التثبيت. راجع
[ما يرسله kombify Guard](/ar/techstack/guard-telemetry).
</Note>
