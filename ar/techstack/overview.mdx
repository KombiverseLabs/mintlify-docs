Techstack هو تجربة التنسيق والمشغّل الاختيارية المبنية فوق عقد StackKits CLI. يواصل StackKits
امتلاك تعريفات الـ stack ودورة الحياة المستقلة؛ ويضيف Techstack التهيئة الموجّهة وجرد وقت
التشغيل وتنسيق الخوادم المتعددة وعمليات Day-2 الخاضعة للحوكمة.

<Warning>
Techstack حالياً في مرحلة Alpha. يدعم عميل Windows مفتوح المصدر المسار المحلي دون حساب،
بينما يبقى المدخل المستضاف
[techstack.kombify.io](https://techstack.kombify.io) والقدرات المُدارة ضمن نطاق المعاينة.
</Warning>

## ما يمتلكه Techstack

- مسارات تهيئة Easy وTechie التي تنتج مقترح StackSpec
- جرد وقت التشغيل والخدمات عبر الخوادم المسجلة
- تنسيق StackKits CLI مُصدَرة ومثبّتة
- مراجعة وتنفيذ عمليات Day-2 الخاضعة للحوكمة
- مسارات التوزيع المتصل والمُدار

لا يعيد Techstack تعريف معماريات StackKit ولا ينسخ كتالوج StackKits ولا يصبح شرطاً لتشغيل
StackKit محلي. ويظل StackSpec المُولَّد يمر عبر حد التحقق والتنفيذ في StackKits.

## علاقته بـ StackKits

| الاهتمام | المالك |
| --- | --- |
| الـ kits والوحدات وStackSpec ودورة الحياة المحلية والتحقق | StackKits |
| المعالج ومقترحات التهيئة والجرد والتنسيق | Techstack |
| دورة حياة المزود والعقود وتنظيف الموارد المُدارة | Techstack |
| هوية المالك المحلية وأدلة التشغيل المستقل | StackKits |

يجب ألا يجعل حذف Techstack أي StackKit مستقل غير صالح للاستخدام. ابدأ بـ
[البدء السريع لـ StackKits](/ar/stackkits/quickstart) عندما تريد مسار تثبيت متاحاً للعموم
اليوم.
