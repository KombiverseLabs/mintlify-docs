<Warning>
لم يُطلق kombify Wallet بعد. تصف هذه الصفحات طريقة عمله لتعرف ما الذي تتوقعه. لا يمكنك استخدامه اليوم.
</Warning>

kombify Wallet هو المكان الواحد الذي يحتفظ فيه kombify بما تسلّمه إياه: مفاتيح API وبيانات تسجيل الدخول والمتغيرات وملفات الإعدادات وطرق الوصول إلى خوادمك. أنت ووكلاؤك ومنتجات kombify التي تختارها تستخدمون هذه العناصر بالطريقة نفسها، ولا يحصل كل منهم إلا على الحقوق التي تمنحها.

## ما الذي يحتفظ به

| العنصر | الغرض منه |
| --- | --- |
| **مفتاح API أو رمز مميز أو شهادة** | قيمة سرية واحدة، مثل مفتاح API لدى مزوّد. |
| **بيانات تسجيل الدخول** | اسم مستخدم وكلمة مرور لخدمة أخرى، مع سر اختياري لرموز الاستخدام لمرة واحدة. |
| **متغير** | قيمة واحدة تبحث عنها أدواتك بالاسم، مثل `DATABASE_URL`. |
| **إعدادات** | مستند، مثل ملف `.env`. |
| **الوصول إلى خادم** | كيفية الوصول إلى خادم: المضيف والمستخدم ومفتاح SSH خاص أو كلمة مرور. |
| **جهة إصدار شهادات SSH** | توقّع شهادات SSH قصيرة العمر لك ولوكلائك ولخوادمك. |

الحسابات التي تربطها بخدمات أخرى، مثلًا عبر OAuth، مخطَّط لها وستأتي بمسار خاص بها.

## كيف تحمي Wallet ما تحتفظ به

- **تشفير قبل أن يغادر جهازك.** يشفّر متصفحك، أو سطر الأوامر `kombify-wallet`، القيمة على جهازك. تكتفي الخدمات الواقعة بينك وبين Wallet بنقل البيانات المشفّرة، ولا تخزّن Wallet إلا قيمًا مشفّرة. تُحفظ المفاتيح التي تفتحها بمعزل عن البيانات المخزَّنة، لذا لا يمكن قراءة نسخة من البيانات المخزَّنة وحدها.
- **كل استخدام يُسجَّل.** تكتب Wallet سجل تدقيق قبل أن تسلّم قيمة أو تستخدمها، سواء أظهرتها أنت أو استخدمها وكيل أو منتج. وإذا تعذّرت كتابة السجل فإنها لا تسلّم القيمة.
- **تسجيل دخولك عبر Auth0 يحمي الوصول.** تصل إلى Wallet الخاصة بك بتسجيل الدخول إلى حساب kombify عبر Auth0 على `login.kombify.io`. لا توجد كلمة مرور ثانية لـ Wallet. لا يمكن إدارة Wallet الخاصة بك إلا بواسطتك أنت بعد تسجيل دخولك بنفسك. ولا يمكن ذلك للوكلاء أو الجلسات المفوّضة.
- **أنت تمنح الحقوق واحدًا واحدًا.** استخدام عنصر وقراءة قيمته وإدارته حقوق منفصلة. ولا يرث وكيل أو منتج حقوقك أبدًا.

<Note>
يستطيع أي شخص يمكنه تسجيل الدخول إلى حساب kombify الخاص بك أن يفتح Wallet الخاصة بك بصفتك. احمِ الحساب بمفتاح مرور (passkey) أو بتسجيل دخول متعدد العوامل.
</Note>

## ما لا تستطيع Wallet فعله

لا يمكن استرجاع قيمة رآها شخص بالفعل. وإذا كانت قيمة قد وصلت إلى من لا ينبغي أن تصل إليه، فأضف إصدارًا جديدًا من العنصر لاستبدالها.
