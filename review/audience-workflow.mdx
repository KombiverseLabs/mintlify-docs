# Documentation review workflow

This page is available to the `kombify-team` reviewer group only. It is a
customer-safe description of the publication workflow; it does not contain
credentials, private customer information, internal hostnames, or operational
runbooks.

## Review stages

1. Add future public documentation to this repository and register it in the
   restricted review navigation.
2. Review the content on the authenticated Mintlify preview with the
   `kombify-team` group.
3. When the content is ready for anonymous readers, make the small,
   reviewable access-control change from the group restriction to `public: true`
   and move the page into public navigation.
4. Run the public and authenticated local gates before merging.

Public pages remain the only pages exposed through public `llms.txt`, MCP, and
search results under Mintlify partial authentication. Access control is not
permission to store secrets, private customer data, or internal operational
detail in this repository.
