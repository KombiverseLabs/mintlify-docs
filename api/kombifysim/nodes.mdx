---
title: Nodes API
description: Manage simulation nodes
---


Node endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io/v1/simulation`.

## List nodes

```bash
GET /api/v1/nodes
```

## Get node

```bash
GET /api/v1/nodes/{id}
```

## Get SSH details

```bash
GET /api/v1/nodes/{id}/ssh
```

## Get node logs

```bash
GET /api/v1/nodes/{id}/logs
```
