---
title: Templates API
description: Use pre-built templates
---


Template endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io/v1/simulation`.

## List templates

```bash
GET /api/v1/templates
```

## Get template

```bash
GET /api/v1/templates/{name}
```

## Apply template

```bash
POST /api/v1/templates/{name}/apply
Content-Type: application/json

{
  "simulation_name": "my-test",
  "auto_start": true
}
```
