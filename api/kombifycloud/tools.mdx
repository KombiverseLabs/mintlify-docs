---
title: Tools API
description: Tool management endpoints
---


Tool endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io`.

## List tools

```bash
GET /v1/tools
```

## Get tool

```bash
GET /v1/tools/{id}
```

## Launch tool

```bash
POST /v1/tools/{id}/launch
```

## Get tool status

```bash
GET /v1/tools/{id}/status
```
