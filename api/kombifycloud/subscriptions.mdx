---
title: Subscriptions API
description: Subscription management endpoints
---


Subscription endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io`.

## Get subscription

```bash
GET /v1/subscriptions/me
```

## Update subscription

```bash
PUT /v1/subscriptions/me
Content-Type: application/json

{
  "plan": "pro"
}
```

## Get usage

```bash
GET /v1/subscriptions/me/usage
```

## Get invoices

```bash
GET /v1/subscriptions/me/invoices
```
