---
title: Stacks API
description: Manage infrastructure stacks
---


Stack endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io/v1/orchestrator`.

## List stacks

```bash
GET /api/v1/stacks
```

## Create stack

```bash
POST /api/v1/stacks
Content-Type: application/json

{
  "name": "my-homelab",
  "stackkit": "basement-kit",
  "spec": "..."
}
```

## Get stack

```bash
GET /api/v1/stacks/{id}
```

## Update stack

```bash
PUT /api/v1/stacks/{id}
```

## Delete stack

```bash
DELETE /api/v1/stacks/{id}
```
