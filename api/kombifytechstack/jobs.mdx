---
title: Jobs API
description: Track deployment jobs
---


Job endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io/v1/orchestrator`.

## List jobs

```bash
GET /api/v1/jobs
```

## Get job

```bash
GET /api/v1/jobs/{id}
```

## Get job logs

```bash
GET /api/v1/jobs/{id}/logs
```

## Cancel job

```bash
POST /api/v1/jobs/{id}/cancel
```
