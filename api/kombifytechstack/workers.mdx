---
title: Workers API
description: Manage worker nodes
---


Worker endpoints are served through the Cloudflare Edge gateway at `https://api.kombify.io/v1/orchestrator`.

## List workers

```bash
GET /api/v1/workers
```

## Get worker

```bash
GET /api/v1/workers/{id}
```

## Update worker

```bash
PUT /api/v1/workers/{id}
```

## Delete worker

```bash
DELETE /api/v1/workers/{id}
```
