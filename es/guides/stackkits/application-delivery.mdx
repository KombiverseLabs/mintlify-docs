StackKits separa la elección de aplicaciones de la responsabilidad de ejecución. Standalone Compose es la opción nativa predeterminada. Komodo es una plataforma de operaciones sin tienda de aplicaciones. Marketplace está previsto como caso de uso opcional con Coolify; Coolify es su aplicación, no un destino de ejecución nativo.

Consulta la matriz incluida en tu versión instalada:

```bash
stackkit app compatibility --json
```

## Elige un adaptador

| Adaptador | Estado actual | Úsalo cuando |
| --- | --- | --- |
| `standalone-compose` | Opción nativa predeterminada | Usa la vía declarada de la versión instalada y comprueba su evidencia del ciclo de vida. |
| [Coolify](/es/stackkits/apps/coolify) | Aplicación Marketplace prevista | Instalable como Marketplace solo cuando el catálogo publicado incluya el caso de uso y su ciclo de vida esté verificado. |
| [Komodo](/es/stackkits/apps/komodo) | Plataforma de operaciones en borrador | Selecciona la vía explícitamente y solo para workloads con evidencia en la versión fijada actual. |

La matriz publicada de [compatibilidad de la entrega de aplicaciones](/es/stackkits/reference/application-delivery-compatibility) describe contratos declarados de adaptadores. Las filas históricas no demuestran soporte en la versión fijada actual. Comprueba la evidencia del ciclo de vida de tu aplicación y versión; el despliegue por sí solo no demuestra copia de seguridad ni restauración.

Para un Basement Kit independiente, empieza con `standalone-compose`, salvo que operes de forma intencionada una de las plataformas de aplicaciones:

```json
{
  "workloads": {
    "files": {
      "alternative": "cloudreve",
      "runtimeAdapterRef": "standalone-compose",
      "placement": {
        "siteRefs": ["home"],
        "nodeRefs": ["main"]
      }
    }
  }
}
```

## Mantén un único responsable por workload

- No enrutes el mismo workload a través de Coolify y de Compose independiente al mismo tiempo.
- No añadas a mano etiquetas de Docker ni rutas generadas.
- La vía explícita de Komodo necesita evidencia en la versión fijada actual; no es la opción predeterminada ni una tienda.
- Valida la intención modificada e inspecciona el plan resuelto antes de aplicar un adaptador distinto.

Consulta [Servicios de plataforma](/es/stackkits/apps/overview) para las integraciones de plataforma y [Configura un StackSpec](/es/guides/stackkits/configure-stack-spec) para el flujo de edición completo.
