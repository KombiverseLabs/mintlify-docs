Game da a tu hogar un servidor de Minecraft autoalojado para amigos y familia, en un host que tú operas. Pterodactyl ejecuta el panel y los contenedores de juego. El catálogo de la versión llama a este caso de uso Game Server y lo entrega como el workload opcional `game`.

## Elige tu edición

| Edición | Transporte | Puerto por defecto |
| --- | --- | --- |
| Minecraft Java | TCP | 25565 |
| Minecraft Bedrock | UDP (RakNet) | 19132 |

Ambos perfiles seleccionados arrancan con verificación de modo online, una lista de permitidos, sin RCON y sin derechos de operador automáticos.

## Configúralo

1. Selecciona el workload `game` en tu [StackSpec](/es/guides/stackkits/configure-stack-spec), genera y aplícala en un [Basement Kit](/es/stackkits/kits/basement-kit) o [Cloud Kit](/es/stackkits/kits/cloud-kit) verificado.
2. Crea un archivo de configuración privado, relativo al workspace, por ejemplo `.stackkit/setup/game.json`:

```json
{
  "profile": "minecraft-java",
  "name": "Family Survival",
  "acceptEula": true,
  "allowList": ["PlayerOne"]
}
```

3. Lee y acepta tú mismo el [Contrato de Licencia de Usuario Final de Minecraft](https://www.minecraft.net/en-us/eula) antes de establecer `acceptEula` en `true`. Nunca lo aceptes en nombre de otra persona.
4. Ejecuta el comando de configuración:

```bash
stackkit setup game --owner-approve --credentials-file .stackkit/setup/game.json --json
```

El comando crea un servidor con el perfil que elegiste, aplica los valores seguros por defecto anteriores con una parada ordenada y vuelve a leer la lista de permitidos para que confirmes que surtió efecto. Una cuenta que no figure en la lista no puede unirse.

## Elige alojamiento local o gestionado

- Ejecuta el workload en un nodo local de [Basement Kit](/es/stackkits/kits/basement-kit) para que sea accesible en tu LAN.
- Ejecútala en un VPS de [Cloud Kit](/es/stackkits/kits/cloud-kit) para que tus amigos puedan unirse mientras tu ordenador de casa está apagado.

Un nodo doméstico no es accesible desde internet, a menos que elijas deliberadamente un VPS gestionado o un puente explícito. No confíes en la redirección de puertos del router para sortearlo.

## Invita a los jugadores

Comparte la dirección del nodo y el puerto del perfil con los jugadores de tu lista de permitidos. Gestiona la lista de permitidos, el encendido del servidor y los recursos desde el panel de Pterodactyl en tu ruta de Game generada.

## Copia de seguridad de los mundos

Las copias de seguridad de Game siguen la programación declarada de tu kit, pero hoy se aplican dos límites:

- Las copias de seguridad son consistentes ante fallos: el servidor todavía no se detiene de forma ordenada antes de ejecutar la instantánea.
- Aún no se ha ejercitado de extremo a extremo una restauración aislada de una copia de seguridad de Game.

Practica una restauración en un entorno aislado antes de depender de ella para un mundo que no puedas recrear. Consulta [Copia de seguridad y restauración](/es/guides/stackkits/back-up-and-restore).
