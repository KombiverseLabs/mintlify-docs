Photos da a tu hogar una única biblioteca de fotos y vídeos en un host que tú operas. Immich ejecuta la biblioteca, y sus apps móviles suben las imágenes desde tus teléfonos. El catálogo de la versión llama a este caso de uso Photos and Memories y lo entrega como el workload opcional `photos`.

## Elige el host

- Usa [Basement Kit](/es/stackkits/kits/basement-kit) para hardware local y acceso orientado a la LAN.
- Usa [Cloud Kit](/es/stackkits/kits/cloud-kit) para un VPS o un host en la nube existente con un dominio que controlas.

## Planifica el almacenamiento y la recuperación

Las fotos y los vídeos suelen convertirse en el mayor conjunto de datos de un homelab. Planifica el almacenamiento y las copias de seguridad antes de importar una biblioteca familiar.

- Dimensiona el almacenamiento principal y el de copias de seguridad para el crecimiento de fotos y vídeos.
- La recuperación necesita tanto las fotos y los vídeos originales como la base de datos de Immich. Una de las dos partes por sí sola no es una restauración completa.
- Practica una restauración preparada antes de que la biblioteca sea la única copia de tus fotos. Consulta [Copia de seguridad y restauración](/es/guides/stackkits/back-up-and-restore).

## Configúralo

Selecciona el workload y completa el primer uso en la página de [Immich](/es/stackkits/apps/immich). Después conecta cada teléfono con [Copia de seguridad de fotos desde tu teléfono](/es/guides/stackkits/use-cases/photos/phone-backup) y comprueba que llega una foto de prueba.
