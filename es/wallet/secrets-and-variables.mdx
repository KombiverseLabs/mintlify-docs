Abre **Ajustes** en tu panel de kombify y elige **Claves y conexiones**. La
sección **Wallet** muestra tus elementos. La sección **Claves de API** que hay
debajo es independiente: contiene claves de la API de herramientas de kombify,
no elementos de Wallet.

## Añadir un elemento

1. Selecciona **Añadir elemento**.
2. Elige el **Tipo**. El formulario muestra entonces los campos de ese tipo.
3. Escribe un **Nombre**. Se muestra en las listas, así que no pongas nunca en
   él el secreto. La descripción es opcional.
4. Elige el **Ámbito**.
5. Selecciona **Guardar en Wallet**.

Tu navegador cifra el valor antes de enviarlo. Un valor puede ocupar hasta
64 KiB.

| Tipo | Campos |
| --- | --- |
| **Clave de API, token o certificado** | **Valor secreto** |
| **Inicio de sesión** | **Nombre de usuario**, **Contraseña** y, opcionalmente, **Secreto para códigos de un solo uso** |
| **Variable** | **Nombre de la variable** y **Valor** |
| **Configuración** | **Nombre de la configuración** y **Documento** |
| **Acceso a servidor** | **Host**, **Usuario** y un **Método de acceso**: **Clave privada SSH** o **Contraseña** |
| **Autoridad de certificación SSH** | Consulta [Certificados SSH](/es/wallet/ssh-certificates) |

## Ámbitos

El **Ámbito** decide dónde se aplica un elemento:

- **Toda la cuenta** se aplica en todas partes.
- **Un proyecto** necesita un **ID del proyecto**.
- **Un entorno de un proyecto** necesita un **ID del proyecto** y un
  **Entorno**.

Los ID de proyecto y los entornos usan letras, dígitos, puntos, guiones y
guiones bajos, hasta 64 caracteres. Cuando existen variables o configuraciones
con el mismo nombre en varios ámbitos, el entorno prevalece sobre el proyecto y
el proyecto sobre la cuenta.

## Nombres de variables y de configuraciones

Tus herramientas buscan una variable o una configuración por su nombre. Un
nombre es único dentro de un ámbito.

- Un **Nombre de la variable** usa mayúsculas, dígitos y guiones bajos, no
  empieza por un dígito y tiene hasta 128 caracteres, por ejemplo
  `DATABASE_URL`.
- Un **Nombre de la configuración** usa minúsculas, dígitos, puntos, guiones y
  guiones bajos, empieza por una letra o un dígito y tiene hasta 128 caracteres,
  por ejemplo `app.env`.

## Hacer que una variable apunte a un secreto

Para guardar un secreto en un solo lugar, pon como valor de una variable
`secret://personal/<item ID>` en vez de copiar el secreto en ella. Cuando se lee
la variable, por ejemplo con `kombify-wallet run`, Wallet sustituye ese valor
por el valor actual del elemento. El elemento debe ser de un tipo distinto de
variable o configuración y estar en tu propia Wallet.

Si el elemento no existe, está revocado o es de solo uso, la lectura de las
variables falla en lugar de devolver un resultado parcial. Un listado de
variables nunca muestra el secreto. `kombify-wallet list` muestra los ID de los
elementos; consulta [la línea de comandos](/es/wallet/cli).

## Mostrar un valor

Selecciona **Mostrar** en un elemento. El valor se descifra en tu navegador, se
muestra solo allí y se vuelve a ocultar tras 30 segundos. Mientras está abierto
puedes usar **Ver**, **Ocultar** y **Copiar**. Cada vez que se muestra queda
registrado.

**Mostrar** no está disponible para un valor de solo uso ni para una autoridad
de certificación SSH. Consulta [Valores de solo uso](/es/wallet/use-only-values).

## Sustituir un valor

Selecciona **Nueva versión**, escribe el nuevo valor y selecciona **Guardar
nueva versión**. El nuevo valor pasa a ser la versión actual, y **Mostrar** la
enseña. Una autoridad de certificación SSH no tiene versiones nuevas; la
sustituyes por una autoridad nueva.

## Revocar o eliminar

- **Revocar** deja el elemento en la lista como **Revocado**. Ya no se puede
  mostrar ni usar. No se puede deshacer; añade un elemento nuevo para
  sustituirlo.
- **Eliminar** con **Eliminar definitivamente** borra el valor y todas sus
  versiones. Tampoco se puede deshacer.

Si un mensaje indica que un registro de auditoría aún se está escribiendo, el
cambio está guardado y el registro llegará en breve.
