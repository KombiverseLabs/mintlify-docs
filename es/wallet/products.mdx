Algunos productos de kombify trabajan por ti mientras estás fuera: sincronizan
tu correo, llaman a un proveedor o gestionan tus servidores. Cuando un producto
necesita una clave o un inicio de sesión de tu Wallet, le asignas ese elemento.
Un producto nunca recibe tus demás elementos.

## Asignar un elemento a un producto

1. Abre **Ajustes** y elige **Claves y conexiones**.
2. En la sección **Wallet**, selecciona **Productos** en el elemento.
3. Activa los derechos que quieras para cada producto.

Los tres derechos son los mismos que para los [agentes](/es/wallet/agents):
**Usar**, **Leer** y **Gestionar**. Cada uno se concede por separado.

| Producto | Qué hace por ti |
| --- | --- |
| kombify Techstack | Planifica y ejecuta tus servidores y stacks. |
| Paperwork | Se ocupa de tu correo, tus documentos y tus tareas. |
| Plataforma kombify AI | Ejecuta funciones de IA y agentes por ti. |
| kombify Simulate | Ejecuta simulaciones de tus configuraciones. |
| kombify Cloud | Se ocupa de las funciones de tu cuenta de kombify Cloud. |

## Lo que un producto puede y no puede hacer

- Un producto usa solo los elementos que le asignaste. Actúa según tu
  asignación permanente, así que no hace falta que tengas la sesión iniciada.
- Con **Usar**, un producto hace llamadas con el elemento, pide certificados a
  una autoridad de certificación SSH o recibe el valor para un único uso que su
  trabajo necesita, por ejemplo sincronizar el correo.
- Un producto nunca recibe un valor de solo uso. Solo puede hacer llamadas con él
  mediante sus [destinos de uso](/es/wallet/use-only-values).
- Un producto nunca recibe la clave de una autoridad de certificación SSH.
- Da **Gestionar** solo para un elemento que el producto mantiene al día por sí
  mismo, como una conexión cuyo token rota el proveedor. Permite que el producto
  guarde versiones nuevas de ese elemento.
- Cada uso queda registrado, igual que para ti y tus agentes.

## Dejar que un producto añada elementos

Algunos productos pueden trasladar a tu Wallet un secreto que ya guardas.
Selecciona **Productos que añaden elementos**, encima de la lista, y activa
**Puede añadir elementos** para cada producto que permitas. Un elemento que añade
un producto se le asigna a ese producto para que pueda usarlo. El producto sigue
usando solo los elementos que le asignas.

## Retirar el acceso

Desactiva el derecho. Se aplica desde la siguiente operación del producto, y una
operación que ya estaba permitida dura como máximo alrededor de un minuto. Si el
producto ha recibido el valor de un elemento, añade después una versión nueva del
elemento. Wallet todavía no marca por sí sola el elemento para sustituirlo.
