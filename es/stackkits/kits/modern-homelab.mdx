Modern Homelab describe un homelab que abarca un entorno Home y un entorno
Cloud. Su definición mantiene el control y la autoridad de datos
predeterminada en Home y exige conexiones y publicación declaradas
explícitamente entre ubicaciones.

<Warning>
  Modern Homelab es un archivo de definición alfa sin una vía de instalación
  compatible. Puedes inicializarlo, validarlo y generarlo con la CLI
  publicada. Descargar su archivo no establece una conexión funcional entre
  hosts, un acceso protegido a las aplicaciones ni la recuperación entre
  ubicaciones. Usa Basement Kit o Cloud Kit para una guía de instalación
  existente.
</Warning>

## Qué contiene el archivo alfa

El [release público de StackKits](https://github.com/kombifyio/StackKits/releases/latest)
incluye archivos de definición de Modern Homelab junto con la CLI. Describen
los sites previstos, la ubicación de las aplicaciones, las conexiones y los
límites de autoridad. Revisa el `release-evidence.json` del release para ver la
evidencia de runtime que realmente está adjunta a esa versión.

La [guía de instalación solo de la cadena de herramientas](/es/guides/stackkits/choosing-a-kit#instala-solo-la-cadena-de-herramientas)
explica cómo descargar la CLI y las definiciones de Modern. Un despliegue
completo de Modern sigue necesitando un comportamiento concreto de conexión,
identidad, enrutamiento, TLS y fallo de ubicación. Una configuración o un plan
generado por sí solos no verifican esos comportamientos.

## Elige una vía de entrada

Elige [Basement Kit](/es/stackkits/kits/basement-kit) para un host Linux
existente en casa, o [Cloud Kit](/es/stackkits/kits/cloud-kit) para un host en
la nube existente con un dominio que controles. Sus guías mantienen separados el
arranque de la configuración y la evidencia de runtime específica del release.

Mantén la misma distinción al explorar Modern: protege los datos existentes y
conserva la configuración y la salida de operación de cada workspace. No des
por sentado que una aplicación sigue disponible durante una caída de la
conexión o de Cloud hasta que el release seleccionado tenga evidencia de ese
comportamiento.

Consulta [Elige un StackKit](/es/guides/stackkits/choosing-a-kit) para ver todas
las vías de entrada y la [compatibilidad de entrega de aplicaciones](/es/stackkits/reference/application-delivery-compatibility)
para las capacidades declaradas por los adaptadores de aplicación publicados.
