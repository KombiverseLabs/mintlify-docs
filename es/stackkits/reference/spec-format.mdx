La StackSpec es la entrada de configuración de un workspace de StackKits. No coloques en la StackSpec credenciales de proveedor, secretos en texto plano, detalles de adquisición de servidores ni estado de despliegue generado.

La CLI instalada establece `apiVersion` a partir de su contrato CUE integrado. Conserva ese valor generado al editar el documento. Sus grupos de intención principales son:

- `metadata`, `kit` y `source` para la identidad y el linaje
- `install` y `generation` para el ciclo de vida y la estrategia de salida
- `storage`, `container` y `network` para la intención del runtime local
- `sites`, `nodes` y `controlPlane` para la ubicación
- `capabilities`, `workloads` y `modules` para las selecciones gobernadas
- `backupPolicy` y `driftPolicy` para la política de evidencia

Consulta [Configurar una StackSpec](/es/guides/stackkits/configure-stack-spec) para ver extractos validados por release.

Consulta [CUE y StackKits](/es/stackkits/explanations/cue-architecture) para el modelo de validación.
