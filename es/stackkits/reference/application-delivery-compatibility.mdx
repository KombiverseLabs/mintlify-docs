<Note>
Las ejecuciones del ciclo de vida de v0.46.6 aún no están proyectadas; las filas muestran v0.39.7, el release proyectado más reciente.
</Note>

El estado y las capacidades los declara [v0.46.6](https://github.com/kombifyio/StackKits/releases/tag/v0.46.6). La columna **Prueba del ciclo de vida** se proyecta a partir de las ejecuciones automatizadas del ciclo de vida de StackKits [v0.39.7](https://github.com/kombifyio/StackKits/releases/tag/v0.39.7):

- `supported`: Todas las fases del ciclo de vida se superaron en la ejecución más reciente sobre este release.
- `preview`: De install a verify se superó en la ejecución más reciente; una fase posterior falló.
- `unverified`: Aún no hay una ejecución completada en este release, o la ejecución más reciente falló antes de verify.
- no probado: Ninguna ejecución automatizada del ciclo de vida cubre aún este caso de uso en este adaptador.
