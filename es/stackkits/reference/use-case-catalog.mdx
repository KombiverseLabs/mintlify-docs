Esta página se genera a partir del [release v0.50.3](https://github.com/kombifyio/StackKits/releases/tag/v0.50.3) publicado. Lista cada caso de uso que declara ese release, agrupado por caso de uso principal, con su propósito, sus componentes y su app predeterminada. Un componente declarado no es evidencia de una instalación ni de una ejecución verificada en un host; la [compatibilidad de SO](/es/stackkits/reference/os-compatibility) contiene las calificaciones verificadas del ciclo de vida. [Casos de uso](/es/guides/stackkits/use-cases/overview) ofrece la vista general de las guías de configuración.

## Correo

### Correo privado

Webmail privado mediante Roundcube para un buzón que ya tienes en un proveedor externo. No se crea ningún servidor de correo, DNS ni registro MX.

Guía: [Abrir la guía](/es/guides/stackkits/use-cases/mail)

| Componente | Función | Tipo | Predeterminado |
| --- | --- | --- | --- |
| kombify Paperwork (`paperwork`) | alternativa | conector |  |
| Roundcube Webmail (`roundcube`) | principal | aplicación | ✓ |

### Servidor de correo propio

Tu propio servidor de correo en un nodo Cloud dedicado mediante Stalwart: buzones para tu dominio con SMTP, IMAP y submission. StackKits muestra los registros DNS que debes publicar; nunca modifica el DNS.

Guía: [Abrir la guía](/es/guides/stackkits/use-cases/mail)

| Componente | Función | Tipo | Predeterminado |
| --- | --- | --- | --- |
| mailcow (`mailcow`) | alternativa | aplicación |  |
| Stalwart Mail Server (`stalwart`) | principal | aplicación | ✓ |
