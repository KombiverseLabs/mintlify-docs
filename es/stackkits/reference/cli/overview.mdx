Configura y mantén tus propios servicios con StackKits portables. Estas páginas listan cada comando de `stackkit` con sus flags y ejemplos. Se generan a partir de las definiciones de comandos de StackKits; si tu versión instalada es anterior, `stackkit <command> --help` es la fuente autorizada para ella.

## Instala la CLI

```bash
curl -sSL https://install.stackkit.cc | STACKKIT_CLI_ONLY=1 sh
```

Con `STACKKIT_CLI_ONLY=1` el instalador coloca `stackkit`, `stackkit-server`, `stackkit-mcp`, OpenTofu empaquetado y el catálogo público de kits en `~/.stackkits` sin instalar ningún StackKit. Sin esa variable, el instalador detecta el host y continúa con Basement Kit o Cloud Kit.

## Flags globales

Estos flags funcionan con todos los comandos.

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--chdir, -C` | string | `.` | Cambia al directorio indicado antes de ejecutar |
| `--correlation-id` | string | — | ID de correlación validado de quien llama, registrado en la evidencia local del despliegue |
| `--no-log` | bool | — | Desactiva el registro estructurado del despliegue |
| `--progress-jsonl` | string | — | Escribe el progreso del despliegue en JSONL redactado y legible por máquinas en una ruta, o '-' para stdout |
| `--quiet, -q` | bool | — | Suprime la salida no esencial |
| `--spec, -s` | string | `stack-spec.yaml` | Ruta al archivo de especificación del stack (se acepta kombination.yaml cuando falta el predeterminado) |
| `--verbose, -v` | bool | — | Activa la salida detallada |
