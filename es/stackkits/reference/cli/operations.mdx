Lista los contratos canónicos de operaciones del ciclo de vida independiente.

```bash
stackkit operations [flags]
```

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--json` | bool | — | Emite los contratos de operaciones como JSON |

**Ejemplos**

```bash
# List each lifecycle operation, its access level, and what it does
stackkit operations

# The same contracts as JSON
stackkit operations --json
```
