Adopta aplicaciones existentes con soporte sin sustituir sus cuentas ni sus datos.

```bash
stackkit application [flags]
```

Subcomandos: [`stackkit application adopt`](#stackkit-application-adopt), [`stackkit application control`](#stackkit-application-control), [`stackkit application inspect`](#stackkit-application-inspect), [`stackkit application release`](#stackkit-application-release), [`stackkit application verify`](#stackkit-application-verify)

## stackkit application adopt

Vincula la aplicación existente revisada a su ciclo de vida declarado.

```bash
stackkit application adopt [workload] [flags]
```

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--container-id` | string | — | ID exacto e inmutable del contenedor Docker, de 64 caracteres |
| `--json` | bool | — | Emite la evidencia de aplicación versionada y sin secretos |
| `--operation-id` | string | — | Identificador estable de la operación para reanudarla de forma idempotente |
| `--owner-approve` | bool | — | Aprueba esta operación exacta de la aplicación vinculada al propietario |
| `--owner-file` | string | `.stackkit/setup/home-assistant-owner.json` | Archivo privado existente de concesión del propietario, relativo al workspace, que contiene accessToken |
| `--plan-digest` | string | — | Digest exacto del plan de adopción revisado y vinculado a la fuente |
| `--workload` | string | — | Carga de trabajo exacta de la aplicación seleccionada (alternativa a la carga de trabajo posicional) |
