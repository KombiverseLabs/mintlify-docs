Gestiona la custodia local de secretos ligada al propietario.

```bash
stackkit secrets [flags]
```

Subcomandos: [`stackkit secrets materialize`](#stackkit-secrets-materialize), [`stackkit secrets reveal`](#stackkit-secrets-reveal)

## stackkit secrets materialize

Establece la custodia de las referencias a secretos de la StackSpec actual.

Establece o reutiliza la custodia local ligada al propietario para cada referencia secret:// de la StackSpec canónica actual.

Ejecuta este paso explícito e idempotente después de añadir un workload a un workspace independiente existente y antes de generate/apply. Nunca imprime referencias ni material secreto y nunca reemplaza una custodia inválida o ajena.

```bash
stackkit secrets materialize [flags]
```

**Ejemplos**

```bash
# After adding a workload to stack-spec.yaml, create its secrets, then roll out
stackkit secrets materialize
stackkit generate
stackkit apply
```

## stackkit secrets reveal

Imprime un secreto de workload seleccionado desde la custodia local del propietario.

Imprime el valor existente de un slot de secreto declarado por un workload seleccionado en la StackSpec actual válida para CUE. La salida contiene material secreto; úsala solo en un terminal privado o en un pipe intencionado. Ningún valor se escribe en los logs de despliegue ni en los recibos.

```bash
stackkit secrets reveal [flags]
```

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--slot` | string | — | **Obligatorio.** Slot de secreto del workload declarado |
| `--workload` | string | — | **Obligatorio.** ID del workload seleccionado |

**Ejemplos**

```bash
# Print the Photos database password from local owner custody
stackkit secrets reveal --workload photos --slot database-password
```
