Inspecciona las acciones explícitas del ciclo de vida de transacciones de salida de Architecture v2.

```bash
stackkit output-transaction [flags]
```

Subcomandos: [`stackkit output-transaction gc-retired`](#stackkit-output-transaction-gc-retired)

## stackkit output-transaction gc-retired

Inspecciona o recolecta explícitamente la lápida de una transacción de salida retirada.

```bash
stackkit output-transaction gc-retired [flags]
```

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--action` | string | — | Acción exacta informada por una inspección previa |
| `--apply` | bool | — | Ejecuta la acción repetida; la inspección es lo predeterminado |
| `--transaction-id` | string | — | **Obligatorio.** ID exacto de la transacción en minúsculas |
