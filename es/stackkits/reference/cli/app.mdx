Inspecciona la entrega de aplicaciones de StackKits y gestiona los traspasos v0.6.

Inspecciona la matriz gobernada de entrega de aplicaciones de Architecture v2 para Coolify, Komodo y Compose independiente.

Los metadatos opcionales de traspaso a PaaS del cliente solo siguen disponibles en la línea de compatibilidad explícita de StackSpec v0.6. Architecture v2 no tiene un mapeo arbitrario de workloads del cliente; las aplicaciones propias de StackKit provienen del catálogo CUE, mientras que el estado deseado de los workloads del cliente pertenece a Techstack.

```bash
stackkit app [flags]
```

Subcomandos: [`stackkit app compatibility`](#stackkit-app-compatibility)

## stackkit app compatibility

Muestra la matriz gobernada de soporte de aplicaciones y adaptadores.

Muestra las filas de soporte inmutables, propiedad de CUE, para las aplicaciones de StackKits. Informa de la capacidad del producto, no del plan seleccionado, de la disponibilidad en vivo del adaptador ni de la evidencia de despliegue.

```bash
stackkit app compatibility [flags]
```

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--json` | bool | — | Imprime la matriz de compatibilidad como JSON |

**Ejemplos**

```bash
# Show which applications each runtime adapter supports
stackkit app compatibility

# The same matrix as JSON
stackkit app compatibility --json
```
