Muestra el estado del despliegue.

Muestra el estado actual del despliegue de StackKit.

```text
Shows:
  • Deployment state (running, degraded, error)
  • Service statuses and health
  • Resource usage
  • URLs and endpoints
```

```bash
stackkit status [flags]
```

| Flag | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `--http` | bool | — | Sondea las rutas de servicio verificadas desde este host verificador |
| `--inventory` | string | — | Inventory observado de Architecture v2 utilizado para identificar un entorno de ejecución de procesos Standard configurado |
| `--json` | bool | — | Genera la salida como JSON |
| `--resolved-plan` | string | — | ResolvedPlan canónico de Architecture v2 (predeterminado: deploy/.stackkit/resolved-plan.json) |

**Ejemplos**

```bash
# Show status
stackkit status

# Output as JSON
stackkit status --json
```
