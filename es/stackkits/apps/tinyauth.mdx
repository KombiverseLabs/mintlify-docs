TinyAuth es el punto de entrada de forward-auth predeterminado del catálogo publicado de StackKits. Normalmente aparece en `auth.<domain>` y usa la configuración local del propietario de PocketID para las rutas protegidas.

Tras un despliegue correcto, abre la dirección generada, completa la configuración local del propietario y verifica que una ruta protegida redirige por la vía de inicio de sesión esperada.

Si una ruta entra en bucle o se salta la autenticación, compara primero el nombre de host solicitado con la ruta generada y confirma que el propietario local de PocketID puede autenticarse. No cambies una aplicación solo para esquivar un problema de enrutamiento o de configuración del propietario.

Consulta [PocketID](/es/stackkits/apps/pocketid) para el componente de identidad local.
