kombify Point DNS se distribuye como contrato de módulo publicado para una zona DNS local, pero la StackSpec v2 nativa inicial no expone ninguna guía pública actual para habilitarlo.

Úsalo solo para una configuración de resolutor de LAN que operes tú. El DNS público sigue siendo responsabilidad de tu propio proveedor de DNS y de la configuración de tu dominio.

No inventes un objeto de habilitación a partir de ejemplos anteriores. Cuando una StackSpec publicada exponga el módulo, prueba los nombres generados solo desde clientes configurados deliberadamente para usar ese resolutor.
