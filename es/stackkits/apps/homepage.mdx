Homepage se distribuye como contrato de módulo publicado, pero la StackSpec v2 nativa inicial no lo selecciona. El Node Hub es el punto de entrada central generado actual.

Su función prevista es la navegación diaria. Usa el Node Hub y la salida de la CLI para el estado del primer arranque, el material de recuperación y los detalles de verificación.

No inventes una selección del módulo Homepage a partir de un esquema anterior. Si una futura StackSpec lo expone, usa solo los campos validados del release instalado y la ruta generada.
