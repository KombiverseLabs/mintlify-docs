Coolify es una plataforma de aplicaciones y un adaptador de workloads opcionales. Selecciónalo de forma explícita cuando quieras que Coolify gestione tus aplicaciones. El workspace independiente predeterminado usa Compose directamente.

| Rol | Comportamiento del catálogo publicado |
| --- | --- |
| Selección | Integración explícita opcional; Compose independiente no necesita una plataforma de aplicaciones |
| Adaptador de workloads | Compatible con `files`, `photos` y `vault` |
| Evidencia de ruta y TLS | Compatible |
| Copia de seguridad y restauración de workloads | No las proporciona el adaptador de Coolify |

## Úsalo con seguridad

1. Completa y verifica el despliegue de StackKits antes de abrir la plataforma de aplicaciones.
2. Abre la URL de Coolify generada desde el Node Hub o desde la salida de StackKits.
3. Usa una sola vía de entrega de aplicaciones por workload; no crees a mano rutas generadas que compitan entre sí.
4. Mantén las credenciales de la aplicación y el material de recuperación bajo el control del Owner local.
5. Usa la vía de copia de seguridad de StackKits solo donde el adaptador seleccionado declare compatibilidad con copia de seguridad y restauración.

## Verifica

- La ruta de Coolify generada se abre en la dirección que indica el despliegue.
- La verificación de StackKits informa de que la plataforma de aplicaciones y sus rutas configuradas están en buen estado.
- El workspace de StackKits sigue siendo la fuente de la intención de configuración.

Para la alternativa beta, consulta [Komodo](/es/stackkits/apps/komodo). Para la matriz completa de adaptadores, consulta [Entrega de aplicaciones](/es/guides/stackkits/application-delivery).
