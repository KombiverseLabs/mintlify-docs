---

Uptime Kuma se distribuye como contrato de módulo publicado, pero la StackSpec v2 nativa inicial no lo selecciona. No deduzcas un conjunto de monitores activo solo a partir del archivo.

Añade monitores solo para servicios que operes. En las rutas protegidas, usa un endpoint de salud intencionado o espera la respuesta de autenticación configurada; no debilites la protección de una ruta solo para que un monitor devuelva HTTP 200.

No hay un ejemplo de configuración de Uptime Kuma compatible para la StackSpec inicial. El ciclo de vida de StackKits sigue siendo la fuente de la verificación del stack aunque operes un monitor aparte; [Monitorizar el stack](/es/stackkits/reference/day-2-operations#monitorizar-el-stack) lista las comprobaciones que debes ejecutar.
