[Coolify](https://coolify.io) es una plataforma autoalojable de código abierto
para desplegar aplicaciones, bases de datos y servicios en tus propios
servidores. Conectas un servidor por SSH y Coolify construye, despliega y
actualiza tus aplicaciones desde una interfaz web. También ofrece una
biblioteca de servicios en un clic.

## Cómo encajan

kombify y Coolify hacen trabajos distintos. Coolify es una plataforma de
aplicaciones. kombify es una capa al lado y por encima de ella. kombify define
el homelab: identidad, política de acceso, enrutamiento, copias de seguridad y
actualizaciones. Coolify es una forma de construir y desplegar tus propias
aplicaciones sobre ese homelab.

## El estado actual de la integración

La integración está en desarrollo.

- StackKits puede instalar Coolify como plataforma opcional, seleccionada
  explícitamente. Nunca forma parte del espacio de trabajo predeterminado.
  Consulta [Coolify](/es/stackkits/apps/coolify).
- El caso de uso Marketplace, una tienda de aplicaciones en tu homelab con
  Coolify como motor, es un borrador. La prueba en tiempo de ejecución, la
  copia de seguridad y restauración, y la aceptación completa en la versión
  actual están pendientes.
- El adaptador de Coolify no proporciona copia de seguridad y restauración de
  cargas de trabajo para todas las cargas. Consulta la
  [compatibilidad de entrega de aplicaciones](/es/stackkits/reference/application-delivery-compatibility).
- Las aplicaciones que instalas desde la propia tienda de Coolify pertenecen a
  Coolify y a ti. kombify no es propietaria de ellas.

Esto describe el encaje previsto. No lo leas como una función de producto ya
publicada.

## Qué hace bien Coolify

- Desplegar desde un repositorio Git con pasos de compilación.
- Ejecutar bases de datos y servicios junto a tus aplicaciones.
- Gestionar varios servidores desde una sola interfaz.
- Acceder a una amplia biblioteca de servicios listos para usar.

Para construir y desplegar tus propias aplicaciones, Coolify es la herramienta
adecuada hoy.

## Límites de kombify hoy

- kombify es anterior a 1.0 y publica versiones con frecuencia.
- La compatibilidad sigue verificándose. Consulta la
  [compatibilidad de SO](/es/stackkits/reference/os-compatibility) para ver las
  filas actuales.
- La instalación necesita un host Linux preparado y un comando. No hay imagen
  de arranque.
- Incorporar tu propio proyecto Compose bajo el inicio de sesión, el
  enrutamiento y la copia de seguridad del homelab no está implementado.
- El catálogo está curado y aparece en el
  [catálogo de casos de uso](/es/stackkits/reference/use-case-catalog).

## Qué hace kombify hoy

- Inicio de sesión con passkeys mediante Pocket ID, sin contraseñas por
  defecto.
- Una política de acceso explícita por servicio.
- Restauración en una copia de pruebas aislada.
- Actualizaciones que toman primero una instantánea.
- Planificar, aplicar y verificar desde una definición.
- Un servidor MCP local en cada instalación para tu propio agente de IA.

## Úsalos juntos

Define el homelab con kombify y usa Coolify para tus propias aplicaciones sobre
él. Usa una sola vía de entrega por carga de trabajo para que Coolify y kombify
no creen rutas enfrentadas. Si solo necesitas desplegar aplicaciones y ya
gestionas el host tú mismo, Coolify por sí solo es suficiente.
