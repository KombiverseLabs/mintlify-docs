# Documentación de kombify

Esta documentación pública cubre el estándar publicado de homelab StackKits,
la beta actual de Homelab incluidas las direcciones públicas kombify.me,
kombify Cloud (la parte de cuenta a la que se puede conectar un homelab),
kombify AI y el framework de voz SpeechKit. Cada área de producto indica qué
artefactos son públicos y qué funciones siguen en vista previa.

<Info>
StackKits y SpeechKit tienen versiones públicas independientes. Homelab ya
cuenta con una Beta de código abierto sin firmar para Windows, pensada para la
orquestación local sin cuenta.
</Info>

## Autoridad de las versiones

Las instrucciones basadas en versiones enlazan al artefacto público actual y no
a una versión congelada, de modo que un enlace de descarga de aquí siempre lleva
a la última versión publicada. Cuando una página indica una versión, esa línea
se genera a partir de la versión publicada y se concilia automáticamente. Las
funciones en vista previa se etiquetan por separado y no reciben pasos de
descarga o instalación inventados.

<Note>
Esta documentación excluye deliberadamente la infraestructura interna de
desarrollo, los detalles de implementación privados y las promesas de producto
no compatibles.
</Note>
