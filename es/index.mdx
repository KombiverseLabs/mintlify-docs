# Documentación de kombify

Esta documentación pública cubre el estándar de homelab StackKits publicado, el framework de
voz SpeechKit y la versión Alfa actual de Techstack, incluidas las direcciones públicas de
kombify.me. Cada área de producto indica qué artefactos están disponibles públicamente y qué
capacidades siguen siendo preliminares.

<Info>
StackKits y SpeechKit tienen versiones públicas independientes. Techstack ofrece ahora una
versión Alfa de código abierto para Windows, sin firma y sin necesidad de una cuenta, destinada
a la orquestación local.
</Info>

## Autoridad de las versiones

Las instrucciones respaldadas por versiones enlazan al artefacto público actual en lugar de a
una versión fija. Así, los enlaces de descarga siempre apuntan a la publicación más reciente.
Cuando una página indica una versión, esa línea se genera a partir de la versión publicada y se
concilia automáticamente. Las funciones preliminares se identifican por separado y no reciben
pasos de descarga o instalación inventados.
