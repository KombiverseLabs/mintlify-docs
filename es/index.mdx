# Documentación de kombify

Esta documentación pública cubre el estándar de homelab StackKits ya publicado,
el framework de voz SpeechKit y la Techstack Alpha actual, incluidas las
direcciones públicas de kombify.me. Cada área de producto indica qué artefactos
están disponibles públicamente y qué funciones siguen siendo una vista previa.

<Info>
StackKits y SpeechKit tienen versiones públicas independientes. Techstack ya
cuenta con una Alpha de código abierto sin firmar para Windows, pensada para la
orquestación local sin cuenta.
</Info>

## Autoridad de las versiones

Las instrucciones basadas en versiones enlazan al artefacto público actual y no
a una versión congelada, de modo que un enlace de descarga de aquí siempre lleva
a la última versión publicada. Cuando una página indica una versión, esa línea
se genera a partir de la versión publicada y se concilia automáticamente. Las
vistas previas de producto se etiquetan por separado y no reciben pasos de
descarga o instalación inventados.
