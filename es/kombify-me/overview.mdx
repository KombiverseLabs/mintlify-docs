kombify.me da a un servicio del homelab un nombre HTTPS estable en
`*.kombify.me`. Es la ruta opcional de ingreso conectado: útil cuando quieres
una dirección pública, y sin usar cuando el stack permanece en la red local.

<Warning>
kombify.me es software Alpha. Los nombres, las cabeceras y la forma de los
errores todavía pueden cambiar. No lo trates como una versión de disponibilidad
general.
</Warning>

En términos cotidianos: una app en tu propio servidor normalmente tiene una
dirección que solo funciona en casa. kombify.me puede darle una dirección web
normal que funciona desde cualquier lugar, con el candado (HTTPS) ya puesto. Tú
decides qué apps reciben una dirección y cuáles permanecen privadas.

## Qué puedes hacer

- Abrir un servicio de un kit en un host `*.kombify.me` cuando el origen ya es
  accesible en internet público.
- Mantener los nombres de kit propios, como `auth`, en
  `{your-lab}-auth.kombify.me`, nunca en un apex reservado como
  `auth.kombify.me`.
- Retransmitir un destino HTTP(S) privado a través del agente de nodo de
  Techstack cuando el origen no es público.

kombify.me no sustituye a StackKits. Un kit local sigue instalándose,
verificándose y ejecutándose sin una dirección de kombify.me.

## Cómo encaja

| Asunto | Responsable |
| --- | --- |
| Definiciones de kits, ciclo de vida local y accesibilidad en la LAN | StackKits |
| Orquestación y el agente de nodo para destinos privados | Techstack |
| Nombres HTTPS públicos, proxy y relay HTTP privado | kombify.me |
| Inicio de sesión para cuentas alojadas de kombify | `login.kombify.io` |

## Por dónde empezar

1. Lee [Pública, privada o redirección: ¿cuál necesito?](/es/kombify-me/public-or-private)
   para elegir el tipo de dirección que coincide con el lugar donde vive tu app.
2. Sigue [Obtén tu primera dirección de kombify.me](/es/kombify-me/get-your-first-address)
   para elegir un nombre, apuntarlo a tu app y activarlo.
3. Si usas un servidor de StackKits, consulta
   [Usa una dirección con un servidor de StackKits](/es/kombify-me/connect-a-stackkits-server).
4. Más adelante, [cambia, pausa o elimina una dirección](/es/kombify-me/change-pause-or-remove-an-address)
   cuando lo necesites.
