Techstack está en desarrollo activo como la experiencia de operador opcional para
StackKits. Su primera Alpha de Windows de código abierto es pública para recibir comentarios
sobre servidores locales; las capacidades conectadas y gestionadas siguen siendo de vista previa.

## En palabras sencillas

Algunas partes de Techstack son públicas hoy y otras siguen en vista previa. Esta
página te dice cuál es cuál, para que elijas una vía que te funcione ahora.

| Superficie | Estado actual |
| --- | --- |
| Resumen del producto y modelo operativo | Documentación pública |
| Acceso alojado en `techstack.kombify.io` | Vista previa; el acceso puede ser limitado |
| Instalador de Windows y paquete de escritorio | Alpha pública sin firmar |
| Distribución anónima del código fuente público | Pública en `kombifyio/TechStack` |
| Operación conectada y gestionada | Vista previa; no es una afirmación de disponibilidad general |
| Nombres HTTPS públicos de kombify.me y relé HTTP privado | Documentación Alpha pública |
| Ciclo de vida independiente de StackKits | Disponible públicamente a través de StackKits |

<Warning>
El paquete de Windows es una Alpha sin firmar, no una versión estable ni lista
para producción. Usa solo el repositorio oficial y verifica el checksum
publicado antes de abrirlo.
</Warning>

## Qué necesitas primero

Para probar la Alpha de Windows necesitas un ordenador con Windows y un servidor en tu red
doméstica. No se requiere cuenta de kombify para la vía local. El acceso a la vista previa
alojada depende de lo que tenga habilitado tu cuenta de kombify.

## Qué esperar

El instalador de Windows no está firmado, por lo que Windows puede mostrar una advertencia de SmartScreen.
Compara el instalador con el checksum publicado antes de continuar. Los servidores
gestionados aparecen solo cuando tu cuenta los tiene habilitados; en caso contrario, la opción sigue
sin estar disponible.

## Qué puedes hacer ahora

- instalar y operar StackKits mediante la
  [guía de inicio rápido pública](/es/stackkits/quickstart)
- [descargar Techstack Alpha para Windows](/es/techstack/install-windows) y usar su
  modo local sin cuenta
- revisar los [modos de operación de Techstack](/es/techstack/operating-modes)
- abrir la [vista previa alojada](https://techstack.kombify.io) si tu cuenta tiene
  acceso
- contactar con el [soporte de kombify](mailto:info@kombify.io) sobre el acceso a la vista previa

## Si algo sale mal

- Si el acceso alojado no te deja entrar, puede que tu cuenta aún no tenga acceso a la
  vista previa. Escribe al [soporte de kombify](mailto:info@kombify.io).
- Si quieres un servidor que funcione hoy, usa en su lugar la
  [guía de inicio rápido de StackKits](/es/stackkits/quickstart).
- Para ver qué opciones desbloquea tu cuenta, lee
  [Servidores gestionados](/es/techstack/managed-servers).

El [repositorio de código abierto](https://github.com/kombifyio/TechStack) es la
autoridad de publicación para el código fuente, los recursos del instalador, los checksums y las actualizaciones Alpha.
