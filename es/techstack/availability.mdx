Techstack está en desarrollo activo como la experiencia de operador opcional
para StackKits. Su primera Windows Alpha de código abierto es pública para
recibir comentarios sobre servidores locales; las capacidades conectadas y
gestionadas siguen siendo de alcance de vista previa.

| Superficie | Estado actual |
| --- | --- |
| Resumen del producto y modelo de operación | Documentación pública |
| Entrada alojada en `techstack.kombify.io` | Vista previa; el acceso puede ser limitado |
| Instalador de Windows y paquete de escritorio | Alpha pública sin firmar |
| Distribución pública anónima del código fuente | Pública en `kombifyio/TechStack` |
| Operación conectada y gestionada | Vista previa; no es una afirmación de disponibilidad general |
| Nombres HTTPS públicos de kombify.me y relay HTTP privado | Documentación Alpha pública |
| Ciclo de vida independiente de StackKits | Disponible públicamente a través de StackKits |

<Warning>
El paquete de Windows es una Alpha sin firmar, no un release estable ni listo
para producción. Usa solo el repositorio oficial y verifica la suma de
comprobación publicada antes de abrirlo.
</Warning>

## Qué puedes hacer ahora

- instalar y operar StackKits con la
  [guía de inicio rápido pública](/es/stackkits/quickstart)
- [descargar la Windows Alpha de Techstack](/es/techstack/install-windows) y usar
  su modo local sin cuenta
- revisar los [modos de operación de Techstack](/es/techstack/operating-modes)
- abrir la [vista previa alojada](https://techstack.kombify.io) si tu cuenta
  tiene acceso
- contactar con el [soporte de kombify](mailto:info@kombify.io) sobre el acceso
  a la vista previa

El [repositorio de código abierto](https://github.com/kombifyio/TechStack) es la
autoridad de release para el código fuente, los recursos del instalador, las
sumas de comprobación y las actualizaciones Alpha.
