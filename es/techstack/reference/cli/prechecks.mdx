## techstack api prechecks get-by-request

Obtiene los resultados de las comprobaciones previas por ID de solicitud.

```bash
techstack api prechecks get-by-request <id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/prechecks/request/{id}` |
| Cambia el estado | No |
| Herramienta MCP | Ninguna |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `<id>` | string | **Obligatorio.** ID del recurso. |
