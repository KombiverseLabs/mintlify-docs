## techstack api addons detect

Detecta automáticamente los complementos aplicables a una especificación.

```bash
techstack api addons detect [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/addons/detect` |
| Cambia el estado | Sí |
| Herramienta MCP | `detect_addons` |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `--body` | json | **Obligatorio.** Cuerpo de la solicitud JSON (`application/json`) como literal, `@path` o `-` para stdin. |

## techstack api addons list

Lista los complementos disponibles.

```bash
techstack api addons list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/addons` |
| Cambia el estado | No |
| Herramienta MCP | `list_addons` |
