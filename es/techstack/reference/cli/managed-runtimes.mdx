## techstack api managed-runtimes authority

Verifica la autoridad de runtime gestionado ligada a la solicitud sin crear ningún recurso.

Preflight de solo lectura de la cadena de autoridad desde el Gateway hasta la admisión nativa. Las solicitudes alojadas deben llevar la decisión `cloud.runtime.credits` `managed_servers`, firmada con v2 por el Gateway, sobre runtime gestionado, Cloud Kit y derecho del proveedor, ligada exactamente a esta solicitud. Una respuesta correcta nunca reserva capacidad ni crea un despliegue de StackKit, un trabajo en cola, un arrendamiento, una proyección de Node ni una operación del proveedor; la solicitud real de Add-Server repite de forma atómica cada comprobación de admisión mutable.

```bash
techstack api managed-runtimes authority [flags]
```
