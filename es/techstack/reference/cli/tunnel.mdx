## techstack api tunnel install-command

Genera el comando de instalación del worker con la URL del túnel.

```bash
techstack api tunnel install-command [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/tunnel/install-command` |
| Cambia el estado | Sí |
| Herramienta MCP | Ninguna |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `--token` | string | **Obligatorio.** |
| `--body` | json | Cuerpo de la solicitud JSON (`application/json`) como literal, `@path` o `-` para stdin. |

## techstack api tunnel subdomains list

Lista los subdominios propios de kombify.me de quien llama para diagnóstico; el registro es propiedad de StackKits.

Requiere quien llama autenticado. Con la identidad compartida de la plataforma, la lista se limita al vínculo de propietario de quien llama.

```bash
techstack api tunnel subdomains list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/tunnel/subdomains` |
| Cambia el estado | No |
| Herramienta MCP | `list_tunnel_subdomains` |
