## techstack api services execute-application-adoption

Ejecuta el plan de origen exacto revisado con aprobación explícita del propietario.

Revalida el digest conservado, la identidad del origen, la revisión y el release. Solo un recibo de custodia autenticado de la CLI fijada establece la pertenencia. Conserva las cuentas, la configuración y los datos persistentes; no crea un runtime nuevo. No admite el traslado a otro Node ni una adopción genérica.

```bash
techstack api services execute-application-adoption [flags]
```

## techstack api services run-action

Pone en cola una acción de servicio de StackKits autorizada por el propietario.

Deriva la autoridad sobre el stack, el servidor, el agente, el kit y el servicio a partir de un inventario canónico actualizado. Las repeticiones exactas convergen mediante un recibo de trabajo duradero; el Idempotency-Key sin procesar nunca se persiste. Las mutaciones van seguidas de una verificación de StackKits antes de que cambie el estado medido. Las acciones ejecutadas por el agente se rechazan con 409 `maintenance_active` mientras el servidor se reinicia o se actualiza.

```bash
techstack api services run-action <service-id> [flags]
```

## techstack api services setup-application-connector

Asegura o revoca un conector Home Assistant propio declarado en su nodo.

Requiere propiedad reciente verificada por el backend, autoridad operate positiva, inventario actual exacto y aprobación del propietario. Solo transporta metadatos de correlación definidos mediante Guard a la CLI publicada fijada; siguen siendo obligatorias su autoridad local signedApply y la autorización de configuración del propietario. Guarda la intención durable antes del envío; ante una confirmación desconocida solo reconcilia la operación original en modo de solo lectura. La v0.51.8 actual carece del catálogo compatible y devuelve SourcePreview no ejecutable. Las credenciales permanecen bajo custodia del nodo.

```bash
techstack api services setup-application-connector [flags]
```

<Warning>Requiere confirmación. Esta operación emite o revoca la credencial revisada del conector Home Assistant propiedad del nodo para este servicio exacto. Pasa `--yes` o responde a la pregunta; una ejecución no interactiva sin `--yes` se detiene antes de cualquier solicitud con el código de salida 9.</Warning>
