## techstack api registry services list

Lista los servicios propios con su catálogo y ubicación canónica.

Los registros del runtime usan la misma proyección de estado, capacidades, versión y bloqueo del propietario que los detalles del servicio. Los registros históricos siguen siendo legibles con estado observado desconocido y sin capacidades de acción no medidas.

```bash
techstack api registry services list [flags]
```
