## techstack api system capabilities

Descubre las capacidades de la API para los clientes.

Devuelve una lista estructurada de todas las capacidades de la API para el descubrimiento programático. Las apps de cliente nativas usan este endpoint para enumerar las acciones disponibles, la autenticación requerida y el comportamiento asíncrono.

```bash
techstack api system capabilities [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/capabilities` |
| Cambia el estado | No |
| Herramienta MCP | Ninguna |

## techstack api system client-bootstrap

Configuración pública de runtime para la SPA estática.

Devuelve la configuración pública no secreta, variable en runtime, del frontend estático integrado (edición, modo de despliegue, interruptores de telemetría). Los valores están vacíos salvo que el operador o quien despliega configure las variables de entorno correspondientes, de modo que los despliegues autoalojados y locales quedan sin telemetría de forma predeterminada.

```bash
techstack api system client-bootstrap [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/client/bootstrap` |
| Cambia el estado | No |
| Herramienta MCP | Ninguna |
