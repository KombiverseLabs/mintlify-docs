## techstack api stackkits get

Obtiene los detalles de un StackKit concreto.

```bash
techstack api stackkits get <name> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/stackkits/{name}` |
| Cambia el estado | No |
| Herramienta MCP | `get_stack_kit` |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `<name>` | string | **Obligatorio.** |
