## techstack api client-pairing issue

Emite un ClientPairingEnvelope v1 de corta duración.

Requiere un administrador de la instancia autenticado. Solo está disponible para una instancia autoalojada con HTTPS que tenga un tenant configurado y una autoridad OIDC nativa. El modo local de un solo propietario falla de forma cerrada.

```bash
techstack api client-pairing issue [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/client-pairing/issue` |
| Cambia el estado | Sí |
| Herramienta MCP | Ninguna |

## techstack api client-pairing redeem

Canjea de forma atómica un código de ClientPairingEnvelope v1.

El cliente verifica la huella del certificado HTTPS antes de enviar esta solicitud. Si tiene éxito, consume el código exactamente una vez y devuelve metadatos públicos para el flujo normal de cuenta OIDC; nunca devuelve una sesión ni duplica la identidad del propietario local.

```bash
techstack api client-pairing redeem [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/client-pairing/redeem` |
| Cambia el estado | Sí |
