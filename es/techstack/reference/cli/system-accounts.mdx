## techstack api system-accounts reset

Restablece la contraseña de una cuenta del sistema.

```bash
techstack api system-accounts reset <role> [flags]
```

| --- | --- |
| HTTP | `POST /api/v1/system-accounts/{role}/reset` |
| Cambia el estado | Sí |
| Herramienta MCP | Ninguna |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `<role>` | string | **Obligatorio.** |
