## techstack api drift results delete

Elimina un resultado de deriva.

```bash
techstack api drift results delete <id> [flags]
```

<Warning>Requiere confirmación. Esta operación elimina de forma permanente el resultado de deriva almacenado. Pasa `--yes` o responde a la pregunta; una ejecución no interactiva sin `--yes` se detiene antes de cualquier solicitud con el código de salida 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/drift/results/{id}` |
| Cambia el estado | Sí |
| Herramienta MCP | `delete_drift_result` |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `<id>` | string | **Obligatorio.** ID del recurso. |
