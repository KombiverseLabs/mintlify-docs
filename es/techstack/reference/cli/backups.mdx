## techstack api backups delete

Elimina una copia de seguridad (solo administradores).

```bash
techstack api backups delete <name> [flags]
```

<Warning>Requiere confirmación. Esta operación elimina de forma permanente el archivo local de la copia de seguridad. Pasa `--yes` o responde a la pregunta; una ejecución no interactiva sin `--yes` se detiene antes de cualquier solicitud con el código de salida 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/backups/{name}` |
| Cambia el estado | Sí |
| Herramienta MCP | Ninguna |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `<name>` | string | **Obligatorio.** |
