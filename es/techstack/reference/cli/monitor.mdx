## techstack api monitor availability

Disponibilidad, episodios de caída y estado diario, derivados de la línea temporal de transiciones.

Una proyección sobre la línea temporal de transiciones del servidor, de solo anexado, y no un muestreador: cada episodio está delimitado por dos transiciones registradas y lleva los códigos de motivo con los que se escribieron. La respuesta publica su propio vocabulario de contabilidad, de modo que un lector puede ver qué estados de conexión se contaron como caída sin leer el código fuente.

```bash
techstack api monitor availability [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/monitor/availability` |
| Cambia el estado | No |
| Herramienta MCP | `get_availability_report` |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `--window` | string | Conjunto cerrado; una ventana ilimitada sería un mando para la denegación de servicio. Uno de `24h`, `7d`, `30d`, `90d`. Predeterminado: `"30d"`. |
| `--server-id` | string | Limita el informe a un servidor, para la página de detalle del servidor. |
