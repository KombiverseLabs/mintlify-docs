## techstack api unifier analyze

Analiza una especificación para obtener sus requisitos (fase 1).

Seguro e idempotente. Devuelve los requisitos de hardware, los complementos detectados y las credenciales requeridas.

```bash
techstack api unifier analyze [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/unifier/analyze` |
| Cambia el estado | Sí |
| Herramienta MCP | `analyze_spec` |

| Argumento | Tipo | Descripción |
| --- | --- | --- |
| `--body` | json | **Obligatorio.** Cuerpo de la solicitud JSON (`application/json`) como literal, `@path` o `-` para stdin. |

## techstack api unifier pipeline preview

Previsualiza los resultados del pipeline sin efectos secundarios.

Seguro e idempotente. Muestra lo que se generaría. Los fallos de validación del backend o de resolución del StackKit devuelven 200 con data.valid=false y data.errors estructurado; las entradas mal formadas y los fallos de autenticación siguen siendo errores HTTP.

```bash
techstack api unifier pipeline preview [flags]
```

| --- | --- |
| HTTP | `POST /api/v1/unifier/pipeline/preview` |
