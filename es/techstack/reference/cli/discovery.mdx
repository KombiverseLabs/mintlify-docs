## techstack api discovery cache clear

Vacía la caché de descubrimiento (solo administradores).

```bash
techstack api discovery cache clear [flags]
```

<Warning>Requiere confirmación. Esta operación descarta todos los resultados de descubrimiento en caché; el siguiente descubrimiento vuelve a escanear la red. Pasa `--yes` o responde a la pregunta; una ejecución no interactiva sin `--yes` se detiene antes de cualquier solicitud con el código de salida 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/discovery/cache` |
| Cambia el estado | Sí |
| Herramienta MCP | `clear_discovery_cache` |

## techstack api discovery devices probe

Quienes llaman sin ser administradores solo pueden sondear IP de sus propios resultados de descubrimiento; los administradores pueden sondear cualquier IP.

```bash
techstack api discovery devices probe [flags]
```
