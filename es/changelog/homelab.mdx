### Actualizaciones

- **Techstack Open Core v0.33.5.** El código fuente y el instalador de [Techstack](https://github.com/kombifyio/Homelab) se publican para v0.26.0 y v0.33.5, y la aplicación añade español, chino simplificado, hindi y árabe. Consulta [Descripción general de Techstack](/es/homelab/overview).

<Update label="2026-09-07" description="Direcciones públicas de kombify.me" tags={["Weekly digest"]}>

## Nombres HTTPS públicos de kombify.me

La documentación pública ahora cubre [kombify.me](/es/kombify-me/overview) dentro de Techstack: nombres HTTPS estables para servicios de homelab que ya son accesibles, nombres de kit propios como `{your-lab}-auth.kombify.me` y un relay HTTP privado opcional a través del agente de nodo de Techstack. La navegación solo local permanece en el resolvedor del homelab. kombify.me es Alpha.

</Update>

<Update label="2026-08-21" description="Semana del 15 ago – 21 ago" tags={["Weekly digest"]}>

## Techstack Alpha de código abierto

Techstack ya es público: una Alpha de Windows sin firmar y un cliente de código abierto que puedes instalar en tu propio equipo para operar un servidor local sin una cuenta alojada de kombify.

### Novedades

- **Techstack Alpha para Windows, de código abierto.** El cliente open-core de Techstack ya se publica bajo AGPL-3.0 en [kombifyio/TechStack](https://github.com/kombifyio/Homelab), y la Alpha de Windows sin firmar está disponible para recibir comentarios sobre el servidor local. Techstack es la experiencia opcional de orquestación y operación sobre StackKits, y esta Alpha admite la vía local sin cuenta. Consulta [Resumen de Techstack](/es/homelab/overview), [disponibilidad](/es/homelab/availability) e [Instalar Techstack Alpha en Windows](/es/homelab/install-windows).

</Update>
