El Voice Agent es una conversación hablada en directo. Puedes hacer preguntas de
seguimiento e interrumpir. No escribe en tus apps. Para eso usa Dictation o
Assist. El Voice Agent es una función de Windows. En macOS no está verificado en
la beta actual.

## Antes de empezar

- SpeechKit está instalado y Dictation funciona.
- El Voice Agent está desactivado en una instalación nueva. Lo activas a
  continuación.
- El Voice Agent necesita un proveedor para la conversación en directo, local o en
  la nube. Elígelo teniendo en cuenta los
  [ajustes de privacidad](/es/speechkit/privacy-settings). Un proveedor en la nube
  recibe tu voz.

## Pasos

<Steps>
  <Step title="Activa el Voice Agent">
    En **Settings > Overview**, activa el Voice Agent en la lista **Modes**.
    También puedes abrir **Voice Agent Mode** y habilitar allí su atajo.
  </Step>
  <Step title="Comprueba qué requiere atención">
    **Overview** enumera las claves de proveedor que faltan en **Needs
    attention**. Añade la clave o elige otro proveedor.
  </Step>
  <Step title="Inicia una conversación">
    El atajo por defecto es `Ctrl+Shift`. Mantenlo pulsado, habla y suéltalo.
    También puedes iniciar y detener el agente con los botones **Start voice
    agent** y **Stop voice agent** de la ventana del Voice Agent.
  </Step>
  <Step title="Haz una pregunta de seguimiento">
    La ventana muestra la conversación. Después de que el agente responda, haz una
    pregunta de seguimiento. Por ejemplo: "help me decide the next release
    slice". Luego interrumpe con otra pregunta de seguimiento.
  </Step>
  <Step title="Termina la sesión">
    Termina la sesión para obtener un resumen. Tras soltar el atajo, el diálogo
    sigue pudiendo reanudarse durante un breve tiempo (la **Resume window**). El
    resumen y el cierre del panel ocurren cuando esa ventana se agota.
  </Step>
</Steps>

## Ajustes que puedes cambiar

Abre **Settings > Voice Agent Mode**.

| Ajuste | Qué hace |
| --- | --- |
| Voice Agent hotkey | La combinación que inicia la conversación. |
| Agent profile | Elige el perfil del agente. |
| Personal refinement prompt | Añade tus propias preferencias, por ejemplo respuestas cortas. |
| Resume window (seconds) | Cuánto tiempo puede reanudarse un diálogo. 0 termina la sesión de inmediato. |
| Pause tolerance (ms) | Las pausas cortas de hasta esta duración no provocan una respuesta. 0 usa el valor por defecto del proveedor. |
| Session summary | Conserva un resumen de la sesión. |
| Closing the window | Elige **Minimise and keep chat** o **End chat on close**. |

Las conversaciones pasadas aparecen en **Library**, en la pestaña de voz.

## Empieza con tu voz

**Hands-Free** puede iniciar un modo con una frase de activación en lugar de un
atajo. Actívalo en **Settings > Hands-Free** con **Enable hands-free
activation**, y luego elige la frase y el destino (**Voice Agent conversation**,
**Assist voice companion** o **Dictation (UI-assisted)**). El audio del micrófono
para la detección de la frase de activación permanece en el dispositivo.
Hands-Free no está disponible en macOS.

## Si algo sale mal

- **El agente no se inicia.** Comprueba que el Voice Agent está activado y que su
  proveedor tiene una clave. Consulta **Needs attention** en **Overview**.
- **Responde demasiado pronto.** Aumenta **Pause tolerance (ms)**.
- **No lo oyes.** Usa el control de salida de altavoz de la ventana del Voice
  Agent para elegir otro altavoz.
- **Sigues atascado.** Consulta [Soluciona los problemas habituales](/es/speechkit/fix-common-problems).
