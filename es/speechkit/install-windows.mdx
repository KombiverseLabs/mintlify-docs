El cliente de escritorio de SpeechKit es compatible con Windows 10 y Windows 11
en sistemas x64. Windows es el destino completo: los tres modos, Hands-Free y
Meeting. Descarga los recursos solo desde la versión oficial de
`kombifyio/SpeechKit`.

{/* speechkit-release:begin */}
La versión pública actual es [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1), publicada el 2026-09-20.
{/* speechkit-release:end */}

## Verifica la descarga

1. Descarga el
   [SHA256SUMS.txt](https://github.com/kombifyio/SpeechKit/releases/latest/download/SHA256SUMS.txt)
   correspondiente.
2. Calcula el hash SHA-256 del instalador o del ZIP con una herramienta de tu
   confianza.
3. Compara el hash completo con la entrada de `SHA256SUMS.txt` antes de abrir
   el paquete.
4. Lee el
   [aviso de versión sin firmar](https://github.com/kombifyio/SpeechKit/releases/latest/download/UNSIGNED-WINDOWS-RELEASE.txt).

<Warning>
La versión gratuita para Windows no está firmada. Windows puede mostrar una
advertencia de reputación. Verifica la suma de comprobación y el origen de la
versión antes de decidir si continúas.
</Warning>

## Primer uso

1. Inicia SpeechKit y selecciona el micrófono que quieres que use.
2. Elige un Network Scope. All networks permite proveedores externos; local
   network only y this device only restringen a qué puede conectarse el backend.
3. Elige un proveedor local o externo adecuado para el modo.
4. Prueba Dictation antes de activar Assist, Voice Agent o Meeting.
5. Revisa qué sale del dispositivo al seleccionar un proveedor externo.

Los atajos de teclado por defecto son `Ctrl+Win` para Dictation, `Win+Alt` para
Assist y `Ctrl+Shift` para Voice Agent. Durante una reunión, `Ctrl+Alt+S`
captura una imagen de la pantalla.
