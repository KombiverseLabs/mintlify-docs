El módulo público de SpeechKit contiene el kernel de voz independiente de la
plataforma. Úsalo cuando tu aplicación deba gestionar su propio proceso,
configuración y credenciales de proveedor en lugar de depender de un servidor
SpeechKit aparte.

{/* speechkit-release:begin */}
La versión pública actual es [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1), publicada el 2026-09-20.
{/* speechkit-release:end */}

## Requisitos

- Go 1.26 o posterior
- una aplicación capaz de proporcionar el micrófono, el audio o la entrada de texto elegidos
- credenciales de proveedor solo cuando elijas un proveedor externo

## Añade el módulo

```bash
go get github.com/kombifyio/SpeechKit@latest
```

`@latest` se resuelve a la última versión publicada. Anota la versión exacta que
resolvió tu compilación y fíjala antes de publicar: es software beta, y las API
públicas, las claves de configuración y los valores por defecto pueden cambiar
entre versiones menores.

Importa solo los paquetes que necesite tu host: `pkg/speechkit/dictation` para
el dictado, `pkg/speechkit/wakeword` para la activación, `pkg/speechkit/tts`
para la salida hablada, `pkg/speechkit/companion` más los adaptadores de Assist
y de texto a voz para hosts de un solo uso, `pkg/speechkit/speaker` para apps
con reconocimiento de hablante, `pkg/speechkit/meeting` para sesiones de
grabación y `pkg/speechkit/client` para apps conectadas a un servidor. El
paquete raíz `speechkit` contiene únicamente contratos y tipos de valor.

Para controlar el framework desde un `config.toml` en lugar de construir los
ajustes a mano, `pkg/speechkit/hostconfig` convierte un archivo de
configuración en los ajustes públicos de los modos y en una política de runtime
inicial con una sola llamada:

```go
settings, policy, err := hostconfig.Load("config.toml")
```

Un archivo ausente produce los valores por defecto incluidos: solo local, sin
claves de nube. El cliente de escritorio delega en el mismo cargador, de modo
que un integrador y la app de referencia leen un `config.toml` de forma idéntica.

Algunos paquetes necesitan cgo (captura de audio en Windows, la palabra de
activación ONNX) o un binario externo (`whisper-server`). Cada uno falla de
forma cerrada con un error centinela cuando falta su dependencia, en lugar de
fingir que funciona.
