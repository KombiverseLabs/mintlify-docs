<Note>
The kombify Wallet is not released yet. This page describes how it works.
</Note>

Open **Settings** in your kombify dashboard and choose **Keys & connections**.
The **Wallet** section lists your items. The **API keys** section below it is
separate: it holds keys for the kombify tool API, not Wallet items.

## Add an item

1. Select **Add item**.
2. Choose the **Type**. The form then shows the fields for that type.
3. Enter a **Name**. It is shown in lists, so never put the secret itself in
   it. A description is optional.
4. Choose the **Scope**.
5. Select **Save to Wallet**.

Your browser encrypts the value before it is sent. A value can be up to 64 KiB.

| Type | Fields |
| --- | --- |
| **API key, token or certificate** | **Secret value** |
| **Login** | **Username**, **Password**, and optionally **One-time code secret** |
| **Variable** | **Variable name** and **Value** |
| **Configuration** | **Configuration name** and **Document** |
| **Server access** | **Host**, **User**, and a **Sign-in method**: **SSH private key** or **Password** |
| **SSH certificate authority** | See [SSH certificates](/wallet/ssh-certificates) |

## Scopes

The **Scope** decides where an item applies:

- **Whole account** applies everywhere.
- **One project** needs a **Project ID**.
- **One environment of a project** needs a **Project ID** and an
  **Environment**.

Project IDs and environments use letters, digits, dots, dashes and
underscores, up to 64 characters. When variables or configurations with the
same name exist in several scopes, the environment wins over the project, and
the project wins over the account.

## Variable and configuration names

Your tools look a variable or configuration up by its name. A name is unique
within one scope.

- A **Variable name** uses capital letters, digits and underscores, does not
  start with a digit, and has up to 128 characters, for example
  `DATABASE_URL`.
- A **Configuration name** uses lowercase letters, digits, dots, hyphens and
  underscores, starts with a letter or digit, and has up to 128 characters,
  for example `app.env`.

## Point a variable at a secret

To keep a secret in one place, set a variable's value to
`secret://personal/<item ID>` instead of copying the secret into it. When the
variable is read, for example by `kombify-wallet run`, the Wallet substitutes
the current value of that item. The item must be of another type than a
variable or configuration, and must be in your own Wallet.

If the item is missing, revoked or use only, reading the variables fails
instead of returning a partial result. A variable listing never shows the
secret. `kombify-wallet list` shows the item IDs; see
[the command line](/wallet/cli).

## Reveal a value

Select **Reveal** on an item. The value is decrypted in your browser, shown
only there, and hidden again after 30 seconds. Use **Show**, **Hide** and
**Copy** while it is open. Every reveal is recorded.

**Reveal** is not offered for a value that is use only or for an SSH
certificate authority. See [Use-only values](/wallet/use-only-values).

## Replace a value

Select **New version**, enter the new value and select **Save new version**.
The new value becomes the current version, and **Reveal** shows it. An SSH
certificate authority has no new versions; you replace it with a new
authority.

## Revoke or delete

- **Revoke** keeps the item in the list as **Revoked**. It can no longer be
  revealed or used. You cannot undo this; add a new item to replace it.
- **Delete** with **Delete permanently** erases the value and all its
  versions. You cannot undo this either.

If a message says an audit record is still being written, the change is saved
and the record follows shortly.
