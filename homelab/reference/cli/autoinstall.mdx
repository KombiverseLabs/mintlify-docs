## techstack api autoinstall run

Install missing dependencies.

Installs the missing host dependencies (OpenTofu, cloudflared, Docker) on the machine a self-hosted kombify Homelab runs on, all of them or the named ones. Only the owner of a self-hosted kombify Homelab may call it, and an agent acts with the owner's reach there; hosted kombify Homelab refuses every caller with 403 `host_install_unavailable` (reason_code `hosted_control_plane`) before anything is detected.

```bash
techstack api autoinstall run [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/autoinstall/install` |
| Changes state | Yes |
| MCP tool | `install_host_dependencies` |

| Argument | Type | Description |
| --- | --- | --- |
| `--dependencies` | string\[\] | Names of the missing dependencies to install; all when omitted. |
| `--body` | json | JSON request body (`application/json`) as a literal, `@path` or `-` for stdin. |
