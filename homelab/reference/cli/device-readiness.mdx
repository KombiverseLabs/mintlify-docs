## techstack api device-readiness prepare

Apply catalog fixes to a not-yet-enrolled device over SSH.

Connects to the named machine over SSH, runs the named catalog resolutions in order (only catalog ids are accepted), optionally opens a temporary egress path while they run, and probes again to report the result. Requires the signed techstack.device.prepare entitlement, and techstack.device.egress when egress is true. Registered only on a local (non-SaaS) control plane. The login comes from the Wallet item connection.wallet_item_id, resolved inside kombify Homelab for this request only. A failing resolution stops the run with 409 and the receipts collected so far.

```bash
techstack api device-readiness prepare [flags]
```

## techstack api device-readiness probe

Look at a not-yet-enrolled device over SSH and report whether it is ready.

Opens one SSH session to the named machine, reads its facts (network, proxy, virtualization, enrollment reachability) and answers a readiness report; nothing on the device changes. The login comes from the Wallet item connection.wallet_item_id, resolved inside kombify Homelab for this request only and never answered or stored. Registered only on a local (non-SaaS) control plane and requires the signed techstack.device.prepare entitlement. Unknown body fields are refused. The first request may omit host_key_fingerprint; the answer then carries the key the device presented so it can be pinned on the next call.

```bash
techstack api device-readiness probe [flags]
```
