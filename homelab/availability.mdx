kombify Homelab is under active development as the optional operator experience for
StackKits. Its first open-source Windows Beta is public for local-server
feedback; connected and managed capabilities remain preview scope.

## In plain words

Some parts of kombify Homelab are public today and some are still a preview. This
page tells you which is which, so you can pick a path that works for you now.

| Surface | Current status |
| --- | --- |
| Product overview and operating model | Public documentation |
| Hosted entry at `homelab.kombify.io` | Beta; access may be limited |
| Windows installer and desktop package | Unsigned Beta |
| Anonymous public source distribution | Public at `kombifyio/TechStack` |
| Connected and managed operation | Preview; not a general-availability claim |
| kombify.me public HTTPS names and private HTTP relay | Beta documentation |
| Standalone StackKits lifecycle | Publicly available through StackKits |

<Warning>
The Windows package is an unsigned Beta, not a stable or
production-readiness release. Use only the official repository and verify the
published checksum before opening it.
</Warning>

## What you need first

To try the Windows Beta you need a Windows computer and a server in your home
network. No kombify account is required for the local path. Hosted Beta access depends on what your kombify account has enabled.

## What to expect

The Windows installer is unsigned, so Windows may show a SmartScreen warning.
Compare the installer with the published checksum before you continue. Managed
servers appear only when your account has them enabled, and the option stays
unavailable otherwise.

## What you can do now

- install and operate StackKits through the
  [public quickstart](/stackkits/quickstart)
- [download kombify Homelab Windows Beta](/homelab/install-windows) and use its
  account-free local mode
- review the [kombify Homelab operating modes](/homelab/operating-modes)
- open the [hosted Beta](https://homelab.kombify.io) if your account has
  access
- contact [kombify support](mailto:info@kombify.io) about hosted Beta access

## If something goes wrong

- If the hosted entry does not let you in, your account may not have access yet. Write to [kombify support](mailto:info@kombify.io).
- If you want a server that works today, use the
  [StackKits quickstart](/stackkits/quickstart) instead.
- To see which options your account unlocks, read
  [Managed servers](/homelab/managed-servers).

The [open-source repository](https://github.com/kombifyio/TechStack) is the
release authority for source, installer assets, checksums, and Beta updates.
