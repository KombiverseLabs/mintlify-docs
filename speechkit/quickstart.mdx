Pick the path that matches how you want to use SpeechKit.

<Tabs>
  <Tab title="Windows Client">
    The fastest way to try SpeechKit on a Windows 10/11 x64 machine.

    <Steps>
      <Step title="Download">
        Get the installer or portable build from [GitHub Releases](https://github.com/kombifyio/SpeechKit/releases). Release assets include SHA-256 hashes.
      </Step>
      <Step title="Set up a provider">
        Open Settings and add at least one provider (local runtime or your own cloud API key). The built-in test bench lets you validate providers and models before using them.
      </Step>
      <Step title="Talk">
        Use the default global hotkeys: `Ctrl+Win` for Dictation, `Win+Alt` for Assist, `Ctrl+Shift` for Voice Agent. Hands-Free wake activation can be enabled in Settings.
      </Step>
    </Steps>

    The client runs local-first on your machine and can optionally delegate work to a SpeechKit Server you operate.
  </Tab>
  <Tab title="Go backend">
    Embed SpeechKit into your own Go application — no server, no desktop app required.

    ```bash
    go get github.com/kombifyio/SpeechKit
    ```

    Import only the components your host needs: a dictation-only app can use `pkg/speechkit/dictation`; wake activation uses `pkg/speechkit/wakeword`; spoken output uses `pkg/speechkit/tts`; one-shot Voice Companion hosts use `pkg/speechkit/companion`; server-connected apps use `pkg/speechkit/client`.

    To drive the framework from a config file instead of building settings by hand:

    ```go
    settings, policy, err := hostconfig.Load("config.toml")
    ```

    Real providers run **in-process** — realtime Voice Agents (for example Gemini Live or OpenAI Realtime) work without a SpeechKit server.
  </Tab>
  <Tab title="Self-host Server">
    Run SpeechKit as a long-lived Linux service for your own clients. One published image exposes all three modes under one URL: Dictation and Assist over REST, Voice Agent over WebSocket.

    ```bash
    # 1. Provide keys for the providers you want to enable (all optional, bring your own)
    export OPENAI_API_KEY="..."      # OpenAI STT/LLM/TTS
    export GOOGLE_AI_API_KEY="..."   # Gemini Assist + Gemini Live
    export DEEPGRAM_API_KEY="..."    # Deepgram STT + diarization
    export ASSEMBLYAI_API_KEY="..."  # AssemblyAI STT + diarization
    export HF_TOKEN="..."            # Hugging Face STT
    export SPEECHKIT_SERVER_TOKEN="replace-with-a-local-dev-token"

    # 2. Start from the published image
    docker compose -f deploy/docker/docker-compose.oss.yml up -d
    ```

    The image is published as `ghcr.io/kombifyio/speechkit-server`. The server reads `/etc/speechkit/config.toml` (start from `deploy/config/server.example.toml`) and takes secrets from environment variables referenced in that config. Health and readiness routes, bearer or edge-auth modes, CORS/origin controls, and an OpenAPI contract are built in.
  </Tab>
</Tabs>
