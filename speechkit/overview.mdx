SpeechKit is kombify's local-first voice framework and runtime. One public
project provides the Go voice kernel, a self-hosted server, agent tools,
Android modules, and desktop clients for Windows and macOS.

{/* speechkit-release:begin */}
The current public release is [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1), published 2026-09-20.
{/* speechkit-release:end */}

SpeechKit is beta software: public APIs, configuration keys, and defaults can
change between minor releases, so pin the version you tested.

## Three modes and one recording service

| Surface | Purpose |
| --- | --- |
| Dictation | Turn speech into text without LLM rewriting. |
| Assist | Turn speech or text into one bounded result, optionally spoken. |
| Voice Agent | Run a realtime audio conversation for interactive work. |
| Meeting | Record a call on two channels and write it up afterwards. |

Hands-Free is an activation and output layer over the three modes, not a
fourth mode. Meeting is a separate recording service that shares only the
speech-to-text transcriber with Dictation.

## Where SpeechKit runs

| Target | Availability |
| --- | --- |
| Windows 10/11 x64 desktop client | Public beta; all three modes, Hands-Free, and Meeting |
| macOS 14+ on Apple Silicon | Dictation-only beta, ad-hoc signed, with known gaps |
| Go framework | Public module; embed the kernel in your own Go host |
| Self-hosted server | Linux target built from public source |
| Android | Apache-2.0 Gradle modules plus an in-repo reference app |
| Browser | TypeScript client and voice UI packages in the public repository |
| Linux desktop | Not available; Linux is a server runtime |

## Privacy boundaries you set

Two independent settings decide what SpeechKit may do:

- **Network Scope** answers where the process may reach: all networks, local
  network only, or this device only. The backend enforces the boundary for
  speech providers, model downloads, updates, telemetry, server connections,
  and integrations. A stricter scope suspends incompatible settings instead of
  deleting them.
- **Retention Scope** answers what outlives the work that produced it: retain,
  or zero retention. Zero retention sweeps the raw material when a session ends
  and keeps only the generated result.

The two are orthogonal. A device-only install still writes transcripts to disk
unless you also choose zero retention.
