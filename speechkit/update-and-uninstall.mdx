This guide covers updating and removing SpeechKit on Windows. For macOS, see
[Install on macOS](/speechkit/install-macos).

## Update SpeechKit

<Steps>
  <Step title="Open the update settings">
    In **Settings**, open **App** and find **Updates**. It shows your installed
    version and when SpeechKit last checked.
  </Step>
  <Step title="Check for updates">
    Select **Check for updates**. If a newer version exists, you see **Update
    available**. **Change log** shows what is new.
  </Step>
  <Step title="Download and install">
    Select **Download**. When it finishes, select **Install and restart**.
    SpeechKit restarts by itself. It never installs or restarts without your
    confirmation.
  </Step>
</Steps>

You can switch on **Download updates automatically**. SpeechKit then fetches and
checks the new version in the background, so installing takes one click.

## Unsigned releases

The free Windows release is unsigned. SpeechKit compares the download with the
SHA-256 checksum published with the release and refuses it if they differ. If a
release has no checksum list, SpeechKit does not start it for you. Use **Open
download page** and run the installer yourself. See
[Install on Windows](/speechkit/install-windows).

If your administrator manages updates, Settings says so. SpeechKit then only
reports that a version exists.

## Uninstall SpeechKit

1. Open the Windows Start menu and find SpeechKit, then choose **Uninstall**.
   You can also remove it from the Windows list of installed apps.
2. The uninstaller asks whether to also remove your user data and
   configuration.
   - Choose **No** to keep your settings and history for a later install.
   - Choose **Yes** to delete them for your Windows account. This removes
     settings, onboarding state, saved keys, your database with transcripts and
     notes, audio, screenshots, wake-word clips and logs.
3. If you used the portable ZIP, close SpeechKit and delete the folder that you
   extracted.

<Warning>
Removing user data cannot be undone. It does not remove copies that were
already sent somewhere else, for example to a provider you used.
</Warning>

## If something goes wrong

- **The check fails.** Check your internet connection and the network scope. A
  strict scope can block update checks.
- **Updates are switched off.** If automatic checks are disabled, SpeechKit
  does not contact the release server. Use the download page instead.
- **The install does not start.** Download the installer from the release page
  and verify the checksum as described in
  [Install on Windows](/speechkit/install-windows).
- **After a reinstall the setup does not start again.** The old data was kept.
  Use **Repeat setup** in **Settings > App**.
