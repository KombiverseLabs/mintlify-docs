# kombify 文档

将你已有的电脑变成运行中的家庭实验室，开箱即用 Photos、Files 和 Vault。它运行在你自己的硬件上，无需 kombify 账户，并可在需要时添加公开 HTTPS 地址。

## 你的地址

一条命令即可为应用分配 HTTPS 名称，无需提前配置域名。公开 `*.kombify.me` 名称是免配置的默认选项：无需域名、无需 DNS 设置，也无需在手机或笔记本上安装证书。若你希望任何服务都不可从外部访问，可显式选择仅限本地网络。

| 模式 | 地址 | 所需条件 |
| --- | --- | --- |
| 公开名称 | `*.kombify.me` | 公网服务器默认启用。在家庭服务器上，运行单行命令前设置 `DOMAIN=kombify.me`，再通过 `stackkit reach` 启用访问路径。 |
| 仅限本地网络 | `*.lab.home` | 家庭服务器默认启用，也可随时通过 `DOMAIN=lab.home` 显式选择。每台设备需完成一次 DNS 和 CA 配置步骤。 |

`stackkit connect` 会将服务器绑定到你的 kombify 账户，从而激活 `{base}-{app}.kombify.me` 名称。之后你可以按应用逐一决定仅限家庭内网或对互联网开放。

<Note>
  kombify.me 处于 Beta 阶段。名称、请求头和错误格式仍可能变化。
</Note>

## 六个核心命令

这六个命令覆盖了安装、日常运维以及可选的 kombify 连接：

| 命令 | 作用 |
| --- | --- |
| <code>stackkit init</code> | 从 StackKit 初始化新部署 |
| <code>stackkit apply</code> | 应用基础设施变更 |
| <code>stackkit status</code> | 查看部署状态 |
| <code>stackkit verify</code> | 运行部署后验证检查 |
| <code>stackkit backup</code> | 管理备份（Kopia 引擎） |
| <code>stackkit connect</code> | 将服务器绑定到 kombify 账户以启用公开 `*.kombify.me` 名称 |

[CLI 参考](/zh-Hans/stackkits/reference/cli/overview)列出了所有命令的参数与示例；其余命令收纳在其中的“高级参考”分组下。
