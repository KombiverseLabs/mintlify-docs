# kombify 文档

本公开文档涵盖已发布的 StackKits homelab 标准、包含公开 kombify.me 地址在内的当前 Homelab Beta、kombify Cloud（可连接 homelab 的账户部分）、kombify AI 以及 SpeechKit 语音框架。每个产品部分均会说明哪些产物已公开提供，以及哪些功能仍处于预览阶段。

<Info>
StackKits 和 SpeechKit 均有独立的公开发布版本。Homelab 现已提供未签名的开源 Windows Beta 版本，可在无需账号的情况下进行本地编排。
</Info>

## 发布权威

基于发布版本的说明会链接到当前的公开制品，而不是某个固定版本，因此这里的下载链接始终指向最新发布的版本。凡是页面中标明版本的地方，该行内容都由已发布的版本生成并自动核对。处于预览阶段的功能会单独标注，不提供合成的下载或安装步骤。
