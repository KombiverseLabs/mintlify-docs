# kombify 文档

这些公开文档涵盖已发布的 StackKits 家庭实验室标准、SpeechKit 语音框架，以及当前的 Techstack Alpha（包括 kombify.me 公共地址）。每个产品领域都会说明哪些制品已公开提供，哪些功能仍处于预览阶段。

<Info>
StackKits 和 SpeechKit 均有独立的公开发布版本。Techstack 现已提供未签名的开源 Windows Alpha 版本，可在无需账号的情况下进行本地编排。
</Info>

## 发布权威

基于发布版本的说明会链接到当前的公开制品，而不是某个固定版本，因此这里的下载链接始终指向最新发布的版本。凡是页面中标明版本的地方，该行内容都由已发布的版本生成并自动核对。产品预览会单独标注，不提供合成的下载或安装步骤。
