本指南涵盖在 Windows 上更新和移除 SpeechKit。macOS 请参见[在 macOS 上安装](/zh-Hans/speechkit/install-macos)。

## 更新 SpeechKit

<Steps>
  <Step title="打开更新设置">
    在 **Settings** 中，打开 **App** 并找到 **Updates**。它显示你已安装的版本以及 SpeechKit 上次检查的时间。
  </Step>
  <Step title="检查更新">
    选择 **Check for updates**。如果存在较新的版本，你会看到 **Update available**。**Change log** 显示有哪些新内容。
  </Step>
  <Step title="下载并安装">
    选择 **Download**。完成后，选择 **Install and restart**。SpeechKit 会自行重启。未经你确认，它绝不会安装或重启。
  </Step>
</Steps>

你可以开启 **Download updates automatically**。SpeechKit 随后会在后台获取并检查新版本，这样安装只需点击一次。

## 未签名的发行版

免费的 Windows 发行版未经签名。SpeechKit 会将下载内容与随发行版发布的 SHA-256 校验和进行比对，如果不一致就拒绝。如果某个发行版没有校验和列表，SpeechKit 不会为你启动它。请使用 **Open download page** 并自行运行安装程序。参见[在 Windows 上安装](/zh-Hans/speechkit/install-windows)。

如果由你的管理员管理更新，Settings 会这样说明。SpeechKit 此时只会报告存在某个版本。

## 卸载 SpeechKit

1. 打开 Windows 开始菜单，找到 SpeechKit，然后选择 **Uninstall**。你也可以从 Windows 的已安装应用列表中移除它。
2. 卸载程序会询问是否同时移除你的用户数据和配置。
   - 选择 **No** 可保留你的设置和历史记录，供以后安装使用。
   - 选择 **Yes** 将为你的 Windows 账户删除它们。这会移除设置、引导状态、已保存的密钥、含转录文本和笔记的数据库、音频、截图、唤醒词片段和日志。
3. 如果你使用的是便携 ZIP，请关闭 SpeechKit 并删除你解压出的文件夹。

<Warning>
移除用户数据无法撤销。它不会移除已经发送到别处的副本，例如发给你使用过的某个提供方的副本。
</Warning>

## 如果出了问题

- **检查失败。** 检查你的网络连接和网络范围。严格的范围可能会阻止更新检查。
- **更新被关闭。** 如果自动检查被禁用，SpeechKit 不会联系发行服务器。请改用下载页面。
- **安装无法开始。** 从发行页面下载安装程序，并按[在 Windows 上安装](/zh-Hans/speechkit/install-windows)中所述验证校验和。
- **重新安装后设置没有再次开始。** 旧数据被保留了下来。请在 **Settings > App** 中使用 **Repeat setup**。
