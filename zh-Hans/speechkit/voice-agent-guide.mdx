Voice Agent 是实时的口头对话。你可以追问并打断。它不会在你的应用中输入文字。要输入文字，请使用 Dictation 或 Assist。Voice Agent 是 Windows 功能。在 macOS 上，当前测试版中尚未验证。

## 开始之前

- SpeechKit 已安装，且 Dictation 可以正常工作。
- 全新安装时 Voice Agent 是关闭的。你在下面开启它。
- Voice Agent 需要一个用于实时对话的提供方，本地或云端均可。选择时请结合[隐私设置](/zh-Hans/speechkit/privacy-settings)考虑。云端提供方会接收你的语音。

## 步骤

<Steps>
  <Step title="开启 Voice Agent">
    在 **Settings > Overview** 中，于 **Modes** 列表里开启 Voice Agent。你也可以打开 **Voice Agent Mode** 并在那里启用其热键。
  </Step>
  <Step title="检查有哪些需要处理">
    **Overview** 在 **Needs attention** 下列出缺失的提供方密钥。添加密钥，或选择另一个提供方。
  </Step>
  <Step title="开始对话">
    默认热键是 `Ctrl+Shift`。按住它，说话，然后松开。你也可以使用 Voice Agent 窗口中的 **Start voice agent** 和 **Stop voice agent** 按钮来启动和停止代理。
  </Step>
  <Step title="继续追问">
    窗口会显示对话内容。代理回答后，继续提出追问。例如：“help me decide the next release slice”。然后用追问打断它。
  </Step>
  <Step title="结束会话">
    结束会话即可得到摘要。松开热键后，对话会在短时间内保持可恢复（即 **Resume window**）。摘要和面板的关闭发生在该时间窗用尽时。
  </Step>
</Steps>

## 你可以更改的设置

打开 **Settings > Voice Agent Mode**。

| 设置 | 作用 |
| --- | --- |
| Voice Agent hotkey | 启动对话的组合键。 |
| Agent profile | 选择代理配置文件。 |
| Personal refinement prompt | 添加你自己的偏好，例如简短回答。 |
| Resume window (seconds) | 对话保持可恢复的时长。0 会立即结束会话。 |
| Pause tolerance (ms) | 不超过此长度的短暂停顿不会触发回答。0 使用提供方的默认值。 |
| Session summary | 保留会话的摘要。 |
| Closing the window | 选择 **Minimise and keep chat** 或 **End chat on close**。 |

过去的对话显示在 **Library** 的语音标签页下。

## 用语音开始

**Hands-Free** 可以用唤醒短语代替热键来启动某个模式。在 **Settings > Hands-Free** 下通过 **Enable hands-free activation** 开启它，然后选择短语和目标（**Voice Agent conversation**、**Assist voice companion** 或 **Dictation (UI-assisted)**）。用于唤醒检测的麦克风音频保留在设备上。macOS 上不提供 Hands-Free。

## 如果出了问题

- **代理无法启动。** 检查 Voice Agent 是否已开启，以及其提供方是否有密钥。参见 **Overview** 中的 **Needs attention**。
- **它回答得太早。** 调高 **Pause tolerance (ms)**。
- **你听不到它。** 使用 Voice Agent 窗口中的扬声器输出控件选择另一个扬声器。
- **仍然无法解决。** 参见[修复常见问题](/zh-Hans/speechkit/fix-common-problems)。
