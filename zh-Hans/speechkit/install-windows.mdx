SpeechKit 桌面客户端支持 x64 系统上的 Windows 10 和 Windows 11。Windows 是功能最完整的目标：包含全部三种模式、Hands-Free 和 Meeting。请仅从官方的 `kombifyio/SpeechKit` 发布页下载资源。

## 验证下载

1. 下载对应的 [SHA256SUMS.txt](https://github.com/kombifyio/SpeechKit/releases/latest/download/SHA256SUMS.txt)。
2. 使用你信任的工具计算安装程序或 ZIP 的 SHA-256 哈希值。
3. 在打开安装包之前，将完整的哈希值与 `SHA256SUMS.txt` 中的条目进行比对。
4. 阅读[未签名版本说明](https://github.com/kombifyio/SpeechKit/releases/latest/download/UNSIGNED-WINDOWS-RELEASE.txt)。

<Warning>
免费的 Windows 版本未经签名。Windows 可能会显示信誉警告。在决定是否继续之前，请先验证校验和和发布来源。
</Warning>

## 首次使用

1. 启动 SpeechKit，并选择你希望使用的麦克风。
2. 选择网络范围。“所有网络”允许使用外部提供方；“仅本地网络”和“仅此设备”会限制后端可以联系的对象。
3. 选择适合该模式的本地或外部提供方。
4. 在启用 Assist、Voice Agent 或 Meeting 之前，先测试 Dictation。
5. 选择外部提供方时，请查看哪些内容会离开设备。

默认热键为：Dictation 使用 `Ctrl+Win`，Assist 使用 `Win+Alt`，Voice Agent 使用 `Ctrl+Shift`。在会议中，`Ctrl+Alt+S` 用于捕获屏幕快照。
