SpeechKit 使用三种严格划分的模式。请选择与任务相匹配的最小模式，让预期的处理和输出保持清晰。

## Dictation

Dictation 把语音转换为文字。它不会进行 LLM 改写、执行工具，也不会生成语音回复。适用于笔记、表单、消息和其他直接转录的任务。

## Assist

Assist 把语音或文本转换为一个有边界的结果。该结果可能来自确定性替换、工具或 LLM，也可以选择朗读出来。当你需要转换或单个答案，而不是实时对话时，请使用它。

## Voice Agent

Voice Agent 是实时音频对话。它适用于互动式头脑风暴、支持和追问，在这些场景中轮次检测和语音输出很重要。

## Hands-Free 与自定义

Hands-Free 在三种模式之上控制激活、麦克风采集、自动检测说话结束以及可选的扬声器输出。Words（词汇）用于教 SpeechKit 识别特定术语；Replacements（替换）则应用确定性的文本、命令、片段、同义词或模板转换。

[Meeting](/zh-Hans/speechkit/meeting) 与这三种模式并列，而不在其中。它在自己的管线上录制通话，只与 Dictation 共用语音转文字转录器，因此通话音频绝不会进入听写浮层、历史记录或剪贴板快捷方式。

## 本地与外部提供方

提供方的选择决定数据路径：

| 提供方类型 | 数据边界 |
| --- | --- |
| 本地语音转文字或本地模型 | 处理保留在设备上。 |
| 自托管 SpeechKit 服务器或本地运行时 | 数据发送到你运营的机器。 |
| 外部语音提供方 | 音频、文本或两者都可能按其条款发送给该提供方。 |

SpeechKit 随附以下适配器：本地 `whisper.cpp` 和 Piper、自托管 `whisper-server`、Ollama 及其他兼容 OpenAI 的端点，以及外部提供方 OpenAI、Groq、Deepgram、AssemblyAI、Hugging Face、OpenRouter、Azure Speech 和 Microsoft Foundry。Google 语音转文字、Google 文本转语音和 Gemini Live 已被移除；仍然引用它们的配置会安全失败，而不是悄悄选择另一个提供方。

SpeechKit 不会让外部提供方变成本地的。在发送敏感音频之前，请查看提供方配置和隐私条款。

## 网络范围

网络范围是你设置一次、由后端在各处强制执行的边界——包括提供方组装、模型下载、更新、遥测、服务器连接和集成。

| 范围 | 可以联系什么 |
| --- | --- |
| 所有网络 | 所有已配置的提供方和集成，包括公共云端点。 |
| 仅本地网络 | 设备上的运行时，以及回环或私有地址上的服务，例如你局域网中的 Ollama 主机或你自己的 SpeechKit 服务器。公共端点会被阻止，包括在 DNS 解析之后的连接建立阶段。 |
| 仅此设备 | 只有 SpeechKit 自己作为本地子进程管理的运行时。所有外部服务都会被阻止，包括同一台机器上的服务，因为无法证明其自身的出站流量。 |

选择更严格的范围会暂停不兼容的设置而不是删除它们，设置页面会说明哪些被停用以及原因。

## 保留范围

保留范围是第二个独立的维度：它回答的是什么内容会比产生它的工作存在得更久。

| 范围 | 效果 |
| --- | --- |
| 保留 | 内容是持久的，只会通过保留设置、删除或擦除请求消失。 |
| 零保留 | 原始材料在工作进行期间写入，会话结束时清除。生成的结果会保留；其背后的转录文本不会。无法声明不存储的提供方界面会被拒绝。 |

没有网络访问的安装仍然会把转录文本写入磁盘。请有意识地设置这两个范围。
