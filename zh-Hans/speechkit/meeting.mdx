会议功能将通话录制为两个独立的通道——你的麦克风和系统回环——把两者转写到同一个会话中，并根据转写文本、你自己的笔记和模板撰写会议纪要。它是一项独立的录制服务，而不是第四种模式：它只与听写共用语音转文字转写器。

<Info>
会议是 Windows 桌面端的功能。系统音频采集尚未移植到 macOS 测试版。
</Info>

通俗地说：你照常加入通话，SpeechKit 在后台聆听双方，之后你会得到一份可以阅读、搜索和复制的书面摘要。它记录的是所说的内容，而不是可以回放的录音，因为音频本身从不被保留。

## 开始之前

- 使用 Windows 桌面客户端。请参阅[在 Windows 上安装](/zh-Hans/speechkit/install-windows)。
- 允许 SpeechKit 使用你的麦克风。如果你还没有设置麦克风，请参阅[设置热键、麦克风和语言](/zh-Hans/speechkit/hotkeys-microphone-language)。
- 确保没有其他 SpeechKit 模式正在使用麦克风。同一时间只能有一个采集占用它。
- 如果你希望一切都保留在你的电脑上，请先检查你的隐私范围。请参阅[隐私设置](/zh-Hans/speechkit/privacy-settings)。

## 一次会议会产出什么

- 包含两个通道的转写文本，按采集通道标注。通道标签说明某一行来自通话的哪一方；它们并不识别每一位远程发言者。
- 你自己的笔记，会原样复现在纪要中。
- 一份持久的**会议回顾（Meeting Review）**：五句话的执行摘要、行动项，以及引用其来源转写文本的正文。
- 支持英语、德语、西班牙语、中文、印地语和阿拉伯语的回顾。

音频从不被持久保存。留下来的是转写文本、笔记和回顾，保留多长时间由[保留范围](/zh-Hans/speechkit/modes#retention-scope)决定。

## 开始并结束录制

1. 从桌面客户端开始一场会议，或者在你接听通话时让通话检测提供一个选项。检测只是一个由你决定是否接受的建议，而不是自动录制。
2. 通话期间，一个紧凑的透明浮层会显示采集状态和控件，并可以展开以记录笔记。
3. 滚动摘要在采集持续进行的同时分批运行，因此长时间通话不必等到结束才被消化。
4. 通话应用释放麦克风后不久，SpeechKit 就会停止，并通知你回顾已就绪或失败的原因。你手动开始的录制绝不会被自动停止。

每一步之后的预期情况：开始之后，浮层显示采集正在进行。通话期间，转写文本不断增长，滚动摘要分批出现。通话结束之后，SpeechKit 会告诉你回顾何时就绪，或为何无法生成，并且该会议会出现在会议列表中。

同一时间只有一个采集占用麦克风。在会议录制期间启动听写、Assist 或 Voice Agent 会被拒绝，而不是悄悄抢占设备。

## 屏幕快照

会议期间按 `Ctrl+Alt+S`，可采集所选窗口或光标所在的显示器。快照会作为标记出现在转写时间线中，在生成的回顾中被引用，并在会议胶囊中短暂预览，以便你确认采集的是正确的窗口。任何图像都不会离开设备。

## 查找与导出

会议列表按发生时间对会话进行分组。搜索涵盖标题、转写文本、笔记和纪要。笔记以格式化的 Markdown 渲染，完整的纪要提供**复制 Markdown**和**保存 .md**。

## 回顾生成

本地路径不需要云端凭据：内置的本地模型在设备上生成回顾。GitHub Copilot 是可选的回顾生成提供商，需要单独的、可撤销的转写处理授权。

在**仅限本地网络**和**仅限此设备**的[网络范围](/zh-Hans/speechkit/modes#network-scope)下，导出连接器和云端回顾提供商不可用。全新安装不会配置任何连接器，因此在你选择之前，没有任何内容会离开这台机器。

## 如果出了问题

- **会议无法开始。** 可能是另一种 SpeechKit 模式占用了麦克风。请结束或停止听写、Assist 或 Voice Agent，然后重新开始会议。另请参阅[解决常见问题](/zh-Hans/speechkit/fix-common-problems)。
- **没有转写文本，或只有通话的一方。** 请按照[设置热键、麦克风和语言](/zh-Hans/speechkit/hotkeys-microphone-language)中的说明检查麦克风。会议将你的麦克风和系统声音记录为两个通道；如果只选择了麦克风，则不会采集通话的另一方。
- **没有出现回顾。** 通知中会说明原因。回顾需要一个回顾提供商：内置的本地模型无需账户即可使用，而云端提供商在**仅限本地网络**和**仅限此设备**范围下不可用。请参阅[使用本地模型离线工作](/zh-Hans/speechkit/work-offline)和[隐私设置](/zh-Hans/speechkit/privacy-settings)。
- **检测没有提供任何选项。** 通话检测只是建议，而不是保证。请改为从桌面客户端开始会议。
- **你使用的是 Mac。** 会议在 macOS 测试版上不可用。请参阅[在 macOS 上安装](/zh-Hans/speechkit/install-macos)。
- **仍然无法解决。** 请参阅[解决常见问题](/zh-Hans/speechkit/fix-common-problems)和[更新或卸载 SpeechKit](/zh-Hans/speechkit/update-and-uninstall)，确保你使用的是当前版本。
