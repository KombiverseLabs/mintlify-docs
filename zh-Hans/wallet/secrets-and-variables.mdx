在 kombify 控制台中打开**设置**，选择**密钥与连接**。**Wallet** 部分列出你的条目。下方的 **API 密钥**部分是另一回事：它保存 kombify 工具 API 的密钥，而不是 Wallet 条目。

## 添加条目

1. 选择**添加条目**。
2. 选择**类型**。表单随即显示该类型的字段。
3. 输入**名称**。它会显示在列表中，所以切勿把机密本身写进去。描述为可选。
4. 选择**范围**。
5. 选择**保存到 Wallet**。

你的浏览器会在发送前加密该值。一个值最大 64 KiB。

| 类型 | 字段 |
| --- | --- |
| **API 密钥、令牌或证书** | **机密值** |
| **登录信息** | **用户名**、**密码**，以及可选的**一次性验证码密钥** |
| **变量** | **变量名**和**值** |
| **配置** | **配置名**和**文档** |
| **服务器访问** | **主机**、**用户**，以及**登录方式**：**SSH 私钥**或**密码** |
| **SSH 证书颁发机构** | 参见 [SSH 证书](/zh-Hans/wallet/ssh-certificates) |

## 范围

**范围**决定条目在哪里生效：

- **整个账户**在所有地方生效。
- **单个项目**需要一个**项目 ID**。
- **项目中的单个环境**需要一个**项目 ID**和一个**环境**。

项目 ID 和环境只能使用字母、数字、点、短横线和下划线，最长 64 个字符。当多个范围中存在同名的变量或配置时，环境优先于项目，项目优先于账户。

## 变量名和配置名

你的工具通过名称查找变量或配置。名称在同一范围内唯一。

- **变量名**使用大写字母、数字和下划线，不以数字开头，最长 128 个字符，例如 `DATABASE_URL`。
- **配置名**使用小写字母、数字、点、连字符和下划线，以字母或数字开头，最长 128 个字符，例如 `app.env`。

## 让变量指向机密

若想把机密只放在一个地方，请把变量的值设为 `secret://personal/<item ID>`，而不是把机密复制进去。读取该变量时（例如通过 `kombify-wallet run`），Wallet 会代入该条目的当前值。该条目的类型必须不是变量或配置，并且位于你自己的 Wallet 中。

如果该条目不存在、已被撤销或仅可使用，读取变量就会失败，而不是返回不完整的结果。变量列表绝不会显示该机密。`kombify-wallet list` 会显示条目 ID；参见[命令行](/zh-Hans/wallet/cli)。

## 查看值

在条目上选择**查看**。该值在你的浏览器中解密，只在那里显示，并在 30 秒后再次隐藏。打开期间可以使用**显示**、**隐藏**和**复制**。每次查看都会被记录。

对于仅可使用的值，以及 SSH 证书颁发机构，不提供**查看**。参见[仅可使用的值](/zh-Hans/wallet/use-only-values)。

## 替换值

选择**新版本**，输入新值，然后选择**保存新版本**。新值成为当前版本，**查看**显示的就是它。SSH 证书颁发机构没有新版本；你需要用一个新的颁发机构来替换它。

## 撤销或删除

- **撤销**会让条目以**已撤销**的状态留在列表中。它无法再被查看或使用。此操作无法撤消；请添加新条目来替代它。
- 使用**永久删除**进行**删除**，会清除该值及其所有版本。这同样无法撤消。

如果有消息提示审计记录仍在写入，说明更改已保存，记录稍后完成。
