有些 kombify 产品会在你不在时替你工作：同步你的邮件、调用服务商，或运行你的服务器。当产品需要你 Wallet 中的某个密钥或登录信息时，你就把该条目分配给它。产品绝不会获得你的其他条目。

## 将条目分配给产品

1. 打开**设置**，选择**密钥与连接**。
2. 在 **Wallet** 部分，对该条目选择**产品**。
3. 为每个产品打开你想要的权限。

这三项权限与[代理](/zh-Hans/wallet/agents)相同：**使用**、**读取**和**管理**。每项都单独授予。

| 产品 | 它为你做什么 |
| --- | --- |
| kombify Techstack | 规划并运行你的服务器和堆栈。 |
| Paperwork | 处理你的邮件、文档和任务。 |
| kombify AI 平台 | 为你运行 AI 功能和代理。 |
| kombify Simulate | 对你的设置运行模拟。 |
| kombify Cloud | 处理你的 kombify Cloud 账户功能。 |

## 产品能做什么、不能做什么

- 产品只使用你分配给它的条目。它依据你的长期分配行事，因此你无需保持登录。
- 拥有**使用**权限时，产品可以用该条目发起调用、向 SSH 证书颁发机构申请证书，或收到其工作所需的一次性使用的值，例如同步邮件。
- 产品绝不会收到仅可使用的值，只能通过其[使用目标](/zh-Hans/wallet/use-only-values)用它发起调用。
- 产品绝不会收到 SSH 证书颁发机构的密钥。
- 只有当某个条目由产品自己负责保持更新时，才授予**管理**，例如服务商会轮换令牌的连接。它让产品可以存储该条目的新版本。
- 每次使用都会被记录，与你和你的代理一样。

## 让产品添加条目

有些产品可以把你已保存的机密迁移到你的 Wallet 中。选择列表上方的**可添加条目的产品**，然后为你允许的每个产品打开**可添加条目**。产品添加的条目会分配给该产品，以便它能使用。该产品仍然只使用你分配给它的条目。

## 收回访问

关闭该权限。它从产品的下一次操作起生效，而已经获准的操作最多持续约一分钟。如果产品已收到某个条目的值，之后请为该条目添加新版本。Wallet 目前还不会自动把该条目标记为需要替换。
