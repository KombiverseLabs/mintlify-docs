代理永远不会继承你的访问权限。在你授予之前，它对条目没有任何权限，而且只能看到它持有权限的条目。只有你本人登录后才能管理你的 Wallet，代理不能。

## 让代理访问某个条目

1. 打开**设置**，选择**密钥与连接**。
2. 在 **Wallet** 部分，对该条目选择**代理访问**。
3. 为你的每个代理打开你想要的权限。

列表显示你创建的代理。每项权限都单独授予，互不包含。

| 权限 | 代理可以做什么 |
| --- | --- |
| **使用** | 在看不到该值的情况下用它执行操作，例如在 API 调用中。它需要[使用目标](/zh-Hans/wallet/use-only-values)。 |
| **读取** | 查看该值本身。 |
| **管理** | 管理该条目及其设置。 |

目前，代理只通过**使用**和**读取**来操作条目。无论代理拥有什么权限，添加条目、添加版本、更改设置、撤销和删除仍由你来做。

有两种情况需要留意：

- 如果条目的值仅可使用，**读取**不会向任何人显示它。
- 如果条目没有使用目标，拥有**使用**权限的代理也无法用它进行任何调用。

对于 SSH 证书颁发机构，**使用**允许代理在该机构的签发策略范围内申请短期证书。代理只会收到用户证书。参见 [SSH 证书](/zh-Hans/wallet/ssh-certificates)。

## 缺少权限时

Wallet 会拒绝，并指出缺少哪项权限：使用、读取或管理。不会交出任何内容。代理需要请求该权限，你可以按上文所述授予。

## 收回权限

关闭该权限。它从代理的下一次操作起生效，而已经获准的操作最多持续约一分钟。除此之外，权限会一直保留，直到你收回它或代理终止。

## 会统计查看次数

每当代理读取某个值，Wallet 都会记录，并按条目计数。该条目随后会显示提示：**建议轮换：自上一个版本以来，该值已被提供 N 次。添加新版本以替换它。** 添加新版本会重置计数。

尽可能优先使用**使用**而不是**读取**。只使用某个值的代理从不持有它，因此无需轮换。
