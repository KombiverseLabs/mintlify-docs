kombify Cloud 是 kombify 的托管账户部分。它包含你的登录信息、套餐以及用于打开你有权使用的 kombify 工具的仪表板。你的 homelab 可以连接到它，kombify AI 也可以协助或操作该 homelab。

<Warning>
kombify Cloud 处于 Beta 阶段。功能仍可能发生变化，kombify 不保证可用性，也不提供服务级别协议（SLA）。你的法定权利不受影响。请参阅 kombify.io 上的条款。
</Warning>

## 各产品如何配合

- [StackKits](/zh-Hans/stackkits/overview) 定义你的 homelab：包含哪些套件和应用，以及如何安装、备份和更新。
- [Homelab](/zh-Hans/homelab/overview) 负责配置并运行该 homelab。
- kombify Cloud 是你的 homelab 可以连接到的账户，并提供展示其运行情况的仪表板。
- [kombify AI](/zh-Hans/apps/ai/overview) 可以协助或操作已连接的 homelab。

<span id="three-ways-to-run-a-homelab"></span>

## 运行 homelab 的三种方式

这些是同一个 homelab 的运行模式，而不是套餐等级。只要你启用，任何一种模式都可以通过你自己的域名或 `*.kombify.me` 地址从任何地方访问；也都可以仅保留在你的家庭网络内。远程访问并非 kombify Cloud 独有。请参阅 [kombify.me](/zh-Hans/kombify-me/overview)。

是否使用 kombify 账户，以及使用哪种 AI，是两个相互独立的选择（参见[使用或不使用账户，以及选择哪种 AI](/zh-Hans/start/account-and-ai)）。

| 模式 | 含义 | kombify 账户 |
| --- | --- | --- |
| 自管 | 你在自己的硬件上使用 StackKits 或 Homelab [Windows Beta](/zh-Hans/homelab/install-windows) 安装并运行一切。 | 不需要 |
| 已连接 | 你自己的服务器绑定到 kombify Cloud。请参阅[连接服务器](/zh-Hans/apps/cloud/connect-a-server)。 | 需要 |
| 由 kombify 托管 | kombify 在托管商处订购并运行服务器。你无需提供服务器或托管商凭据。请参阅[托管服务器](/zh-Hans/apps/cloud/managed-servers)。 | 需要 |

## 当前已可用功能

- 注册、登录以及位于 `app.kombify.io` 的仪表板。请参阅[创建账户](/zh-Hans/apps/cloud/get-started)。
- 套餐与账单，支持按月或按季付款，并可在账单周期结束时取消。请参阅[套餐与账单](/zh-Hans/apps/cloud/plans-and-billing)。
- 为你的 stack 使用自己的域名。请参阅[连接你自己的域名](/zh-Hans/apps/cloud/domains)。
- Feed 与通知偏好设置。请参阅[选择 kombify 如何通知你](/zh-Hans/apps/cloud/notifications)。
- 家庭组：邀请成员、选择每位成员可使用的内容以及移除成员。请参阅[家庭组](/zh-Hans/apps/cloud/household)。
- 账户删除。请参阅[删除你的账户和数据](/zh-Hans/apps/cloud/delete-your-account)。
- 使用 StackKits 的自管 homelab，无需 kombify 账户即可工作。

## 预览中的功能

- 连接服务器以及显示其状态的 Monitoring 视图。
- 托管服务器。
- 让 kombify AI 操作已连接的 homelab。请参阅[让 kombify AI 操作你的 homelab](/zh-Hans/apps/cloud/ai-operation)。
- 家庭成员在 homelab 本身登录。

## 如果出了问题

大多数问题都是登录问题。请先查看[登录问题与账户基础知识](/zh-Hans/apps/cloud/sign-in-and-account)。如有其他问题，请写信至 [info@kombify.io](mailto:info@kombify.io)，说明你当时所在的页面与时间，并切勿发送密码。
