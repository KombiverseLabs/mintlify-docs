kombify Cloud 是 kombify 的托管账户部分。它保存你的登录信息、你的订阅，以及仪表板；你可以从仪表板打开你有权使用的 kombify 工具。

<Warning>
kombify Cloud 处于公开测试版。不保证可用性，付费套餐也不例外。你的法定权利不受影响。请参阅 kombify.io 上条款中的测试版部分。
</Warning>

## Cloud 的功能

- **账户和登录。** 登录、注册和账户选择都在 kombify 的托管登录页面上完成，由 Auth0 提供支持。
- **仪表板。** 登录后你会进入 `app.kombify.io` 上的应用，在那里启动工具并更改设置。
- **套餐和计费。** 套餐通过 Stripe 按月或按季度计费，你可以在任何计费周期结束时取消。
- **家庭。** 家庭让你邀请的人可以相互共享项目。可用性遵循上述测试版状态。

## Cloud 不做什么

运行自有基础设施时，Cloud 是可选的。用 [StackKits CLI](/zh-Hans/stackkits/overview) 安装的 kit 无需 kombify 账户即可工作，[身份与访问概念](/zh-Hans/identity/overview)说明了本地登录与托管登录的关系。
