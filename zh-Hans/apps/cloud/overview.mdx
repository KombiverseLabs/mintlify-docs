kombify Cloud 是 kombify 的托管账户部分。它保存着你的登录信息、你的订阅，以及可以打开你有权使用的 kombify 工具的仪表板。

<Warning>
kombify Cloud 处于公开测试阶段。不保证可用性，包括付费套餐在内。你的法定权利不受影响。请参阅 kombify.io 上条款中的测试阶段部分。
</Warning>

通俗地说：Cloud 是 kombify 存在于互联网上、并知道你是谁的那一部分。运行在你自己的电脑和服务器上的工具并不需要它也能工作，但 Cloud 让你可以在一个地方更方便地访问它们。

## Cloud 的功能

- **账户和登录。** 登录、注册和账户选择都在 kombify 的托管登录页面上完成，由 Auth0 提供支持。
- **仪表板。** 登录后，你会进入 `app.kombify.io` 上的应用，在那里启动你的工具并更改设置。
- **套餐和计费。** 套餐通过 Stripe 按月或按季度计费，你可以在任意计费周期结束时取消。
- **家庭组。** 家庭组让你邀请的人可以彼此共享内容。可用性取决于上述测试阶段状态。

## 你可以在仪表板中做什么

- 熟悉左侧栏、主页、Feed 和设置。请参阅[仪表板导览](/zh-Hans/apps/cloud/dashboard-tour)。
- 选择 kombify 通知你的内容和方式。请参阅[选择 kombify 如何通知你](/zh-Hans/apps/cloud/notifications)。
- 将你拥有的域名连接到你的 stack。请参阅[连接你自己的域名](/zh-Hans/apps/cloud/domains)。
- 请求 kombify 删除你的账户和数据。请参阅[删除你的账户和数据](/zh-Hans/apps/cloud/delete-your-account)。

## 如果出了问题

大多数问题都是登录问题。请先查看[登录问题与账户基础知识](/zh-Hans/apps/cloud/sign-in-and-account)。如有其他问题，请写信到 [info@kombify.io](mailto:info@kombify.io)，说明你当时所在的页面和发生问题的时间，并且切勿发送密码。

## Cloud 不做什么

运行你自己的基础设施时，Cloud 是可选的。使用 [StackKits CLI](/zh-Hans/stackkits/overview) 安装的 kit 无需 kombify 账户即可工作，[身份与访问概念](/zh-Hans/identity/overview)说明了本地登录与托管登录之间的关系。
