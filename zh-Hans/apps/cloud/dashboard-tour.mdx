本页告诉你 `app.kombify.io` 仪表板中各项内容的位置。你不需要任何技术知识。

<Warning>
kombify Cloud 处于公开测试阶段。根据你的套餐以及为你开启的功能，某些入口在你的账户中可能显示不同，或者根本不显示。
</Warning>

## 开始之前

[登录](/zh-Hans/apps/cloud/get-started)，使仪表板在 `app.kombify.io` 打开。

## 步骤

<Steps>
  <Step title="查看左侧导航栏">
    左侧的栏就是导航栏（rail），整个导航都在其中。在手机上，它隐藏在顶部的菜单按钮后面；点按该按钮即可打开。在电脑上，你可以折叠导航栏以节省空间，也可以拖动其边缘来调宽或调窄。

    你会看到以下入口：

    - **Home** 是你的起始页。
    - **Monitoring** 显示你的 homelab 运行情况。
    - **Tools** 汇集了 kombify 工具。**Techstack**、**StackKits** 和 **Companion** 都在这里，**Workpaths** 用于查看运行记录和审批。**Simulate** 和 **Paperwork** 仅在你的账户可用时才会出现。
    - **Docs** 打开本文档。
  </Step>
  <Step title="将指针停在某个工具上">
    在电脑上，工具入口旁会打开一张小卡片，列出该工具自己的内容，例如 Techstack 下已连接的机器，或 Companion 下你最近的会话。如果列表无法读取，卡片会如此说明。这与“还没有内容”不是一回事。
  </Step>
  <Step title="打开 Home">
    Home 会向你问候并显示你的 homelab：一行文字告诉你有多少个应用在响应、有多少台机器在线，一个用于搜索应用和使用场景的搜索框，以及每个使用场景一张卡片。如果你还没有任何使用场景，请选择 **Add your first use case**。

    选择 **Arrange**，把你最常用的使用场景排在最前。第一个会获得大卡片。目前该顺序仅保存在此设备上。
  </Step>
  <Step title="查看 Feed">
    导航栏中标有 **Feed** 的铃铛显示需要你处理的事项。打开它可以阅读条目、将其标为已读或忽略；**Open Feed** 会显示完整列表，并提供 Active、Unread、Needs you、Resolved 和 Archive 视图。要选择哪些内容会通知你，参见[选择 kombify 通知你的内容](/zh-Hans/apps/cloud/notifications)。
  </Step>
  <Step title="打开账户菜单">
    在导航栏底部，点击你的名字会打开账户菜单，其中有 **Settings**、**Billing**、显示和语言控件以及 **Sign out**。套餐和发票请参见[更改或取消你的套餐](/zh-Hans/apps/cloud/plans-and-billing)。
  </Step>
  <Step title="浏览 Settings">
    Settings 按以下顺序提供这些标签页：

    | 标签页 | 用途 |
    | --- | --- |
    | Account | 来自你登录信息的姓名和电子邮件、重新播放介绍、Cookie 设置，以及删除账户的请求 |
    | Stack Identity | kombify 工具为你的技术栈显示的名称和性格 |
    | Design | 浅色或深色，以及仪表板的外观。更改仅在你选择 **Apply** 后生效 |
    | Feed & Push | 通知你的内容和渠道 |
    | Keys & connections | 你的 Wallet 和 API 密钥 |
    | Dashboard | 你的仪表板默认包含哪些工具，以及从哪里获取 kombify 应用 |
    | Budgets & quotas | 你已使用了多少套餐额度 |
    | Domains | 你的域名。参见[连接你自己的域名](/zh-Hans/apps/cloud/domains) |
    | AI assistants | kombify AI 助手在各个产品中可以做什么 |
  </Step>
</Steps>

## 确认已成功

当你无需搜索就能打开 Home、Feed 和 Settings 时，就说明你已熟悉了界面。

## 重新播放介绍

在 **Settings**、**Account** 中，关于入门的部分有按钮，可随时重新播放设置向导和介绍。

## 如果出了问题

- **缺少某个工具入口。** 有些工具仅在你的账户可用时才显示。你的套餐决定你可以使用什么；参见[套餐与计费](/zh-Hans/apps/cloud/plans-and-billing)。
- **悬停卡片提示某个列表无法读取。** 稍等片刻，再将指针移到该入口上。
- **你被送回了登录页。** 你的会话已结束。请重新登录；参见[登录问题与账户基础](/zh-Hans/apps/cloud/sign-in-and-account)。
- **仍然无法解决。** 写信给 [info@kombify.io](mailto:info@kombify.io)，说明你当时所在的页面以及发生的时间。切勿发送密码。
