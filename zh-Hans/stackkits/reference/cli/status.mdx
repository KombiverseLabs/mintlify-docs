显示部署状态。

显示 StackKit 部署的当前状态。

```text
Shows:
  • Deployment state (running, degraded, error)
  • Service statuses and health
  • Resource usage
  • URLs and endpoints
```

```bash
stackkit status [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--http` | bool | — | 从此验证主机探测已验证的服务路由 |
| `--inventory` | string | — | 用于识别已配置 Standard 进程运行时的 Architecture v2 观测 Inventory |
| `--json` | bool | — | 以 JSON 输出 |
| `--resolved-plan` | string | — | 规范的 Architecture v2 ResolvedPlan（默认：deploy/.stackkit/resolved-plan.json） |

**示例**

```bash
# Show status
stackkit status

# Output as JSON
stackkit status --json
```
