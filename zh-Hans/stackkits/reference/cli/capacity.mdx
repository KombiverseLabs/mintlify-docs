根据观测到的主机容量评估所选模块需求。

解析当前由 CUE 绑定的选择，并以 JSON 输出其容量评估建议。缺失的测量值保持为未验证。不会更改任何文件或运行时状态；这不能替代 Apply 准入。

```bash
stackkit capacity [spec-file] [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--inventory` | string | — | 观测到的 Inventory；缺失的容量保持为未验证 |
| `--module-root` | string | — | 架构权威根目录 |
