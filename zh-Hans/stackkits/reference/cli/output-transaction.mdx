```bash
stackkit output-transaction [flags]
```

子命令：[`stackkit output-transaction gc-retired`](#stackkit-output-transaction-gc-retired)

## stackkit output-transaction gc-retired

检查或显式地垃圾回收一个已退役的输出事务墓碑。

```bash
stackkit output-transaction gc-retired [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--action` | string | — | 先前检查所报告的确切操作 |
| `--apply` | bool | — | 执行回显的操作；默认只做检查 |
| `--transaction-id` | string | — | **必填。** 确切的小写事务 ID |
