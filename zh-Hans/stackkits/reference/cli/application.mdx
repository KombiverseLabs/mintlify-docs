纳管受支持的现有应用，而不替换其账户或数据。

```bash
stackkit application [flags]
```

子命令：[`stackkit application adopt`](#stackkit-application-adopt)、[`stackkit application control`](#stackkit-application-control)、[`stackkit application inspect`](#stackkit-application-inspect)、[`stackkit application release`](#stackkit-application-release)、[`stackkit application verify`](#stackkit-application-verify)

## stackkit application adopt

将经过审查的现有应用绑定到其声明的生命周期。

```bash
stackkit application adopt [workload] [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--container-id` | string | — | Docker 容器精确且不可变的 64 字符 ID |
| `--json` | bool | — | 输出带版本且不含秘密的应用证据 |
| `--operation-id` | string | — | 用于幂等恢复的稳定操作标识符 |
| `--owner-approve` | bool | — | 批准这项与 Owner 精确绑定的应用操作 |
| `--owner-file` | string | `.stackkit/setup/home-assistant-owner.json` | 工作区相对路径，指向包含 accessToken 的现有私有 Owner 授权文件 |
| `--plan-digest` | string | — | 经过审查且与源绑定的纳管计划精确摘要 |
| `--workload` | string | — | 精确选择的应用工作负载（作为位置工作负载参数的替代方式） |

## stackkit application control

```bash

```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--action` | string | — | 获准的电源操作：start、stop 或 restart |
| `--container-id` | string | — | Docker 容器精确且不可变的 64 字符 ID |
| `--json` | bool | — | 输出带版本且不含秘密的应用证据 |
