用可移植的 StackKits 搭建并维护你自己的服务。这些页面列出了每个 `stackkit` 命令及其标志和示例。它们由 StackKits 命令定义生成；如果你安装的版本较旧，请以 `stackkit <command> --help` 为准。

## 安装 CLI

```bash
curl -sSL https://install.stackkit.cc | STACKKIT_CLI_ONLY=1 sh
```

使用 `STACKKIT_CLI_ONLY=1` 时，安装器会把 `stackkit`、`stackkit-server`、`stackkit-mcp`、打包好的 OpenTofu 和公开的 Kit 目录放入 `~/.stackkits`，而不安装任何 StackKit。不使用它时，安装器会检测主机并继续安装 Basement Kit 或 Cloud Kit。

## 全局标志

这些标志适用于所有命令。

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--chdir, -C` | string | `.` | 运行前切换到该目录 |
| `--correlation-id` | string | — | 经过验证的调用方关联 ID，记录在本地 rollout 证据中 |
| `--no-log` | bool | — | 禁用结构化部署日志 |
| `--progress-jsonl` | string | — | 将已脱敏的机器可读 rollout 进度 JSONL 写入某个路径，或用 '-' 写入 stdout |
| `--quiet, -q` | bool | — | 抑制非必要的输出 |
| `--spec, -s` | string | `stack-spec.yaml` | 栈规格文件的路径（默认文件缺失时接受 kombination.yaml） |
| `--verbose, -v` | bool | — | 启用详细输出 |
