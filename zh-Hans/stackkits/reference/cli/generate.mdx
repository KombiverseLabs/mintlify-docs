根据栈规格生成受治理的部署产物。

别名：`gen`

通过内嵌的 CUE 权威解析规范的 StackSpec v2 意图，原子地持久化确切的 ResolvedPlan，并在计划拥有的 outputRoot 之下以事务方式渲染其受治理的产物。

StackSpec v1 的生成已停用。对历史工作区请使用已发布的确切 v0.6 二进制文件，或在生成之前先将意图迁移到 StackSpec v2。原生 v2 路径会拒绝旧版的 `--force` 和 `--fragments` 开关。

```bash
stackkit generate [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--force, -f` | bool | — | 已停用的旧版覆盖开关；StackSpec v2 会拒绝 |
| `--fragments` | bool | — | 已停用的旧版片段开关；StackSpec v2 会拒绝 |
| `--inventory` | string | — | Architecture v2 观测到的 Inventory（否则会选取一个常规的 inventory 文件） |
| `--local-node` | string | — | 由本地 generate 进程显式拥有的 Architecture v2 节点 |
| `--local-site` | string | — | 由本地 generate 进程显式拥有的 Architecture v2 Site |
| `--output, -o` | string | `deploy` | 覆盖计划拥有的输出根目录 |
| `--resolved-plan` | string | — | Architecture v2 规范的 ResolvedPlan（默认：&lt;outputRoot&gt;/.stackkit/resolved-plan.json） |

**示例**

```bash
# Resolve the plan and render deployment artifacts into deploy/
stackkit generate

# Render into an explicit output root
stackkit generate --output ./deploy

# Name the Site and node this process owns
stackkit generate --local-node main --local-site home
```
