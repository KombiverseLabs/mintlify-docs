管理与 Owner 绑定的本地密钥托管。

```bash
stackkit secrets [flags]
```

子命令：[`stackkit secrets materialize`](#stackkit-secrets-materialize), [`stackkit secrets reveal`](#stackkit-secrets-reveal)

## stackkit secrets materialize

为当前 StackSpec 中的密钥引用建立托管。

为当前规范 StackSpec 中的每个 secret:// 引用建立或复用与 Owner 绑定的本地托管。

在向现有的独立工作区添加工作负载之后、generate/apply 之前，运行这个显式且幂等的步骤。它从不输出密钥引用或密钥材料，也从不替换无效或外来的托管。

```bash
stackkit secrets materialize [flags]
```

**示例**

```bash
# After adding a workload to stack-spec.yaml, create its secrets, then roll out
stackkit secrets materialize
stackkit generate
stackkit apply
```

## stackkit secrets reveal

从本地 Owner 托管中输出一个选定工作负载的密钥。

输出当前通过 CUE 校验的 StackSpec 中某个选定工作负载所声明的一个密钥槽位的现有值。输出包含密钥材料；仅在私密终端或有意使用的管道中使用。不会向部署日志或回执写入任何值。

```bash
stackkit secrets reveal [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--slot` | string | — | **必填。** 已声明的工作负载密钥槽位 |
| `--workload` | string | — | **必填。** 选定的工作负载 ID |

**示例**

```bash
# Print the Photos database password from local owner custody
stackkit secrets reveal --workload photos --slot database-password
```
