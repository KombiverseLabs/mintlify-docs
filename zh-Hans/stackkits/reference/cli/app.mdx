检查 StackKits 应用交付并管理 v0.6 交接。

检查针对 Coolify、Komodo 和独立 Compose 的受治理 Architecture v2 应用交付矩阵。

可选的客户 PaaS 交接元数据仅在显式的 v0.6 StackSpec 兼容线上继续可用。Architecture v2 没有任意的客户工作负载映射；StackKit 自有的应用来自 CUE 目录，而客户工作负载的期望状态归 Techstack 管理。

```bash
stackkit app [flags]
```

子命令：[`stackkit app compatibility`](#stackkit-app-compatibility)

## stackkit app compatibility

显示受治理的应用/适配器支持矩阵。

显示 StackKits 应用不可变的、由 CUE 拥有的支持行。它报告的是产品能力，而不是所选计划、线上适配器可用性或部署证据。

```bash
stackkit app compatibility [flags]
```

| 标志 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--json` | bool | — | 以 JSON 输出兼容性矩阵 |

**示例**

```bash
# Show which applications each runtime adapter supports
stackkit app compatibility

# The same matrix as JSON
stackkit app compatibility --json
```
