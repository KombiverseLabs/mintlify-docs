## 邮件

### 私有邮件

通过 Roundcube 为你在外部提供商处已有的邮箱提供私有网页邮件。不会创建邮件服务器、DNS 或 MX 记录。

指南：[打开指南](/zh-Hans/guides/stackkits/use-cases/mail)

| 组件 | 角色 | 类型 | 默认 |
| --- | --- | --- | --- |
| kombify Paperwork (`paperwork`) | 备选 | 连接器 |  |
| Roundcube Webmail (`roundcube`) | 主要 | 应用 | ✓ |

### 自有邮件服务器

通过 Stalwart 在专用 Cloud 节点上运行你自己的邮件服务器：为你的域名提供邮箱以及 SMTP、IMAP 和 submission。StackKits 会输出由你发布的 DNS 记录；它绝不会更改 DNS。

指南：[打开指南](/zh-Hans/guides/stackkits/use-cases/mail)

| 组件 | 角色 | 类型 | 默认 |
| --- | --- | --- | --- |
| mailcow (`mailcow`) | 备选 | 应用 |  |
| Stalwart Mail Server (`stalwart`) | 主要 | 应用 | ✓ |
