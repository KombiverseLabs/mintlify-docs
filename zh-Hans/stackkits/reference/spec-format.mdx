StackSpec 是 StackKits 工作区的配置输入。不要在 StackSpec 中放置提供商凭据、明文密钥、服务器采购详情或生成的部署状态。

已安装的 CLI 会根据其内嵌的 CUE 契约设置 `apiVersion`。编辑文档时请保留这个生成的值。它的主要意图分组是：

- `metadata`、`kit` 和 `source`，用于标识和谱系
- `install` 和 `generation`，用于生命周期和输出策略
- `storage`、`container` 和 `network`，用于本地运行时意图
- `sites`、`nodes` 和 `controlPlane`，用于放置
- `capabilities`、`workloads` 和 `modules`，用于受管控的选择
- `backupPolicy` 和 `driftPolicy`，用于证据策略

经过版本验证的摘录请参见[配置 StackSpec](/zh-Hans/guides/stackkits/configure-stack-spec)。

验证模型请参见 [CUE 与 StackKits](/zh-Hans/stackkits/explanations/cue-architecture)。
