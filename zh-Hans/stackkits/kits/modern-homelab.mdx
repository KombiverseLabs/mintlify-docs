Modern Homelab 描述一个横跨 Home 环境和 Cloud 环境的 homelab。它的定义把控制权和默认的数据权限保留在 Home，并要求在各位置之间显式声明连接和发布。

<Warning>
  Modern Homelab 是没有受支持安装路径的 alpha 定义归档。你可以使用已发布的 CLI 对它进行初始化、验证和生成。下载它的归档并不能建立主机之间的有效连接、受保护的应用访问，或跨位置的恢复。如需已有安装的指南，请使用 Basement Kit 或 Cloud Kit。
</Warning>

## alpha 归档包含什么

[公开的 StackKits 版本](https://github.com/kombifyio/StackKits/releases/latest)在 CLI 之外还包含 Modern Homelab 定义归档。它们描述了预期的站点、应用放置、连接和权限边界。请查看该版本的 `release-evidence.json`，了解实际附在该版本上的运行时证据。

[仅工具链安装指南](/zh-Hans/guides/stackkits/choosing-a-kit#仅安装工具链)说明了如何下载 CLI 和 Modern 定义。完整的 Modern 部署仍然需要具体的连接、身份、路由、TLS 和位置故障行为。仅有配置或生成的计划并不能验证这些行为。

## 选择入口路径

对于家中已有的 Linux 主机，请选择 [Basement Kit](/zh-Hans/stackkits/kits/basement-kit)；对于带有你所掌控域名的已有云主机，请选择 [Cloud Kit](/zh-Hans/stackkits/kits/cloud-kit)。它们的指南把配置引导和特定版本的运行时证据分开陈述。

探索 Modern 时也请保持同样的区分：保护已有数据，并保留每个工作区的配置和运维输出。在所选版本对该行为有证据之前，不要假定应用在连接或 Cloud 故障期间仍然可用。

所有入口路径参见[选择 StackKit](/zh-Hans/guides/stackkits/choosing-a-kit)，已发布应用适配器所声明的能力参见[应用交付兼容性](/zh-Hans/stackkits/reference/application-delivery-compatibility)。
