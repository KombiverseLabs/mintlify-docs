Cloud Kit 作为预览版包含在当前公开版本（v0.35.x）中。目前还没有自动化的生命周期运行覆盖公网 VPS，因此[操作系统兼容性](/zh-Hans/stackkits/reference/os-compatibility)将其列为 `unverified`。它使用与 Basement Kit 相同的独立创作生命周期，但面向一台已有的、公共 DNS 和 TLS 由你掌控的云主机。

<Note>
  该版本包含 Cloud Kit 定义和安装程序。请把配置引导和特定版本的实时运行时证据当作两个独立的声明。
</Note>

## 开始之前

请在 StackKits 之外准备好以下内容：

- 一台你有权运维的、现成可用的主机
- 一个你掌控的域名和 DNS 记录
- 与公开服务相适应的主机和网络安全态势

StackKits 会针对该主机验证并应用它自己的系统定义。它不会配置服务器、选择提供商或保管提供商凭据。

## 启动 Cloud Kit

在 Linux 或 macOS 上引导已发布的工作区：

```bash
curl -sSL https://cloud.stackkit.cc | DOMAIN=example.com sh
cd ~/my-cloud-homelab
```

请用你自己拥有的域名替换 `example.com`。把 StackSpec 和验证输出与工作区放在一起，重新生成产物之前只更改 StackSpec。

如果你已经有 CLI，请[选择 kit](/zh-Hans/guides/stackkits/choosing-a-kit)并[配置 StackSpec](/zh-Hans/guides/stackkits/configure-stack-spec)。
