Immich 提供[照片](/zh-Hans/guides/stackkits/use-cases/photos)用例。它是可选的原生 v2 `photos` 工作负载的已发布备选方案，初始的 Basement 和 Cloud StackSpec 不会启用它。选择它之前，请先在“照片”页面规划存储和恢复。

## 已发布的契约

| 属性 | 值 |
| --- | --- |
| 工作负载 | `photos` |
| 备选方案 | `immich` |
| 数据类别 | personal |
| 必需的密钥引用 | `database-password` |
| 支持的独立适配器 | `standalone-compose` |

已发布的 CLI 会验证并生成这一工作负载契约，包括持久的照片和数据库分配，以及生成的 Photos 路由。[用例目录](/zh-Hans/stackkits/reference/use-case-catalog)展示了该版本所声明的组件。

`database-password` 槽位保存一个不透明的 `secret://` 引用；其密码由本地所有者托管保管。请在 [StackSpec](/zh-Hans/guides/stackkits/configure-stack-spec) 中选择工作负载、放置位置和适配器，然后按照[添加工作负载](/zh-Hans/stackkits/reference/day-2-operations#向现有工作区添加工作负载)进行验证、建立托管、生成、检查计划、应用并验证。

## 首次使用

1. 在一次已具备有效的、绑定所有者的托管的部署之后，完成 StackKits 验证。
2. 从 Node Hub 或部署输出中打开生成的 Immich 地址。
3. 创建应用所有者账户，并且只在确认存储容量和备份之后再连接客户端。
4. 使用[从手机备份照片](/zh-Hans/guides/stackkits/use-cases/photos/phone-backup)连接每一部手机。

任何配置变更之后，请再次验证 StackKits 工作区。
