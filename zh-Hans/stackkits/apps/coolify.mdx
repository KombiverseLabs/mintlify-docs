Coolify 是可选的应用平台和工作负载适配器。当你希望由 Coolify 管理你的应用时，请显式选择它。默认的独立工作区直接使用 Compose。

| 角色 | 已发布目录中的行为 |
| --- | --- |
| 选择方式 | 可选的显式集成；独立 Compose 不需要应用平台 |
| 工作负载适配器 | 支持 `files`、`photos` 和 `vault` |
| 路由和 TLS 证据 | 支持 |
| 工作负载备份与恢复 | Coolify 适配器不提供 |

## 安全使用

1. 在打开应用平台之前，先完成并验证 StackKits 部署。
2. 从 Node Hub 或 StackKits 的输出中打开生成的 Coolify URL。
3. 每个工作负载只使用一条应用交付路径；不要手动创建相互竞争的生成路由。
4. 应用凭据和恢复材料由本地所有者掌管。
5. 只有当所选适配器声明支持备份与恢复时，才使用 StackKits 的备份路径。

## 验证

- 生成的 Coolify 路由可以在部署所报告的地址上打开。
- StackKits 验证报告应用平台及其已配置的路由状态健康。
- StackKits 工作区仍然是配置意图的来源。

关于 beta 备选方案，参见 [Komodo](/zh-Hans/stackkits/apps/komodo)。关于完整的适配器矩阵，参见[应用交付](/zh-Hans/guides/stackkits/application-delivery)。
