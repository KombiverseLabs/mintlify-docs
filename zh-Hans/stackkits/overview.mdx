StackKits 是独立的、开放的 homelab 标准。它提供可移植的 kit 定义、`stackkit` CLI 和 MCP 连接器，以及用于验证、生成、应用和检验栈的本地生命周期。

StackKits 针对你已经掌控的主机工作；它不需要 kombify 账户，也不需要托管的 kombify 端点。

## 特定版本的文档

请查看[用例目录](/zh-Hans/stackkits/reference/use-case-catalog)、[操作系统兼容性](/zh-Hans/stackkits/reference/os-compatibility)和[应用交付兼容性](/zh-Hans/stackkits/reference/application-delivery-compatibility)，了解列出的组件和声明的兼容性。每份参考文档都标明并链接了它所描述的已发布版本。操作系统兼容性以及应用交付兼容性中的 Lifecycle test 列，来自该版本在全新虚拟机上的自动化生命周期运行：install、init、generate、apply、verify、backup 和 restore。用例目录和声明的适配器能力不是在真实主机上部署或验证的证据。

提到某个版本的指南和示例，描述的就是该版本。不要假定旧示例已经针对更新的版本验证过。

Modern Homelab 在每个版本中都作为 alpha 定义归档提供，用于创作和验证；它不是安装路径。

请根据你所掌控的环境来选择 kit，而不是根据你想运行的服务数量。

第一条成功的独立路径见[快速开始](/zh-Hans/stackkits/quickstart)。

## StackKits 不做什么

- 为你创建或购买服务器
- 保管提供商凭据或管理提供商资源
- 要求 Standard Mode 使用托管控制平面
- 取代独立生命周期所产生的本地所有者和证据
