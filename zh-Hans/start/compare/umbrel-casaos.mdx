[Umbrel](https://umbrel.com) 和 [CasaOS](https://casaos.io)，连同同一厂商定位为其继任者的 ZimaOS，能把家里的电脑变成个人服务器。你打开浏览器，在应用商店中点击即可安装应用。它们是通往可用家用服务器最快的方式，而且许多人永远也不需要更多功能。

## 它们擅长什么

- 你可以从镜像安装系统，或购买预装好系统的硬件，然后在浏览器中完成全部设置。
- 应用商店就是主界面。安装应用只需点击一次。
- 界面对不想接触终端的用户非常友好。
- CasaOS 也可以通过一条命令安装在现有的受支持 Linux 系统之上。

## kombify 是什么

kombify 通过声明式文件而不是点击操作来定义 homelab。StackKits 负责规划、应用和验证。通过 Pocket ID 使用通行密钥登录、每个服务的访问策略、路由、备份和更新都随定义一起提供。Homelab 负责运行它，而 kombify Cloud 和 kombify AI 均为可选项。

## 它们目前的区别

Umbrel、CasaOS 和 ZimaOS 从镜像或脚本与浏览器起步。它们的应用商店是主界面，拥有庞大的社区目录，且可以通过商店工具安装 Compose 项目。kombify 从一台准备好的 Linux 宿主机和一条命令起步。它的主界面是一份声明式定义（以 Homelab 作为应用），其目录经过精选，列在[使用场景目录](/zh-Hans/stackkits/reference/use-case-catalog)中。它不包含 Plex，也不包含 Sonarr 或 Radarr 系列。将你自己的 Compose 项目纳入 homelab 的登录、路由与备份体系尚未实现。kombify 中的恢复会先进入隔离的暂存副本，并且每次安装都带有供你自己的 AI 代理使用的本地 MCP 服务器。

## kombify 目前的局限性

kombify 仍处于 1.0 之前阶段，发布频率较高。兼容性仍在验证中，请参阅[系统兼容性](/zh-Hans/stackkits/reference/os-compatibility)。目前没有引导镜像，因此你需要从一台准备好的 Linux 宿主机起步。如果你今天想烧录一个 U 盘并在应用商店里点选安装，请使用 Umbrel 或 CasaOS。

## 结合使用或二选一

- 如果你希望以最短路径跑起应用并拥有包含大量应用的商店，请选择 Umbrel、CasaOS 或 ZimaOS。
- 如果你希望整个 homelab 都描述在一份你可以审阅、在第二台服务器上重复部署并交由你自己的 AI 代理读取的定义中，请选择 kombify。
- 它们可以运行在彼此独立的机器上。kombify 中没有任何功能依赖它们。
