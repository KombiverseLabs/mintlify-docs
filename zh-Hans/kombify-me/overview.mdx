kombify.me 为家庭实验室服务提供 `*.kombify.me` 下稳定的 HTTPS 名称。它是可选的联网入口路径：需要公共地址时很有用，技术栈保持在本地网络时则无需使用。

<Warning>
kombify.me 是 Alpha 软件。名称、标头和错误格式仍可能变化。请不要将其视为正式发布版本。
</Warning>

## 你可以做什么

- 当源站已可从公共互联网访问时，在 `*.kombify.me` 主机上打开套件服务。
- 让 `auth` 这类官方套件名称使用 `{your-lab}-auth.kombify.me`，而不是 `auth.kombify.me` 这样的保留根域名。
- 当源站不是公开的时，通过 Techstack 节点代理中继私有 HTTP(S) 目标。

kombify.me 不会取代 StackKits。即使没有 kombify.me 地址，本地套件依然可以安装、验证和运行。

## 如何协同

| 关注点 | 负责方 |
| --- | --- |
| 套件定义、本地生命周期和局域网可达性 | StackKits |
| 编排以及用于私有目标的节点代理 | Techstack |
| 公共 HTTPS 名称、代理和私有 HTTP 中继 | kombify.me |
| 托管 kombify 账号的登录 | `login.kombify.io` |
