### 电子邮件支持何时回复

- 服务时间为每天 08:00 至 22:00（Europe/Berlin 时间）。
- 你会在 4 个服务小时内收到首次回复。
- 22:00 之后收到的邮件会在次日 12:00 之前回复。

### 私下报告安全问题

请仅通过 [GitHub Security Advisories](https://github.com/kombifyio/StackKits/security/advisories/new) 报告安全问题。切勿为此提交公开的 issue 或讨论，因为任何人都可以阅读它们。

## 需要包含的内容

一封好的首封邮件可以省去一轮追问。请包含：

1. 你的操作系统及其版本，例如 Ubuntu 24.04。
2. 你的硬件，例如“迷你主机”或“虚拟机”，以及内存大小。
3. 你安装的套件，例如 Basement Kit。
4. 你卡住的步骤，以及你预期会发生什么。
5. 在你的工作区文件夹中运行以下命令的输出，并去除机密信息：

```bash
cd ~/my-homelab
stackkit version
stackkit logs latest --json
```

你也可以附上一份已做脱敏处理的支持文件。以下命令会把一份部署日志及其回执写入新文件，并去除机密信息：

```bash
stackkit support export --output support-evidence.json
```

发送前请先阅读该文件，并删除你不想分享的任何内容。

<Warning>
  切勿在电子邮件、讨论或 issue 中发布 `.stackkit/access.json` 的内容或任何密码。也不要包含通行密钥的恢复材料和私钥。
</Warning>
