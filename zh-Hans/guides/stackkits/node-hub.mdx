StackKits Node Hub 是生成的本地服务总览。部署成功后，打开 CLI 打印出的或验证输出中显示的 `base.<domain>` 地址。

## 检查什么

- 页面能识别当前的 StackKits 工作区。
- 只显示经过验证的配置所选择的服务。
- 列出的每个服务都使用本次部署生成的地址。

如果 Node Hub 打不开，请把它预期的 `base.<domain>` 地址与部署输出中的地址对比。确认该主机名能在你使用的客户端上解析，并且该路由属于当前工作区。请修改 StackSpec 并重新生成产物，而不是直接编辑生成的 Node Hub 或路由器配置。

## 完成首次运行保护

1. 通过 CLI 验证核心部署。
2. 打开生成的 Hub 路由。
3. 建立本地 PocketID 所有者。
4. 确认 TinyAuth 保护了预期的路由。
5. 只有在所有者能够完成身份验证之后，才使用 Hub 的保护操作。
6. 配置本地备份仓库，并按照[备份与恢复](/zh-Hans/guides/stackkits/back-up-and-restore)演练一次恢复。

Hub 用于查看状态和已批准的操作。它不是组件安装器、提供商控制台，也不能替代 StackSpec 验证。

[平台服务](/zh-Hans/stackkits/apps/overview)说明了 Hub 背后的服务。[使用场景](/zh-Hans/guides/stackkits/use-cases/overview)列出了你可以添加的工作负载。
