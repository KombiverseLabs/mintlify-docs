设置完成之后，大多数日子里你只需要打开某个服务并使用它。本页介绍会遇到的一些小事。

## 打开你的服务

1. 打开设置时给出的 `base.<domain>` 地址上的 Node Hub。使用默认域名时，就是 `base.home.test`。
2. 点击你想要的服务。每个服务在同一个域名下都有自己的地址。
3. 如果页面要求你登录，请使用你的本地身份登录。

请在家人的每台设备上收藏 Node Hub。那里只会列出你所选择的服务。

## 在手机或另一台电脑上使用

该地址必须能在那台设备上解析。在你的家庭网络内的设备上，其工作方式与你的第一台电脑相同。如果某个服务在一台设备上能打开而在另一台上打不开，说明第二台设备没有使用你的家庭实验室所需要的名称解析。参见[故障排除](/zh-Hans/guides/stackkits/troubleshooting)。

对于手机上的应用，请遵循相应使用场景的指南，例如[来自手机的照片](/zh-Hans/guides/stackkits/use-cases/photos/phone-backup)或[密码管理器应用](/zh-Hans/guides/stackkits/use-cases/passwords/clients)。

## 从家庭之外访问

默认情况下，你的家庭实验室只能在你的网络内访问。如果你想为某个服务使用公开的 `https://` 名称，请阅读 [kombify.me](/zh-Hans/kombify-me/overview)。是否发布由你按服务逐个选择。没有暴露的服务保持未发布状态。

## 保持健康运行

偶尔在文件夹 `~/my-homelab` 中执行：

```bash
stackkit verify --json
stackkit drift detect --json
```

`verify` 检查技术栈是否仍与已应用的内容一致。`drift detect` 告诉你是否有内容在 StackKits 之外被更改。请把输出保存在工作区旁边，以便日后比较。参见[运维 StackKit](/zh-Hans/stackkits/reference/day-2-operations)。

## 更改内容

不要编辑生成的文件。请编辑 StackSpec，检查计划，然后应用。步骤见[查看计划并应用](/zh-Hans/guides/stackkits/review-plan-and-apply)。

## 养成备份的习惯

在每次较大的更改之前先备份，并不时练习一次恢复。参见[备份与恢复](/zh-Hans/guides/stackkits/back-up-and-restore)。
