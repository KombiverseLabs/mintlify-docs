邮件目前还无法安装。设计方向是客户端优先：先连接你现有的邮箱，再考虑是否运行自己的邮件服务器，这两个决定彼此独立。

## 规划中的设计

| 体验 | 含义 | 状态 |
| --- | --- | --- |
| 连接现有邮箱 | 使用自托管的网页邮件客户端，通过你当前服务商的 IMAP/SMTP 或受支持的登录方式收发邮件，而无需自己运营邮件投递 | 规划中 |
| 运行自己的邮件服务器 | 使用 Stalwart 或 mailcow 之类的集成套件，为你自己的域名运营邮件投递 | 已在目录中声明；无法安装 |

选择邮件时，计划保证绝不会在没有明确、单独的批准步骤的情况下修改 DNS 或 MX、开放公共 SMTP 监听端口，或代你发送任何内容。运行自己的邮件服务器规划为一个可选项，面向想要运营自己域名的家庭，而不是使用现有账户配合邮件客户端的前提条件。

## 目前已有什么

发布目录声明了一个 `mail` 使用场景，包含 Stalwart Mail Server 组件和一项已记录的设置：你的邮件域名。已记录是指该设置被保存下来，留待后续版本应用。当前版本不会安装或配置 Stalwart，因此目前没有可供选择、生成或应用的邮件内容。

## 你可以期待什么

- 客户端优先的流程，先于任何自托管邮件服务器的要求。
- 发送真实邮件将需要明确、单独的批准步骤。
- 自有邮件服务器或套件发布后，将是额外的可选项，而不是取代你现有邮箱的方案。
