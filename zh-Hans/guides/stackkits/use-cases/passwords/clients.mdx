<div className="step-content">

### 在浏览器中打开你的保险库。

<p className="step-intro">先从电脑开始。你的保险库有自己的网址，就像一个只有你们家庭使用的网站。</p>

<ol className="click-list">
<li><span className="click-num">1</span><span>在浏览器的地址栏中输入你的保险库地址，例如 <strong>https://vault.home.test</strong>，然后按 Enter。</span></li>
<li><span className="click-num">2</span><span>在登录框下方点击 <span className="key">Create account</span>。</span></li>
</ol>

<div className="micro-note">本指南中的地址只是示例。请使用设置 kombify 的人提供给你的地址。</div>

<div style={{ marginBlock: "1rem" }}>
<p><strong>什么是保险库地址？</strong></p>

它是你们家庭密码保险库的网址。通常以 <strong>https://vault.</strong> 开头，以你家庭网络的名称结尾。设置 kombify 的人可以告诉你确切的地址。

</div>

<div className="step-check">你看到 <span className="key">Create account</span> 表单。</div>

</div>

<div className="step-content">

### 创建你的账号。

<p className="step-intro">你的保险库只接受受邀的邮箱地址。请使用收到邀请的同一个地址。</p>

<ol className="click-list">
<li><span className="click-num">1</span><span>在 <span className="key">Email address</span> 中输入你受邀的邮箱地址。</span></li>
<li><span className="click-num">2</span><span>在 <span className="key">Name</span> 中输入你的名字。运营保险库的人以及你与之共享密码的人都可以看到它。</span></li>
<li><span className="click-num">3</span><span>点击 <span className="key">Continue</span>。</span></li>
</ol>

<div style={{ marginBlock: "1rem" }}>
<p><strong>这是我的 kombify 账号吗？</strong></p>

不是。这个账号只属于你的密码保险库。它有自己的邮箱地址和自己的主密码。

</div>

<div className="step-check">页面现在要求你 <span className="key">Set a strong password</span>。</div>

</div>

<div className="step-content">

### 选择你的主密码。

<p className="step-intro">主密码是你仍然需要记住的唯一一个密码。它可以解锁所有其他密码。</p>

<ol className="click-list">
<li><span className="click-num">1</span><span>在 <span className="key">Master password</span> 中输入一个较长的密码。由四个或更多词组成的一句短话效果很好。</span></li>
<li><span className="click-num">2</span><span>在 <span className="key">Confirm master password</span> 中再次输入相同的密码。</span></li>
<li><span className="click-num">3</span><span>点击 <span className="key">Create account</span>。如果页面建议安装浏览器扩展，请点击 <span className="key">Add it later</span>，然后点击 <span className="key">Skip to web app</span>。你会在第 5 步连接扩展。</span></li>
</ol>

<div className="micro-note"><strong>忘记的主密码无人能够找回</strong>，运营你保险库的人也不行。请把它写下来，并把纸条保存在保险库之外的安全地方。</div>

<div style={{ marginBlock: "1rem" }}>
<p><strong>强度条是什么意思？</strong></p>

它估计你的密码有多难被猜到。请争取达到 <strong>Strong</strong>。长一些比复杂更好。

</div>

<div className="step-check">你的空保险库会打开，标题为 <span className="key">All vaults</span>。</div>

</div>

<div className="step-content">

### 保存你的第一个密码。

<p className="step-intro">保存一条登录信息作为测试。之后它可以证明你的应用已连接到你的保险库。</p>

<ol className="click-list">
<li><span className="click-num">1</span><span>在右上角点击 <span className="key">New</span>，然后选择 <span className="key">Login</span>。如果先出现欢迎窗口，请点击 <span className="key">Skip</span>。</span></li>
<li><span className="click-num">2</span><span>在 <span className="key">Item name</span> 中输入一个你认得的名称，例如某个商店的名称。</span></li>
<li><span className="click-num">3</span><span>输入你的 <span className="key">Username</span>。在 <span className="key">Password</span> 旁点击圆形箭头生成一个密码，然后点击 <span className="key">Use this password</span>。</span></li>
<li><span className="click-num">4</span><span>点击 <span className="key">Save</span>。</span></li>
</ol>

<div className="micro-note">在 <span className="key">Website (URI)</span> 下添加该商店的网址。之后浏览器扩展就会在该网站上建议使用这条登录信息。</div>

<div className="step-check">出现消息 <span className="key">Item added</span>，并且你的登录信息显示在列表中。</div>

</div>

<div className="step-content">

### 连接 Bitwarden 应用。

<p className="step-intro">每个 Bitwarden 应用起初都会连接到 Bitwarden 自己的服务器。请告诉它一次，改用你的保险库。</p>

<ol className="click-list">
<li><span className="click-num">1</span><span>从上面的列表安装 Bitwarden 应用并打开它。</span></li>
<li><span className="click-num">2</span><span>在登录界面中，打开 <span className="key">Logging in on</span> 菜单并选择 <span className="key">Self-hosted</span>。在电脑应用中，该菜单叫作 <span className="key">Accessing</span>。</span></li>
<li><span className="click-num">3</span><span>在 <span className="key">Server URL</span> 中输入你的保险库地址，开头带上 <strong>https://</strong>，然后点按 <span className="key">Save</span>。</span></li>
<li><span className="click-num">4</span><span>使用你的邮箱地址和主密码登录。</span></li>
</ol>

<div className="micro-note">请在你使用的每部手机、每个浏览器和每台电脑上重复这些步骤。每一个都需要输入一次你的保险库地址。</div>

<div style={{ marginBlock: "1rem" }}>
<p><strong>为什么这里没有应用的图片？</strong></p>

Bitwarden 的条款没有授权复用其图片。它自己的指南展示了每一个界面，上面的标签与之一致。

</div>

<div className="step-check">应用显示你在第 4 步保存的登录信息。</div>

</div>

<div className="step-content">

### 一切都连接好了吗？

<p className="step-intro">在网页版保险库和一个应用中检查。只勾选你亲自检查过的项目。</p>

<div className="verify-list">
<label><input type="checkbox" data-guide-step="5" data-guide-check="0" id="kcg-passwords-verify-5-0" /><span>我可以打开我的保险库地址并登录。</span></label>
<label><input type="checkbox" data-guide-step="5" data-guide-check="1" id="kcg-passwords-verify-5-1" /><span>我保存的登录信息显示在我手机、浏览器或电脑上的 Bitwarden 应用中。</span></label>
<label><input type="checkbox" data-guide-step="5" data-guide-check="2" id="kcg-passwords-verify-5-2" /><span>我的主密码已写下来，并保存在保险库之外。</span></label>
</div>

<div className="micro-note">本指南不会读取你的保险库。你的勾选只保存在此浏览器中。</div>

<div className="step-check">现在你可以把其他密码迁移到保险库中了。</div>

</div>
