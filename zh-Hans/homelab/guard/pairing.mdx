配对是将一台服务器在 Homelab 中归属到你名下的过程。本页从你的视角说明整个过程：你发起什么、服务器做什么、你确认什么，以及中途停止时如何恢复。如需运行命令本身，请使用[配对命令](/zh-Hans/homelab/pairing-command)；若改为通过 SSH 连接，请参阅[通过 SSH 连接服务器](/zh-Hans/homelab/ssh-connection)。两者都会安装同一个 Guard。

<Note>
Homelab 处于 1.0 之前，已连接运行模式属于预览范围；请参阅 [Homelab 可用性](/zh-Hans/homelab/availability)。诸如密钥批准步骤等细节取决于服务器上安装的 Guard 版本。
</Note>

## 按顺序发生的事情

<Steps>
  <Step title="你发起配对">
    在 Add Node 向导中，Homelab 会创建一个个人配对令牌。它只能使用一次，并在 15 分钟后过期。
  </Step>
  <Step title="服务器安装 Guard">
    该命令会从你自己的 Homelab（而非公共镜像）下载 Guard，并使用同一响应中提供的校验和进行核验。签名验证从 Guard 的首次更新开始，因此首次安装信任与你的 Homelab 之间的连接。
  </Step>
  <Step title="服务器生成自己的密钥">
    Guard 会在服务器上生成一个身份密钥。该密钥保留在服务器上。Homelab 将该密钥的公钥指纹绑定到你的服务器。
  </Step>
  <Step title="服务器兑换令牌">
    令牌被消耗，Guard 获得其凭据。Homelab 仅保存该凭据的哈希值。配对确认后，Guard 会删除其保留的令牌。
  </Step>
  <Step title="Guard 建立连接">
    从此之后，Guard 发出的每个请求都带有短期令牌和由服务器密钥签名的证明，因此仅复制凭据会被拒绝。
  </Step>
</Steps>

## 你会看到什么

在 Guard 的首条汇报到达前，进度页面会显示 **Not connected yet**。之后，该服务器的 Guard 面板会列出各项事实，并附上每项的观察时间：

| 事实 | 对配对的含义 |
| --- | --- |
| **Bound** | 服务器在每次连接时都用自己的密钥证明其身份 |
| **Connected** | Guard 通过经过身份验证的连接响应了命令 |

**Connected** 需要一次完整的命令往返，而不仅仅是心跳。刚配对的服务器可能会显示已有汇报到达，但仍在等待第一个操作来确认连接。没有新鲜证据的事实会显示为未证实，绝不会显示为正常。

## 在较旧的 Guard 上批准密钥

在引入主机密钥之前安装的 Guard 仅使用其凭据来证明身份。它会继续汇报，但处于只观察状态：Homelab 不会向其下发变更。当你在服务器上更新 Guard 后，它会提交自己的密钥，面板会在 **Approve this server's key** 下显示指纹。

1. 在服务器上读取 Guard 写入日志的密钥指纹（`sudo journalctl -u homelab-agent`）。
2. 将其与面板中的指纹对比。仅在完全一致时批准。
3. 选择 **Approve key**。这需要过去五分钟内使用第二因素完成的新鲜登录。该提议在 24 小时内有效；选择 **Reject key** 可拒绝它。

## 如果配对被中断

- **命令中断或连接断开。** 在令牌仍有效期间重新运行同一命令。Guard 会恢复同一次纳管注册，而不是重新开始。
- **令牌已过期。** 选择 **Generate new command** 并运行新命令。带有相同服务器密钥的新令牌会替换从未确认过的凭据，因此不会为同一台机器产生两条记录。
- **服务器已经确认过。** 已确认的服务器绝不会被接管。不同的密钥会作为另一台机器纳管注册。
- **Guard 报告时钟问题。** 证明必须在服务器时钟一分钟误差内，且每个只接受一次。时钟错误会显示原因 `proof_clock_skew`；请校正服务器时间。
- **令牌被误复制或泄露。** 使用 `homelab api pairing-tokens delete <id>` 删除它；请参阅 [homelab api pairing-tokens](/zh-Hans/homelab/reference/cli/pairing-tokens) 参考。

## 重新配对已撤销的服务器

在[分离或撤销](/zh-Hans/homelab/guard/revoke-and-uninstall)之后，服务器会显示为已撤销，Guard 会停止执行。如需再次管理该机器，请创建一个新的配对命令并运行它。新配对是在更高代数下的新绑定，因此请随后检查服务器的远程访问设置，不要假定之前的设置已自动沿用。
