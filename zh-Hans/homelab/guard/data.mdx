kombify Guard 会汇报关于你服务器的一组少量固定信息，以便 Homelab 显示其健康状况、安全状态和操作结果。本页列出这些信息，说明它们的去向和保留时长，并指出 Guard 从不发送的内容。

<Note>
Homelab 处于 1.0 之前，已连接运行属于预览范围；请参阅[可用性](/zh-Hans/homelab/availability)。下面的保留期限是当前版本实际执行的。凡是未列出的期限，都尚未确认，本页也不作声明。
</Note>

## 数据的去向

- **自管 Homelab：** Guard 只汇报给你自己的 Homelab。除非你连接该安装，kombify 不会收到任何内容。
- **已连接或托管：** Guard 通过其经过身份验证、绑定密钥的连接汇报给由 kombify 运营的 Homelab（参见[配对服务器](/zh-Hans/homelab/guard/pairing)）。

Guard 始终通过 HTTPS 向外连接，你不需要为它开放任何入站端口。每份汇报在接收时都会绑定到你的账户，每次读取也都限定在该账户内：任何客户都无法读取其他客户的主机名、地址或指标。

## Guard 汇报的内容

| 内容 | 示例 | 用途 |
| --- | --- | --- |
| 服务器身份 | 服务器和所有者标识符、服务器公钥的指纹、Guard 版本 | 验证服务器并将其绑定到你 |
| 存活状态 | 上次汇报的时间、启动 ID、机器 ID 的摘要（绝不是机器 ID 本身）、日志健康状况、未解决操作的数量 | 显示服务器是否已连接，并检测重启或克隆 |
| 资源使用 | CPU、内存、交换、负载、各挂载点的磁盘、运行时长；各容器的 CPU 和内存 | 容量与健康状况 |
| 主机详细信息 | 主机名、操作系统及版本、架构、CPU、内存和磁盘大小、运行时版本、公网、私网和本地 IP 地址、SSH 主机公钥、监听端口、观测到的网络位置（地址、网关、子网、接口、无线网络名称）、磁盘健康状况 | 可达性、SSH 主机固定、暴露面检查以及检测网络变更 |
| 服务 | StackKit 名称、版本和模式，服务和容器名称、镜像引用、探测到的健康状况、端点 | 运维并验证你的服务 |
| 安全状态 | 哪些主机控制项符合、发生偏离或未知，预期值和观测值，已批准的例外，基线版本 | 显示并提醒受保护的配置 |
| 恢复状态 | 上次备份的时间和状态、上次已验证恢复的结果 | 显示服务器是否可恢复 |
| 操作回执 | 命令 ID、操作、结果状态、有界的结果摘要、脱敏的日志行 | 可审计的执行记录 |

默认情况下，Guard 大约每 30 秒收集一次资源数据，并大约每 15 分钟向主机请求一次新的安全观测。观测主机不会对主机做任何更改。

还有一类是可选加入的。如果服务器上的智能家居自动化已设置为通知你，Guard 只转发其作者撰写的通知文本（最多 280 个字符），以便它作为通知送达你。该功能默认关闭，按自动化逐项开启，并且从不发送实体状态、在家状态、门锁、摄像头或传感器历史。

<Note>
指标和标签名称是一份允许列表，会在两处强制执行：服务器上、在本地存储任何数据之前，以及数据到达时。不在列表中的值会被丢弃，因此行为异常的采集器无法扩大离开你主机的内容范围。
</Note>

## Guard 从不发送的内容

- 应用内容：你的服务所保存的文件、数据库、消息或照片。
- 你应用的环境变量、机密或凭据。
- 你家庭成员的个人数据。
- 所有者的电子邮件地址。它属于 StackKits 配置，不属于 Guard 数据。

应用内容只会通过一个独立的、只读的组件到达 kombify，该组件有自己的同意模式，绝不会通过 Guard 的连接、暂存、回执或日志。

## 保留时长

| 数据 | 保留时间 |
| --- | --- |
| 安全发现历史 | 发现解决后再保留 90 天 |
| 资源指标 | 约 15 天；驾驶舱的趋势图会保留更粗粒度的数据点，最长 30 天 |
| 服务器的当前状态 | 只要服务器处于配对状态 |
| 故障期间未发送的数据 | 服务器上有限的本地队列（默认 8 MiB，约六小时）。队列溢出时会丢弃最旧的数据，并留下一个标记记录该缺口。 |

故障之后，Guard 会按从旧到新的顺序发送排队的数据。缺口会得到明确汇报，绝不会被悄悄补齐。

## 分离服务器后数据会怎样

分离服务器会撤销其凭据并终止其远程可达性，如[撤销与分离](/zh-Hans/homelab/guard/revoke-and-uninstall)所述。随后，服务器上的 Guard 会删除其身份密钥、凭据、排队的遥测数据，以及 Homelab 已确认的操作记录。服务器记录会作为已分离记录连同其审计轨迹保留在 Homelab 中，而已经收集的历史会按上面的期限逐步过期。

数据约定还设定了在 30 天内移除已分离服务器的清单、指标和安全状态的目标。本版本尚未确认该自动移除，因此本页不把它作为保证来声明。
