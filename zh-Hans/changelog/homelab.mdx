<Update label="2026-09-07" description="kombify.me 公共地址" tags={["Weekly digest"]}>

## kombify.me 公共 HTTPS 名称

公开文档现在在 Techstack 下介绍 [kombify.me](/zh-Hans/kombify-me/overview)：为已经可访问的 Homelab 服务提供稳定的 HTTPS 名称、`{your-lab}-auth.kombify.me` 这类第一方 Kit 名称，以及通过 Techstack 节点代理提供的可选私有 HTTP 中继。仅限本地的浏览仍使用 Homelab 解析器。kombify.me 目前处于 Alpha 阶段。

</Update>

<Update label="2026-08-21" description="8 月 15 日 – 8 月 21 日当周" tags={["Weekly digest"]}>

## Techstack 开源 Alpha

Techstack 现已公开：一个未签名的 Windows Alpha，以及一个可以安装在你自己机器上的开源客户端，无需托管的 kombify 账户即可操作本地服务器。

### 新功能

- **Techstack Windows Alpha，开源。** Techstack 开放核心客户端现已在 [kombifyio/TechStack](https://github.com/kombifyio/Homelab) 以 AGPL-3.0 发布，未签名的 Windows Alpha 可用于本地服务器的反馈。Techstack 是构建在 StackKits 之上的可选编排与运维体验，这个 Alpha 支持无需账户的本地路径。参见 [Techstack 概览](/zh-Hans/homelab/overview)、[可用性](/zh-Hans/homelab/availability)以及[在 Windows 上安装 Techstack Alpha](/zh-Hans/homelab/install-windows)。

</Update>
