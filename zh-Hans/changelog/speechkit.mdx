## SpeechKit adds Grok Voice

SpeechKit rolled from [v0.76.6](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.6) to [v0.77.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.77.0) : Grok Voice, meeting exports to any note destination, and outbound Network Scope.

### New features

- **Grok Voice for the Voice Agent.** [SpeechKit v0.77.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.77.0) adds xAI Grok Voice 3.0 next to GPT-Live and Gemini Live. Registered agents can now speak natively through any of the three.
- **Export meetings anywhere.** [v0.76.6](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.6) sends a finished meeting to a file, a note app, or your own target, as Markdown or XHTML. See [Meeting Mode](/zh-Hans/speechkit/meeting).

### Updates

- **Outbound Network Scope.** [SpeechKit v0.76.6](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.6) applies Network Scope to outgoing traffic too: device-only, local network, or open. Model downloads and update checks run only when you allow them. See [Modes and data paths](/zh-Hans/speechkit/modes).
- **Provider allow lists and ephemeral retention.** [v0.76.6](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.6) lets hosts allow only named providers. Ephemeral retention keeps your typed notes and sweeps recordings.
- **Complete releases.** [v0.77.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.77.0) publishes the self-hosted server image, Android libraries and app, and desktop bundle together.

### Bug fixes

- **Complete Deepgram dictation.** [SpeechKit v0.76.6](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.6) can transcribe the finished recording, so words at chunk boundaries and at the end are no longer lost.
- **Hold-to-talk ends on release.** [v0.76.9](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.9) always ends a hold-to-talk conversation when you release the shortcut.
- **Meeting and privacy fixes.** [v0.76.6](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.6) withdraws an unanswered meeting offer, lets you repeat onboarding safely, and erases wake-word audio on the server by default.

</Update>

- 取消会中断排队的语音。Android 和网页客户端在发送麦克风音频前先等待服务器就绪。 [v0.75.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.75.0)
- 保留流式单词之间的空格，移除透明悬浮窗口后面的白色边框。 [v0.74.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.74.1) [v0.74.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.74.0)

## SpeechKit 接入 Microsoft 365

SpeechKit 从 [v0.71.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.71.0) 升级到 [v0.73.4](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.4) ：支持导入 Microsoft 365 会议、使用自有密钥的 Google 语音、兼容 OpenAI 的音频端点，以及提供六种语言的应用。

### 新功能

- **会议接入 Microsoft 365。** [SpeechKit v0.72.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.0) 可在 Teams 会议结束后导入 Teams 文字记录或 Microsoft 365 Copilot 回顾，并允许你在同意处理文字记录后选择 Microsoft Foundry 来生成会议纪要。多租户登录让你无需重新安装即可切换公司。参见[会议](/zh-Hans/speechkit/meeting)。
- **使用你自己的 Google 语音密钥。** [v0.73.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.0) 恢复 Google Cloud 语音转文字、文字转语音和 Gemini Live，并将它们作为使用你自己密钥的可选提供商。参见[模式与数据路径](/zh-Hans/speechkit/modes)。
- **SpeechKit 服务器上的 OpenAI 兼容音频。** [v0.73.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.1) 提供 `POST /v1/audio/transcriptions` 和 `POST /v1/audio/speech`，Open WebUI 等客户端可以直接使用。本地专用配置无需云提供商即可运行。
- **SpeechKit 支持六种语言。** [v0.73.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.1) 和 [v0.73.2](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.2) 将 Android 应用、网站、桌面应用和托盘本地化为英语、德语、西班牙语、简体中文、印地语和阿拉伯语。

### 更新

- **带时间戳项目符号的会议笔记。** [SpeechKit v0.71.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.71.0) 将笔记写成带时间戳的项目符号，并允许从会议浮窗快速添加笔记。

### 错误修复

- **更新首次尝试即可重新启动应用。** [SpeechKit v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1) 让首次“安装并重启”操作就能重新启动应用。
- **德语听写更干净。** [v0.72.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.0) 会清除德语填充词后残留的逗号，说明会议截图为何未保存，并允许会议纪要按各自预算依次尝试所有模型。

</Update>

## SpeechKit 登陆 macOS、Google AI 停用

SpeechKit 从 [v0.68.24](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.24) 升级到 [v0.70.3](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.3) ：首个 macOS 构建、把 Microsoft Foundry 作为语音和模型的统一连接，并移除了所有 Google 语音适配器。

### 新功能

- **SpeechKit 可以在 Mac 上运行。** [v0.70.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.0) 在 Windows 资源旁发布了 `SpeechKit-macOS-arm64.zip`：面向 Apple Silicon 上 macOS 14+ 的 Dictation 测试版，采用 ad-hoc 签名，支持麦克风采集、文本注入、菜单栏项、内置本地模型以及云端语音转文字服务商。随之而来的还有一个已知缺口：全局热键监听器会安装，但收不到任何按键事件，因此按住说话（hold-to-talk）暂时无法使用，入口是菜单栏项。参见[在 macOS 上安装](/zh-Hans/speechkit/install-macos)。
- **Microsoft Foundry，三种连接方式。** [v0.69.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.69.0) 新增 Connect 对话框：可使用项目端点和 API 密钥、你机器上已有的 Azure CLI 账户，或你所在组织自己的 Microsoft 应用注册。一个连接同时服务于 Dictation、语音输出、Assist 和 Voice Agent；点击 Test 会列出该项目实际拥有的部署和语音。
- **每种模式一个标签页的 Library。** [v0.70.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.0) 为 Transcriptions、Quick Notes 和 Voice Sessions 各自提供标签页，历史记录按页向前加载，任意一行都可以原地展开，并且你可以像固定 Quick Note 一样固定一条转写记录。

### 更新

- **Google 语音适配器已移除。** [v0.70.2](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.2) 移除了 Google 语音转文字、Google 文字转语音和 Gemini Live。仍然指定其中任何一个的配置会以拒绝（fail closed）方式失败，而不是悄悄解析成别的东西；空的设备配置默认使用 AssemblyAI。参见[模式与数据路径](/zh-Hans/speechkit/modes)。
- **唤醒词是 `hey_kubi`。** [v0.70.2](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.2) 将其设为默认，并保留 `hey_quby` 作为别名，因此现有配置仍可继续使用。
- **这些文档跟随当前版本。** SpeechKit 下载链接现在指向最新发布的版本，而不是某个冻结的版本；macOS 客户端和 Meeting 有了各自的页面，每个页面所标注的发布版本会自动与公开发布版本对齐。

### 问题修复

- **macOS 首次运行可以启动。** [v0.70.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.0) 修复了全新安装会把 Windows 音频后端写入配置、因此拒绝打开麦克风，并且退出时没有任何消息、日志和崩溃报告的问题。
- **Voice Agent 不再启动到已停用的服务商上。** [v0.70.3](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.3) 修复了服务器内置配置仍选择 Gemini Live，因而在 Google 停用后无法启动的问题。
- **Dictation 先打开麦克风。** [v0.70.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.1) 在实时流握手之前而不是之后打开设备，并且安装更新后应用只会重新启动一次。

</Update>

## SpeechKit Meeting Mode 与网络隐私范围

SpeechKit 从 [v0.65.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.65.0) 升级到 [v0.68.24](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.24) ：完整的 Meeting Mode（支持六种语言的评审）、划定硬性网络边界的隐私设置，以及绝不离开设备的会议内截图。

### 新功能

- **Meeting Mode 成为一等模式。** [SpeechKit v0.67.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.67.0) 让 Meeting Mode 与 Dictation、Assist 和 Voice Agent 并列，并提供专属的采集、评审生成、语言和保留设置。通话期间，紧凑的透明浮层会显示采集状态和控制项，滚动摘要不会阻塞采集，会议结束后会生成持久的 Meeting Review、五句话的 Executive Brief，以及英语、德语、西班牙语、中文、印地语和阿拉伯语的待办事项。GitHub Copilot 是可选的评审生成服务商，需要单独且可撤销的转录处理授权；本地路径不需要任何云端凭据。参见 [SpeechKit 模式](/zh-Hans/speechkit/modes)。
- **选定网络边界，SpeechKit 强制执行。** [v0.67.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.67.0) 新增 Network Scope（网络范围）设置：所有网络、仅本地网络或仅此设备。后端会对语音服务商、模型下载、更新、遥测、服务器连接和集成强制执行该边界。切换到更严格的范围时，不兼容的设置会被暂停而不是删除，Settings 会说明哪些被禁用以及原因。参见 [SpeechKit 概览](/zh-Hans/speechkit/overview)。
- **会议中的截图，保留在你的机器上。** [v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 可以捕获选定的窗口或光标所在的显示器，快捷键 `Ctrl+Alt+S` 可配置。截图会作为标记出现在转录时间线中，并在生成的 Meeting Review 中被引用；紧凑的会议标签会短暂展开预览，让你确认捕获的是正确的窗口。任何图像都不会离开设备。
- **查找并导出任意会议。** [v0.68 补丁版本](https://github.com/kombifyio/SpeechKit/releases)按会议发生的时间对会议列表分组，新增对标题、转录、笔记和总结的搜索，把笔记渲染为格式化的 Markdown，并为完整总结新增 Copy Markdown 和 Save .md。

### 更新

- **会议自动结束。** [SpeechKit v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 会在通话应用释放麦克风后不久停止录制，并通过通知告诉你 Meeting Review 何时就绪或失败原因。手动启动的录制不会被自动停止。
- **集成会显示其成熟度。** [SpeechKit v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 在 Settings 中把每个集成标记为 Ready、Partial、Planned 或 Unavailable，并附带各模式的标签。此版本无法运行的内容会被置灰，而不是在启用时失败。
- **更精简的 SpeechKit SDK。** [v0.65.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.65.0) 移除了 v0.64.0 中弃用的服务商名称，因此只使用 Deepgram 的应用编译 49 个外部包，而不是 286 个。[v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 把根包拆分为契约与实现，并通过机械化的导入重写完成迁移。[v0.66.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.66.0) 把全部五个 Android 模块作为 Apache-2.0 制品发布到 JitPack，可匿名解析。参见 [SpeechKit 框架](/zh-Hans/speechkit/framework)。
- **浮层设置变成了设计器。** [v0.68 补丁版本](https://github.com/kombifyio/SpeechKit/releases)把 General 设置重绘为紧凑卡片，并实时预览浮层：样式、位置以及悬停条上的快捷按钮都会立即在预览中更新。

### 问题修复

- **不再有静默失败。** [SpeechKit v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 会在活动日志中报告被丢弃的 Voice Agent 语音、浮层定位失败、静默的截图错误和停滞的会议摘要，并附上原因，而不是让你去猜。
- **会议音频不再进入听写。** [v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 让会议转录运行在自己的管线上。通话音频不再闪现听写浮层、不再填充听写历史，也不再成为复制和插入快捷键所复用的“上一次转录”。
- **长会议也能生成总结。** [v0.68 补丁版本](https://github.com/kombifyio/SpeechKit/releases)为内置本地模型调整摘要批次大小，在句子边界处拆分过长的转录片段，恢复因重启而中断的总结，并在本地模型暂时不可达时重试，而不是让评审永久失败。
- **本地听写可在非 ASCII 安装路径下启动。** [v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 修复了模型路径包含变音符号时，内置 whisper-server 在全新安装上启动失败的问题。如果本地语音转文字仍无法启动，活动日志会指出原因，并说明听写是离线，还是回退到了某个具名的云端服务商。
- **多语言评审依次运行。** [v0.68.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.0) 阻止并行的评审运行饿死本地模型并一起错过截止时间，进度会跟随实际运行的语言，而不是卡在 0% 的排队任务上。
- **仪表盘以合适的尺寸打开。** [v0.68 补丁版本](https://github.com/kombifyio/SpeechKit/releases)不再让窗口打开得比缩放后的笔记本屏幕更高，把最小尺寸保持在 13 英寸显示器范围内，并保留你选择的尺寸。
- **Connect 按钮如实反映状态。** [v0.67.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.67.0) 修复了托管连接在从未获得凭据的情况下声称已就绪的问题；Android 应用现在会在 Companion 配对因两个已安装的应用不匹配而失败时明确说明，而不是显示一般性失败。

</Update>

## SpeechKit 会议笔记与局域网发现

SpeechKit 从 [v0.59.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.59.0) 升级到 [v0.64.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.64.0) ：从你手写的笔记出发的会议笔记、让设备无需输入地址就能找到你的 Homelab 服务器的局域网发现，以及所有客户端上的点按打断。

### 新功能

- **从你自己的笔记开始的会议笔记。** [SpeechKit v0.59.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.59.0) 新增会议记事本：你的笔记为主，转录补全其余内容，总结会引用其出处的原话。麦克风和系统音频保持在各自独立的音轨上，因此说话人标签自然可得，且音频不会被保留。当通话应用占用麦克风时，SpeechKit 会注意到并提议做笔记；在你接受之前不会录制任何内容。会议一结束，总结就会出现在仪表盘中。参见 [SpeechKit 模式](/zh-Hans/speechkit/modes)。
- **在家庭网络中找到你的 SpeechKit 服务器。** [v0.60.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.60.0) 让 Homelab 服务器通过 mDNS/DNS-SD 自我宣告，桌面应用、Android 应用和 `speechkitctl discover` 无需输入地址就能找到它。发现功能需主动开启、默认关闭，因此托管实例保持静默；宣告只说明去哪里敲门：设备连接后仍需登录。参见 [SpeechKit 概览](/zh-Hans/speechkit/overview)。
- **可从任意客户端打断助手。** [SpeechKit v0.62.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.62.0) 把点按停止语音回答的功能带到了 Web 和 Android 客户端，而不仅限于桌面应用。开启说话人识别后，Web 和 Android 上的转录会带有说话人标签，每个客户端也会显示当前会话使用的语音后端。参见 [SpeechKit 模式](/zh-Hans/speechkit/modes)。
- **Android 上的语音笔记转录与摘要。** [v0.60.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.60.0) 可以在 SpeechKit 应用中转录语音笔记，并对 WhatsApp 和 Telegram 的语音消息生成摘要。

### 更新

- **Words 和 Replacements 可管理。** [SpeechKit v0.62.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.62.0) 让自定义 Words 和 Replacements 在 Settings 中可搜索、可分页、可删除。多种口语形式可以改写为同一个词条，别名在 Dictation、Assist 和 Voice Agent 中生效。
- **一个控件选择你的听写引擎。** [v0.62.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.62.0) 在一个 Dictation 设置中切换 Deepgram Nova-3 和 AssemblyAI Universal 3.5，AssemblyAI 的 LLM Gateway 成为原生后端，使用与语音转文字相同的 API 密钥。
- **浮层就是控制条。** [v0.59.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.59.0) 让你选择哪些操作放在 Windows 浮层上、轮换语音语言，并从浮层启动会议。参见 [SpeechKit 框架](/zh-Hans/speechkit/framework)。
- **每个语音服务商一个 Go 包。** [v0.64.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.64.0) 把每个语音和实时语音服务商拆分为独立的 SDK 包，因此只对接一个后端的应用不再编译其余部分。旧名称在 v0.64 之前仍可使用，并附有迁移表，将在 v0.65.0 中移除。模型目录现在是单一来源，条目带有 `modality` 字段。

### 问题修复

- **被拒绝的语音会话会自行说明原因。** [SpeechKit v0.62.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.62.0) 让被拒绝的 Voice Agent 会话指出唯一需要更改的一处，并且每个错误都带有支持人员查找该请求所需的 ID。
- **口语数字输出为阿拉伯数字。** [v0.61.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.61.0) 把口语数字写成阿拉伯数字，并去除德语填充词，如 äh 和 ähm，包括语言设置为所有语言时。
- **助手不再打断自己。** [v0.61.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.61.0) 拒绝把代理自己的声音当作插话（barge-in），避免挂起的服务商关闭操作让会话卡在结束状态，并以正确的 24 kHz 采样率播放回复。
- **Windows 在更新后显示真实版本。** [v0.61.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.61.0) 让 Install and restart 显示已发布的版本，而不是之前的版本。
- **完整采集的 Dictation 遵循你的引擎选择。** [v0.62.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.62.0) 使用所选的语音引擎，而不是总是先尝试 Deepgram。
- **键盘在 Android 上表现正常。** [v0.60.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.60.0) 让 SpeechKit 出现在 Gboard 建议栏上并恢复键盘上的服务商按钮，[v0.61.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.61.0) 让测试连接保持可用，直到你明确切换到托管连接。

## SpeechKit v0.53.0 – v0.57.0：随处可用的统一语音助手、Android Voice Agent、托管的 Web 助手

SpeechKit 发布了 [v0.57.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.57.0)。Android 应用现在可以进行真正的口语对话，并可直接从 SpeechKit 键盘访问助手。每个 SpeechKit 服务器都提供开箱即用的 `/assistant` 网页。同一个动画助手在 Android、Windows 浮层和 Web 上呈现一致，由同一个共享库驱动。Deepgram Flux v2 现在可用于实时、语音转文字和文字转语音。

### 新功能

- **Android Voice Agent 客户端。** [SpeechKit v0.57.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.57.0) 为 Android 应用新增实时 Voice Agent。按下说话，听取回答，并在说话时看着转录逐步生成。SpeechKit 键盘会就地打开助手，因此对话不会进入文本框，而听写仍然写入其中。参见 [SpeechKit 模式](/zh-Hans/speechkit/modes)。
- **每个 SpeechKit 服务器上的托管 `/assistant` 网页。** [v0.55.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.55.0) 提供开箱即用的 Voice Assistant 页面。在任意浏览器中打开、连接，然后开始说话。参见 [SpeechKit 概览](/zh-Hans/speechkit/overview)。
- **Voice Assistant 外观设置，以及随处一致的视觉语言。** [v0.55.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.55.0) 新增 Settings，可选择动画（Aura 球体或 Waveform）、中心标志，以及默认是否显示实时转录，并带有实时预览。[v0.57.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.57.0) 发布共享球体，使 Android 应用、Windows 浮层和托管网页基于同一来源绘制同一个助手。参见 [SpeechKit 框架](/zh-Hans/speechkit/framework)。
- **覆盖所有语音路径的 Deepgram Flux v2。** [v0.54.10](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.10) 让 Deepgram Flux v2 可用于实时 Voice Agent、语音转文字和文字转语音。
- **Local Box 媒体生命周期。** [v0.54.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.0) 通过已配对 Kombify Box 上的本地设备代理播放媒体，因此音频路径保持在你自己的网络内。

### 更新

- **重建的 Windows Voice Agent 浮层。** [SpeechKit v0.56.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.56.0) 把浮层变成一个深色、易读、以动画和对话为中心的面板。控制项只在你伸手去用时才出现。Quick Note 移到了浮层上，每个浮层图标都有工具提示。
- **带独立验证阶段的静默更新器。** [v0.52.11](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.11) 静默安装更新，[v0.52.12](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.12) 让 SpeechKit 在安装后自行重新启动，[v0.54.10](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.10) 显示独立的验证阶段，而不是看起来停在 100%。
- **数字形式的 1.0 之前版本重新回到公开渠道。** [v0.52.9](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.9) 把数字形式的 `v0.x` 版本作为普通 GitHub Release 发布，并推进规范的 `latest` 别名，使网站、安装器镜像和应用内更新器对最新构建保持一致。[v0.52.10](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.10) 恢复了 v0.51.37 至 v0.52.9 缺失的公开发布说明。

### 问题修复

- **启动 SpeechKit 就会打开 SpeechKit。** [v0.56.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.56.0) 从任务栏或开始菜单调出窗口，重复点击时返回到正在运行的应用。
