## StackKits 支持选择游戏平台并就地添加使用场景；SpeechKit Voice 可连接自有模型

StackKits v0.50.4–v0.52.6 带来游戏平台选择、现有安装中的场景添加和更安全的恢复。SpeechKit v0.74.0–v0.76.4 支持自有模型、AssemblyAI 和 Deepgram 对话，并改进听写可靠性。 [v0.50.4](https://github.com/kombifyio/stackKits/releases/tag/v0.50.4) [v0.52.6](https://github.com/kombifyio/stackKits/releases/tag/v0.52.6) [v0.74.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.74.0) [v0.76.4](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.4)

### 新功能

- 新建游戏安装默认使用 Calagopus，也可选 Pelican 或 Pterodactyl。所有者密钥仅允许读取、电源控制、控制台和文件编辑。stackkit setup game、game list、power 和 allow 在三种平台上保持一致；现有安装保留原平台。 [StackKits v0.52.0](https://github.com/kombifyio/stackKits/releases/tag/v0.52.0) [参考文档](/zh-Hans/guides/stackkits/use-cases/game)

- 通过 stackkit use-cases add（例如 mail）向运行中的安装添加场景，无需改变已有工作负载、路由或存储。StackKits MCP 也支持此操作。 [v0.51.0](https://github.com/kombifyio/stackKits/releases/tag/v0.51.0) [`stackkit use-cases`](/zh-Hans/stackkits/reference/cli/use-cases)

- 服务器迁移到新网络后，stackkit network 重新绑定服务，使监听地址随之更新。 [v0.51.7](https://github.com/kombifyio/stackKits/releases/tag/v0.51.7) [`stackkit network`](/zh-Hans/stackkits/reference/cli/network)

- Voice 对话可使用自己的 AI 端点和模型，并延续已有聊天，包括从浮动面板发起的聊天。 [SpeechKit v0.76.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.0) [参考文档](/zh-Hans/speechkit/modes)

- 已注册的代理可通过 AssemblyAI 或 Deepgram 进行 Voice 对话。整个会话持续检查云处理许可；AssemblyAI 另行征求录音许可。新增均衡、低延迟和高精度配置。 [v0.75.5](https://github.com/kombifyio/SpeechKit/releases/tag/v0.75.5) [v0.76.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.0)

- 模型目录新增 Microsoft Foundry 的 GPT-Live 和 Gemini Transcribe Live 听写，并移除停用模型。 [v0.74.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.74.0)

### 更新

- Home Assistant 代理连接器通过 stackkit setup 签发、复用和撤销，仅存于节点本地的加密存储中。 [StackKits v0.52.0](https://github.com/kombifyio/stackKits/releases/tag/v0.52.0) [参考文档](/zh-Hans/guides/stackkits/use-cases/smart-home)

- 支持经身份验证访问历史恢复点。 [v0.52.5](https://github.com/kombifyio/stackKits/releases/tag/v0.52.5) [参考文档](/zh-Hans/guides/stackkits/back-up-and-restore)

- Paperless、Mosquitto、Stalwart、Zigbee2MQTT、SearXNG、Roundcube、Euro-Office、Navidrome、Audiobookshelf、ESPHome、Emby 等应用可直接通过 OpenTofu 执行，无需 Compose 包装；原生执行需逐个应用选择启用。 [v0.51.0](https://github.com/kombifyio/stackKits/releases/tag/v0.51.0)

- 应用密钥以文件交付，不放入环境变量。Zigbee2MQTT 的 MQTT 密码和 Pterodactyl 的应用密钥也不再写入数据卷。 [v0.51.0](https://github.com/kombifyio/stackKits/releases/tag/v0.51.0)

- Advanced 模式为托管的 kombify.me 源站签发 Origin CA 证书。 [v0.51.7](https://github.com/kombifyio/stackKits/releases/tag/v0.51.7) [`stackkit advanced`](/zh-Hans/stackkits/reference/cli/advanced)

- 每次实时听写保存为一个 Library 条目；按住说话在松开快捷键时仅插入一次文本。 [SpeechKit v0.75.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.75.1)

- 连接提供商期间即开始录音，可从录音恢复流中缺失的音频。词典中的词适用于所有听写模式。 [v0.76.4](https://github.com/kombifyio/SpeechKit/releases/tag/v0.76.4)

- 设置改为选项卡。网页语音界面增加录音指示、实时转写和会话开始前的麦克风检查。 [v0.74.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.74.0)

- Voice 优先使用托管语音提供商，并支持最长四小时的会话。 [v0.75.3](https://github.com/kombifyio/SpeechKit/releases/tag/v0.75.3)

- v0.74.0 和 v0.75.0 对 Go SDK 与 Android 键盘集成包含不兼容变更。升级前请阅读发布说明。 [v0.74.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.74.0) [v0.75.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.75.0) [参考文档](/zh-Hans/speechkit/framework)

### 问题修复

## StackKits 带来私有 AI 实验室、游戏服务器和每次安装自带的 MCP；SpeechKit 接入 Microsoft 365

StackKits 发布了从 [v0.33.0](https://github.com/kombifyio/stackKits/releases/tag/v0.33.0) 到 [v0.50.3](https://github.com/kombifyio/stackKits/releases/tag/v0.50.3) 的版本：完整的本地 AI 实验室、Game 用例、每个用例更多可选应用、Advanced 模式，以及每次安装自带的 StackKits MCP。SpeechKit 从 [v0.71.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.71.0) 升级到 [v0.73.4](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.4)：支持导入 Microsoft 365 会议、使用自有密钥的 Google 语音、兼容 OpenAI 的音频端点，以及提供六种语言的应用。

### 新功能

- **私有 AI 变成本地 AI 实验室。** [StackKits v0.48.0](https://github.com/kombifyio/stackKits/releases/tag/v0.48.0) 让你选择 Open WebUI 或 AnythingLLM 作为聊天界面，并可添加网页搜索、文档解析、Hermes 助手、在 gVisor 下运行的 OpenHands 智能体，以及用于图像和视频的 ComfyUI。它可在 CPU 或 NVIDIA、AMD GPU 上运行。可选连接器通过出站连接把你的 homelab 模型连接到 kombify AI，因此无需开放入站端口。参见[个人 AI](/zh-Hans/guides/stackkits/use-cases/personal-ai)。
- **游戏服务器。** [v0.41.0](https://github.com/kombifyio/stackKits/releases/tag/v0.41.0) 新增带 Pterodactyl Panel 的可选 Game 用例。`stackkit setup game` 会以安全默认配置创建 Minecraft Java 和 Bedrock 服务器，[v0.43.0](https://github.com/kombifyio/stackKits/releases/tag/v0.43.0) 还加入了 Paper、Terraria 和 Valheim。设置过程会通过真实客户端加入来检查就绪状态，并拒绝创建主机内存无法承载的服务器。参见 [Game](/zh-Hans/guides/stackkits/use-cases/game)。
- **每个用例有更多应用。** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) 可安装 Nextcloud、Forgejo、Emby 和 Passbolt，作为默认应用的替代选择。附加组件会安装在用例旁边：Paperless-ngx、Euro-Office、Navidrome、Audiobookshelf 和 ESPHome。参见[用例目录](/zh-Hans/stackkits/reference/use-case-catalog)。
- **按你的方式使用邮件。** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) 为你已有的邮箱新增 Roundcube 网页邮件，并提供可选的 Stalwart 邮件服务器，可安装在专用节点上。参见[邮件](/zh-Hans/guides/stackkits/use-cases/mail)。
- **面向托管家庭环境的 Advanced 模式。** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) 通过 Terramate 和 OpenTofu 运行变更集、按栈检测并协调偏移、协同回滚和恢复演练。Basement 安装现在默认使用 OpenTofu，[v0.48.0](https://github.com/kombifyio/stackKits/releases/tag/v0.48.0) 还会加密其状态和计划。参见 [`stackkit advanced`](/zh-Hans/stackkits/reference/cli/advanced)。
- **每次安装都自带 StackKits MCP。** [v0.46.0](https://github.com/kombifyio/stackKits/releases/tag/v0.46.0) 在每个 Core 上发布受令牌保护的 `/mcp` 端点，让 AI 智能体可以直接连接你的服务器。现在每个公共 CLI 命令要么对应一个 MCP 工具，要么列为明确的例外；可能暴露秘密的命令仍仅限 CLI。参见 [MCP 连接器](/zh-Hans/stackkits/reference/mcp-connector)。
- **通过 CLI 更新操作系统。** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) 可以规划并应用操作系统更新，还能安排节点重启。参见 [`stackkit host`](/zh-Hans/stackkits/reference/cli/host)。
- **预制镜像。** [v0.50.0](https://github.com/kombifyio/stackKits/releases/tag/v0.50.0) 新增 `stackkit image plan`、`prepare` 和 `verify`，可提前缓存工具链和核心镜像。每次安装仍会在首次启动时获得自己的所有者密钥和秘密。参见 [`stackkit image`](/zh-Hans/stackkits/reference/cli/image)。
- **会议接入 Microsoft 365。** [SpeechKit v0.72.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.0) 可在 Teams 会议结束后导入 Teams 文字记录或 Microsoft 365 Copilot 回顾，并允许你在同意处理文字记录后选择 Microsoft Foundry 来生成会议纪要。多租户登录让你无需重新安装即可切换公司。参见[会议](/zh-Hans/speechkit/meeting)。
- **使用你自己的 Google 语音密钥。** [v0.73.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.0) 恢复 Google Cloud 语音转文字、文字转语音和 Gemini Live，并将它们作为使用你自己密钥的可选提供商。参见[模式与数据路径](/zh-Hans/speechkit/modes)。
- **SpeechKit 服务器上的 OpenAI 兼容音频。** [v0.73.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.1) 提供 `POST /v1/audio/transcriptions` 和 `POST /v1/audio/speech`，Open WebUI 等客户端可以直接使用。本地专用配置无需云提供商即可运行。
- **SpeechKit 支持六种语言。** [v0.73.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.1) 和 [v0.73.2](https://github.com/kombifyio/SpeechKit/releases/tag/v0.73.2) 将 Android 应用、网站、桌面应用和托盘本地化为英语、德语、西班牙语、简体中文、印地语和阿拉伯语。

- **更多应用支持登录。** [StackKits v0.48.0](https://github.com/kombifyio/stackKits/releases/tag/v0.48.0) 通过 PocketID 为 Paperless-ngx、Media 和 Smart Home 提供登录，并在 Files 中配置家庭账户。[v0.38.0](https://github.com/kombifyio/stackKits/releases/tag/v0.38.0) 新增 `stackkit user owner status` 和 `activate`，用于所有者通行密钥。参见 [PocketID](/zh-Hans/stackkits/apps/pocketid)。

- **每个应用都有路由。** [v0.39.0](https://github.com/kombifyio/stackKits/releases/tag/v0.39.0) 为 Media、Smart Home、AI、Dev 和 Documents 提供与 Photos、Files 和 Vault 相同的 HTTPS 路由和数据绑定。

- **默认使用 Ubuntu 26.04。** [v0.50.0](https://github.com/kombifyio/stackKits/releases/tag/v0.50.0) 将 Ubuntu 26.04 LTS 作为新安装的目标，并保持与 24.04 兼容。[v0.35.0](https://github.com/kombifyio/stackKits/releases/tag/v0.35.0) 新增 Debian 13 上的备份支持。参见[操作系统兼容性](/zh-Hans/stackkits/reference/os-compatibility)。
- **以真实运行结果判定兼容性。** [v0.33.0](https://github.com/kombifyio/stackKits/releases/tag/v0.33.0) 和 [v0.34.0](https://github.com/kombifyio/stackKits/releases/tag/v0.34.0) 根据自动化的安装到恢复运行，为每个环境中的 Kit 评定等级；[v0.41.0](https://github.com/kombifyio/stackKits/releases/tag/v0.41.0) 将公共 VPS 上的 Cloud Kit 评为受支持。
- **记录每个命令。** [v0.33.0](https://github.com/kombifyio/stackKits/releases/tag/v0.33.0) 为 `stackkit <command> --help` 添加示例，并发布完整的 [CLI 参考](/zh-Hans/stackkits/reference/cli/overview)。安装器还会根据发行版校验和验证下载的归档文件。
- **Basement 默认使用 `lab.home`。** [v0.47.5](https://github.com/kombifyio/stackKits/releases/tag/v0.47.5) 将 `lab.home` 用作默认域名，现有 Basement 域名会通过签名恢复完成迁移。

- **Techstack Open Core v0.33.5。** [Techstack](https://github.com/kombifyio/TechStack) 源代码和安装器已发布 v0.26.0 和 v0.33.5，应用还新增了西班牙语、简体中文、印地语和阿拉伯语。参见 [Techstack 概览](/zh-Hans/techstack/overview)。

## SpeechKit 登陆 macOS、Google AI 停用，以及能自动选择 Kit 的 StackKits 安装器

SpeechKit 从 [v0.68.24](https://github.com/kombifyio/SpeechKit/releases/tag/v0.68.24) 升级到 [v0.70.3](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.3)：首个 macOS 构建、把 Microsoft Foundry 作为语音和模型的统一连接，并移除了所有 Google 语音适配器。StackKits 发布了 [v0.25.1](https://github.com/kombifyio/stackKits/releases/tag/v0.25.1) 至 [v0.32.1](https://github.com/kombifyio/stackKits/releases/tag/v0.32.1)：能检测主机并推荐 Kit 的安装器、Homelab 路由前的登录门禁，以及通过 PocketID 管理的家庭用户。

### 新功能

- **SpeechKit 可以在 Mac 上运行。** [v0.70.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.70.0) 在 Windows 资源旁发布了 `SpeechKit-macOS-arm64.zip`：面向 Apple Silicon 上 macOS 14+ 的 Dictation 测试版，采用 ad-hoc 签名，支持麦克风采集、文本注入、菜单栏项、内置本地模型以及云端语音转文字服务商。随之而来的还有一个已知缺口：全局热键监听器会安装，但收不到任何按键事件，因此按住说话（hold-to-talk）暂时无法使用，入口是菜单栏项。参见[在 macOS 上安装](/zh-Hans/speechkit/install-macos)。

### 更新

- **Cloud Kit 异地备份现在需主动开启。** [v0.16.1](https://github.com/kombifyio/stackKits/releases/tag/v0.16.1) 让异地备份成为 Cloud Kit 上的显式选择。参见[备份与恢复](/zh-Hans/guides/stackkits/back-up-and-restore)。
- **Cloud Kit 上的 Traefik 管理 API 仅限 localhost。** [v0.18.1](https://github.com/kombifyio/stackKits/releases/tag/v0.18.1) 在产品契约和公开发布契约中都让 Traefik 管理 API 保持绑定到 localhost。
- **重建的 Windows Voice Agent 浮层。** [SpeechKit v0.56.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.56.0) 把浮层变成一个深色、易读、以动画和对话为中心的面板。控制项只在你伸手去用时才出现。Quick Note 移到了浮层上，每个浮层图标都有工具提示。
- **带独立验证阶段的静默更新器。** [v0.52.11](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.11) 静默安装更新，[v0.52.12](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.12) 让 SpeechKit 在安装后自行重新启动，[v0.54.10](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.10) 显示独立的验证阶段，而不是看起来停在 100%。
- **数字形式的 1.0 之前版本重新回到公开渠道。** [v0.52.9](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.9) 把数字形式的 `v0.x` 版本作为普通 GitHub Release 发布，并推进规范的 `latest` 别名，使网站、安装器镜像和应用内更新器对最新构建保持一致。[v0.52.10](https://github.com/kombifyio/SpeechKit/releases/tag/v0.52.10) 恢复了 v0.51.37 至 v0.52.9 缺失的公开发布说明。

### 问题修复

- **Apply 把变更绑定到预期的计划哈希。** [StackKits v0.17.0](https://github.com/kombifyio/stackKits/releases/tag/v0.17.0) 防止 apply 针对在其底层已发生变化的计划运行。参见[审查、计划与应用](/zh-Hans/guides/stackkits/review-plan-and-apply)。
- **经过认证的公共运行时镜像拉取。** [v0.16.8](https://github.com/kombifyio/stackKits/releases/tag/v0.16.8) 对全新安装所执行的公共运行时镜像拉取进行认证。
- **松开按住说话会结束对话。** [SpeechKit v0.56.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.56.0) 在松开 hold-to-talk 时关闭对话。短暂的时间窗口仍允许立即再次按下并接着上次继续。
- **启动 SpeechKit 就会打开 SpeechKit。** [v0.56.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.56.0) 从任务栏或开始菜单调出窗口，重复点击时返回到正在运行的应用。
- **Android 键盘设置能检测到我们自己的键盘。** [v0.57.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.57.0) 不再让设置流程在某一步尚未完成时就声称已完成。
- **转录保持其自身语言。** [v0.54.0](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.0) 不再无论说的是什么都把转录标记为德语，因此自定义词汇和替换会应用于你实际使用的语言。静默录音被丢弃的情况也不再出现：当录音因所说语言与配置语言不匹配而没有产生文本时，SpeechKit 会告知，而不是直接丢弃。
- **服务器在探测偶发失败时继续运行。** [v0.54.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.1) 阻止单次探测失败杀死 SpeechKit 服务器，并在本地 Whisper 恢复时清除其就绪标志的锁定。
- **模型设置会重试偶发的 Whisper 下载。** [v0.54.10](https://github.com/kombifyio/SpeechKit/releases/tag/v0.54.10) 在偶发网络错误时重试，而不是让安装失败。
