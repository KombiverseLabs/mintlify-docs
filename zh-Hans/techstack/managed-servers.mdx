<Warning>
托管服务器属于预览范围。它不代表正式发布，并且只有当你的 kombify 账号启用了托管服务器时，该选项才可选。请参阅[可用性](/zh-Hans/techstack/availability)。
</Warning>

托管服务器是 Add Node 向导中 **I need a server** 下的 **kombify VPS** 选项。kombify 会与合作提供商一起创建虚拟服务器，对其进行准备，并将其连接到你的家庭实验室。你无需自己租用服务器，也不必自己运行命令。

## 托管服务器如何工作

1. 在 Node 步骤中，选择 **I need a server**，然后选择 **kombify VPS**。Techstack 会检查你的账号可以使用哪些提供商。如果没有启用任何提供商，该选项保持不可用，向导会指出缺少什么。你仍然可以连接自己的设备。
2. 查看向导显示的服务器详情：规格（vCPU、内存、磁盘）、位置和提供商。
3. 完成向导。kombify 会基于 Ubuntu 24.04 镜像创建服务器，将其连接到你的家庭实验室，然后设置你所选的工具。进度页面会显示每一步。

托管服务器使用 [Cloud Kit](/zh-Hans/stackkits/kits/cloud-kit) 基础。与其他节点一样，它的服务可以通过你自己的域名或 `*.kombify.me` 地址访问；请参阅 [kombify.me](/zh-Hans/kombify-me/overview)。

## 提供商

Techstack 目前为托管服务器列出两家合作提供商：

- **IONOS**
- **centron**

你可以选择其中哪一家取决于你的账号。当启用了多家时，打开 **Provider & server details** 来选择其一。只启用了一家时，向导会将其显示为你的服务器的提供商。

对于 IONOS，服务器创建在德国法兰克福的 IONOS 数据中心。向导会在服务器详情中显示位置。向导目前还不支持选择其他规格或位置。

如果你更愿意自己租用服务器，请改为选择 **Find a server with a partner**。它链接到相同的提供商。服务器准备好后，使用[配对命令](/zh-Hans/techstack/pairing-command)或[通过 SSH](/zh-Hans/techstack/ssh-connection) 连接它。

## 标准版与高级版

托管服务器有两种规格。向导会以 **Your standard VPS** 或 **Your premium VPS** 显示适用的规格，并附上确切的 vCPU、内存、磁盘大小和位置。

- **Standard** 是新托管服务器的默认规格。
- **Premium** 目前比 Standard 拥有更多资源：所有提供商都提供更多磁盘空间，在 IONOS 上还有更多的 vCPU 和内存。

确切规格取决于提供商，因此请在确认之前检查向导显示的数值。添加到现有托管 StackKit 的托管节点会沿用该 StackKit 的规格。

## 可用性

托管服务器处于预览阶段。只有当你的 kombify 账号拥有托管服务器访问权限，并且至少启用了一家提供商时，该选项才可选。如果 Techstack 此刻无法检查你的账号，向导会说明这一点，并提供 **Try again**。无论哪种情况，你都可以改为添加自己拥有的服务器，使用[配对命令](/zh-Hans/techstack/pairing-command)或[通过 SSH](/zh-Hans/techstack/ssh-connection)。

有关 Techstack 当前的公开与预览边界，请参阅[可用性](/zh-Hans/techstack/availability)。
