Techstack 正在积极开发中，它将成为 StackKits 的可选运维体验。其首个开源 Windows Alpha 已公开，用于收集本地服务器的反馈；联网和托管功能仍属于预览范围。

| 界面 | 当前状态 |
| --- | --- |
| 产品概览与运行模型 | 公开文档 |
| `techstack.kombify.io` 上的托管入口 | 预览；访问可能受限 |
| Windows 安装程序和桌面安装包 | 公开的未签名 Alpha |
| 匿名公开源码分发 | 公开于 `kombifyio/TechStack` |
| 联网与托管运行 | 预览；不代表正式发布 |
| kombify.me 公共 HTTPS 名称和私有 HTTP 中继 | 公开的 Alpha 文档 |
| 独立的 StackKits 生命周期 | 通过 StackKits 公开提供 |

<Warning>
Windows 安装包是未签名的 Alpha 版本，不是稳定版，也不代表已达到生产就绪。请只使用官方仓库，并在打开前验证已发布的校验和。
</Warning>

## 你现在可以做什么

- 通过[公开的快速入门](/zh-Hans/stackkits/quickstart)安装和运行 StackKits
- [下载 Techstack Windows Alpha](/zh-Hans/techstack/install-windows)并使用其无需账号的本地模式
- 查看 [Techstack 运行模式](/zh-Hans/techstack/operating-modes)
- 如果你的账号有访问权限，打开[托管预览版](https://techstack.kombify.io)
- 就预览版访问权限联系 [kombify 支持](mailto:info@kombify.io)

[开源仓库](https://github.com/kombifyio/TechStack)是源码、安装程序资源、校验和以及 Alpha 更新的发布权威。
