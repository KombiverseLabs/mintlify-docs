## techstack api services run-action

将所有者授权的 StackKits 服务操作加入队列。

根据最新的规范清单推导栈、服务器、代理、Kit 和服务的授权。精确重放会通过持久的任务回执收敛；原始 Idempotency-Key 从不持久化。每次变更之后都会先执行 StackKits 验证，然后才更改测量状态。在服务器重启或更新期间，由代理执行的操作会以 409 `maintenance_active` 拒绝。

## techstack api services setup-application-connector

在节点上确保或撤销一个已声明且拥有的 Home Assistant 连接器。

需要新鲜的后端所有权、正向 operate 授权、精确的当前库存和所有者批准。只通过 Guard 将封闭定义的关联元数据传输给已发布的固定版本 CLI；其本地 signedApply 和所有者设置权限始终必需。派发前存储持久意图；确认结果未知时，仅以只读方式协调原操作。当前 v0.51.8 缺少支持目录，返回不可派发的 SourcePreview。凭据保留在节点保管中。

```bash
techstack api services setup-application-connector [flags]
```

<Warning>需要确认：此操作为这个精确服务签发或撤销已审查、由节点拥有的 Home Assistant 连接器凭据。传入 `--yes` 或回答提示；非交互式运行未提供 `--yes` 时，会在发出任何请求前以退出码 9 停止。</Warning>
