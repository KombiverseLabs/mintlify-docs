## techstack api jobs get

获取某个自有任务的当前状态。

这是供 UI、API 客户端、MCP 工具和代理使用的规范轮询接口。`waiting_enrollment` 表示非终态的等待；在任务恢复并达到终态成功状态之前，对目标的访问仍不可用。

```bash
techstack api jobs get <id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/jobs/{id}` |
| 更改状态 | 否 |
| MCP 工具 | `get_job` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `<id>` | string | **必填。** 资源 ID。 |

## techstack api jobs list

列出经过认证的用户所拥有的任务。

返回运维 UI 和自动化客户端所使用的同一份按所有者限定的任务状态。处于 `state: waiting` 的任务仍然是活动的，当前的编排器进程会安排它的下一次检查；这并不是失败的提供商操作。如果进程重启后该安排已过时，请使用针对精确目标的 `resumeStackEnrollment` 操作。

```bash
techstack api jobs list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/jobs` |
| 更改状态 | 否 |
| MCP 工具 | `list_jobs` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `--page` | integer | 页码（默认 1）。 |
| `--per-page` | integer | 默认值：`50`。 |
| `--stack-id` | string | — |
| `--state` | string | 可选值：`pending`、`running`、`waiting`、`completed`、`failed`、`canceled`。 |
| `--type` | string | — |
| `--search` | string | — |
