## techstack api registry services list

列出拥有的服务及其目录信息和规范放置。

运行时记录使用与服务详情相同的状态、能力、版本和所有者锁定投影。历史记录仍可读取，其观测状态为未知，并且不会提供未测量的操作能力。

```bash
techstack api registry services list [flags]
```

| --- | --- |

| 更改状态 | 否 |
| MCP 工具 | `list_registry_services` |
