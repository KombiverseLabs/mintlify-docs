## techstack api drift results delete

删除漂移结果。

```bash

```

<Warning>需要确认：此操作会永久删除已存储的漂移结果。传入 `--yes` 或回答提示；未使用 `--yes` 的非交互式运行会在发出任何请求之前以退出码 9 停止。</Warning>
