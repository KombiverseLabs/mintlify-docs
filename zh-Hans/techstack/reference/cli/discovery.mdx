## techstack api discovery cache clear

清除发现缓存（仅限管理员）。

```bash
techstack api discovery cache clear [flags]
```

<Warning>需要确认：此操作会丢弃所有已缓存的发现结果；下一次发现会重新扫描网络。传入 `--yes` 或回答提示；未使用 `--yes` 的非交互式运行会在发出任何请求之前以退出码 9 停止。</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/discovery/cache` |
| 更改状态 | 是 |
| MCP 工具 | `clear_discovery_cache` |
