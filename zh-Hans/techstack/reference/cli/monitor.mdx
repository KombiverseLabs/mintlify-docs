## techstack api monitor availability

可用性、停机时段和每日状态，均由状态转换时间线推导得出。

这是基于只追加的服务器状态转换时间线的投影，而不是采样器：每个时段都由两次已记录的状态转换界定，并带有写入这些转换时使用的原因代码。响应会公布其自身的统计口径，因此读者无需阅读源码即可看出哪些连接状态被计为停机。

```bash
techstack api monitor availability [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/monitor/availability` |
| 更改状态 | 否 |
| MCP 工具 | `get_availability_report` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `--window` | string | 封闭集合；无界窗口会成为拒绝服务的调节旋钮。可选值：`24h`、`7d`、`30d`、`90d`。默认值：`"30d"`。 |
| `--server-id` | string | 将报告限定到一台服务器，用于服务器详情页。 |
