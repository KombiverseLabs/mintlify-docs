## techstack api pairing-tokens delete

删除配对令牌。

```bash
techstack api pairing-tokens delete <id> [flags]
```

<Warning>需要确认：此操作会吊销该配对令牌；尚未配对的设备将无法再使用它。传入 `--yes` 或回答提示；未使用 `--yes` 的非交互式运行会在发出任何请求之前以退出码 9 停止。</Warning>
