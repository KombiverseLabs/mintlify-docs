## techstack api tunnel install-command

生成带隧道 URL 的 Worker 安装命令。

```bash
techstack api tunnel install-command [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/tunnel/install-command` |
| 更改状态 | 是 |
| MCP 工具 | 无 |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `--token` | string | **必填。** |
| `--body` | json | JSON 请求正文（`application/json`），可以是字面量、`@path`，或用 `-` 表示 stdin。 |
