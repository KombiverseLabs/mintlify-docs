## techstack api agents remove


<Warning>需要确认：此操作会注销该代理；在该节点重新注册之前，它将停止上报。传入 `--yes` 或回答提示；未使用 `--yes` 的非交互式运行会在发出任何请求之前以退出码 9 停止。</Warning>

## techstack api agents send-command

向代理发送命令。

```bash
techstack api agents send-command <id> [flags]
```

<Warning>需要确认：此操作会在已连接的节点代理上运行该命令。传入 `--yes` 或回答提示；未使用 `--yes` 的非交互式运行会在发出任何请求之前以退出码 9 停止。</Warning>

| | |
| --- | --- |
| HTTP | `POST /api/v1/agents/{id}/command` |
| 更改状态 | 是 |
| MCP 工具 | `send_agent_command` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `<id>` | string | **必填。** 资源 ID。 |
| `--args` | string\[\] | — |
| `--command` | string | **必填。** |
| `--type` | string | **必填。** |
| `--body` | json | JSON 请求正文（`application/json`），可以是字面量、`@path`，或用 `-` 表示 stdin。 |
