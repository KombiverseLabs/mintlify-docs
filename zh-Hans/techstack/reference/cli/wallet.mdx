## techstack api wallet list

列出已脱敏的 Wallet 恢复条目。

列出调用方在已解析租户下的 Wallet 恢复条目。`secret` 和 `totp` 值始终会从此响应中剥离；只暴露存在标志（`has_secret`、`has_totp`）。

```bash
techstack api wallet list [flags]
```

| MCP 工具 | `list_wallet_items` |

## techstack api wallet reauth-proof

在新近完成平台重新认证后，签发一个短期有效的重新认证证明。

在新近完成生物识别/平台重新认证后，签发一个短期有效的可信重新认证 HMAC 证明（时间戳 + 签名），可用于在 5 分钟窗口内授权后续的揭示操作。请求中需要包含有效的、新近的平台重新认证断言。

```bash
techstack api wallet reauth-proof <id> [flags]
```

## techstack api wallet reveal

揭示 Wallet 恢复密钥/TOTP，受新近重新认证证明的保护。

受生物识别保护。需要在正文或 `X-Kombify-Reauth-\*` / `X-TechStack-Reauth-\*` 标头中提供新近的可信重新认证 HMAC 证明（时间戳 + 签名，5 分钟窗口）。以明文形式返回一次恢复值；揭示操作会在服务器端审计。

```bash
techstack api wallet reveal <id> [flags]
```
