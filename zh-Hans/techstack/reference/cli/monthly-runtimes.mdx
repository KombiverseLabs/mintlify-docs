## techstack api monthly-runtimes cleanup-readback

读取已脱敏的托管运行时清理状态事实。

返回按租户和所有者限定的、针对该租约当前确切的提供商控制资源代际的状态事实。此只读端点从不调用提供商或运行时代理，也从不返回提供商资源句柄、命令、证据文档或凭据。终态操作表示已不再运行，但其本身并不能证明清理成功：提供商侧的不存在需要 absence_evidence_ref，容量释放需要 capacity_released。

```bash
techstack api monthly-runtimes cleanup-readback <lease-id> [flags]
```

## techstack api monthly-runtimes reconnect

恢复托管运行时的 Guard 会话。

探测规范聚合；当它无法证明存在 Guard 连接时，会为正在运行的服务器中具备权益的所有者，通过固定的执行通道重启 Guard，并在有界窗口内重新观测该连接，然后使注册收敛到 enrolled。已停止的运行时会被拒绝（managed_runtime_stopped）。不会触碰任何提供商资源。

```bash
techstack api monthly-runtimes reconnect <lease-id> [flags]
```

| HTTP | `POST /api/v1/monthly-runtimes/{lease_id}/reconnect` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `<lease-id>` | string | **必填。** 月度运行时租约 ID。 |

## techstack api monthly-runtimes recreate

重建一个已完全释放的托管服务器代际。

在代际 N 具备终态的租约和规范服务器状态、终态的提供商操作状态、不透明的提供商原生不存在证据以及精确的容量释放之后，为同一个与提供商无关的运行时槽位显式预配代际 N+1。不可变的提供商、区域、套餐、角色、StackKit 和服务意图从旧的、按所有者限定的租约中恢复；客户端无法替换它。该端点委托给与 Add Node 相同的托管运行时扩展授权，因此注册、Guard 证据、端点和 StackKit rollout 都会经过完整的创建流程。标准的 Idempotency-Key 是必需的，并会安全地重放已接受的代际。

```bash
techstack api monthly-runtimes recreate <lease-id> [flags]
```

<Warning>需要确认：此操作会用新预配的服务器替换该运行时的提供商服务器，并会产生费用。传入 `--yes` 或回答提示；未使用 `--yes` 的非交互式运行会在发出任何请求之前以退出码 9 停止。</Warning>

| | |
| --- | --- |
| HTTP | `POST /api/v1/monthly-runtimes/{lease_id}/recreate` |
| 更改状态 | 是 |
| MCP 工具 | `recreate_monthly_runtime` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `<lease-id>` | string | **必填。** 月度运行时租约 ID。 |
| `--confirmed` | boolean | **必填。** 显式确认 Recreate 会预配一个新的托管服务器代际并为其计费。可选值：`true`。 |
| `--body` | json | JSON 请求正文（`application/json`），可以是字面量、`@path`，或用 `-` 表示 stdin。 |

## techstack api monthly-runtimes stop

停止托管服务器但不销毁它。

接纳一次与代际绑定、朝向停止状态的提供商控制协调。centron 使用其来宾系统正常关机操作；IONOS 则通过执行通道关闭来宾系统，因为 IONOS 提供商的停止操作会释放已绑定的 DHCP IPv4。服务器会保留其磁盘、地址、租约、容量预留和月度计费。

```bash
techstack api monthly-runtimes stop <lease-id> [flags]
```
