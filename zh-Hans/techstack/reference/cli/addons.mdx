## techstack api addons detect

自动检测适用于某个规格的附加组件。

```bash
techstack api addons detect [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/addons/detect` |
| 更改状态 | 是 |
| MCP 工具 | `detect_addons` |

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `--body` | json | **必填。** JSON 请求正文（`application/json`），可以是字面量、`@path`，或用 `-` 表示 stdin。 |
