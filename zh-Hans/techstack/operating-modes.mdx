Techstack 是对现有 StackKits 环境的扩展。它不会取代独立路径。

## 独立的 StackKits

公开的 StackKits CLI 无需 Techstack、账号或托管的 kombify 端点，就能初始化、验证、生成、应用并检查一个技术栈。这是本地家庭实验室或你自己运营的现有 VPS 的默认路径。

## 本地编排

Techstack 产品契约围绕同一个已发布的 StackKits CLI，增加了可视化的运维体验、运行时清单以及协调的 Day-2 运维。此模式让技术栈及其所有者权限保持在本地。

<Note>
[Windows Alpha](/zh-Hans/techstack/install-windows) 现已作为未签名的公开下载提供。它支持无需账号的本地运行；云同步仍是单独的联网路径。
</Note>

## 联网运行

联网的运行时可以将账号上下文和远程状态投射到运维体验中。连接是可选的：本地所有者身份、本地凭据以及运维技术栈的能力始终保留在本地环境中。

当服务需要公共 HTTPS 名称时，[kombify.me](/zh-Hans/kombify-me/overview) 是联网入口路径。公共源站会得到 `*.kombify.me` 地址；私有 HTTP 目标则使用 Techstack 节点代理。没有它，StackKits 依然可以运行。

## 托管部署

在托管运行中，Techstack 负责提供商选择、资源租约、提供商凭据、生命周期回执和最终清理。这些路径需要明确准入，仍属于预览范围；公开文档不声称已正式发布。

## Advanced Mode

Advanced Mode 是有边界的、从 Techstack 到 StackKits 的接缝。Techstack 可以为经批准的高级操作签发一个短期能力令牌，而固定版本的 StackKits CLI 负责验证并执行它。Techstack 不会成为第二个渲染器，也不会绕过 StackKits 的验证。
