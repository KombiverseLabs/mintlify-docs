Techstack 是构建在 StackKits CLI 契约之上的可选编排与运维体验。StackKits 继续负责技术栈定义和独立的生命周期；Techstack 则增加了引导式配置、运行时清单、多服务器协调以及受管控的 Day-2 运维。

<Warning>
Techstack 目前处于 Alpha 阶段。开源的 Windows 客户端支持无需账号的本地路径，而 [techstack.kombify.io](https://techstack.kombify.io) 上的托管入口和托管功能仍属于预览范围。
</Warning>

## Techstack 负责什么

- 生成 StackSpec 提案的 Easy 和 Techie 配置流程
- 跨已注册服务器的运行时和服务清单
- 对固定版本、已发布的 StackKits CLI 的编排
- 受管控的 Day-2 运维的审查与执行
- 联网与托管的部署工作流

Techstack 不会重新定义 StackKit 架构，不会复制 StackKits 目录，也不会成为本地 StackKit 的必要条件。生成的 StackSpec 仍会经过 StackKits 的验证与执行边界。

## 它与 StackKits 的关系

| 关注点 | 负责方 |
| --- | --- |
| 套件、模块、StackSpec、本地生命周期和验证 | StackKits |
| 向导、配置提案、清单和编排 | Techstack |
| 提供商生命周期、租约和托管资源清理 | Techstack |
| 本地所有者身份和独立证据 | StackKits |

移除 Techstack 不得使独立的 StackKit 无法使用。如果你想要一条如今已公开可用的安装路径，请从 [StackKits 快速入门](/zh-Hans/stackkits/quickstart)开始。
