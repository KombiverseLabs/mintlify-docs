## Goal

Install StackKits locally and obtain verified runtime state without creating a
kombify account.

## Boundaries

- Local-only must remain useful.
- No hidden managed-service requirement.
- Evidence class is `local-dev` or `self-hosted`, not SaaS.

<Note>
Techstack is part of the public/open-core runtime architecture, but its current
public distribution lane graduates separately and does not block Wave 1.
</Note>

Availability/evidence: this journey is a reference contract unless backed by an
