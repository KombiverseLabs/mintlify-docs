## Goal

The same operated run is visible in Workbench and Companion state views.
Voice-requested actions and mobile approvals are target/preview interaction
contracts; durable execution stays in governed server-side paths.

## Boundaries

- Mobile does not become orchestration authority.
- SpeechKit voice uses explicit consent and entitlement checks.
- Local/homelab voice evidence does not imply hosted SaaS voice availability.

<Warning>
Availability/evidence: Companion action approval side effects and SpeechKit
voice UI are not current guaranteed mobile capabilities. Treat this as a
reference contract journey unless release evidence states otherwise.
</Warning>
