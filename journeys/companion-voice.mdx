## Goal

The same operated run is visible in Workbench and Companion. A voice request
can initiate the next step, Companion can approve it, and durable execution
stays in governed server-side paths.

## Boundaries

- Mobile does not become orchestration authority.
- SpeechKit voice uses explicit consent and entitlement checks.
- Local/homelab voice evidence does not imply hosted SaaS voice availability.
