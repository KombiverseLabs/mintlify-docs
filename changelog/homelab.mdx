<Update label="v0.44.4" description="2026-10-30" tags={["Stable"]}>

- Add use cases to the servers you already have: "Add use cases" now appears on the dashboard, the Servers page and each server's page, and lets you pick one of your StackKits or servers before it offers a new server.
- Move freely through the creation wizard: every step you already reached opens from the stepper, the browser's back and forward buttons move between steps, and a reload keeps your place.
- See your applications as they really are: Techstack recognizes far more applications on a server, including containers you started by hand with Docker or Compose, and shows each with its proper name, its logo and an open link that reaches its web interface with the right http or https address.
- Hide or replace any application's logo yourself; the new Credits page lists where the logos come from.
- Devices & people keeps your homelab's owner and the people you planned in the wizard visible when the homelab cannot report sign-in status, and tells you what is missing.
- Techstack for Windows starts again on new installations and on installations created before the last database update.

</Update>

<Update label="2026-09-07" description="kombify.me public addresses" tags={["Weekly digest"]}>

## kombify.me public HTTPS names

Public docs now cover [kombify.me](/kombify-me/overview) under Techstack: stable HTTPS names for homelab services that are already reachable, first-party kit names such as `{your-lab}-auth.kombify.me`, and an optional private HTTP relay through the Techstack node agent. Local-only browsing stays on the homelab resolver. kombify.me is Alpha.

</Update>

<Update label="2026-08-21" description="Week of Aug 15 – Aug 21" tags={["Weekly digest"]}>

## Techstack open-source Alpha

Techstack is now public: an unsigned Windows Alpha and an open-source client you can install on your own machine to operate a local server without a hosted kombify account.

### New features

- **Techstack Windows Alpha, open source.** The Techstack open-core client is now published under AGPL-3.0 at [kombifyio/TechStack](https://github.com/kombifyio/Homelab), and the unsigned Windows Alpha is available for local-server feedback. Techstack is the optional orchestration and operator experience on top of StackKits, and this Alpha supports the account-free local path. See [Techstack overview](/homelab/overview), [availability](/homelab/availability), and [Install Techstack Alpha on Windows](/homelab/install-windows).

</Update>
