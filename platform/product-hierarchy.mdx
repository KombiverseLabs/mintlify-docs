This hierarchy is the public naming authority for active kombify products.
Internal repository names are implementation details and should not replace
customer navigation.

| Customer-facing name | Role |
| --- | --- |
| Kombify | Platform account, identity, and commercial relationship |
| StackKits | Portable system definitions and StackKit Open Spec |
| Techstack | Local/connected runtime and governed execution hand |
| Kombify Cloud | Optional identity, commerce, sync, monitoring, managed operations |
| Kombify AI | One AI identity across Guide, Support, and Operator |
| Kombify Workbench | Full authenticated web experience for AI/support/agent operations |
| Kombify Companion | Native mobile status, approvals, alerts, evidence, and AI |
| SpeechKit | Local-first voice framework and runtime |

## Implementation components vs products

Gateway, Administration, DB, Notifications, Agents, and shared frameworks are
critical platform components, but they are not standalone customer products.

## Canonical customer hosts

| Host | Purpose |
| --- | --- |
| `kombify.io` | Platform story, pricing, Guide entry |
| `docs.kombify.io` | Canonical public docs (this site) |
| `app.kombify.io` | Authenticated app home |
| `techstack.kombify.io` | Techstack deep link |
| `workbench.kombify.io` | Workbench |
| `ai.kombify.io` | Public AI site and anonymous Guide |
| `api.kombify.io` | Public API/AI/agents/MCP frontdoor |
| `login.kombify.io` | Canonical identity issuer/login host |

`cloud.kombify.io` redirects to `app.kombify.io`. `auth.kombify.io` is not a
canonical customer integration host.
