This page tracks public-facing retirements so old references do not re-enter
active guidance.

## Retired products/repositories (history only)

- `kombify-Desk`
- standalone `kombify-MCP`
- standalone public-authority narrative for legacy `cloud.kombify.io` and
  `auth.kombify.io` routes

## Extracted/historical sources

- legacy `docs` repository has been extracted into `mintlify-docs` as the
  canonical public docs source.
- `homelab-architect` is an extracting historical source.
- `kombify-api-toolkit` is an extracting historical source.
- legacy `kombify-AI` content is historical/extracting; active public AI docs
  are governed by this site and active product repositories.
- `kombify-Core` remains active as an internal folded workspace tree.

## Route and host guidance

- use `app.kombify.io` (not `cloud.kombify.io`) for authenticated app entry.
- use `login.kombify.io` as canonical issuer/login host.
- use `api.kombify.io` as the public API/AI/agents/MCP frontdoor.

When adding new public pages, prefer active product names and current hosts.
