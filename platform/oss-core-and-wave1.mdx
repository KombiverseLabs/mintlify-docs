## Public core boundary

Public/open-core includes:

- StackKits code and releases,
- StackKit Open Spec,
- Techstack runtime core and contracts as part of the open-core architecture,
- public install/update/troubleshooting/security/contribution docs.

Private commercial layer includes:

- managed account/commerce services,
- hosted synchronization/monitoring/managed operations,
- provider brokerage and fleet policy,
- paid agent operations and managed support.

## Wave 1 authority

Wave 1 priority is StackKits OSS release readiness and technical truth:

- curated public StackKits tree,
- release artifacts and user-facing assets from that tree,
- fresh install and verification evidence,
- canonical docs at `docs.kombify.io`,
- release notes and support channel ownership.

Cloud-connected previews can accompany Wave 1, but cannot block OSS delivery.

<Note>
Techstack remains part of the public/open-core product core and a Wave 2
platform blocker, but its current public distribution lane is separate from
Wave 1 proof. Wave 1 does not require Techstack public release evidence.
</Note>
