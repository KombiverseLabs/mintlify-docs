SpeechKit is the target shared voice framework for approved Companion,
Workbench, and embedded integrations.

## Core rules

- raw microphone audio is local/LAN by default,
- hosted voice requires explicit entitlement and user choice,
- MCP and product APIs expose voice diagnostics/management, not raw audio
  streams,
- denials must include clear reason and user guidance before side effects.

<Note>
  **Availability / evidence:** Companion voice UI is not currently implemented.
  References here are target contract boundaries, not hosted/preview/live
  availability proof.
</Note>
