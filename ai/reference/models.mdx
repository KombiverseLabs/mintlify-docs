kombify AI runs on a **managed model catalog**: the platform selects and operates model providers, and your requests are routed to an appropriate model — you never manage provider accounts or keys for the hosted service.

## Listing models

The current catalog is always available from the platform API:

```bash
curl https://api.kombify.io/v1/ai/models \
  -H "Authorization: Bearer <your-token>"
```

The response lists the models your plan can use, with their identifiers and capability metadata. The catalog is plan-aware: different subscription plans see different model sets.

## Routing and transparency

- Requests are routed to managed providers (for example Google's Gemini family) based on the requested model and capability.
- Every response records a **model execution**: which model ran and what it consumed. You can review executions via the API (`/v1/ai/model-executions`).
- Usage and cost tracking are built into the platform, so plan limits are enforced transparently rather than by surprise.

<Note>
  The catalog evolves during beta — always read the live `/v1/ai/models` response rather than hardcoding model identifiers into your integrations.
</Note>
