Techstack Alpha is an early, local-first Windows client for operating servers
in your home network. It can run without a kombify Cloud account. StackKits on
the server still bootstraps its required local Owner/Admin identity.

<Warning>
This is an unsigned Alpha release for real-user feedback, not a stable or
production-readiness claim. Windows may display a SmartScreen warning. Verify
the GitHub release origin and checksum before deciding whether to continue.
</Warning>

## Use Techstack locally

1. Start Techstack and choose **Use locally**. A kombify Cloud account is not
   required for this mode.
2. To connect a server that already has Basement Kit, choose **Connect my
   server** and enter its local SSH details.
3. The Creation Wizard also exposes **Give me a one-liner** for a new Ubuntu
   server. See the Alpha limitation below before using that path.
4. Keep the Windows client running while the server downloads its LAN agent
   and registers with the local Techstack runtime.
5. Confirm that the server and its StackKits services appear in the local UI.

<Warning>
In Windows Alpha `v0.7.95`, the local client, device Admin, dashboard, and both
server choices are available. Creating the Basement Kit through **Give me a
one-liner** currently stops before command generation because the controller
package does not yet include the Basement Kit catalog. For the first-user
handoff, install Basement Kit with the standalone one-liner below, then use
**Connect my server** in Techstack.
</Warning>

<Note>
Cloud sync and connected operation require a separate account later. They are
not prerequisites for the local Alpha path.
</Note>
