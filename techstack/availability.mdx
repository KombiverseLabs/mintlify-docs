Techstack is under active development as the optional operator experience for
StackKits. Its first open-source Windows Alpha is public for local-server
feedback; connected and managed capabilities remain preview scope.

| Surface | Current status |
| --- | --- |
| Product overview and operating model | Public documentation |
| Hosted entry at `techstack.kombify.io` | Preview; access may be limited |
| Windows installer and desktop package | Public unsigned Alpha |
| Self-hosted Open Core control plane | Public development release |
| Anonymous public source distribution | Public at `kombifyio/TechStack` |
| Connected and managed operation | Preview; not a general-availability claim |
| Standalone StackKits lifecycle | Publicly available through StackKits |

<Warning>
The Windows package is an unsigned Alpha, not a stable or
production-readiness release. Use only the official repository and verify the
published checksum before opening it.
</Warning>

## What you can do now

- install and operate StackKits through the
  [public quickstart](/stackkits/quickstart)
- [download Techstack Windows Alpha](/techstack/install-windows) and use its
  account-free local mode
- [self-host the Techstack Open Core control plane](/techstack/self-host) with
  Docker Compose
- review the [Techstack operating modes](/techstack/operating-modes)
- open the [hosted preview](https://techstack.kombify.io) if your account has
  access
- contact [kombify support](mailto:info@kombify.io) about preview access

The [open-source repository](https://github.com/kombifyio/TechStack) is the
release authority for source, installer assets, checksums, and Alpha updates.
