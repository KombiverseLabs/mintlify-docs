## techstack api tunnel install-command

Generate worker install command with tunnel URL.

Answers the Linux (and, outside the LAN bridge, Windows) command that installs and enrolls a new server through the current registry URL. Techstack mints the one-time pairing token the command carries (15 minutes) and answers its id and expiry; the token is never an argument.

```bash
techstack api tunnel install-command [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/tunnel/install-command` |
| Changes state | Yes |
| MCP tool | `create_install_command` |
