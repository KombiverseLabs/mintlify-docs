## techstack api runtime logs

Get recent runtime/deploy logs.

Returns recent runtime/deploy log entries (job/deploy progress plus
container tail) from the gRPC server's runtime log buffer, filtered by
the supplied query parameters. Requires authentication and an available
gRPC server.

```bash
techstack api runtime logs [flags]
```
