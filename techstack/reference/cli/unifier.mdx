## techstack api unifier layout recommend

Compute and record a verified workload layout for a planned change.

Plans where the selected goals run across the nodes of one owned StackKit deployment for an add-server or add-use-case change, verifies the option with the pinned StackKits feasibility check and, when it is feasible, records it as an open recommendation the owner can accept inside a wizard run, reject or snooze. An option that is not verified is returned with state `unverified` and no id. Records the proposal but changes no infrastructure.

```bash
techstack api unifier layout recommend [flags]
```

## techstack api unifier layout snooze

Snooze one layout recommendation until a later time.

Hides an open or snoozed layout recommendation of the authenticated owner until `until`, which must lie in the future and within 90 days, and answers its updated view. A recommendation in any other state answers 409 `layout_recommendation_changed`.

```bash
techstack api unifier layout snooze <recommendation-id> [flags]
```

## techstack api unifier recommendations

Rank StackKits for the goals and services of a wizard selection.

Computes ranked StackKit recommendations from the selected goals, the deployment lane and surface, and the authenticated owner's worker inventory and self-disclosure. Safe and idempotent: nothing is stored. A non-ready status (`incomplete`, `stale`, `degraded`) is still a useful answer that names the evidence to supply.

```bash
techstack api unifier recommendations [flags]
```
