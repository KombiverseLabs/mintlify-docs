## techstack api wallet create

Create a wallet item without secret values.

Creates a wallet item owned by the caller in the resolved tenant and returns it redacted. The server assigns the id. `secret` and `totp` values are entered by the person in the Wallet and are not part of this contract; an item created here has no secret until the person adds one, and a secret can never be read back through this API without the person's fresh re-authentication. Only deployments that keep credentials in Techstack's own Wallet serve this route; elsewhere it answers 409 `self_hosted_only`.

```bash
techstack api wallet create [flags]
```

## techstack api wallet delete

Delete a wallet item.

Deletes an item the caller owns, including its encrypted secret and TOTP. An item owned by someone else answers 404. Only deployments that keep credentials in Techstack's own Wallet serve this route; elsewhere it answers 409 `self_hosted_only`.

```bash
techstack api wallet delete <id> [flags]
```

<Warning>Requires confirmation: This operation permanently deletes the wallet item with any secret and TOTP stored in it; if the person has no other copy of those credentials they are lost. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>

## techstack api wallet reauth-proof

Mint a short-lived reauth proof after a fresh platform re-auth.

After a fresh biometric/platform re-authentication, mints a short-lived
trusted-reauth HMAC proof (timestamp + signature) usable to authorize a
subsequent reveal within the 5-minute window. Requires a valid fresh
platform reauth assertion on the request.

## techstack api wallet reveal

Reveal a wallet recovery secret/TOTP, gated by a fresh reauth proof.

Biometric-gated. Requires a fresh trusted-reauth HMAC proof (timestamp +
signature, 5-minute window) supplied in the body or the
`X-Kombify-Reauth-\*` / `X-TechStack-Reauth-\*` headers. Returns the
plaintext recovery values once; the reveal is audited server-side.

```bash
techstack api wallet reveal <id> [flags]
```

## techstack api wallet update

Update the metadata of a wallet item.

Merges the supplied fields into an item the caller owns and returns it redacted. Fields that are not supplied keep their value, including the stored secret and TOTP, which this contract can neither read nor change: the person sets those in the Wallet. The item kind and owner are immutable. An item owned by someone else answers 404. Only deployments that keep credentials in Techstack's own Wallet serve this route; elsewhere it answers 409 `self_hosted_only`.

```bash
techstack api wallet update <id> [flags]
```
