## techstack api inventory servers access-context

Get sanitized access context for one owned server.

Returns address metadata, channel state, and freshness-qualified service links only. It never returns endpoint references, access-profile references, route IDs, credentials, tokens, SSH users, ports, keys, commands, or logs. This surface requires inventory operate permission; read permission alone is insufficient.

```bash
techstack api inventory servers access-context <server-id> [flags]
```

## techstack api inventory servers list

List sanitized server inventory for the authenticated owner.

Returns only servers owned by the authenticated subject in the trusted tenant context. Tenant and owner overrides are not accepted. Raw metadata, channel endpoints, provider-resource references, credentials, SSH material, tokens, and logs are never returned. The lease projection contains only an opaque identifier and state. Cursor pages share one authorization- and filter-bound collection watermark and exclude later inserts.

techstack api inventory servers list [flags]

## techstack api inventory servers rename

Set or clear the owner-chosen name of one owned server.

Writes servers.display_name, which runtime projections never overwrite. `null` or an empty string clears the rename. Requires the signed techstack.inventory.write entitlement and the FGA server `caller` relation; the write is bound to the authenticated tenant and owner, and a server outside that scope is denied without revealing whether it exists. The canonical inventory `name` reports the chosen name when one is set.

```bash
techstack api inventory servers rename <server-id> [flags]
```
