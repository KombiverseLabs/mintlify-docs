## techstack api stack-identity sync

Apply one kombify Cloud sync step to the local stack identity.

Takes the kombify Cloud stack identity record (read by the caller through the Gateway with the user's own token; `null` when Cloud has none) and applies the sync rules to the local copy: adopt the Cloud record, confirm an identical one, or answer the body to push to Cloud with the `If-Match` revision. The call itself never writes to Cloud. When no local stack identity exists yet it only reports `homelab_missing`.

```bash
techstack api stack-identity sync [flags]
```

## techstack api stack-identity update-conditional

Update the stack identity only when its local revision still matches.

Revision-checked variant of the stack identity update. `If-Match` carries the `local_revision` read from the stack identity, in double quotes (for example `"3"`); a stale revision answers 412 and a reused `Idempotency-Key` with different content answers 409. The edit is stored locally and marked pending until it is synced with kombify Cloud. The body is limited to 4096 bytes. Requires the Postgres control plane (503 `stack_identity_store_unavailable` otherwise).

```bash
techstack api stack-identity update-conditional [flags]
```
