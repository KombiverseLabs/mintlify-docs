## techstack api services execute-application-adoption

Execute the exact reviewed source plan with explicit Owner approval.

Revalidates the retained digest, source identity, revision and release. Only an authenticated pinned-CLI custody receipt establishes membership. Accounts, configuration and persistent data are preserved; no new runtime is created. Moving to another Node and generic adoption are not supported.

```bash
techstack api services execute-application-adoption [flags]
```

## techstack api services setup-application-connector

Ensure or revoke one declared owned Home Assistant connector on its node.

Requires fresh backend ownership, positive operate authority, exact current inventory and Owner approval. Transports only closed correlation metadata through Guard to the published pinned CLI, whose local signedApply and Owner setup authority remain mandatory. Stores pre-send durable intent; unknown acknowledgement only reconciles the original operation read-only. Current v0.51.8 lacks the supporting catalog and returns nondispatchable SourcePreview. Credentials stay in node custody.

```bash
techstack api services setup-application-connector [flags]
```

<Warning>Requires confirmation: This operation issues or revokes the reviewed node-owned Home Assistant connector credential for this exact service. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>
