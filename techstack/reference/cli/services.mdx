## techstack api services run-action

Queue an owner-authorized StackKits service action.

Derives stack, server, agent, kit and service authority from fresh canonical inventory. Exact replays converge through a durable job receipt; the raw Idempotency-Key is never persisted. Mutations are followed by StackKits verify before measured state changes. Agent-executed actions refuse with 409 `maintenance_active` while the server is being rebooted or updated.

```bash
techstack api services run-action <service-id> [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/registry/services/{serviceId}/actions` |
| Changes state | Yes |
| MCP tool | `run_managed_service_action` |

| --- | --- | --- |
| `<service-id>` | string | **Required.** Canonical service runtime ID. |
| `--body` | json | **Required.** JSON request body (`application/json`) as a literal, `@path` or `-` for stdin. |
