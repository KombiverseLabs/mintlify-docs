## techstack api client-pairing issue

Issue a short-lived ClientPairingEnvelope v1.

Requires an authenticated instance administrator. Available only for an HTTPS self-hosted instance with a configured tenant and native OIDC authority. Local single-owner mode fails closed.

```bash
techstack api client-pairing issue [flags]
```

## techstack api client-pairing redeem

Atomically redeem a ClientPairingEnvelope v1 code.

The client verifies the HTTPS certificate fingerprint before sending this request. Success consumes the code exactly once and returns public metadata for the normal OIDC account flow; it never returns a session or duplicates the local owner identity.

```bash
techstack api client-pairing redeem [flags]
```
