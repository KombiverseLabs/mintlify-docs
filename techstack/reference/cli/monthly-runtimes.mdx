## techstack api monthly-runtimes cleanup-readback

Read redacted managed runtime cleanup state facts.

Returns tenant- and owner-scoped state facts for the lease's exact current provider-control resource generation. This read-only endpoint never calls a provider or a runtime agent and never returns provider resource handles, commands, evidence documents, or credentials. A terminal operation is no longer running, but is not by itself proof of successful cleanup: provider absence requires absence_evidence_ref, and capacity release requires capacity_released.

## techstack api monthly-runtimes recreate

Recreate one fully released managed server generation.

Explicitly provisions generation N+1 for the same provider-neutral runtime slot after generation N has terminal lease and canonical server state, terminal provider operation state, opaque provider-native absence evidence, and exact capacity release. The immutable provider, region, offering, role, StackKit, and service intent is recovered from the old owner-scoped lease; clients cannot replace it. The endpoint delegates to the same managed-runtime expansion authority as Add Node, so enrollment, Guard evidence, endpoints, and StackKit rollout proceed through the full Creation flow. A standard Idempotency-Key is mandatory and safely replays the accepted generation.

```bash
techstack api monthly-runtimes recreate <lease-id> [flags]
```

<Warning>Requires confirmation: This operation replaces the runtime's provider server with a newly provisioned one and is billed. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>

| HTTP | `POST /api/v1/monthly-runtimes/{lease_id}/recreate` |
| Changes state | Yes |

| --- | --- | --- |

## techstack api monthly-runtimes stop

Stop a managed server without destroying it.

Admits one generation-bound provider-control reconcile toward stopped. centron uses its graceful guest shutdown action; IONOS shuts the guest down over the execution channel because the IONOS provider stop releases the bound DHCP IPv4.
