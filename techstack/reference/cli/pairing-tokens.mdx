## techstack api pairing-tokens delete

Delete pairing token.

```bash
techstack api pairing-tokens delete <id> [flags]
```

<Warning>Requires confirmation: This operation revokes the pairing token; devices that have not paired yet can no longer use it. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>
