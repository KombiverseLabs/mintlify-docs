## techstack api discovery cache clear

Clear discovery cache (admin only).

```bash
techstack api discovery cache clear [flags]
```

<Warning>Requires confirmation: This operation discards every cached discovery result; the next discovery rescans the network. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>

| --- | --- |
| HTTP | `DELETE /api/v1/discovery/cache` |
| Changes state | Yes |
