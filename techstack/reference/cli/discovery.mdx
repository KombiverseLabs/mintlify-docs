## techstack api discovery devices probe

Deep probe a caller-owned device.

Logs in to the device over SSH with the login held in the Wallet item `ssh_wallet_item_id` (a kombify Wallet node access item assigned to Techstack and bound to this IP or to no host, or an SSH key or password item of the built-in wallet whose URL names this IP) and reads its system facts. The login is resolved inside Techstack for this probe only and never answered. This contract accepts no password or private key. Non-admin callers may only probe IPs from their own discovery results; admins may probe arbitrary IPs. Local control planes only (409 `lan_executor_required` on a hosted one).

```bash
techstack api discovery devices probe [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/discovery/probe` |
| Changes state | Yes |
| MCP tool | `probe_discovered_device` |

| Argument | Type | Description |

| `--ssh-port` | integer | Default `22`. |
| `--ssh-user` | string | **Required.** |

| `--timeout-seconds` | integer | Default `30`. |

## techstack api discovery test-ssh

Test SSH connectivity to a device.

Opens one SSH connection with the login held in the Wallet item `ssh_wallet_item_id` (its key when it holds one, otherwise its password; a built-in wallet item must name this IP as its URL), resolved inside Techstack and never answered; nothing is stored. This contract accepts no password. A failed connection answers 200 with `success: false`. Non-admin callers may only test IPs from their own discovery results; admins may test arbitrary IPs. Local control planes only.

```bash
techstack api discovery test-ssh [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/discovery/test-ssh` |
| Changes state | Yes |
| MCP tool | `test_discovered_device_ssh` |

| Argument | Type | Description |
| --- | --- | --- |
| `--ip` | string | **Required.** |
| `--port` | integer | Default `22`. |
| `--ssh-wallet-item-id` | string | **Required.** Wallet item holding the SSH key or password. |
| `--user` | string | **Required.** |
| `--body` | json | JSON request body (`application/json`) as a literal, `@path` or `-` for stdin. |
