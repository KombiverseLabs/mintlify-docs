## techstack api homelab get

Get the caller's homelab and its StackKit deployments.

Resolves the authenticated owner's canonical Homelab umbrella together with its StackKit deployments. `homelab` is null while a backfill has deployments but no Homelab row yet; with neither, the route is 404. `homelab.identity_authority` names the identity Authority (the server that runs Pocket ID) and the identity origin.

```bash
techstack api homelab get [flags]
```

## techstack api homelab identity-join

Join one kit deployment of the homelab to the homelab's identity Authority.

Joins this kit deployment's server to the server that runs the homelab's Pocket ID (the homelab's authority pointer, never a client choice). The job runs the pinned StackKits CLI on each server: the join request pinned to `authority_root` (the root fingerprint the Owner reads at the Authority's console or Hub), the Owner's passkey approval in the Authority's Hub (the job waits up to five minutes), the install of the Authority-signed trust bundle, the joined server's sign-in client registered at the Authority (a second passkey approval) with its secret delivered only through the homelab's Wallet, and the homelab DNS zone on every server. The server joins after its StackKit init and before its first apply; its own domain is always one of the hostnames. Techstack carries the documents and signs none of them. Needs exactly one Idempotency-Key; a replay returns the same job and never asks for approval again.

```bash
techstack api homelab identity-join <stack-id> [flags]
```

## techstack api homelab rename

Rename the caller's homelab.

Renames the authenticated owner's homelab. The homelab name is the Stack Identity name and syncs to kombify Cloud when connected. Reversible; the homelab is resolved from the authenticated owner, never from an argument.

```bash
techstack api homelab rename <name> [flags]
```
