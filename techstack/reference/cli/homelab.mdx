## techstack api homelab get

Get the caller's homelab and its StackKit deployments.

Resolves the authenticated owner's canonical Homelab umbrella together with its StackKit deployments. `homelab` is null while a backfill has deployments but no Homelab row yet; with neither, the route is 404.

```bash
techstack api homelab get [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/homelab` |
| Changes state | No |
| MCP tool | `get_homelab` |

## techstack api homelab rename

Rename the caller's homelab.

Renames the authenticated owner's homelab. The homelab name is the Stack Identity name and syncs to kombify Cloud when connected. Reversible; the homelab is resolved from the authenticated owner, never from an argument.

```bash
techstack api homelab rename <name> [flags]
```

| HTTP | `PATCH /api/v1/homelab` |
| Changes state | Yes |
