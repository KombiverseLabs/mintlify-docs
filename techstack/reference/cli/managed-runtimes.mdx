## techstack api managed-runtimes authority

Verify request-bound managed-runtime authority without creating a resource.

Read-only preflight for the Gateway-to-native-admission authority chain.
Hosted requests must carry the Gateway's v2-signed managed-runtime,
Cloud Kit, provider entitlement, and `cloud.runtime.credits`
`managed_servers` decision bound to this exact request. A successful
response never reserves capacity or creates a StackKit deployment, queue
job, lease, Node projection, or provider operation; the real Add-Server request
repeats every mutable admission check atomically.

```bash
techstack api managed-runtimes authority [flags]
```
