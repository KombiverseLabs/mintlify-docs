## techstack api failures outcome record

Record the outcome of an applied failure resolution.

Attributes a finished procedure job of the caller tenant to the
failure resolution it applied and the failure signature it was
applied to. The outcome is the job's terminal state (completed is
succeeded, failed is failed), never a value the caller sends; a job
that is still running or was canceled is refused. The context is the
one of the tenant's own latest occurrence of that signature. The
record stays in the tenant; repeating the call for the same
resolution and job returns the stored record.

```bash
techstack api failures outcome record [flags]
```

## techstack api failures outcomes

List the tenant's failure resolution outcomes.

Returns the caller tenant's own recorded resolution outcomes, newest
first, and the succeeded and failed counts per resolution and
signature. Another tenant's outcomes are never visible.

## techstack api failures signatures

List the tenant's failure signatures.

Returns the caller tenant's own failed operations normalized into
failure signatures, most recently seen first. A signature is the
SHA-256 over the normalizer version, component, phase, error code and
a template in which every variable token (timestamps, IDs, addresses,
host names, paths, user names, quoted values, numbers) is replaced.
No raw error text is stored or returned, and another tenant's
occurrences are never visible.

```bash
techstack api failures signatures [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/failures/signatures` |
| Changes state | No |
| MCP tool | `list_failure_signatures` |

| Argument | Type | Description |
| --- | --- | --- |
| `--limit` | integer | Default `50`. |
| `--window-days` | integer | Length of the growth window; recent_occurrences counts the last window, previous_occurrences the one before it. Default `7`. |
