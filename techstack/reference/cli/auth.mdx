## techstack api auth cloud-link delete

Remove the kombify Cloud link of the signed-in operator.

Deletes the stored kombify Cloud profile link of the authenticated operator on this install. The link is per operator; nothing at kombify Cloud changes. When no link exists the call succeeds with `removed: false`. Re-linking is a browser sign-in and is not available to agents.

```bash
techstack api auth cloud-link delete [flags]
```

<Warning>Requires confirmation: This operation removes the kombify Cloud link of the signed-in operator from this install; a stack can seed its owner from the Cloud identity again only after the link is re-created through a browser sign-in. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>
