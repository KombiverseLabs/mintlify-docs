## techstack api ril action-cards create

Create a governed action card for one owned server.

Stores a card that describes one approved-action primitive, its target and its evidence sink for the authenticated owner. The card starts as `awaiting_grant` (no `grant` given) or `awaiting_approval` and runs nothing until it is approved and executed. The body is decoded strictly and must stay under 64 KiB.

```bash
techstack api ril action-cards create [flags]
```

## techstack api ril action-cards execute

Run one approved governed action card on its server.

Starts the durable workflow of a card that the owner approved and that holds a live grant, after checking that the caller may operate the card's server. `execution_id`, `trace_id` and `idempotency_key` bind one execution; repeating them returns the stored result. A card of operation class `drift-correction` also needs `compensation_card_id`, any other card must not send it. A missing approval or grant, an expired grant and a connector binding that does not match answer 403 or 409 with a stable `reason_code`.

```bash
techstack api ril action-cards execute <card-id> [flags]
```
