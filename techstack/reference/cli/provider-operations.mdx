## techstack api provider-operations provision-discovery

Observe what the provider holds for one parked provision operation.

First step of operator resolution for a provision whose outcome is unknown. Reads the provider (read-only) and appends the immutable discovery evidence; it never creates or retries anything at the provider. A replay re-verifies the same observation. The answer names the confirmation string the second step requires. Administrator-only: a non-administrator caller is refused with 403, and the operation must belong to the caller's tenant.

```bash
techstack api provider-operations provision-discovery <operation-id> [flags]
```

## techstack api provider-operations provision-resolution

Record the operator decision for one parked provision operation.

Second step of operator resolution. With the exact confirmation from the discovery step it appends one decision against the persisted observation: no candidate, adopt the single exact candidate, or quarantine several. The decision is local custody state and never starts or retries provider creation. Replays return the original decision. Administrator-only; a stale or mismatching observation answers 409.

```bash
techstack api provider-operations provision-resolution <operation-id> [flags]
```
