## techstack api wizard preview

Preview the StackKit spec a wizard intent would produce.

Projects a wizard intent onto the pinned kit seed and validates the result with the pinned StackKits CLI. Safe and idempotent: nothing is persisted. An invalid projection answers 200 with `valid: false` and `validate_error`; join previews need `base_spec`. Requires the `native_v2_wizard` feature for the caller (403 `feature_not_enabled` otherwise).

```bash
techstack api wizard preview [flags]
```

## techstack api wizard remote test-ssh

Test an SSH connection to a machine before connecting it.

Opens one SSH connection to the given host with a credential held in the Wallet and reports whether it succeeded; nothing is stored. The credential is a Wallet node access item (`ssh_wallet_item_id`, bound to the host) or, on deployments that read the built-in wallet, the label of a stored SSH key. This contract accepts no password or private key. A failed connection answers 200 with `success: false` and the error. Requires the `native_v2_wizard` feature for the caller.

```bash
techstack api wizard remote test-ssh [flags]
```

## techstack api wizard runs create

Run the creation wizard to found, join or extend a StackKit deployment.

Persists one wizard run for the authenticated owner. A found run creates the deployment and its first server, a join run adds a Node and an extend run adds use cases; the first run in a Homelab founds it and later first-run requests are coerced to expansions. The kombify-cloud transport orders a billed managed server, the hypervisor transport creates a guest on the owner's hypervisor and connect-remote enrolls over SSH. Join, extend, managed and hypervisor runs require `X-Idempotency-Key`; a replay with the same key and request returns the original outcome. Requires the `native_v2_wizard` feature for the caller.

```bash
techstack api wizard runs create [flags]
```

<Warning>Requires confirmation: This operation starts a wizard run that creates or extends the StackKit deployment and, on the kombify-cloud transport, orders a billed managed server. Pass `--yes` or answer the prompt; a non-interactive run without `--yes` stops before any request with exit code 9.</Warning>

## techstack api wizard runs dismiss

Hide one wizard run's dashboard notice.

Hides the dashboard notice of one of the authenticated owner's wizard runs on every device. The run's job is not touched; cancelling is a separate operation. An unknown or foreign run answers 404.

```bash
techstack api wizard runs dismiss <run-id> [flags]
```
