## techstack api system client-bootstrap

Public runtime config for the static SPA.

Returns non-secret, runtime-varying public configuration for the
embedded static frontend (edition, deployment mode, telemetry
toggles). Values are empty unless the operator or deployer sets the
corresponding environment variables, keeping self-hosted and local
deployments telemetry-free by default.

```bash
techstack api system client-bootstrap [flags]
```

## techstack api system data-profile

Data protection profile of the signed-in user.

The data protection profile that applies to this request (workspace
DATA-ARCHITECTURE.md section 5). A hosted request returns the profile
the Gateway signed for it; a self-hosted install returns its boot
profile. A profile that cannot be confirmed is the
data_profile_unresolvable denial, never Standard.

```bash
techstack api system data-profile [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/data-profile` |
| Changes state | No |
