## techstack api system capabilities

## techstack api system client-bootstrap

Public runtime config for the static SPA.

Returns non-secret, runtime-varying public configuration for the
embedded static frontend (edition, deployment mode, telemetry
toggles). Values are empty unless the operator or deployer sets the
corresponding environment variables, keeping self-hosted and local
deployments telemetry-free by default.

```bash
techstack api system client-bootstrap [flags]
```
