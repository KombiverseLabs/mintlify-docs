## techstack api operator self-disclosure get

Read the operator's own answers about experience, goals, placement and household.

Returns the signed-in operator's stored self-disclosure, its source and the capability profile the Unifier derives from it. An operator who never answered gets an empty `disclosure`. Pass the returned `source` and `disclosure` as `if_unchanged` to replace it safely.

```bash
techstack api operator self-disclosure get [flags]
```

| Changes state | No |

## techstack api operator self-disclosure set

Store the operator's own answers about experience, goals, placement and household.

Replaces the signed-in operator's whole self-disclosure; an unanswered question means "not told". The body is decoded strictly and every answer must come from the closed vocabulary below. The capability profile in the answer is derived by the Unifier, never stored from the request. With `if_unchanged` the replacement is applied only when the stored value still equals it, otherwise the answer is 412 `self_disclosure_changed`.

```bash
techstack api operator self-disclosure set [flags]
```

| | |
| --- | --- |
| HTTP | `PUT /api/v1/operator/self-disclosure` |
| Changes state | Yes |
| MCP tool | `set_operator_self_disclosure` |

| Argument | Type | Description |

| `--disclosure` | object | **Required.** |
| `--if-unchanged` | object | The stored value this replacement must still match. |

| `--body` | json | JSON request body (`application/json`) as a literal, `@path` or `-` for stdin. |
