## techstack api backups delete

Backup löschen (nur Admins).

```bash
techstack api backups delete <name> [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation löscht das lokale Backup-Archiv dauerhaft. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>

| --- | --- |
| HTTP | `DELETE /api/v1/backups/{name}` |
