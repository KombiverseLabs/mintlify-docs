## techstack api discovery cache clear

Discovery-Cache leeren (nur Admins).

```bash
techstack api discovery cache clear [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation verwirft jedes zwischengespeicherte Discovery-Ergebnis; die nächste Discovery scannt das Netzwerk neu. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/discovery/cache` |
| Ändert Zustand | Ja |
| MCP-Tool | `clear_discovery_cache` |

## techstack api discovery devices probe

Ein Gerät des Aufrufers eingehend prüfen (Deep Probe).

Aufrufer ohne Admin-Rechte dürfen nur IPs aus ihren eigenen Discovery-Ergebnissen prüfen; Admins dürfen beliebige IPs prüfen.

```bash
techstack api discovery devices probe [flags]
```
