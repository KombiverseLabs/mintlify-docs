## techstack api tunnel install-command

Worker-Installationsbefehl mit Tunnel-URL generieren.

```bash
techstack api tunnel install-command [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/tunnel/install-command` |
| Ändert Zustand | Ja |
| MCP-Tool | Keine |

| Argument | Typ | Beschreibung |
| --- | --- | --- |
| `--token` | string | **Erforderlich.** |
| `--body` | json | JSON-Request-Body (`application/json`) als Literal, `@path` oder `-` für stdin. |

## techstack api tunnel subdomains list

Die eigenen kombify.me-Subdomains des Aufrufers zur Diagnose auflisten; die Registrierung gehört zu StackKits.

Erfordert einen authentifizierten Aufrufer. Mit der gemeinsamen Plattform-Identität ist die Liste auf die Owner-Bindung des Aufrufers begrenzt.

```bash
techstack api tunnel subdomains list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/tunnel/subdomains` |
| Ändert Zustand | Nein |
| MCP-Tool | `list_tunnel_subdomains` |
