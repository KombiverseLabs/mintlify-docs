## techstack api pairing-tokens delete

Pairing-Token löschen.

```bash
techstack api pairing-tokens delete <id> [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation widerruft das Pairing-Token; Geräte, die sich noch nicht gekoppelt haben, können es nicht mehr verwenden. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/trust/pairing-tokens/{id}` |
| Ändert Zustand | Ja |
| MCP-Tool | `delete_pairing_token` |

| Argument | Typ | Beschreibung |
| --- | --- | --- |
| `<id>` | string | **Erforderlich.** Ressourcen-ID. |
