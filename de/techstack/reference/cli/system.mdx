## techstack api system capabilities

API-Fähigkeiten für Clients ermitteln.

Gibt eine strukturierte Liste aller API-Fähigkeiten zur programmatischen Ermittlung zurück. Native Client-Apps verwenden diesen Endpoint, um verfügbare Aktionen, erforderliche Authentifizierung und asynchrones Verhalten aufzulisten.

```bash
techstack api system capabilities [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/capabilities` |
| Ändert Zustand | Nein |
| MCP-Tool | Keine |

## techstack api system client-bootstrap

Öffentliche Runtime-Konfiguration für die statische SPA.

Gibt nicht geheime, zur Laufzeit variierende öffentliche Konfiguration für das eingebettete statische Frontend zurück (Edition, Deployment-Modus, Telemetrie-Schalter). Die Werte sind leer, solange der Operator oder Deployer die entsprechenden Umgebungsvariablen nicht setzt, sodass selbst gehostete und lokale Deployments standardmäßig ohne Telemetrie bleiben.

```bash
techstack api system client-bootstrap [flags]
```

| --- | --- |
| HTTP | `GET /api/v1/client/bootstrap` |
| Ändert Zustand | Nein |
| MCP-Tool | Keine |
