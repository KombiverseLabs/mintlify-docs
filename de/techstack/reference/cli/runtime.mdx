## techstack api runtime logs

Aktuelle Runtime-/Deploy-Logs abrufen.

Gibt aktuelle Runtime-/Deploy-Logeinträge (Job-/Deploy-Fortschritt plus Container-Tail) aus dem Runtime-Log-Puffer des gRPC-Servers zurück, gefiltert nach den übergebenen Query-Parametern. Erfordert Authentifizierung und einen verfügbaren gRPC-Server.

```bash
techstack api runtime logs [flags]
```
