## techstack api drift results delete

Drift-Ergebnis löschen.

```bash
techstack api drift results delete <id> [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation löscht das gespeicherte Drift-Ergebnis dauerhaft. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>
