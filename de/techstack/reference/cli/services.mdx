## techstack api services execute-application-adoption

Den exakt geprüften Quellenplan mit ausdrücklicher Owner-Freigabe ausführen.

Validiert den beibehaltenen Digest, die Quellenidentität, die Revision und das Release erneut. Nur ein authentifizierter Verwahrungsbeleg der gepinnten CLI begründet die Zugehörigkeit. Konten, Konfiguration und persistente Daten bleiben erhalten; es wird keine neue Runtime erstellt. Ein Wechsel auf einen anderen Node und eine generische Übernahme werden nicht unterstützt.

```bash
techstack api services execute-application-adoption [flags]
```

## techstack api services run-action

Eine vom Owner autorisierte StackKits-Service-Aktion einreihen.

Leitet die Autorität für Stack, Server, Agent, Kit und Service aus einem frischen kanonischen Inventory ab. Exakte Wiederholungen konvergieren über einen dauerhaften Job-Beleg; der rohe Idempotency-Key wird nie gespeichert. Auf Änderungen folgt StackKits verify, bevor sich der gemessene Zustand ändert. Vom Agent ausgeführte Aktionen werden mit 409 `maintenance_active` abgelehnt, solange der Server neu gestartet oder aktualisiert wird.

techstack api services run-action <service-id> [flags]

## techstack api services setup-application-connector

Einen deklarierten eigenen Home-Assistant-Connector auf seinem Node sicherstellen oder widerrufen.

Erfordert frische Backend-Ownership, eine positive operate-Autorisierung, exaktes aktuelles Inventory und eine Owner-Freigabe. Überträgt ausschließlich festgelegte Korrelationsmetadaten über Guard an die veröffentlichte gepinnte CLI; deren lokale signedApply- und Owner-Setup-Autorität bleiben verpflichtend. Speichert vor dem Versand eine dauerhafte Absicht; bei unbekannter Bestätigung wird ausschließlich der ursprüngliche Vorgang lesend abgeglichen. Der aktuellen v0.51.8 fehlt der unterstützende Katalog; sie gibt nicht ausführbaren SourcePreview zurück. Zugangsdaten verbleiben in der Verwahrung des Nodes.

```bash
techstack api services setup-application-connector [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation stellt die geprüften Node-eigenen Home-Assistant-Connector-Zugangsdaten für genau diesen Dienst aus oder widerruft sie. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>
