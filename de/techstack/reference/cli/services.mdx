techstack api services get <service-id> [flags]

## techstack api services run-action

Eine vom Owner autorisierte StackKits-Service-Aktion einreihen.

Leitet die Autorität für Stack, Server, Agent, Kit und Service aus einem frischen kanonischen Inventory ab. Exakte Wiederholungen konvergieren über einen dauerhaften Job-Beleg; der rohe Idempotency-Key wird nie gespeichert. Auf Änderungen folgt StackKits verify, bevor sich der gemessene Zustand ändert. Vom Agent ausgeführte Aktionen werden mit 409 `maintenance_active` abgelehnt, solange der Server neu gestartet oder aktualisiert wird.

```bash
techstack api services run-action <service-id> [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/registry/services/{serviceId}/actions` |
| Ändert Zustand | Ja |
| MCP-Tool | `run_managed_service_action` |

| Argument | Typ | Beschreibung |
| --- | --- | --- |
| `<service-id>` | string | **Erforderlich.** Kanonische Service-Runtime-ID. |
| `--body` | json | **Erforderlich.** JSON-Request-Body (`application/json`) als Literal, `@path` oder `-` für stdin. |
