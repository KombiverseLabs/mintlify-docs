## techstack api registry services list

Eigene Dienste mit ihrem Katalog und ihrer kanonischen Platzierung auflisten.

Runtime-Datensätze verwenden dieselbe Projektion von Zustand, Fähigkeiten, Version und Owner-Sperre wie die Dienstdetails. Historische Datensätze bleiben mit unbekanntem beobachtetem Zustand und ohne ungemessene Aktionsfähigkeiten lesbar.

```bash
techstack api registry services list [flags]
```
