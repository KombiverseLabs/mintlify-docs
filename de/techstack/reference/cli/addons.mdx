## techstack api addons detect

Passende Add-ons für eine Spezifikation automatisch erkennen.

```bash
techstack api addons detect [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/addons/detect` |
| Ändert Zustand | Ja |
| MCP-Tool | `detect_addons` |

| Argument | Typ | Beschreibung |
| --- | --- | --- |
| `--body` | json | **Erforderlich.** JSON-Request-Body (`application/json`) als Literal, `@path` oder `-` für stdin. |
