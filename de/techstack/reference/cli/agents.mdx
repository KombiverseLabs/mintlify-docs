## techstack api agents remove

Agent entfernen/abmelden.

```bash
techstack api agents remove <id> [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation meldet den Agent ab; der Node meldet sich erst wieder, wenn er erneut registriert wird. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/agents/{id}` |

## techstack api agents send-command

Befehl an den Agent senden.

```bash
techstack api agents send-command <id> [flags]
```

<Warning>Erfordert Bestätigung: Diese Operation führt den Befehl auf dem verbundenen Node-Agent aus. Übergib `--yes` oder beantworte die Rückfrage; ein nicht interaktiver Lauf ohne `--yes` stoppt vor jeder Anfrage mit Exit-Code 9.</Warning>

| | |
| --- | --- |
| HTTP | `POST /api/v1/agents/{id}/command` |
| Ändert Zustand | Ja |
| MCP-Tool | `send_agent_command` |

| Argument | Typ | Beschreibung |

| `<id>` | string | **Erforderlich.** Ressourcen-ID. |
| `--args` | string\[\] | — |
| `--command` | string | **Erforderlich.** |
| `--type` | string | **Erforderlich.** |
| `--body` | json | JSON-Request-Body (`application/json`) als Literal, `@path` oder `-` für stdin. |
