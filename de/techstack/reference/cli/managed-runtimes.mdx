## techstack api managed-runtimes authority

Anfragegebundene Managed-Runtime-Autorität prüfen, ohne eine Ressource zu erstellen.

Schreibgeschützter Preflight für die Autoritätskette von Gateway bis zur nativen Zulassung. Gehostete Anfragen müssen die v2-signierte Gateway-Entscheidung zu Managed Runtime, Cloud Kit, Anbieter-Entitlement und `cloud.runtime.credits` `managed_servers` tragen, gebunden an genau diese Anfrage. Eine erfolgreiche Antwort reserviert nie Kapazität und erstellt weder ein StackKit-Deployment noch einen Queue-Job, eine Lease, eine Node-Projektion oder eine Anbieter-Operation; die echte Add-Server-Anfrage wiederholt jede veränderliche Zulassungsprüfung atomar.

```bash
techstack api managed-runtimes authority [flags]
```
