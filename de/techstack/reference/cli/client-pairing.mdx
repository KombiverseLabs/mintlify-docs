## techstack api client-pairing issue

Ein kurzlebiges ClientPairingEnvelope v1 ausstellen.

Erfordert einen authentifizierten Instanz-Administrator. Nur für eine selbst gehostete HTTPS-Instanz mit konfiguriertem Tenant und nativer OIDC-Autorität verfügbar. Im lokalen Single-Owner-Modus bricht die Operation sicher ab.

```bash
techstack api client-pairing issue [flags]
```

| HTTP | `POST /api/v1/client-pairing/issue` |
| Ändert Zustand | Ja |
| MCP-Tool | Keine |

## techstack api client-pairing redeem

Einen ClientPairingEnvelope-v1-Code atomar einlösen.

Der Client prüft den Fingerabdruck des HTTPS-Zertifikats, bevor er diese Anfrage sendet. Bei Erfolg wird der Code genau einmal verbraucht, und die Antwort liefert öffentliche Metadaten für den normalen OIDC-Account-Ablauf; sie gibt nie eine Session zurück und dupliziert nie die lokale Owner-Identität.

```bash
techstack api client-pairing redeem [flags]
```
