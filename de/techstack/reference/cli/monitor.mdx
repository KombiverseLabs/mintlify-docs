## techstack api monitor availability

Verfügbarkeit, Ausfallepisoden und Tageszustand, abgeleitet aus der Übergangs-Zeitleiste.

Eine Projektion über die nur anhängende Zeitleiste der Server-Übergänge statt eines Samplers: Jede Episode wird von zwei aufgezeichneten Übergängen begrenzt und trägt die Reason-Codes, mit denen sie geschrieben wurden. Die Antwort veröffentlicht ihr eigenes Abrechnungsvokabular, sodass du ohne Blick in den Quellcode siehst, welche Verbindungszustände als Ausfallzeit gezählt wurden.

```bash
techstack api monitor availability [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/monitor/availability` |
| Ändert Zustand | Nein |
| MCP-Tool | `get_availability_report` |

| Argument | Typ | Beschreibung |
| --- | --- | --- |
| `--window` | string | Geschlossene Menge; ein unbegrenztes Zeitfenster wäre ein Hebel für Denial-of-Service. Mögliche Werte: `24h`, `7d`, `30d`, `90d`. Standard `"30d"`. |
| `--server-id` | string | Den Bericht auf einen Server beschränken, für die Server-Detailseite. |
