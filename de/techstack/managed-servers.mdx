<Warning>
Verwaltete Server gehören zur Vorschau. Sie sind keine Aussage zur allgemeinen
Verfügbarkeit, und die Option ist nur wählbar, wenn dein kombify-Konto
verwaltete Server freigeschaltet hat. Siehe
[Verfügbarkeit](/de/techstack/availability).
</Warning>

Ein verwalteter Server ist die Option **kombify VPS** unter **I need a server**
im Assistenten Add Node. kombify erstellt bei einem Partneranbieter einen
virtuellen Server, bereitet ihn vor und verbindet ihn mit deinem Homelab. Du
mietest den Server nicht selbst und führst keinen Befehl aus.

## So funktioniert ein verwalteter Server

1. Wähle im Node-Schritt **I need a server**, dann **kombify VPS**.
   Techstack prüft, welche Anbieter dein Konto nutzen kann. Ist keiner
   freigeschaltet, bleibt die Option nicht verfügbar, und der Assistent nennt,
   was fehlt. Dein eigenes Gerät kannst du weiterhin verbinden.
2. Prüfe die Serverdetails, die der Assistent zeigt: Größe (vCPU, RAM,
   Speicherplatz), Standort und Anbieter.
3. Schließe den Assistenten ab. kombify erstellt den Server aus einem
   Ubuntu-24.04-Image, verbindet ihn mit deinem Homelab und richtet dann die
   Tools ein, die du gewählt hast. Die Fortschrittsseite zeigt jeden Schritt.

Ein verwalteter Server nutzt die Grundlage des
[Cloud Kit](/de/stackkits/kits/cloud-kit). Wie jeder andere Node lassen sich
seine Dienste über deine eigene Domain oder eine `*.kombify.me`-Adresse
erreichen; siehe [kombify.me](/de/kombify-me/overview).

## Anbieter

Techstack listet derzeit zwei Partneranbieter für verwaltete Server:

- **IONOS**
- **centron**

Welchen davon du wählen kannst, hängt von deinem Konto ab. Sind mehrere
freigeschaltet, öffne **Provider & server details**, um einen auszuwählen. Ist
nur einer freigeschaltet, zeigt der Assistent ihn als Anbieter für deinen
Server.

Bei IONOS wird der Server in einem IONOS-Rechenzentrum in Frankfurt,
Deutschland, erstellt. Der Assistent zeigt den Standort in den Serverdetails.
Andere Größen oder Standorte kannst du im Assistenten noch nicht wählen.

Wenn du einen Server lieber selbst mietest, wähle stattdessen **Find a server
with a partner**. Das verlinkt auf dieselben Anbieter. Sobald dein Server
bereit ist, verbinde ihn mit dem [Pairing-Befehl](/de/techstack/pairing-command)
oder [über SSH](/de/techstack/ssh-connection).

## Standard und Premium

Ein verwalteter Server gibt es in zwei Größen. Der Assistent zeigt als **Your
standard VPS** oder **Your premium VPS**, welche gilt, zusammen mit genauer
vCPU-Zahl, RAM, Speichergröße und Standort.

- **Standard** ist die Standardgröße für einen neuen verwalteten Server.
- **Premium** hat derzeit mehr Ressourcen als Standard: bei jedem Anbieter mehr
  Speicherplatz, bei IONOS außerdem mehr vCPU und RAM.

Die genaue Größe hängt vom Anbieter ab, prüfe also die Werte, die der Assistent
zeigt, bevor du bestätigst. Ein verwalteter Node, der einem bestehenden
verwalteten StackKit hinzugefügt wird, behält die Größe dieses StackKits.

## Verfügbarkeit

Verwaltete Server sind in der Vorschau. Die Option ist nur wählbar, wenn dein
kombify-Konto Zugang zu verwalteten Servern und mindestens einen freigeschalteten
Anbieter hat. Kann Techstack dein Konto gerade nicht prüfen, sagt der
Assistent das und bietet **Try again** an. In jedem Fall kannst du stattdessen
einen eigenen Server hinzufügen, mit dem
[Pairing-Befehl](/de/techstack/pairing-command) oder
[über SSH](/de/techstack/ssh-connection).

Die aktuellen öffentlichen und Vorschau-Grenzen von Techstack findest du unter
[Verfügbarkeit](/de/techstack/availability).
