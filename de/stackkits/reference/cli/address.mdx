Öffentliche Service-Adressen ohne Secrets planen und binden.

```bash
stackkit address [flags]
```

Unterbefehle: [`stackkit address bind`](#stackkit-address-bind), [`stackkit address plan`](#stackkit-address-plan)

## stackkit address bind

Ein zugewiesenes Präfix oder eine Install-Zone an kanonische öffentliche Routen binden.

```bash
stackkit address bind [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--expected-spec-hash` | string | — | Nur native v2: exakter aktueller CUE-normalisierter Spec-Hash, der für den Austausch erforderlich ist |
| `--output, -o` | string | — | Die validierte gebundene StackSpec in diesen Pfad schreiben |
| `--prefix` | string | — | Zugewiesenes DNS-sicheres Subdomain-Präfix: Hosts &lt;prefix&gt;-&lt;service&gt;.&lt;domain&gt; |
| `--zone` | string | — | Zugewiesenes Install-Zonen-Label: Der Stack wird unter &lt;zone&gt;.&lt;domain&gt; ausgeliefert, mit den Hosts &lt;service&gt;.&lt;zone&gt;.&lt;domain&gt; |

## stackkit address plan

Den kontofreien Plan zur Adressregistrierung ausgeben.

```bash
stackkit address plan [flags]
```
