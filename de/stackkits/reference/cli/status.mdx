Bereitstellungsstatus anzeigen.

Den aktuellen Status der StackKit-Bereitstellung anzeigen.

```text
Shows:
  • Deployment state (running, degraded, error)
  • Service statuses and health
  • Resource usage
  • URLs and endpoints
```

```bash
stackkit status [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--http` | bool | — | Verifizierte Dienstrouten von diesem Verifizierer-Host prüfen |
| `--inventory` | string | — | Beobachtetes Architecture-v2-Inventory zur Identifizierung einer konfigurierten Standard-Prozesslaufzeit |
| `--json` | bool | — | Als JSON ausgeben |
| `--resolved-plan` | string | — | Kanonischer Architecture-v2-ResolvedPlan (Standard: deploy/.stackkit/resolved-plan.json) |

**Beispiele**

```bash
# Show status
stackkit status

# Output as JSON
stackkit status --json
```
