Die kanonischen Operationsverträge des Standalone-Lebenszyklus auflisten.

```bash
stackkit operations [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | Operationsverträge als JSON ausgeben |

**Examples**

```bash
# List each lifecycle operation, its access level, and what it does
stackkit operations

# The same contracts as JSON
stackkit operations --json
```
