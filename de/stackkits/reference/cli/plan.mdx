Infrastrukturänderungen in der Vorschau anzeigen.

Prüft den gesteuerten Architecture-v2-Plan oder zeigt eine Vorschau der v0.6-Infrastrukturänderungen.

Auf nativem v0.7 verifiziert und prüft dieser Befehl den exakten ResolvedPlan, das Generierungs-Manifest, den Beleg und die Hashes der generierten Artefakte, ohne einen Executor aufzurufen. Exaktes v0.6 behält seine mitgelieferte OpenTofu-Vorschau; `--out` und `--destroy` gelten nur für diese Vorschau und werden auf der nativen Linie abgelehnt.

```bash
stackkit plan [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--artifact-manifest` | string | — | Architecture-v2-Generierungs-Manifest (Standard: &lt;outputRoot&gt;/.stackkit/generation-manifest.json) |
| `--destroy` | bool | — | Destroy-Plan erstellen |
| `--generation-receipt` | string | — | Architecture-v2-Generierungsbeleg (Standard: &lt;outputRoot&gt;/.stackkit/generation-receipt.json) |
| `--inventory` | string | — | Beobachtetes Architecture-v2-Inventory (andernfalls wird eine übliche Inventory-Datei ausgewählt) |
| `--json` | bool | — | Die native Architecture-v2-Planprüfung als JSON ausgeben |
| `--out, -o` | string | — | Plan in eine Datei speichern |
| `--resolved-plan` | string | — | Kanonischer Architecture-v2-ResolvedPlan (Standard: &lt;outputRoot&gt;/.stackkit/resolved-plan.json) |

**Examples**

```bash
# Inspect the generated plan, its readiness, and artifact hashes
stackkit plan

# The same inspection as JSON
stackkit plan --json
```
