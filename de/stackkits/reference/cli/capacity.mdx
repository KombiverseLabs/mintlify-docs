Bedarf der gewählten Module gegen die beobachtete Host-Kapazität bewerten.

Löst die aktuelle, an CUE gebundene Auswahl auf und gibt ihre beratende Kapazitätsbewertung als JSON aus. Fehlende Messungen bleiben unverifiziert. Es werden keine Dateien oder Runtime-Zustände verändert; dies ersetzt nicht die Zulassung durch Apply.

```bash
stackkit capacity [spec-file] [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--inventory` | string | — | Beobachtetes Inventory; fehlende Kapazität bleibt unverifiziert |
| `--module-root` | string | — | Wurzelverzeichnis der Architecture-Authority |
