Vom aktiven StackKits-Plan deklarierte Services steuern.

```bash
stackkit service [flags]
```

Unterbefehle: [`stackkit service logs`](#stackkit-service-logs), [`stackkit service manager`](#stackkit-service-manager), [`stackkit service restart`](#stackkit-service-restart), [`stackkit service start`](#stackkit-service-start), [`stackkit service stop`](#stackkit-service-stop)

## stackkit service logs

Begrenzte, geschwärzte Service-Logs lesen.

```bash
stackkit service logs <service-key> [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--cursor` | string | — | Opaker Cursor aus einem vorherigen Ergebnis |
| `--json` | bool | — | Die versionierte Service-Log-Seite als JSON schreiben |
| `--tail` | int | `100` | Anzahl der zurückzugebenden geschwärzten Log-Einträge (1..200) |

**Beispiele**

```bash
# Read the last 50 redacted log entries of the TinyAuth login gateway
stackkit service logs auth --tail 50

# Read PocketID logs as JSON
stackkit service logs id --json

# Read the next page with the cursor the previous JSON result returned
stackkit service logs id --json --cursor <cursor>
```

## stackkit service manager

Einen bestehenden, dem Node gehörenden Workload zwischen Compose und Komodo übertragen.

```bash
stackkit service manager <workload-ref> [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | Das versionierte Manager-Ergebnis als JSON schreiben |
| `--owner-approve` | bool | — | Den an den Owner gebundenen Manager-Wechsel ausdrücklich freigeben |
| `--resume` | string | — | Die exakte ausstehende Übergabe-Operation fortsetzen |
| `--status` | bool | — | Den dauerhaften Manager- und Übergabe-Status ohne Änderung lesen |
| `--to` | string | — | Ziel-Manager: standalone-compose oder komodo |

**Beispiele**

```bash
stackkit service manager media --to standalone-compose --owner-approve
stackkit service manager media --to komodo --owner-approve
stackkit service manager media --to komodo --resume handover-<operation-id> --owner-approve
```

## stackkit service restart

Einen verwalteten Service neu starten.

```bash
stackkit service restart <service-key> [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | Das versionierte Service-Aktionsergebnis als JSON schreiben |
| `--owner-approve` | bool | — | Die an den Owner gebundene Service-Änderung explizit freigeben |

**Beispiele**

```bash
# Restart the PocketID identity service
stackkit service restart id --owner-approve

# Restart the TinyAuth login gateway and print the result as JSON
stackkit service restart auth --owner-approve --json
```
