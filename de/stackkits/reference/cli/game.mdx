Die Game-Server des Owners auf dem installierten Game-Workload betreiben.

Game-Server auflisten und die routinemäßigen Owner-Operationen (Power, Allow-List) über das Pterodactyl Panel des angewendeten Game-Workloads ausführen. Einen Server erstellst du mit `stackkit setup game`.

```bash
stackkit game [flags]
```

Unterbefehle: [`stackkit game allow`](#stackkit-game-allow), [`stackkit game list`](#stackkit-game-list), [`stackkit game power`](#stackkit-game-power)

## stackkit game allow

Einen Spieler auf einem StackKits-Allow-List-Game-Server zulassen.

```bash
stackkit game allow <server> [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | stackkit.command-result/v1-JSON ausgeben |
| `--owner-approve` | bool | — | Die Allow-List-Änderung mit der etablierten lokalen Owner-Verwahrung autorisieren |
| `--player` | string | — | **Erforderlich.** Exakter Game-Kontoname (Minecraft-Kontoname oder Xbox-Gamertag) |

**Beispiele**

```bash
stackkit game allow 92c66407 --player Notch --owner-approve
```

## stackkit game list

Die Game-Server des Owners mit Status und Port auflisten.

```bash
stackkit game list [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | stackkit.command-result/v1-JSON ausgeben |

**Beispiele**

```bash
stackkit game list --json
```

## stackkit game power

Einen Game-Server starten, stoppen oder neu starten und auf das Ergebnis warten.

```bash
stackkit game power <server> [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | stackkit.command-result/v1-JSON ausgeben |
| `--owner-approve` | bool | — | Die Power-Änderung mit der etablierten lokalen Owner-Verwahrung autorisieren |
| `--signal` | string | — | **Erforderlich.** Power-Signal: start, stop oder restart |

**Beispiele**

```bash
stackkit game power 92c66407 --signal restart --owner-approve
```
