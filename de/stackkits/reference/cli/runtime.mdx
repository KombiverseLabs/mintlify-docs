Authentifizierte Runtime-Operationen auf dem Node ausführen.

```bash
stackkit runtime [flags]
```

Subcommands: [`stackkit runtime execute`](#stackkit-runtime-execute)

## stackkit runtime execute

Führt ein signiertes execution-channel-bundle/v1 aus stdin aus.

```bash
stackkit runtime execute [flags]
```
