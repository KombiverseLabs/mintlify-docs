Explizite Lebenszyklus-Aktionen von Architecture-v2-Output-Transaktionen prüfen.

```bash
stackkit output-transaction [flags]
```

Subcommands: [`stackkit output-transaction gc-retired`](#stackkit-output-transaction-gc-retired)

## stackkit output-transaction gc-retired

Prüft den Tombstone einer stillgelegten Output-Transaktion oder räumt ihn explizit per Garbage Collection auf.

```bash
stackkit output-transaction gc-retired [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--action` | string | — | Exakte Aktion, die eine vorherige Prüfung gemeldet hat |
| `--apply` | bool | — | Die zurückgegebene Aktion ausführen; standardmäßig wird nur geprüft |
| `--transaction-id` | string | — | **Erforderlich.** Exakte Transaktions-ID in Kleinbuchstaben |
