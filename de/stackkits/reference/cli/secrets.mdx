Owner-gebundene lokale Secret-Verwahrung verwalten.

```bash
stackkit secrets [flags]
```

Subcommands: [`stackkit secrets materialize`](#stackkit-secrets-materialize), [`stackkit secrets reveal`](#stackkit-secrets-reveal)

## stackkit secrets materialize

Verwahrung für Secret-Referenzen in der aktuellen StackSpec herstellen.

Stellt für jede secret://-Referenz in der aktuellen kanonischen StackSpec eine owner-gebundene lokale Verwahrung her oder verwendet sie wieder.

Führe diesen expliziten, idempotenten Schritt aus, nachdem du einem bestehenden Standalone-Workspace einen Workload hinzugefügt hast und bevor du generate/apply ausführst. Er gibt nie Secret-Referenzen oder -Material aus und ersetzt nie ungültige oder fremde Verwahrung.

```bash
stackkit secrets materialize [flags]
```

**Examples**

```bash
# After adding a workload to stack-spec.yaml, create its secrets, then roll out
stackkit secrets materialize
stackkit generate
stackkit apply
```

## stackkit secrets reveal

Ein ausgewähltes Workload-Secret aus der lokalen Owner-Verwahrung ausgeben.

Gibt den bestehenden Wert eines Secret-Slots aus, den ein ausgewählter Workload in der aktuellen CUE-gültigen StackSpec deklariert. Die Ausgabe enthält Secret-Material; verwende sie nur in einem privaten Terminal oder einer bewussten Pipe. Kein Wert wird in Deploy-Logs oder Belege geschrieben.

```bash
stackkit secrets reveal [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--slot` | string | — | **Erforderlich.** Deklarierter Workload-Secret-Slot |
| `--workload` | string | — | **Erforderlich.** ID des ausgewählten Workloads |

**Examples**

```bash
# Print the Photos database password from local owner custody
stackkit secrets reveal --workload photos --slot database-password
```
