Diesen Server an dein kombify-Konto binden (ein kostenloses Konto genügt).

Binde diesen Server, der bereits das öffentliche Paket ausführt, an das kombify-Konto, das die Kopplung im Techstack-Setup erstellt hat. Der Server zeigt seinen Zustand danach in kombify Cloud; Änderungen darüber hinaus bleiben den bezahlten Plänen vorbehalten. Füge die einmalige Kopplung an der verdeckten Terminalabfrage ein. Automatisierung nutzt `--token-file` oder KOMBI_TOKEN, niemals ein Token-Argument. Der Ursprung der Control Plane stammt aus `--server` oder KOMBI_SERVER (öffentlicher Standard https://techstack.kombify.io). Für eine selbst gehostete Control Plane übernimm den genauen `--server`-Ursprung aus dem Techstack-eigenen Server-Setup in kombify Cloud. Ein bereits gebundener Server meldet seine Bindung und ändert nichts. Führe ihn unter Linux als root aus.

```bash
stackkit connect [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--server` | string | — | Ursprung der Control Plane, aus dem die Kopplung stammt (KOMBI_SERVER, sonst https://techstack.kombify.io); übernimm selbst gehostete Ursprünge aus dem Techstack-eigenen Server-Setup |
| `--token-file` | string | — | private Datei mit der einmaligen Kopplung (sonst KOMBI_TOKEN, danach eine verdeckte Terminalabfrage) |

**Beispiele**

```bash
sudo stackkit connect --server https://techstack.kombify.io
sudo stackkit connect --server https://your-techstack.example --token-file /root/kombify-pairing
```
