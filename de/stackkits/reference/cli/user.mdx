Haushaltsmitglieder im lokalen PocketID einladen und verwalten.

Erstellt, listet und entfernt Homelab-Benutzer in der PocketID-Haushaltsgruppe.

Add gibt eine einmalige Passkey-Setup-URL aus. TinyAuth lässt weiterhin die Owner-, Admin- und Haushaltsgruppen zu, die bereits am OIDC-Client gebunden sind. Owner- und Admin-Identities können hier weder erstellt noch entfernt werden.

```bash
stackkit user [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | stackkit.command-result/v1-JSON ausgeben |

**Examples**

```bash
# Invite a household member; share the printed one-time URL only with them
stackkit user add alex --email alex@example.com --owner-approve

# List household users
stackkit user list

# Remove a household user
stackkit user remove alex --owner-approve
```

Subcommands: [`stackkit user add`](#stackkit-user-add), [`stackkit user list`](#stackkit-user-list), [`stackkit user owner`](#stackkit-user-owner), [`stackkit user remove`](#stackkit-user-remove)

## stackkit user add

Ein Haushaltsmitglied mit einer einmaligen Passkey-Setup-URL einladen.

```bash
stackkit user add <username> [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--display-name` | string | — | Optionaler Anzeigename |
| `--email` | string | — | **Erforderlich.** E-Mail des Haushaltsmitglieds |
| `--owner-approve` | bool | — | Das Anlegen dieses Haushaltsmitglieds explizit freigeben |

Geerbt von `stackkit user`:

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | stackkit.command-result/v1-JSON ausgeben |

**Examples**

```bash
# Invite a household member and print their one-time passkey setup URL
stackkit user add alex --email alex@example.com --owner-approve

# Set a display name and return the invitation as JSON
stackkit user add sam --email sam@example.com --display-name "Sam Doe" --owner-approve --json
```
