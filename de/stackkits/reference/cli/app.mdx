Anwendungsbereitstellung in StackKits prüfen und v0.6-Handoffs verwalten.

Die gesteuerte Architecture-v2-Matrix zur Anwendungsbereitstellung für Coolify, Komodo und Standalone-Compose prüfen.

Optionale Handoff-Metadaten für Kunden-PaaS bleiben nur auf der expliziten v0.6-StackSpec-Kompatibilitätslinie verfügbar. Architecture v2 kennt keine beliebige Zuordnung von Kunden-Workloads; von StackKits verwaltete Anwendungen stammen aus dem CUE-Katalog, der gewünschte Zustand von Kunden-Workloads gehört zu Techstack.

```bash
stackkit app [flags]
```

Unterbefehle: [`stackkit app compatibility`](#stackkit-app-compatibility)

## stackkit app compatibility

Die gesteuerte Support-Matrix für Anwendungen und Adapter anzeigen.

Die unveränderlichen, CUE-verwalteten Support-Zeilen für StackKits-Anwendungen anzeigen. Das zeigt die Produktfähigkeit, nicht den gewählten Plan, die Live-Verfügbarkeit von Adaptern oder Deployment-Nachweise.

```bash
stackkit app compatibility [flags]
```

| Flag | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `--json` | bool | — | Die Kompatibilitätsmatrix als JSON ausgeben |

**Beispiele**

```bash
# Show which applications each runtime adapter supports
stackkit app compatibility

# The same matrix as JSON
stackkit app compatibility --json
```
