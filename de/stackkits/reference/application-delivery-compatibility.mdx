<Note>
Die Lebenszyklus-Läufe für v0.54.8 sind noch nicht projiziert; die Zeilen zeigen v0.54.4, das neueste projizierte Release.
</Note>

Status und Fähigkeiten werden von [v0.54.8](https://github.com/kombifyio/StackKits/releases/tag/v0.54.8) deklariert. Die Spalte **Lebenszyklus-Test** wird aus den automatisierten Lebenszyklus-Läufen von StackKits [v0.54.4](https://github.com/kombifyio/StackKits/releases/tag/v0.54.4) projiziert:

- `supported`: Jede Lebenszyklus-Phase hat im neuesten Lauf auf diesem Release bestanden.
- `preview`: Installation bis Verifikation bestanden im neuesten Lauf; eine spätere Phase ist fehlgeschlagen.
- `unverified`: Auf diesem Release noch kein abgeschlossener Lauf, oder der neueste Lauf ist vor der Verifikation fehlgeschlagen.
- nicht getestet: Für diesen Anwendungsfall auf diesem Adapter deckt bisher kein automatisierter Lebenszyklus-Lauf ab.
