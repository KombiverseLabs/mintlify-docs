Die Zeilen werden aus den automatisierten Lebenszyklus-Läufen von StackKits [v0.50.3](https://github.com/kombifyio/StackKits/releases/tag/v0.50.3) auf frischen virtuellen Maschinen projiziert: install, init, generate, apply, verify, backup und restore. Letzter Lebenszyklus-Lauf: 2026-10-02.

- `supported`: Jede Lebenszyklus-Phase hat im neuesten Lauf auf diesem Release bestanden.
- `preview`: Installation bis Verifikation bestanden im neuesten Lauf; eine spätere Phase ist fehlgeschlagen.
- `unverified`: Auf diesem Release noch kein abgeschlossener Lauf, oder der neueste Lauf ist vor der Verifikation fehlgeschlagen.

Die Zeilen für Betriebssysteme und Hypervisoren zeigen das beste Ergebnis über die auf diesem Release getesteten Umgebungen; unter „Kits nach Umgebung“ ist jede Umgebung einzeln aufgeführt.

## Hypervisoren

StackKits laufen in einer Gast-VM auf deinem Hypervisor, nie auf dem Hypervisor-Host selbst. Ein Status deckt diesen Rollout durchgängig ab: Der Gast wird auf dem Hypervisor erstellt und der StackKit-Lebenszyklus läuft darin. Er zertifiziert weder ein Hersteller-Produkt noch einen Server-Provider.

Die Hypervisor-Rollouts und ihre Lebenszyklus-Nachweise für dieses Release sind auf [stackkit.cc/compatibility](https://stackkit.cc/compatibility) aufgeführt. Führe `stackkit compat` auf einem Host aus, um nicht-destruktive Diagnosen und die für sein Betriebssystem und seinen Hypervisor veröffentlichten Nachweise zu erhalten.
