Das öffentliche SpeechKit-Modul enthält den plattformneutralen Voice-Kernel. Nutze es,
wenn deine Anwendung ihren eigenen Prozess, ihre Konfiguration und ihre Provider-Zugangsdaten
selbst verantworten soll, statt von einem separaten SpeechKit-Server abzuhängen.

{/* speechkit-release:begin */}
Das aktuelle öffentliche Release ist [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1), veröffentlicht am 2026-09-20.
{/* speechkit-release:end */}

## Voraussetzungen

- Go 1.26 oder neuer
- eine Anwendung, die die gewählte Mikrofon-, Audio- oder Texteingabe bereitstellen kann
- Provider-Zugangsdaten nur, wenn du einen externen Provider wählst

## Das Modul hinzufügen

```bash
go get github.com/kombifyio/SpeechKit@latest
```

`@latest` löst auf das neueste veröffentlichte Release auf. Notiere die exakte Version,
die dein Build aufgelöst hat, und pinne sie vor der Auslieferung: Dies ist Beta-Software,
und öffentliche APIs, Konfigurationsschlüssel und Standardwerte können sich zwischen
Minor-Releases ändern.

Importiere nur die Pakete, die dein Host braucht: `pkg/speechkit/dictation` für
Diktat, `pkg/speechkit/wakeword` für die Aktivierung, `pkg/speechkit/tts` für
gesprochene Ausgabe, `pkg/speechkit/companion` plus Assist- und Text-to-Speech-
Adapter für One-Shot-Hosts, `pkg/speechkit/speaker` für sprechererkennende Apps,
`pkg/speechkit/meeting` für Aufnahmesitzungen und `pkg/speechkit/client` für
serverangebundene Apps. Das Root-Paket `speechkit` enthält nur Verträge und Werttypen.

Wenn du das Framework aus einer `config.toml` steuern willst, statt Einstellungen
von Hand aufzubauen, macht `pkg/speechkit/hostconfig` aus einer Konfigurationsdatei
in einem Aufruf die öffentlichen Modus-Einstellungen und eine Start-Runtime-Policy:

```go
settings, policy, err := hostconfig.Load("config.toml")
```

Eine fehlende Datei liefert die ausgelieferten Standardwerte — nur lokal, keine Cloud-Schlüssel. Der
Desktop-Client delegiert an denselben Loader, sodass ein Embedder und die Referenz-App
eine `config.toml` identisch lesen.

Einige Pakete brauchen cgo (Windows-Audioaufnahme, das ONNX-Wake-Word) oder eine
externe Binärdatei (`whisper-server`). Jedes schlägt mit einem Sentinel-Fehler
geschlossen fehl, wenn seine Abhängigkeit fehlt, statt so zu tun, als würde es funktionieren.
