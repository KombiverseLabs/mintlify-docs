Der SpeechKit-Desktop-Client unterstützt Windows 10 und Windows 11 auf x64-
Systemen. Windows ist das vollständige Ziel: alle drei Modi, Hands-Free und
Meeting. Lade Assets nur aus dem offiziellen Release `kombifyio/SpeechKit` herunter.

{/* speechkit-release:begin */}
Das aktuelle öffentliche Release ist [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1), veröffentlicht am 2026-09-20.
{/* speechkit-release:end */}

## Den Download verifizieren

1. Lade die passende Datei
   [SHA256SUMS.txt](https://github.com/kombifyio/SpeechKit/releases/latest/download/SHA256SUMS.txt) herunter.
2. Berechne den SHA-256-Hash des Installers oder der ZIP-Datei mit einem Tool, dem du vertraust.
3. Vergleiche den vollständigen Hash mit dem Eintrag in `SHA256SUMS.txt`, bevor du
   das Paket öffnest.
4. Lies die
   [Mitteilung zum unsignierten Release](https://github.com/kombifyio/SpeechKit/releases/latest/download/UNSIGNED-WINDOWS-RELEASE.txt).

<Warning>
Das kostenlose Windows-Release ist unsigniert. Windows zeigt möglicherweise eine Reputationswarnung an.
Prüfe die Prüfsumme und die Herkunft des Releases, bevor du entscheidest, ob du
fortfährst.
</Warning>

## Erste Nutzung

1. Starte SpeechKit und wähle das Mikrofon aus, das es verwenden soll.
2. Wähle einen Network Scope. All networks erlaubt externe Provider; local
   network only und this device only schränken ein, was das Backend kontaktieren darf.
3. Wähle einen lokalen oder externen Provider, der zum Modus passt.
4. Teste Dictation, bevor du Assist, Voice Agent oder Meeting aktivierst.
5. Prüfe bei der Wahl eines externen Providers, was das Gerät verlässt.

Die Standard-Hotkeys sind `Ctrl+Win` für Dictation, `Win+Alt` für Assist und
`Ctrl+Shift` für Voice Agent. In einem Meeting nimmt `Ctrl+Alt+S` einen Bildschirm-
Snapshot auf.
