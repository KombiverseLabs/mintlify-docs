Der Voice Agent ist ein gesprochenes Live-Gespräch. Du kannst Rückfragen stellen
und unterbrechen. Er tippt nicht in deine Apps. Dafür nutze Dictation oder
Assist. Der Voice Agent ist eine Windows-Funktion. Unter macOS ist er in der
aktuellen Beta nicht verifiziert.

## Bevor du beginnst

- SpeechKit ist installiert und Dictation funktioniert.
- Der Voice Agent ist bei einer frischen Installation aus. Du schaltest ihn
  unten ein.
- Der Voice Agent braucht einen Anbieter für das Live-Gespräch, lokal oder in
  der Cloud. Wähle ihn mit Blick auf die
  [Datenschutzeinstellungen](/de/speechkit/privacy-settings). Ein Cloud-Anbieter
  erhält deine Stimme.

## Schritte

<Steps>
  <Step title="Den Voice Agent einschalten">
    Schalte unter **Settings > Overview** in der Liste **Modes** den Voice Agent
    ein. Du kannst auch **Voice Agent Mode** öffnen und dort seinen Hotkey
    aktivieren.
  </Step>
  <Step title="Prüfen, was Aufmerksamkeit braucht">
    **Overview** listet fehlende Anbieterschlüssel unter **Needs attention**
    auf. Füge den Schlüssel hinzu oder wähle einen anderen Anbieter.
  </Step>
  <Step title="Ein Gespräch beginnen">
    Der Standard-Hotkey ist `Ctrl+Shift`. Halte ihn, sprich und lass ihn los. Du
    kannst den Agenten auch mit den Schaltflächen **Start voice agent** und
    **Stop voice agent** im Fenster des Voice Agent starten und stoppen.
  </Step>
  <Step title="Eine Rückfrage stellen">
    Das Fenster zeigt das Gespräch. Nachdem der Agent geantwortet hat, stelle
    eine Rückfrage. Zum Beispiel: "help me decide the next release slice". Dann
    unterbrich mit einer Rückfrage.
  </Step>
  <Step title="Die Sitzung beenden">
    Beende die Sitzung, um eine Zusammenfassung zu erhalten. Nachdem du den
    Hotkey losgelassen hast, bleibt der Dialog kurze Zeit fortsetzbar (das
    **Resume window**). Die Zusammenfassung und das Schließen des Panels
    passieren, wenn dieses Zeitfenster abläuft.
  </Step>
</Steps>

## Einstellungen, die du ändern kannst

Öffne **Settings > Voice Agent Mode**.

| Einstellung | Was sie bewirkt |
| --- | --- |
| Voice Agent hotkey | Die Kombination, die das Gespräch startet. |
| Agent profile | Wählt das Agentenprofil. |
| Personal refinement prompt | Fügt deine eigenen Vorlieben hinzu, zum Beispiel kurze Antworten. |
| Resume window (seconds) | Wie lange ein Dialog fortsetzbar bleibt. 0 beendet die Sitzung sofort. |
| Pause tolerance (ms) | Kurze Pausen bis zu dieser Länge lösen keine Antwort aus. 0 verwendet den Standard des Anbieters. |
| Session summary | Behält eine Zusammenfassung der Sitzung. |
| Closing the window | Wähle **Minimise and keep chat** oder **End chat on close**. |

Vergangene Gespräche erscheinen in der **Library** im Sprach-Tab.

## Mit deiner Stimme starten

**Hands-Free** kann einen Modus mit einer Weckphrase statt mit einem Hotkey
starten. Schalte es unter **Settings > Hands-Free** mit **Enable hands-free
activation** ein und wähle dann die Phrase und das Ziel (**Voice Agent
conversation**, **Assist voice companion** oder **Dictation (UI-assisted)**).
Das Mikrofon-Audio für die Weckerkennung bleibt auf dem Gerät. Hands-Free ist
unter macOS nicht verfügbar.

## Wenn etwas schiefgeht

- **Der Agent startet nicht.** Prüfe, ob der Voice Agent eingeschaltet ist und
  sein Anbieter einen Schlüssel hat. Siehe **Needs attention** in **Overview**.
- **Er antwortet zu früh.** Erhöhe **Pause tolerance (ms)**.
- **Du hörst ihn nicht.** Nutze die Steuerung für die Lautsprecherausgabe im
  Fenster des Voice Agent, um einen anderen Lautsprecher zu wählen.
- **Du kommst nicht weiter.** Siehe
  [Häufige Probleme beheben](/de/speechkit/fix-common-problems).
