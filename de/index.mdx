# kombify-Dokumentation

Diese öffentliche Dokumentation behandelt den veröffentlichten StackKits-Homelab-Standard,
das SpeechKit-Sprach-Framework und die aktuelle Techstack Alpha, einschließlich
öffentlicher kombify.me-Adressen. Jeder Produktbereich nennt, welche Artefakte
öffentlich verfügbar sind und welche Funktionen noch eine Vorschau bleiben.

<Info>
StackKits und SpeechKit haben eigenständige öffentliche Releases. Techstack hat
jetzt eine unsignierte Open-Source-Alpha für Windows zur kontolosen lokalen
Orchestrierung.
</Info>

## Release-Autorität

Release-basierte Anleitungen verlinken auf das aktuelle öffentliche Artefakt
statt auf eine eingefrorene Version, sodass ein Download-Link hier immer zum
neuesten veröffentlichten Release führt. Wo eine Seite eine Version nennt, wird
diese Zeile aus dem veröffentlichten Release erzeugt und automatisch abgeglichen.
Produktvorschauen sind separat gekennzeichnet und erhalten keine erfundenen
Download- oder Installationsschritte.

<Note>
Diese Dokumentation schließt interne Entwicklungsinfrastruktur, private
Implementierungsdetails und nicht unterstützte Produktversprechen bewusst aus.
</Note>
