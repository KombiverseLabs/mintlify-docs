# kombify-Dokumentation

Diese öffentliche Dokumentation beschreibt den veröffentlichten StackKits-Homelab-Standard,
das SpeechKit-Sprachframework und die aktuelle Techstack-Alpha einschließlich öffentlicher
kombify.me-Adressen. Jeder Produktbereich kennzeichnet, welche Artefakte öffentlich verfügbar
sind und welche Funktionen weiterhin eine Vorschau sind.

<Info>
StackKits und SpeechKit sind eigenständig öffentlich veröffentlicht. Techstack bietet jetzt
eine unsignierte Open-Source-Windows-Alpha für die lokale Orchestrierung ohne Konto.
</Info>

## Release-Autorität

Release-gestützte Anleitungen verweisen auf das aktuelle öffentliche Artefakt statt auf eine
eingefrorene Version. Ein Download-Link führt dadurch immer zur neuesten Veröffentlichung.
Wenn eine Seite eine Version nennt, wird diese Angabe aus der veröffentlichten Version erzeugt
und automatisch abgeglichen. Produktvorschauen sind getrennt gekennzeichnet und erhalten keine
erfundenen Download- oder Installationsschritte.

<Note>
Diese Dokumentation schließt interne Entwicklungsinfrastruktur, private Implementierungsdetails
und nicht unterstützte Produktbehauptungen bewusst aus.
</Note>
