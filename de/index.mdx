# kombify-Dokumentation

Mach aus einem Rechner, den du bereits besitzt, ein laufendes Homelab mit
Photos, Files und Vault. Es läuft auf deiner eigenen Hardware, braucht kein
kombify-Konto und kann auf Wunsch eine öffentliche HTTPS-Adresse hinzufügen.

## Deine Adressen

Ein Befehl gibt deinen Apps HTTPS-Namen, ohne dass du vorher eine Domain
einrichtest. Öffentliche `*.kombify.me`-Namen sind der reibungslose Standard:
keine Domain, kein DNS-Setup und kein Zertifikat auf Telefon oder Laptop.
Nur im lokalen Netzwerk ist die bewusste Alternative, wenn nichts von außen
erreichbar sein soll.

| Modus | Adressen | Was du dafür brauchst |
| --- | --- | --- |
| Öffentliche Namen | `*.kombify.me` | Standard auf einem öffentlichen Server. Auf einem Heimserver setze `DOMAIN=kombify.me` vor dem Einzeiler und schalte einen Zugangsweg mit `stackkit reach` ein. |
| Nur im lokalen Netzwerk | `*.lab.home` | Standard auf einem Heimserver und überall gezielt wählbar mit `DOMAIN=lab.home`. Jedes Gerät braucht den einmaligen DNS- und CA-Schritt. |

`stackkit connect` bindet den Server an dein kombify-Konto und aktiviert damit
`{base}-{app}.kombify.me`-Namen. Danach entscheidest du pro App, ob sie nur im
Heimnetz bleibt oder aus dem Internet erreichbar ist.

<Note>
  kombify.me ist Beta-Software. Namen, Header und Fehlerformate können sich
  noch ändern.
</Note>

## Die sechs Befehle

Diese decken Einrichtung, laufenden Betrieb und die optionale Verbindung zu
kombify ab:

| Befehl | Aufgabe |
| --- | --- |
| <code>stackkit init</code> | Neues Deployment aus einem StackKit initialisieren |
| <code>stackkit apply</code> | Infrastrukturänderungen anwenden |
| <code>stackkit status</code> | Deployment-Status anzeigen |
| <code>stackkit verify</code> | Prüfungen nach dem Deployment ausführen |
| <code>stackkit backup</code> | Backups verwalten (Kopia-Engine) |
| <code>stackkit connect</code> | Server für öffentliche `*.kombify.me`-Namen an dein kombify-Konto binden |

Die [CLI-Referenz](/de/stackkits/reference/cli/overview) listet jeden Befehl
mit Flags und Beispielen; der übrige Befehlsbaum liegt dort unter Erweiterte
Referenz.
