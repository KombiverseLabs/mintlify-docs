<Warning>
„Von kombify verwaltet“ befindet sich in der Vorschau. Die Option erscheint nur,
wenn für dein Konto verwaltete Server aktiviert sind, und der Funktionsumfang
kann sich noch ändern. Siehe
[Homelab-Verfügbarkeit](/de/homelab/availability).
</Warning>

„Von kombify verwaltet“ ist der Modus, in dem du keinen Server und keine
Zugangsdaten eines Anbieters bereitstellst. kombify bestellt einen virtuellen
Server bei einem Hosting-Anbieter, bereitet ihn vor und betreibt ihn. Du wählst
deine Apps; kombify richtet das Standard-Homelab auf dem Server ein (Pro enthält
1 Managed-App-Slot und All-You-Need 3 Managed-App-Slots für gehostete Apps,
während selbst hostbare Tools wie Paperwork standardmäßig lokal laufen).

## Was du zuerst brauchst

- Ein kombify-Konto in einem Tarif, der verwaltete Server enthält. Wie viele
  verwaltete Server du haben kannst, hängt von deinem Tarif ab. Siehe
  [Tarife und Abrechnung](/de/apps/cloud/plans-and-billing).
- Für dein Konto aktivierte verwaltete Server.

## Einen verwalteten Server erstellen

<Steps>
  <Step title="Den Assistenten starten">
    Öffne im Dashboard **Homelab** unter **Tools** und starte **Add Node**.
  </Step>
  <Step title="Einen Server anfordern">
    Wähle **I need a server** und dann **kombify VPS**. Wenn dein Konto ihn
    noch nicht nutzen kann, bleibt die Option nicht verfügbar und der Assistent
    nennt, was fehlt.
  </Step>
  <Step title="Die Details prüfen">
    Der Assistent zeigt Größe, Standort und Anbieter. Prüfe sie, bevor du
    bestätigst.
  </Step>
  <Step title="Abschließen und den Fortschritt verfolgen">
    kombify erstellt den Server, verbindet ihn mit deinem Homelab und richtet
    die gewählten Werkzeuge ein. Die Fortschrittsseite zeigt jeden Schritt.
  </Step>
</Steps>

Der Assistent beschreibt den Server und seine Anbieter im Detail. Siehe
[Verwaltete Server in Homelab](/de/homelab/managed-servers).

## Status ansehen

Monitoring in deinem Dashboard listet den Server mit einem Lebenszyklusstatus,
einem Verbindungsstatus und einem Integritätsstatus. Der Lebenszyklus
durchläuft Planned, Provisioning, Enrolling und Active. Ein Server, der nicht
erstellt werden konnte, zeigt Failed.

## Ihn betreuen

- **Wartung.** Wähle auf der Seite des Servers in Homelab **Review OS
  updates** oder **Review reboot**. Homelab listet die Apps und Stacks, die
  betroffen wären, und es läuft nichts, bis du bestätigst. Wartung wird nur
  angeboten, wenn der Server und dein Konto dies unterstützen.
- **Backups.** Die Backups-Karte in Monitoring zeigt den letzten Lauf. Wie
  lange Backups aufbewahrt werden, hängt von deinem Tarif ab.
- **Erreichbarkeit.** Deine Apps sind über deine eigene Domain oder eine
  `*.kombify.me`-Adresse erreichbar, genauso wie auf jedem anderen Server. Siehe
  [kombify.me](/de/kombify-me/overview).

## Den Server löschen

Wähle auf der Seite des Servers **Delete server** und bestätige. Homelab
fordert die kontrollierte Entfernung des Servers an und behält seinen Eintrag,
bis der Server beim Anbieter nachweislich gelöscht ist. Um das gesamte Homelab
samt verwaltetem Server zu entfernen, nutze **Delete this homelab** in den
Homelab-Einstellungen.

Ein verwalteter Server lässt sich nicht wie ein eigener Server trennen. Durch
das Löschen wird er entfernt.

## Wenn etwas schiefgeht

- Bleibt der Server in Provisioning oder zeigt Failed, öffne die
  Fortschrittsseite in Homelab für den Schritt, der angehalten hat.
- Wenn du lieber deinen eigenen Server nutzen möchtest, siehe
  [Server verbinden](/de/apps/cloud/connect-a-server).
- Für alles Weitere schreibe an [info@kombify.io](mailto:info@kombify.io).
