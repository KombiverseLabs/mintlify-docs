## techstack api system capabilities

क्लाइंट के लिए API क्षमताएँ खोजें।

प्रोग्रामेटिक डिस्कवरी के लिए सभी API क्षमताओं की संरचित सूची लौटाता है। नेटिव क्लाइंट ऐप इस एंडपॉइंट से उपलब्ध एक्शन, आवश्यक ऑथ और async व्यवहार की सूची बनाते हैं।

```bash
techstack api system capabilities [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/capabilities` |
| स्टेट बदलता है | नहीं |
| MCP टूल | कोई नहीं |

## techstack api system client-bootstrap

स्टैटिक SPA के लिए सार्वजनिक रनटाइम कॉन्फ़िग।

एम्बेडेड स्टैटिक फ़्रंटएंड के लिए गैर-गोपनीय, रनटाइम के अनुसार बदलने वाला सार्वजनिक कॉन्फ़िगरेशन (एडिशन, डिप्लॉयमेंट मोड, टेलीमेट्री टॉगल) लौटाता है। जब तक ऑपरेटर या डिप्लॉय करने वाला संबंधित एनवायरनमेंट वेरिएबल सेट न करे, मान खाली रहते हैं, जिससे सेल्फ़-होस्टेड और लोकल डिप्लॉयमेंट डिफ़ॉल्ट रूप से टेलीमेट्री-मुक्त रहते हैं।

```bash
techstack api system client-bootstrap [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/client/bootstrap` |
| स्टेट बदलता है | नहीं |
| MCP टूल | कोई नहीं |
