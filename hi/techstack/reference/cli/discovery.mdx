## techstack api discovery cache clear

डिस्कवरी कैश साफ़ करें (केवल एडमिन)।

```bash
techstack api discovery cache clear [flags]
```

<Warning>पुष्टि आवश्यक है: यह ऑपरेशन हर कैश किया गया डिस्कवरी परिणाम हटा देता है; अगली डिस्कवरी नेटवर्क को फिर से स्कैन करती है। `--yes` दें या प्रॉम्प्ट का उत्तर दें; `--yes` के बिना गैर-इंटरैक्टिव रन किसी भी रिक्वेस्ट से पहले एग्ज़िट कोड 9 के साथ रुक जाता है।</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/discovery/cache` |
| स्टेट बदलता है | हाँ |
| MCP टूल | `clear_discovery_cache` |

## techstack api discovery devices get

कॉलर के स्वामित्व वाला खोजा गया डिवाइस प्राप्त करें।

```bash
techstack api discovery devices get <id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/discovery/devices/{id}` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `get_device` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `<id>` | string | **आवश्यक।** संसाधन ID। |

केवल वे डिवाइस लौटाता है जो प्रमाणित कॉलर के स्वामित्व वाले स्कैन से मिले हैं।

```bash
techstack api discovery devices list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/discovery/devices` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `list_devices` |

## techstack api discovery devices probe

कॉलर के स्वामित्व वाले डिवाइस की गहन जाँच करें।

गैर-एडमिन कॉलर केवल अपने डिस्कवरी परिणामों के IP जाँच सकते हैं; एडमिन कोई भी IP जाँच सकते हैं।

```bash
techstack api discovery devices probe [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/discovery/probe` |
| स्टेट बदलता है | हाँ |
| MCP टूल | कोई नहीं |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `--ip` | string | **आवश्यक।** |
| `--ssh-key` | string | — |
| `--ssh-user` | string | — |
| `--body` | json | JSON रिक्वेस्ट बॉडी (`application/json`) लिटरल के रूप में, `@path` के रूप में, या stdin के लिए `-`। |
