## techstack api backups delete

बैकअप हटाएँ (केवल एडमिन)।

```bash

```

<Warning>पुष्टि आवश्यक है: यह ऑपरेशन लोकल बैकअप आर्काइव को स्थायी रूप से हटा देता है। `--yes` दें या प्रॉम्प्ट का उत्तर दें; `--yes` के बिना गैर-इंटरैक्टिव रन किसी भी रिक्वेस्ट से पहले एग्ज़िट कोड 9 के साथ रुक जाता है।</Warning>
