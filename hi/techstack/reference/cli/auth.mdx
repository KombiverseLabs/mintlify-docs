## techstack api auth methods

उपलब्ध लोकल और ब्राउज़र ऑथ विधियाँ सूचीबद्ध करें।

```bash
techstack api auth methods [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/auth/methods` |
| स्टेट बदलता है | नहीं |
| MCP टूल | कोई नहीं |

## techstack api auth mode

वर्तमान ऑथ मोड (लोकल या क्लाउड) प्राप्त करें।

```bash
techstack api auth mode [flags]
```

| | |
| --- | --- |
