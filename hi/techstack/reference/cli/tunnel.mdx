<Note>Techstack v0.32.8 रिलीज़ (सोर्स `4c7d219a5d56`) से जनरेट किया गया। इंस्टॉल किए गए वर्ज़न के लिए `techstack api <command> --help` ही प्रामाणिक है।</Note>

## techstack api tunnel install-command

टनल URL के साथ वर्कर इंस्टॉल कमांड जनरेट करें।

```bash
techstack api tunnel install-command [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/tunnel/install-command` |
| स्टेट बदलता है | हाँ |
| MCP टूल | कोई नहीं |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `--token` | string | **आवश्यक।** |
| `--body` | json | JSON रिक्वेस्ट बॉडी (`application/json`) लिटरल के रूप में, `@path` के रूप में, या stdin के लिए `-`। |

## techstack api tunnel subdomains list

डायग्नोस्टिक के लिए कॉलर के अपने kombify.me सबडोमेन सूचीबद्ध करें; रजिस्ट्रेशन StackKits के स्वामित्व में है।

प्रमाणित कॉलर आवश्यक है। साझा प्लेटफ़ॉर्म पहचान के साथ सूची कॉलर की ओनर बाइंडिंग तक सीमित रहती है।

```bash
techstack api tunnel subdomains list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/tunnel/subdomains` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `list_tunnel_subdomains` |
