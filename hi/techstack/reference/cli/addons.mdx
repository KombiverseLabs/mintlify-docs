## techstack api addons detect

किसी स्पेक के लिए लागू होने वाले ऐड-ऑन स्वतः पहचानें।

```bash
techstack api addons detect [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/addons/detect` |
| स्टेट बदलता है | हाँ |
| MCP टूल | `detect_addons` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `--body` | json | **आवश्यक।** JSON रिक्वेस्ट बॉडी (`application/json`) लिटरल के रूप में, `@path` के रूप में, या stdin के लिए `-`। |

## techstack api addons list

उपलब्ध ऐड-ऑन सूचीबद्ध करें।

```bash
techstack api addons list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/addons` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `list_addons` |
