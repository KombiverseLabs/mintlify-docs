## techstack api monitor availability

ट्रांज़िशन टाइमलाइन से निकाली गई उपलब्धता, डाउनटाइम घटनाएँ और दैनिक स्टेट।

सैंपलर के बजाय केवल-जोड़ने वाली (append-only) सर्वर ट्रांज़िशन टाइमलाइन पर एक प्रक्षेपण: हर घटना दो दर्ज ट्रांज़िशन से सीमित होती है और उन कारण कोड को साथ रखती है जिनके साथ वे लिखे गए थे। रिस्पॉन्स अपनी गणना शब्दावली स्वयं प्रकाशित करता है, ताकि पाठक सोर्स पढ़े बिना देख सके कि कौन-सी कनेक्शन स्टेट डाउनटाइम के रूप में गिनी गईं।

```bash
techstack api monitor availability [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/monitor/availability` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `get_availability_report` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `--window` | string | बंद सेट; असीमित विंडो denial-of-service का ज़रिया बन सकती है। इनमें से एक: `24h`, `7d`, `30d`, `90d`। डिफ़ॉल्ट `"30d"`। |
| `--server-id` | string | सर्वर विवरण पेज के लिए रिपोर्ट को एक सर्वर तक सीमित करें। |
