## techstack api unifier analyze

आवश्यकताएँ जानने के लिए स्पेक का विश्लेषण करें (चरण 1)।

सुरक्षित, आइडेम्पोटेंट। हार्डवेयर आवश्यकताएँ, पहचाने गए ऐड-ऑन और आवश्यक क्रेडेंशियल लौटाता है।

```bash
techstack api unifier analyze [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/unifier/analyze` |
| स्टेट बदलता है | हाँ |
| MCP टूल | `analyze_spec` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `--body` | json | **आवश्यक।** JSON रिक्वेस्ट बॉडी (`application/json`) लिटरल के रूप में, `@path` के रूप में, या stdin के लिए `-`। |

## techstack api unifier pipeline preview

साइड इफ़ेक्ट के बिना पाइपलाइन परिणामों का प्रीव्यू देखें।

सुरक्षित, आइडेम्पोटेंट। दिखाता है कि क्या जनरेट होगा। बैकएंड सत्यापन या StackKit रिज़ॉल्यूशन विफलताएँ data.valid=false और संरचित data.errors के साथ 200 लौटाती हैं; गलत स्वरूप वाला इनपुट और ऑथ विफलताएँ HTTP त्रुटियाँ ही रहती हैं।

```bash
techstack api unifier pipeline preview [flags]
```

| स्टेट बदलता है | हाँ |
