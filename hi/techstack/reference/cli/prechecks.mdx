## techstack api prechecks get-by-request

रिक्वेस्ट ID से प्री-चेक परिणाम प्राप्त करें।

```bash
techstack api prechecks get-by-request <id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/prechecks/request/{id}` |
| स्टेट बदलता है | नहीं |
| MCP टूल | कोई नहीं |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `<id>` | string | **आवश्यक।** संसाधन ID। |
