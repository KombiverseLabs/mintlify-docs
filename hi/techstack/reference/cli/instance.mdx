<Note>Techstack v0.32.8 रिलीज़ (सोर्स `4c7d219a5d56`) से जनरेट किया गया। इंस्टॉल किए गए वर्ज़न के लिए `techstack api <command> --help` ही प्रामाणिक है।</Note>

## techstack api instance enrollment

लोकल एनरोलमेंट रिकॉर्ड प्राप्त करें।

```bash
techstack api instance enrollment [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/enrollment` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `get_enrollment_record` |

## techstack api instance get

स्थिर लोकल इंस्टेंस पहचान प्राप्त करें।

```bash
techstack api instance get [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/instance` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `get_instance_identity` |
