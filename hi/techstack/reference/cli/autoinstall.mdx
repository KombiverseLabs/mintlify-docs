<Note>Techstack v0.32.8 रिलीज़ (सोर्स `4c7d219a5d56`) से जनरेट किया गया। इंस्टॉल किए गए वर्ज़न के लिए `techstack api <command> --help` ही प्रामाणिक है।</Note>

## techstack api autoinstall run

अनुपलब्ध डिपेंडेंसी इंस्टॉल करें।

```bash
techstack api autoinstall run [flags]
```

| | |
| --- | --- |
| HTTP | `POST /api/v1/autoinstall/install` |
| स्टेट बदलता है | हाँ |
| MCP टूल | कोई नहीं |

## techstack api autoinstall status

अनुपलब्ध डिपेंडेंसी जाँचें।

```bash
techstack api autoinstall status [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/autoinstall/status` |
| स्टेट बदलता है | नहीं |
| MCP टूल | कोई नहीं |
