<Note>Techstack v0.32.8 रिलीज़ (सोर्स `4c7d219a5d56`) से जनरेट किया गया। इंस्टॉल किए गए वर्ज़न के लिए `techstack api <command> --help` ही प्रामाणिक है।</Note>

## techstack api drift results delete

ड्रिफ़्ट परिणाम हटाएँ।

```bash
techstack api drift results delete <id> [flags]
```

<Warning>पुष्टि आवश्यक है: यह ऑपरेशन सहेजा गया ड्रिफ़्ट परिणाम स्थायी रूप से हटा देता है। `--yes` दें या प्रॉम्प्ट का उत्तर दें; `--yes` के बिना गैर-इंटरैक्टिव रन किसी भी रिक्वेस्ट से पहले एग्ज़िट कोड 9 के साथ रुक जाता है।</Warning>

| | |
| --- | --- |
| HTTP | `DELETE /api/v1/drift/results/{id}` |
| स्टेट बदलता है | हाँ |
| MCP टूल | `delete_drift_result` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `<id>` | string | **आवश्यक।** संसाधन ID। |

## techstack api drift results get

एक ड्रिफ़्ट परिणाम प्राप्त करें।

```bash
techstack api drift results get <id> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/drift/results/{id}` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `get_drift_result` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `<id>` | string | **आवश्यक।** संसाधन ID। |

## techstack api drift results list

सभी ड्रिफ़्ट परिणाम सूचीबद्ध करें (पेजिनेटेड)।

```bash
techstack api drift results list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/drift/results` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `list_drift_results` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `--page` | integer | पेज नंबर (डिफ़ॉल्ट 1)। |
| `--per-page` | integer | प्रति पेज आइटम (डिफ़ॉल्ट 20, अधिकतम 100)। |
