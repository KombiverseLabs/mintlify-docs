## techstack api stackkits get

किसी विशिष्ट StackKit का विवरण प्राप्त करें।

```bash
techstack api stackkits get <name> [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/stackkits/{name}` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `get_stack_kit` |

| आर्ग्युमेंट | प्रकार | विवरण |
| --- | --- | --- |
| `<name>` | string | **आवश्यक।** |

## techstack api stackkits list

उपलब्ध StackKits सूचीबद्ध करें।

```bash
techstack api stackkits list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/stackkits` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `list_stack_kits` |
