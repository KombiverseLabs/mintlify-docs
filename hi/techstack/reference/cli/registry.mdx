## techstack api registry services list

अपनी सेवाओं को उनके कैटलॉग और कैनोनिकल प्लेसमेंट के साथ सूचीबद्ध करें।

रनटाइम रिकॉर्ड सेवा विवरण के समान स्टेट, क्षमताएँ, वर्ज़न और Owner लॉक प्रक्षेपण उपयोग करते हैं। ऐतिहासिक रिकॉर्ड अज्ञात अवलोकित स्टेट के साथ पढ़े जा सकते हैं और उनमें बिना मापी गई कार्रवाई क्षमताएँ नहीं होतीं।

```bash
techstack api registry services list [flags]
```

| | |
| --- | --- |
| HTTP | `GET /api/v1/registry/services` |
| स्टेट बदलता है | नहीं |
| MCP टूल | `list_registry_services` |
