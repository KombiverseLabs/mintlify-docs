Techstack, StackKits के वैकल्पिक ऑपरेटर अनुभव के रूप में सक्रिय विकास में है। इसका पहला
ओपन-सोर्स Windows Alpha लोकल-सर्वर फ़ीडबैक के लिए सार्वजनिक है; कनेक्टेड और मैनेज्ड क्षमताएँ
प्रीव्यू दायरे में हैं।

| सतह | मौजूदा स्थिति |
| --- | --- |
| प्रोडक्ट अवलोकन और ऑपरेटिंग मॉडल | सार्वजनिक दस्तावेज़ |
| `techstack.kombify.io` पर होस्टेड एंट्री | प्रीव्यू; एक्सेस सीमित हो सकता है |
| Windows इंस्टॉलर और डेस्कटॉप पैकेज | सार्वजनिक अहस्ताक्षरित Alpha |
| गुमनाम सार्वजनिक सोर्स वितरण | `kombifyio/TechStack` पर सार्वजनिक |
| कनेक्टेड और मैनेज्ड संचालन | प्रीव्यू; सामान्य उपलब्धता का दावा नहीं |
| kombify.me सार्वजनिक HTTPS नाम और निजी HTTP रिले | सार्वजनिक Alpha दस्तावेज़ |
| स्टैंडअलोन StackKits लाइफ़साइकल | StackKits के ज़रिए सार्वजनिक रूप से उपलब्ध |

<Warning>
Windows पैकेज अहस्ताक्षरित Alpha है, स्थिर या प्रोडक्शन-तैयार रिलीज़ नहीं। केवल आधिकारिक
रिपॉज़िटरी का उपयोग करें और खोलने से पहले प्रकाशित चेकसम सत्यापित करें।
</Warning>

## आप अभी क्या कर सकते हैं

- [सार्वजनिक क्विकस्टार्ट](/hi/stackkits/quickstart) के ज़रिए StackKits इंस्टॉल करें और चलाएँ
- [Techstack Windows Alpha डाउनलोड करें](/hi/techstack/install-windows) और उसका बिना-अकाउंट
  वाला लोकल मोड इस्तेमाल करें
- [Techstack ऑपरेटिंग मोड](/hi/techstack/operating-modes) देखें
- अगर आपके अकाउंट के पास एक्सेस है, तो [होस्टेड प्रीव्यू](https://techstack.kombify.io) खोलें
- प्रीव्यू एक्सेस के बारे में [kombify सपोर्ट](mailto:info@kombify.io) से संपर्क करें

[ओपन-सोर्स रिपॉज़िटरी](https://github.com/kombifyio/TechStack) सोर्स, इंस्टॉलर एसेट, चेकसम
और Alpha अपडेट के लिए रिलीज़ की प्रामाणिक स्रोत है।
