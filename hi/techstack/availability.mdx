Techstack, StackKits के वैकल्पिक ऑपरेटर अनुभव के रूप में सक्रिय विकास में है। इसका पहला
ओपन-सोर्स Windows Alpha लोकल-सर्वर फ़ीडबैक के लिए सार्वजनिक है; कनेक्टेड और मैनेज्ड क्षमताएँ
प्रीव्यू दायरे में ही हैं।

## सरल शब्दों में

Techstack के कुछ हिस्से आज सार्वजनिक हैं और कुछ अभी प्रीव्यू हैं। यह पेज बताता है कि कौन-सा
कौन-सा है, ताकि आप अभी काम करने वाला रास्ता चुन सकें।

| सरफ़ेस | वर्तमान स्थिति |
| --- | --- |
| उत्पाद अवलोकन और ऑपरेटिंग मॉडल | सार्वजनिक दस्तावेज़ |
| `techstack.kombify.io` पर होस्टेड एंट्री | प्रीव्यू; एक्सेस सीमित हो सकता है |
| Windows इंस्टॉलर और डेस्कटॉप पैकेज | सार्वजनिक अनसाइन्ड Alpha |
| बिना अकाउंट सार्वजनिक सोर्स वितरण | `kombifyio/TechStack` पर सार्वजनिक |
| कनेक्टेड और मैनेज्ड संचालन | प्रीव्यू; सामान्य उपलब्धता का दावा नहीं |
| kombify.me सार्वजनिक HTTPS नाम और निजी HTTP रिले | सार्वजनिक Alpha दस्तावेज़ |
| स्टैंडअलोन StackKits लाइफ़साइकल | StackKits के माध्यम से सार्वजनिक रूप से उपलब्ध |

<Warning>
Windows पैकेज अनसाइन्ड Alpha है, स्थिर या प्रोडक्शन-तैयार रिलीज़ नहीं। केवल आधिकारिक
रिपॉज़िटरी का उपयोग करें और खोलने से पहले प्रकाशित चेकसम सत्यापित करें।
</Warning>

## पहले क्या चाहिए

Windows Alpha आज़माने के लिए आपको एक Windows कंप्यूटर और अपने होम नेटवर्क में एक सर्वर चाहिए।
लोकल रास्ते के लिए kombify अकाउंट ज़रूरी नहीं है। होस्टेड प्रीव्यू एक्सेस इस पर निर्भर करता है
कि आपके kombify अकाउंट में क्या सक्षम है।

## क्या उम्मीद करें

Windows इंस्टॉलर अनसाइन्ड है, इसलिए Windows SmartScreen चेतावनी दिखा सकता है। आगे बढ़ने से
पहले इंस्टॉलर की तुलना प्रकाशित चेकसम से करें। मैनेज्ड सर्वर तभी दिखते हैं जब आपके अकाउंट में
वे सक्षम हों; अन्यथा यह विकल्प अनुपलब्ध रहता है।

## आप अभी क्या कर सकते हैं

- [सार्वजनिक क्विकस्टार्ट](/hi/stackkits/quickstart) से StackKits इंस्टॉल करें और चलाएँ
- [Techstack Windows Alpha डाउनलोड करें](/hi/techstack/install-windows) और उसका बिना अकाउंट
  वाला लोकल मोड इस्तेमाल करें
- [Techstack ऑपरेटिंग मोड](/hi/techstack/operating-modes) देखें
- अगर आपके अकाउंट के पास एक्सेस है, तो [होस्टेड प्रीव्यू](https://techstack.kombify.io) खोलें
- प्रीव्यू एक्सेस के बारे में [kombify सपोर्ट](mailto:info@kombify.io) से संपर्क करें

## कुछ गड़बड़ हो जाए तो

- अगर होस्टेड एंट्री आपको अंदर नहीं आने देती, तो हो सकता है आपके अकाउंट के पास अभी प्रीव्यू एक्सेस
  न हो। [kombify सपोर्ट](mailto:info@kombify.io) को लिखें।
- अगर आपको ऐसा सर्वर चाहिए जो आज काम करे, तो इसके बजाय
  [StackKits क्विकस्टार्ट](/hi/stackkits/quickstart) इस्तेमाल करें।
- आपका अकाउंट कौन-से विकल्प खोलता है, यह जानने के लिए [मैनेज्ड सर्वर](/hi/techstack/managed-servers) पढ़ें।

सोर्स, इंस्टॉलर एसेट, चेकसम और Alpha अपडेट के लिए
[ओपन-सोर्स रिपॉज़िटरी](https://github.com/kombifyio/TechStack) ही रिलीज़ अथॉरिटी है।
