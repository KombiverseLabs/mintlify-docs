SpeechKit डेस्कटॉप क्लाइंट x64 सिस्टम पर Windows 10 और Windows 11 को सपोर्ट करता है। Windows पूरा लक्ष्य है: तीनों मोड,
Hands-Free और Meeting। एसेट केवल आधिकारिक `kombifyio/SpeechKit` रिलीज़ से डाउनलोड करें।

{/* speechkit-release:begin */}
मौजूदा सार्वजनिक रिलीज़ [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1) है, जो 2026-09-20 को प्रकाशित हुआ।
{/* speechkit-release:end */}

## डाउनलोड सत्यापित करें

1. मेल खाती
   [SHA256SUMS.txt](https://github.com/kombifyio/SpeechKit/releases/latest/download/SHA256SUMS.txt)
   डाउनलोड करें।
2. किसी भरोसेमंद टूल से इंस्टॉलर या ZIP का SHA-256 हैश निकालें।
3. पैकेज खोलने से पहले पूरे हैश को `SHA256SUMS.txt` की प्रविष्टि से मिलाएँ।
4. [अहस्ताक्षरित-रिलीज़ सूचना](https://github.com/kombifyio/SpeechKit/releases/latest/download/UNSIGNED-WINDOWS-RELEASE.txt)
   पढ़ें।

<Warning>
बिना-लागत वाला Windows रिलीज़ अहस्ताक्षरित है। Windows प्रतिष्ठा चेतावनी दिखा सकता है। आगे बढ़ने का फ़ैसला करने से पहले
चेकसम और रिलीज़ का स्रोत सत्यापित करें।
</Warning>

## पहला उपयोग

1. SpeechKit शुरू करें और वह माइक्रोफ़ोन चुनें जिसे वह इस्तेमाल करे।
2. Network Scope चुनें। सभी नेटवर्क बाहरी प्रोवाइडर की अनुमति देता है; केवल लोकल नेटवर्क और केवल यह डिवाइस सीमित करते हैं कि
   बैकएंड किससे संपर्क कर सकता है।
3. मोड के लिए उपयुक्त लोकल या बाहरी प्रोवाइडर चुनें।
4. Assist, Voice Agent या Meeting चालू करने से पहले Dictation टेस्ट करें।
5. बाहरी प्रोवाइडर चुनते समय जाँच लें कि डिवाइस से क्या बाहर जाता है।

डिफ़ॉल्ट हॉटकी हैं: Dictation के लिए `Ctrl+Win`, Assist के लिए `Win+Alt` और Voice Agent के लिए `Ctrl+Shift`। मीटिंग के भीतर
`Ctrl+Alt+S` स्क्रीन स्नैपशॉट कैप्चर करता है।
