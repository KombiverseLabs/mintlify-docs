SpeechKit, kombify का लोकल-फ़र्स्ट वॉइस फ़्रेमवर्क और रनटाइम है। एक सार्वजनिक प्रोजेक्ट में Go वॉइस
कर्नेल, सेल्फ़-होस्टेड सर्वर, एजेंट टूल, Android मॉड्यूल और Windows व macOS के लिए डेस्कटॉप क्लाइंट मिलते हैं।

{/* speechkit-release:begin */}
मौजूदा सार्वजनिक रिलीज़ [v0.72.1](https://github.com/kombifyio/SpeechKit/releases/tag/v0.72.1) है, जो 2026-09-20 को प्रकाशित हुआ।
{/* speechkit-release:end */}

SpeechKit बीटा सॉफ़्टवेयर है: सार्वजनिक API, कॉन्फ़िगरेशन कुंजियाँ और डिफ़ॉल्ट माइनर रिलीज़ के बीच बदल सकते हैं,
इसलिए जिस वर्शन को आपने टेस्ट किया है उसे पिन करें।

## तीन मोड और एक रिकॉर्डिंग सेवा

| सतह | उद्देश्य |
| --- | --- |
| Dictation | बिना LLM से दोबारा लिखे बोली हुई बात को टेक्स्ट में बदलें। |
| Assist | बोली हुई या लिखी बात को एक सीमित नतीजे में बदलें, चाहें तो उसे बोलकर सुनाएँ। |
| Voice Agent | इंटरैक्टिव काम के लिए रियलटाइम ऑडियो बातचीत चलाएँ। |
| Meeting | कॉल को दो चैनलों पर रिकॉर्ड करें और बाद में उसका लेख-जोखा तैयार करें। |

Hands-Free तीनों मोड के ऊपर एक सक्रियण और आउटपुट परत है, चौथा मोड नहीं। Meeting एक अलग रिकॉर्डिंग सेवा है, जो
Dictation के साथ केवल स्पीच-टू-टेक्स्ट ट्रांसक्राइबर साझा करती है।

## SpeechKit कहाँ चलता है

| लक्ष्य | उपलब्धता |
| --- | --- |
| Windows 10/11 x64 डेस्कटॉप क्लाइंट | सार्वजनिक बीटा; तीनों मोड, Hands-Free और Meeting |
| Apple Silicon पर macOS 14+ | केवल-Dictation बीटा, ad-hoc हस्ताक्षरित, ज्ञात कमियों के साथ |
| Go फ़्रेमवर्क | सार्वजनिक मॉड्यूल; कर्नेल को अपने Go होस्ट में एम्बेड करें |
| सेल्फ़-होस्टेड सर्वर | सार्वजनिक सोर्स से बना Linux लक्ष्य |
| Android | Apache-2.0 Gradle मॉड्यूल और रिपॉज़िटरी में एक रेफ़रेंस ऐप |
| ब्राउज़र | सार्वजनिक रिपॉज़िटरी में TypeScript क्लाइंट और वॉइस UI पैकेज |
| Linux डेस्कटॉप | उपलब्ध नहीं; Linux एक सर्वर रनटाइम है |

## आपके तय किए गोपनीयता दायरे

दो स्वतंत्र सेटिंग तय करती हैं कि SpeechKit क्या कर सकता है:

- **Network Scope** बताता है कि प्रक्रिया कहाँ तक पहुँच सकती है: सभी नेटवर्क, केवल लोकल नेटवर्क, या केवल यह डिवाइस।
  बैकएंड स्पीच प्रोवाइडर, मॉडल डाउनलोड, अपडेट, टेलीमेट्री, सर्वर कनेक्शन और इंटीग्रेशन के लिए इस सीमा को लागू करता है।
  ज़्यादा सख़्त दायरा असंगत सेटिंग को मिटाता नहीं, स्थगित कर देता है।
- **Retention Scope** बताता है कि काम पूरा होने के बाद क्या बचा रहता है: रखना, या शून्य प्रतिधारण। शून्य प्रतिधारण सेशन
  खत्म होने पर कच्ची सामग्री साफ़ कर देता है और केवल बना हुआ नतीजा रखता है।

दोनों एक-दूसरे से स्वतंत्र हैं। केवल-डिवाइस इंस्टॉल भी ट्रांसक्रिप्ट डिस्क पर लिखता है, जब तक आप शून्य प्रतिधारण भी न चुनें।
