Voice Agent एक लाइव बोली गई बातचीत है। आप फ़ॉलो-अप सवाल पूछ सकते हैं और बीच में टोक सकते हैं।
यह आपके ऐप्स में टाइप नहीं करता। उसके लिए Dictation या Assist इस्तेमाल करें। Voice Agent एक
Windows सुविधा है। macOS पर यह मौजूदा बीटा में सत्यापित नहीं है।

## शुरू करने से पहले

- SpeechKit इंस्टॉल है और Dictation काम करता है।
- नई इंस्टॉलेशन में Voice Agent बंद होता है। आप इसे नीचे चालू करते हैं।
- Voice Agent को लाइव बातचीत के लिए एक प्रोवाइडर चाहिए, लोकल या क्लाउड। इसे
  [गोपनीयता सेटिंग](/hi/speechkit/privacy-settings) को ध्यान में रखकर चुनें। क्लाउड प्रोवाइडर आपकी
  आवाज़ प्राप्त करता है।

## चरण

<Steps>
  <Step title="Voice Agent चालू करें">
    **Settings > Overview** में **Modes** सूची में Voice Agent चालू करें। आप **Voice Agent
    Mode** खोलकर वहाँ उसकी हॉटकी भी सक्षम कर सकते हैं।
  </Step>
  <Step title="जाँचें कि किस पर ध्यान देना है">
    **Overview** **Needs attention** के अंतर्गत गायब प्रोवाइडर कुंजियाँ सूचीबद्ध करता है। कुंजी
    जोड़ें या कोई दूसरा प्रोवाइडर चुनें।
  </Step>
  <Step title="बातचीत शुरू करें">
    डिफ़ॉल्ट हॉटकी `Ctrl+Shift` है। इसे दबाए रखें, बोलें और छोड़ दें। आप Voice Agent विंडो में
    **Start voice agent** और **Stop voice agent** बटन से भी एजेंट को शुरू और बंद कर सकते हैं।
  </Step>
  <Step title="फ़ॉलो-अप पूछें">
    विंडो बातचीत दिखाती है। एजेंट के जवाब देने के बाद फ़ॉलो-अप सवाल पूछें। उदाहरण के लिए:
    "help me decide the next release slice"। फिर फ़ॉलो-अप के साथ बीच में टोकें।
  </Step>
  <Step title="सत्र समाप्त करें">
    सारांश पाने के लिए सत्र समाप्त करें। हॉटकी छोड़ने के बाद डायलॉग थोड़ी देर के लिए फिर शुरू करने
    योग्य रहता है (**Resume window**)। सारांश और पैनल का बंद होना तब होता है जब वह विंडो समाप्त हो
    जाती है।
  </Step>
</Steps>

## जो सेटिंग आप बदल सकते हैं

**Settings > Voice Agent Mode** खोलें।

| सेटिंग | यह क्या करती है |
| --- | --- |
| Voice Agent hotkey | वह संयोजन जो बातचीत शुरू करता है। |
| Agent profile | एजेंट प्रोफ़ाइल चुनता है। |
| Personal refinement prompt | आपकी अपनी प्राथमिकताएँ जोड़ता है, उदाहरण के लिए छोटे जवाब। |
| Resume window (seconds) | डायलॉग कितनी देर फिर शुरू करने योग्य रहता है। 0 सत्र को तुरंत समाप्त कर देता है। |
| Pause tolerance (ms) | इस लंबाई तक के छोटे विराम जवाब को ट्रिगर नहीं करते। 0 प्रोवाइडर का डिफ़ॉल्ट इस्तेमाल करता है। |
| Session summary | सत्र का सारांश रखता है। |
| Closing the window | **Minimise and keep chat** या **End chat on close** चुनें। |

पिछली बातचीतें **Library** में वॉइस टैब के अंतर्गत दिखती हैं।

## अपनी आवाज़ से शुरू करें

**Hands-Free** हॉटकी के बजाय वेक वाक्यांश से कोई मोड शुरू कर सकता है। इसे **Settings >
Hands-Free** में **Enable hands-free activation** के साथ चालू करें, फिर वाक्यांश और लक्ष्य चुनें
(**Voice Agent conversation**, **Assist voice companion** या **Dictation (UI-assisted)**)।
वेक पहचान के लिए माइक्रोफ़ोन ऑडियो डिवाइस पर ही रहता है। Hands-Free macOS पर उपलब्ध नहीं है।

## अगर कुछ गलत हो

- **एजेंट शुरू नहीं होता।** जाँचें कि Voice Agent चालू है और उसके प्रोवाइडर के पास कुंजी है।
  **Overview** में **Needs attention** देखें।
- **यह बहुत जल्दी जवाब दे देता है।** **Pause tolerance (ms)** बढ़ाएँ।
- **आप इसे सुन नहीं पा रहे।** दूसरा स्पीकर चुनने के लिए Voice Agent विंडो में स्पीकर आउटपुट
  नियंत्रण इस्तेमाल करें।
- **अब भी अटके हैं।** देखें [आम समस्याएँ ठीक करें](/hi/speechkit/fix-common-problems)।
