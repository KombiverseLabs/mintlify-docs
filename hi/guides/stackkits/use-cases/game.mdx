<Info>
  प्रमाण स्थिति (2026-09-24, v0.41.0): Pterodactyl के साथ Game `available,
  not yet lifecycle-verified` है। यह v0.41.0 में Basement Kit, Cloud Kit और Modern Homelab के लिए वैकल्पिक वर्कलोड के रूप में शिप हुआ, जिसमें चुनिंदा Minecraft Java
  और Bedrock प्रोफ़ाइल हैं। किसी स्वचालित Depot लाइफ़साइकल रन ने अभी install,
  verify, backup या restore को कवर नहीं किया है, वर्ल्ड बैकअप फ़िलहाल
  क्रैश-कंसिस्टेंट हैं, और आइसोलेटेड रीस्टोर को शुरू से अंत तक आज़माया नहीं गया है।
</Info>

Game आपके घर को आपके चलाए होस्ट पर दोस्तों और परिवार के लिए सेल्फ-होस्टेड Minecraft सर्वर देता है। Pterodactyl पैनल और गेम कंटेनर चलाता है। रिलीज़ कैटलॉग इस उपयोग केस को Game Server कहता है और इसे वैकल्पिक `game` वर्कलोड के रूप में डिलीवर करता है।

## अपना संस्करण चुनें

| संस्करण | ट्रांसपोर्ट | डिफ़ॉल्ट पोर्ट |
| --- | --- | --- |
| Minecraft Java | TCP | 25565 |
| Minecraft Bedrock | UDP (RakNet) | 19132 |

दोनों चुनिंदा प्रोफ़ाइल ऑनलाइन-मोड सत्यापन, अनुमति सूची (allow list), बिना RCON और बिना स्वचालित ऑपरेटर अधिकारों के शुरू होती हैं।

## इसे सेटअप करें

1. अपने [StackSpec](/hi/guides/stackkits/configure-stack-spec) में `game` वर्कलोड चुनें, जनरेट करें, और सत्यापित [Basement Kit](/hi/stackkits/kits/basement-kit) या [Cloud Kit](/hi/stackkits/kits/cloud-kit) पर लागू करें।
2. एक निजी, वर्कस्पेस-सापेक्ष सेटअप फ़ाइल बनाएँ, उदाहरण के लिए `.stackkit/setup/game.json`:

```json
{
  "profile": "minecraft-java",
  "name": "Family Survival",
  "acceptEula": true,
  "allowList": ["PlayerOne"]
}
```

3. `acceptEula` को `true` करने से पहले [Minecraft End User License Agreement](https://www.minecraft.net/en-us/eula) खुद पढ़ें और स्वीकार करें। इसे कभी किसी और की ओर से स्वीकार न करें।
4. सेटअप कमांड चलाएँ:

```bash
stackkit setup game --owner-approve --credentials-file .stackkit/setup/game.json --json
```

यह कमांड आपके चुने प्रोफ़ाइल पर एक सर्वर बनाता है, ऊपर के सुरक्षित डिफ़ॉल्ट ग्रेसफ़ुल स्टॉप के साथ लागू करता है, और अनुमति सूची वापस पढ़ता है ताकि आप पुष्टि कर सकें कि वह प्रभावी हुई। सूची में न रखा गया खाता जुड़ने में विफल रहता है।

## स्थानीय या मैनेज्ड होस्टिंग चुनें

- वर्कलोड को स्थानीय [Basement Kit](/hi/stackkits/kits/basement-kit) नोड पर चलाएँ ताकि वह आपके LAN पर पहुँच योग्य हो।
- इसे [Cloud Kit](/hi/stackkits/kits/cloud-kit) VPS पर चलाएँ ताकि आपका घरेलू कंप्यूटर बंद होने पर भी दोस्त जुड़ सकें।

घरेलू नोड इंटरनेट से तब तक पहुँच योग्य नहीं होता जब तक आप जानबूझकर मैनेज्ड VPS या स्पष्ट ब्रिज न चुनें। इसे टालने के लिए राउटर पोर्ट फ़ॉरवर्डिंग पर निर्भर न रहें।

## खिलाड़ियों को आमंत्रित करें

नोड का पता और प्रोफ़ाइल का पोर्ट अपनी अनुमति सूची के खिलाड़ियों के साथ साझा करें। अनुमति सूची, सर्वर पावर और संसाधन अपने जनरेट किए गए Game रूट पर Pterodactyl पैनल से प्रबंधित करें।

## वर्ल्ड का बैकअप लें

Game बैकअप आपके Kit के घोषित शेड्यूल का पालन करते हैं, पर आज दो सीमाएँ लागू हैं:

- बैकअप क्रैश-कंसिस्टेंट हैं: स्नैपशॉट चलने से पहले सर्वर को अभी शांत (quiesce) नहीं किया जाता।
- Game बैकअप का आइसोलेटेड रीस्टोर शुरू से अंत तक आज़माया नहीं गया है।

ऐसे वर्ल्ड के लिए जिसे आप दोबारा नहीं बना सकते, भरोसा करने से पहले आइसोलेटेड वातावरण में रीस्टोर का अभ्यास करें। देखें [बैकअप और रीस्टोर](/hi/guides/stackkits/back-up-and-restore)।
