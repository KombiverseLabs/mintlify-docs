StackKits एप्लिकेशन चयन को निष्पादन की जिम्मेदारी से अलग रखता है। Standalone Compose मूल डिफ़ॉल्ट है। Komodo बिना ऐप स्टोर वाला संचालन प्लेटफ़ॉर्म है। Marketplace को Coolify पर वैकल्पिक उपयोग केस के रूप में नियोजित किया गया है; Coolify उस उपयोग केस का एप्लिकेशन है, मूल रनटाइम लक्ष्य नहीं।

अपनी इंस्टॉल की गई रिलीज़ में एम्बेड की गई मैट्रिक्स देखें:

```bash
stackkit app compatibility --json
```

## एडैप्टर चुनें

| एडैप्टर | वर्तमान स्थिति | इसे कब उपयोग करें |
| --- | --- | --- |
| `standalone-compose` | मूल डिफ़ॉल्ट | इंस्टॉल की गई रिलीज़ का घोषित वर्कलोड पथ उपयोग करें और उसका लाइफ़साइकल प्रमाण जाँचें। |
| [Coolify](/hi/stackkits/apps/coolify) | नियोजित Marketplace एप्लिकेशन | Marketplace के रूप में तभी इंस्टॉल करें जब प्रकाशित कैटलॉग में उपयोग केस हो और लाइफ़साइकल सत्यापित हो। |
| [Komodo](/hi/stackkits/apps/komodo) | संचालन प्लेटफ़ॉर्म का प्रारूप | केवल वर्तमान पिन के प्रमाण से सिद्ध वर्कलोड दायरे में स्पष्ट रूप से चुनें। |

प्रकाशित [एप्लिकेशन डिलीवरी संगतता](/hi/stackkits/reference/application-delivery-compatibility) मैट्रिक्स घोषित एडैप्टर अनुबंध बताती है। ऐतिहासिक पंक्तियाँ वर्तमान पिन पर समर्थन सिद्ध नहीं करतीं। अपने एप्लिकेशन और रिलीज़ का लाइफ़साइकल प्रमाण जाँचें; केवल डिप्लॉयमेंट क्षमता बैकअप या रीस्टोर सिद्ध नहीं करती।

स्टैंडअलोन Basement Kit के लिए, जब तक आप जानबूझकर किसी एप्लिकेशन प्लेटफ़ॉर्म को नहीं चलाते, `standalone-compose` से शुरू करें:

```json
{
  "workloads": {
    "files": {
      "alternative": "cloudreve",
      "runtimeAdapterRef": "standalone-compose",
      "placement": {
        "siteRefs": ["home"],
        "nodeRefs": ["main"]
      }
    }
  }
}
```

## हर वर्कलोड का एक ही ओनर रखें

- एक ही वर्कलोड को एक साथ Coolify और स्टैंडअलोन Compose से रूट न करें।
- Docker लेबल या जनरेट किए गए रूट हाथ से न जोड़ें।
- स्पष्ट Komodo पथ के लिए वर्तमान पिन का प्रमाण आवश्यक है; यह डिफ़ॉल्ट या ऐप स्टोर नहीं है।
- दूसरा एडैप्टर लागू करने से पहले बदले हुए इरादे को सत्यापित करें और हल किए गए प्लान की जाँच करें।

प्लेटफ़ॉर्म इंटीग्रेशन के लिए [प्लेटफ़ॉर्म सेवाएँ](/hi/stackkits/apps/overview) और पूरे संपादन वर्कफ़्लो के लिए [StackSpec कॉन्फ़िगर करें](/hi/guides/stackkits/configure-stack-spec) देखें।
