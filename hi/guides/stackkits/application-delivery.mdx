StackKits एप्लिकेशन के चुनाव और एप्लिकेशन डिलीवरी को अलग रखता है। Files जैसा वर्कलोड अपना एप्लिकेशन विकल्प चुनता है, जबकि `runtimeAdapterRef` तय करता है कि वही वर्कलोड कैसे डिलीवर होगा।

अपनी इंस्टॉल की गई रिलीज़ में एम्बेड की गई मैट्रिक्स देखें:

```bash
stackkit app compatibility --json
```

## एडैप्टर चुनें

| एडैप्टर | वर्तमान स्थिति | इसे कब उपयोग करें |
| --- | --- | --- |
| `standalone-compose` | समर्थित | आपको घोषित बैकअप और रीस्टोर क्षमता वाला स्थानीय वर्कलोड पथ चाहिए और अलग एप्लिकेशन प्लेटफ़ॉर्म नहीं चाहिए। |
| [Coolify](/hi/stackkits/apps/coolify) | समर्थित | आप पहले से जनरेट किया गया एप्लिकेशन प्लेटफ़ॉर्म चला रहे हैं और मानते हैं कि वर्कलोड बैकअप और रीस्टोर इस एडैप्टर के दायरे से बाहर है। |
| [Komodo](/hi/stackkits/apps/komodo) | बीटा | आप जानबूझकर बीटा एडैप्टर की परिपक्वता स्वीकार करते हैं और उसे अपने वर्कस्पेस में सत्यापित करते हैं। |

परिपक्वता कैटलॉग अनुबंध को दर्शाती है, आपके होस्ट पर देखी गई स्थिति को नहीं। जनरेट की गई [एप्लिकेशन डिलीवरी संगतता](/hi/stackkits/reference/application-delivery-compatibility) मैट्रिक्स प्रकाशित रिलीज़ में हर वर्कलोड और एडैप्टर के लिए डिप्लॉयमेंट, रूट, TLS, बैकअप और रीस्टोर क्षमताएँ सूचीबद्ध करती है। अपने चुने हुए एप्लिकेशन की पंक्ति देखें; किसी प्लेटफ़ॉर्म का केवल डिप्लॉयमेंट समर्थन उसकी रिकवरी क्षमता सिद्ध नहीं करता। जो कॉम्पोनेंट मैट्रिक्स में सूचीबद्ध नहीं है, उसके लिए सार्वजनिक समर्थन न मानें।

स्टैंडअलोन Basement Kit के लिए, जब तक आप जानबूझकर किसी एप्लिकेशन प्लेटफ़ॉर्म को नहीं चलाते, `standalone-compose` से शुरू करें:

```json
{
  "workloads": {
    "files": {
      "alternative": "cloudreve",
      "runtimeAdapterRef": "standalone-compose",
      "placement": {
        "siteRefs": ["home"],
        "nodeRefs": ["main"]
      }
    }
  }
}
```

## हर वर्कलोड का एक ही ओनर रखें

- एक ही वर्कलोड को एक साथ Coolify और स्टैंडअलोन Compose से रूट न करें।
- Docker लेबल या जनरेट किए गए रूट हाथ से न जोड़ें।
- Komodo को इस रिलीज़ में बीटा विकल्प मानें, डिफ़ॉल्ट विकल्प नहीं।
- दूसरा एडैप्टर लागू करने से पहले बदले हुए इरादे को सत्यापित करें और हल किए गए प्लान की जाँच करें।

प्लेटफ़ॉर्म इंटीग्रेशन के लिए [प्लेटफ़ॉर्म सेवाएँ](/hi/stackkits/apps/overview) और पूरे संपादन वर्कफ़्लो के लिए [StackSpec कॉन्फ़िगर करें](/hi/guides/stackkits/configure-stack-spec) देखें।
