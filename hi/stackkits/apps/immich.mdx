Immich [Photos](/hi/guides/stackkits/use-cases/photos) यूज़ केस उपलब्ध कराता है। यह वैकल्पिक नेटिव v2 `photos` वर्कलोड का जारी किया गया विकल्प है, और शुरुआती Basement और Cloud StackSpec इसे सक्षम नहीं करते। इसे चुनने से पहले Photos पेज पर स्टोरेज और रिकवरी की योजना बना लें।

## जारी किया गया कॉन्ट्रैक्ट

| Property | Value |
| --- | --- |
| Workload | `photos` |
| Alternative | `immich` |
| Data class | personal |
| Required secret reference | `database-password` |
| Supported standalone adapter | `standalone-compose` |

जारी किया गया CLI इस वर्कलोड कॉन्ट्रैक्ट को सत्यापित और जनरेट करता है, जिसमें स्थायी फ़ोटो और डेटाबेस आवंटन तथा जनरेट किया गया Photos रूट शामिल है। [यूज़-केस कैटलॉग](/hi/stackkits/reference/use-case-catalog) दिखाता है कि रिलीज़ कौन-से घटक घोषित करती है।

`database-password` स्लॉट एक अपारदर्शी `secret://` संदर्भ रखता है; उसका पासवर्ड स्थानीय ओनर कस्टडी में रहता है। [StackSpec](/hi/guides/stackkits/configure-stack-spec) में वर्कलोड, प्लेसमेंट और एडाप्टर चुनें, फिर सत्यापित करने, कस्टडी स्थापित करने, जनरेट करने, प्लान देखने, लागू करने और सत्यापित करने के लिए [वर्कलोड जोड़ें](/hi/stackkits/reference/day-2-operations#add-a-workload-to-an-existing-workspace) का पालन करें।

## पहला उपयोग

1. ऐसे रोलआउट के बाद StackKits सत्यापन पूरा करें जिसमें पहले से मान्य ओनर-बद्ध कस्टडी हो।
2. Node Hub या रोलआउट आउटपुट से जनरेट किया गया Immich पता खोलें।
3. स्टोरेज क्षमता और बैकअप की पुष्टि करने के बाद ही एप्लिकेशन ओनर अकाउंट बनाएँ और क्लाइंट जोड़ें।
4. हर फ़ोन को [अपने फ़ोन से फ़ोटो का बैकअप लें](/hi/guides/stackkits/use-cases/photos/phone-backup) के साथ जोड़ें।

किसी भी कॉन्फ़िगरेशन बदलाव के बाद StackKits वर्कस्पेस को फिर से सत्यापित करें।
