Vaultwarden [Passwords](/hi/guides/stackkits/use-cases/passwords) यूज़ केस उपलब्ध कराता है। यह वैकल्पिक नेटिव v2 `vault` वर्कलोड का जारी किया गया विकल्प है, और शुरुआती Basement और Cloud StackSpec इसे सक्षम नहीं करते।

| Property | Value |
| --- | --- |
| Workload | `vault` |
| Alternative | `vaultwarden` |
| Data class | secret |
| Required secret reference | `admin-token` |
| Supported standalone adapter | `standalone-compose` |

`admin-token` स्लॉट एक अपारदर्शी `secret://` संदर्भ रखता है; असली टोकन स्थानीय ओनर कस्टडी में रहता है। [StackSpec](/hi/guides/stackkits/configure-stack-spec) में वर्कलोड, प्लेसमेंट और एडाप्टर चुनें, फिर सत्यापित करने, कस्टडी स्थापित करने, जनरेट करने, प्लान देखने, लागू करने और सत्यापित करने के लिए [वर्कलोड जोड़ें](/hi/stackkits/reference/day-2-operations#add-a-workload-to-an-existing-workspace) का पालन करें।

## पहला उपयोग

1. असली सीक्रेट जोड़ने से पहले एप्लिकेशन ओनर अकाउंट बनाएँ और रजिस्ट्रेशन नीति चुनें।
2. आमंत्रण स्वीकार करने के बाद अकाउंट रजिस्ट्रेशन पूरा करें और अपने Bitwarden क्लाइंट से साइन इन करें।
3. अकाउंट के तैयार होने की पुष्टि के लिए एक वॉल्ट प्रविष्टि बनाएँ और सिंक करें। केवल आमंत्रण यह सेटअप पूरा नहीं करता।

पहले से स्वीकार किए गए वर्कलोड के लिए StackKits आशय StackSpec और लाइफ़साइकिल कमांड से बदलें; लक्ष्य पर जनरेट किया गया एप्लिकेशन कॉन्फ़िगरेशन संपादित न करें।
