यह पेज प्रकाशित [v0.50.3 रिलीज़](https://github.com/kombifyio/StackKits/releases/tag/v0.50.3) से जनरेट होता है। यह उस रिलीज़ द्वारा घोषित हर यूज़ केस को मुख्य यूज़ केस के अनुसार समूहित करके, उसके उद्देश्य, घटकों और डिफ़ॉल्ट ऐप के साथ सूचीबद्ध करता है। घोषित घटक किसी होस्ट पर इंस्टॉलेशन या सत्यापित रन का प्रमाण नहीं है; सत्यापित लाइफ़साइकिल ग्रेड [OS संगतता](/hi/stackkits/reference/os-compatibility) में हैं। [यूज़ केस](/hi/guides/stackkits/use-cases/overview) में सेटअप गाइड का अवलोकन है।

## Mail

### निजी Mail

बाहरी प्रदाता पर आपके पास पहले से मौजूद मेलबॉक्स के लिए Roundcube के ज़रिए निजी वेबमेल। कोई मेल सर्वर, DNS या MX रिकॉर्ड नहीं बनाया जाता।

गाइड: [गाइड खोलें](/hi/guides/stackkits/use-cases/mail)

| Component | Role | Kind | Default |
| --- | --- | --- | --- |
| kombify Paperwork (`paperwork`) | वैकल्पिक | कनेक्टर |  |
| Roundcube Webmail (`roundcube`) | प्राथमिक | एप्लिकेशन | ✓ |

### अपना Mail Server

Stalwart के ज़रिए एक समर्पित Cloud नोड पर आपका अपना मेल सर्वर: आपके डोमेन के मेलबॉक्स, SMTP, IMAP और submission के साथ। StackKits वे DNS रिकॉर्ड प्रिंट करता है जिन्हें आप प्रकाशित करते हैं; यह DNS कभी नहीं बदलता।

गाइड: [गाइड खोलें](/hi/guides/stackkits/use-cases/mail)

| Component | Role | Kind | Default |
| --- | --- | --- | --- |
| mailcow (`mailcow`) | वैकल्पिक | एप्लिकेशन |  |
| Stalwart Mail Server (`stalwart`) | प्राथमिक | एप्लिकेशन | ✓ |
