स्पष्ट Architecture v2 आउटपुट-ट्रांज़ैक्शन लाइफ़साइकिल एक्शन का निरीक्षण करें।

```bash
stackkit output-transaction [flags]
```

उप-कमांड: [`stackkit output-transaction gc-retired`](#stackkit-output-transaction-gc-retired)

## stackkit output-transaction gc-retired

एक सेवानिवृत्त आउटपुट ट्रांज़ैक्शन टॉम्बस्टोन का निरीक्षण करें या उसे स्पष्ट रूप से गार्बेज-कलेक्ट करें।

```bash
stackkit output-transaction gc-retired [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--action` | string | — | पिछले निरीक्षण द्वारा रिपोर्ट किया गया सटीक एक्शन |
| `--apply` | bool | — | दोहराए गए एक्शन को निष्पादित करें; निरीक्षण डिफ़ॉल्ट है |
| `--transaction-id` | string | — | **आवश्यक।** सटीक लोअरकेस ट्रांज़ैक्शन ID |
