StackKits ऑटोमेशन के लिए एजेंट-नेटिव सहायक।

एजेंट-नेटिव सहायक रोलआउट में बदलाव किए बिना इंस्टॉल प्लान, सेल्फ़-चेक, प्रॉम्प्ट और MCP कॉन्फ़िगरेशन जारी करते हैं।

```bash
stackkit agent [flags]
```

Subcommands: [`stackkit agent approval`](#stackkit-agent-approval), [`stackkit agent credential`](#stackkit-agent-credential), [`stackkit agent diagnose`](#stackkit-agent-diagnose), [`stackkit agent install-plan`](#stackkit-agent-install-plan), [`stackkit agent mcp-config`](#stackkit-agent-mcp-config), [`stackkit agent prompt`](#stackkit-agent-prompt), [`stackkit agent self-check`](#stackkit-agent-self-check)

## stackkit agent approval

Answer per-call write approval requests from attached agents.

A mutating MCP call from an agent with its own credential is denied until you approve that exact call. The denial names an approval request; approving it lets the agent repeat the identical call once, within 15 minutes.

```bash
stackkit agent approval [flags]
```

Subcommands: [`stackkit agent approval approve`](#stackkit-agent-approval-approve), [`stackkit agent approval deny`](#stackkit-agent-approval-deny), [`stackkit agent approval list`](#stackkit-agent-approval-list)

### stackkit agent approval approve

Allow the agent to run the requested call once.

```bash
stackkit agent approval approve <approval-id> [flags]
```

### stackkit agent approval deny

Refuse the requested call.

```bash
stackkit agent approval deny <approval-id> [flags]
```

### stackkit agent approval list

List open and recent approval requests.

```bash
stackkit agent approval list [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--json` | bool | — | Emit JSON |

## stackkit agent credential

Mint, list, rotate and revoke per-agent MCP credentials.

Each agent that attaches to the StackKits MCP endpoint of this server holds its own credential. The server stores only a digest, shows a token exactly once, and re-checks the credential on every request, so revoking one denies that agent on its next call without touching the others.

```bash
stackkit agent credential [flags]
```

Subcommands: [`stackkit agent credential list`](#stackkit-agent-credential-list), [`stackkit agent credential mint`](#stackkit-agent-credential-mint), [`stackkit agent credential revoke`](#stackkit-agent-credential-revoke), [`stackkit agent credential rotate`](#stackkit-agent-credential-rotate)

### stackkit agent credential list

List agent credentials (never their tokens).

```bash
stackkit agent credential list [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--json` | bool | — | Emit JSON |

### stackkit agent credential mint

Create a credential for one agent.

```bash
stackkit agent credential mint --name <agent> [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--json` | bool | — | Emit JSON |
| `--name` | string | — | **Required.** Agent name (for example claude-laptop) |
| `--token-file` | string | — | Write the token to this new private file instead of stdout |

### stackkit agent credential revoke

Deny an agent from its next request on.

```bash
stackkit agent credential revoke <agent-id> [flags]
```

### stackkit agent credential rotate

Replace an agent's token; the old token stops working at once.

```bash
stackkit agent credential rotate <agent-id> [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--json` | bool | — | Emit JSON |
| `--token-file` | string | — | Write the token to this new private file instead of stdout |

## stackkit agent diagnose

एक स्थिर त्रुटि ID और उसकी रिकवरी कार्रवाई समझाएँ।

CLI विफलताओं, MCP self-check योजना और docs/TROUBLESHOOTING.md में उपयोग होने वाला वही रिकवरी मार्गदर्शन पढ़ें। यह खोज होस्ट को न देखती है और न बदलती है।

```bash
stackkit agent diagnose <error-id> [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | साझा रिकवरी अनुबंध JSON में जारी करें; यह मार्गदर्शन है, देखी गई विफलता नहीं |

## stackkit agent install-plan

बिना इंटरैक्शन वाला StackKits इंस्टॉल प्लान प्रिंट करें।

```bash
stackkit agent install-plan [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--dir` | string | `my-homelab` | वर्कस्पेस डायरेक्टरी |
| `--json` | bool | — | JSON जारी करें |
| `--kit` | string | `basement-kit` | जिस StackKit के लिए प्लान बनाना है |
| `--target` | string | `local` | लक्ष्य प्रकार: local, ssh, vm या ci |

**उदाहरण**

```bash
# Print the install steps for a Basement Kit workspace named my-homelab
stackkit agent install-plan

# A Cloud Kit plan for an agent working over SSH, as JSON
stackkit agent install-plan --kit cloud-kit --target ssh --dir my-cloud --json
```

## stackkit agent mcp-config

एक StackKits MCP क्लाइंट कनेक्शन कॉन्फ़िग प्रिंट करें।

"stackkit" नाम का सीधे पेस्ट करने योग्य MCP क्लाइंट कॉन्फ़िगरेशन प्रिंट करें।

उपयोगकर्ताओं के लिए यह एक ही StackKits MCP कनेक्शन है। स्थानीय रूप से यह stackkit-mcp एडाप्टर शुरू करता है; इंस्टॉल के बाद, संरक्षित एंडपॉइंट स्पष्ट रूप से सक्षम करने पर यही कनेक्टर stackkit-server /mcp के रूप में भी पहुँचा जा सकता है।

With `--remote-url` the output also carries a remote HTTP entry named "stackkit-remote" for the deployed installation endpoint (own domain or kombify.me). It holds only the URL and the NAME of the environment variable that carries the dedicated MCP token; no key or session secret is ever written.

```bash
stackkit agent mcp-config [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--client` | string | `generic` | Client format: generic, codex, claude, or cursor |
| `--credential-env` | string | `STACKKIT_MCP_TOKEN` | Name of the environment variable that holds the dedicated MCP token for the remote entry |
| `--mode` | string | `docs,local,server,actions` | MCP मोड; actions रीड-ओनली लाइफ़साइकिल टूल जोड़ता है, और राइट टूल के लिए अब भी STACKKIT_MCP_ALLOW_WRITE=true चाहिए |
| `--remote-url` | string | — | Also emit a remote HTTP entry for the deployed installation MCP endpoint (https) |
| `--server-url` | string | `http://localhost:8082` | stackkit-server URL |

**उदाहरण**

```bash
# Print the connection as Claude mcpServers JSON
stackkit agent mcp-config --client claude

# Print the Codex config.toml block
stackkit agent mcp-config --client codex

# Add the deployed installation endpoint for Claude, Codex or Cursor
stackkit agent mcp-config --client cursor --remote-url https://home.example.com/mcp
```

## stackkit agent prompt

कॉपी के लिए तैयार StackKits एजेंट प्रॉम्प्ट प्रिंट करें।

```bash
stackkit agent prompt [scenario] [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | JSON जारी करें |
| `--list` | bool | — | उपलब्ध प्रॉम्प्ट परिदृश्य सूचीबद्ध करें |

**उदाहरण**

```bash
# List the available prompt scenarios
stackkit agent prompt --list

# Print the prompt for diagnosing a failed rollout
stackkit agent prompt diagnose-failed-rollout
```

## stackkit agent self-check

एजेंट के लिए ज़रूरी स्थानीय StackKits पूर्वापेक्षाएँ जाँचें।

```bash
stackkit agent self-check [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | JSON जारी करें |
| `--server-url` | string | `http://localhost:8082` | stackkit-server URL |

**उदाहरण**

```bash
# Check that stackkit, stackkit-server, and stackkit-mcp are on PATH
stackkit agent self-check

# The same checks as JSON
stackkit agent self-check --json
```
