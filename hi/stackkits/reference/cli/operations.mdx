कैनोनिकल स्टैंडअलोन लाइफ़साइकिल ऑपरेशन कॉन्ट्रैक्ट सूचीबद्ध करें।

```bash
stackkit operations [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | ऑपरेशन कॉन्ट्रैक्ट को JSON के रूप में जारी करें |

**उदाहरण**

```bash
# List each lifecycle operation, its access level, and what it does
stackkit operations

# The same contracts as JSON
stackkit operations --json
```
