StackKits एप्लिकेशन डिलीवरी का निरीक्षण करें और v0.6 हैंडऑफ़ प्रबंधित करें।

Coolify, Komodo और स्टैंडअलोन Compose के लिए शासित Architecture v2 एप्लिकेशन-डिलीवरी मैट्रिक्स का निरीक्षण करें।

वैकल्पिक ग्राहक PaaS हैंडऑफ़ मेटाडेटा केवल स्पष्ट v0.6 StackSpec संगतता लाइन पर उपलब्ध रहता है। Architecture v2 में मनमाना ग्राहक-वर्कलोड मैपिंग नहीं है; StackKit के स्वामित्व वाले एप्लिकेशन CUE कैटलॉग से आते हैं, जबकि ग्राहक-वर्कलोड की वांछित स्थिति Techstack के पास है।

```bash
stackkit app [flags]
```

उप-कमांड: [`stackkit app compatibility`](#stackkit-app-compatibility)

## stackkit app compatibility

शासित एप्लिकेशन/एडाप्टर सपोर्ट मैट्रिक्स दिखाएँ।

StackKits एप्लिकेशन के लिए अपरिवर्तनीय CUE-स्वामित्व वाली सपोर्ट पंक्तियाँ दिखाएँ। यह उत्पाद की क्षमता बताता है, चुने गए प्लान, लाइव एडाप्टर उपलब्धता या डिप्लॉयमेंट प्रमाण को नहीं।

```bash
stackkit app compatibility [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | संगतता मैट्रिक्स को JSON के रूप में प्रिंट करें |

**उदाहरण**

```bash
# Show which applications each runtime adapter supports
stackkit app compatibility

# The same matrix as JSON
stackkit app compatibility --json
```
