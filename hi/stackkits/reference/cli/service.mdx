सक्रिय StackKits प्लान में घोषित सेवाएँ नियंत्रित करें।

```bash
stackkit service [flags]
```

उप-कमांड: [`stackkit service logs`](#stackkit-service-logs), [`stackkit service manager`](#stackkit-service-manager), [`stackkit service restart`](#stackkit-service-restart), [`stackkit service start`](#stackkit-service-start), [`stackkit service stop`](#stackkit-service-stop)

## stackkit service logs

सीमित, रेडैक्ट किए गए सेवा लॉग पढ़ें।

```bash
stackkit service logs <service-key> [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--cursor` | string | — | पिछले परिणाम से अपारदर्शी कर्सर |
| `--json` | bool | — | वर्ज़न वाले सेवा लॉग पेज को JSON के रूप में लिखें |
| `--tail` | int | `100` | लौटाई जाने वाली रेडैक्ट की गई लॉग प्रविष्टियों की संख्या (1..200) |

**उदाहरण**

```bash
# Read the last 50 redacted log entries of the TinyAuth login gateway
stackkit service logs auth --tail 50

# Read PocketID logs as JSON
stackkit service logs id --json

# Read the next page with the cursor the previous JSON result returned
stackkit service logs id --json --cursor <cursor>
```

## stackkit service manager

नोड के स्वामित्व वाले मौजूदा वर्कलोड को Compose और Komodo के बीच स्थानांतरित करें।

```bash
stackkit service manager <workload-ref> [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | वर्ज़नयुक्त मैनेजर परिणाम JSON के रूप में लिखें |
| `--owner-approve` | bool | — | ओनर से बँधे मैनेजर संक्रमण को स्पष्ट रूप से स्वीकृत करें |
| `--resume` | string | — | सटीक लंबित हैंडओवर ऑपरेशन फिर शुरू करें |
| `--status` | bool | — | बिना बदलाव किए टिकाऊ मैनेजर और हैंडओवर परिणाम पढ़ें |
| `--to` | string | — | लक्ष्य मैनेजर: standalone-compose या komodo |

**उदाहरण**

```bash
stackkit service manager media --to standalone-compose --owner-approve
stackkit service manager media --to komodo --owner-approve
stackkit service manager media --to komodo --resume handover-<operation-id> --owner-approve
```

## stackkit service restart

एक प्रबंधित सेवा रीस्टार्ट करें।

```bash
stackkit service restart <service-key> [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | वर्ज़न वाले सेवा एक्शन परिणाम को JSON के रूप में लिखें |
| `--owner-approve` | bool | — | ओनर-बद्ध सेवा बदलाव को स्पष्ट रूप से स्वीकृत करें |

**उदाहरण**

```bash
# Restart the PocketID identity service
stackkit service restart id --owner-approve

# Restart the TinyAuth login gateway and print the result as JSON
stackkit service restart auth --owner-approve --json
```

| --- | --- | --- | --- |

## stackkit service stop

एक प्रबंधित सेवा रोकें।

```bash
stackkit service stop <service-key> [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | वर्ज़न वाले सेवा एक्शन परिणाम को JSON के रूप में लिखें |
| `--owner-approve` | bool | — | ओनर-बद्ध सेवा बदलाव को स्पष्ट रूप से स्वीकृत करें |

**उदाहरण**

```bash
# Stop a non-critical service; base, id and auth cannot be stopped
stackkit service stop coolify --owner-approve
```
