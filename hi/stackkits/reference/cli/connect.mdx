इस सर्वर को अपने kombify अकाउंट से जोड़ें (मुफ़्त अकाउंट पर्याप्त है)।

इस सर्वर को, जो पहले से सार्वजनिक पैकेज चला रहा है, उस kombify अकाउंट से जोड़ें जिसने Homelab सेटअप में पेयरिंग बनाई थी। इसके बाद सर्वर kombify Cloud में अपनी स्थिति दिखाता है; इसके आगे के बदलाव पेड प्लान में रहते हैं। छिपे हुए टर्मिनल प्रॉम्प्ट पर एक-बार की पेयरिंग पेस्ट करें। ऑटोमेशन `--token-file` या `KOMBI_TOKEN` का उपयोग कर सकता है, कभी भी टोकन आर्ग्युमेंट का नहीं। कंट्रोल प्लेन का ओरिजिन `--server` या `KOMBI_SERVER` से आता है (सार्वजनिक डिफ़ॉल्ट `https://homelab.kombify.io`)। सेल्फ़-होस्टेड कंट्रोल प्लेन के लिए, kombify Cloud में उसके स्वयं-सर्वर सेटअप से सटीक `--server` ओरिजिन कॉपी करें। जो सर्वर पहले से जुड़ा है वह अपना जुड़ाव बताता है और कुछ नहीं बदलता। इसे Linux पर root के रूप में चलाएँ।

```bash
stackkit connect [flags]
```

| फ्लैग | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--server` | string | — | वह कंट्रोल प्लेन ओरिजिन जिससे पेयरिंग बनी थी (`KOMBI_SERVER`, अन्यथा `https://homelab.kombify.io`); सेल्फ़-होस्टेड ओरिजिन स्वयं-सर्वर सेटअप से कॉपी करें |
| `--token-file` | string | — | एक-बार की पेयरिंग रखने वाली निजी फ़ाइल (अन्यथा `KOMBI_TOKEN`, फिर छिपा हुआ टर्मिनल प्रॉम्प्ट) |

**उदाहरण**

```bash
sudo stackkit connect --server https://homelab.kombify.io
sudo stackkit connect --server https://your-homelab.example --token-file /root/kombify-pairing
```
