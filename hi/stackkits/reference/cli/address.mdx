सीक्रेट-मुक्त सार्वजनिक सेवा पते प्लान करें और बाइंड करें।

```bash
stackkit address [flags]
```

उप-कमांड: [`stackkit address bind`](#stackkit-address-bind), [`stackkit address plan`](#stackkit-address-plan)

## stackkit address bind

आवंटित प्रीफ़िक्स या इंस्टॉल ज़ोन को कैनोनिकल सार्वजनिक रूट में बाइंड करें।

```bash
stackkit address bind [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--expected-spec-hash` | string | — | केवल नेटिव v2: बदलने के लिए वर्तमान CUE-नॉर्मलाइज़्ड स्पेक का सटीक हैश आवश्यक है |
| `--output, -o` | string | — | सत्यापित बाउंड StackSpec को इस पथ पर लिखें |
| `--prefix` | string | — | आवंटित DNS-सुरक्षित सबडोमेन प्रीफ़िक्स: होस्ट &lt;prefix&gt;-&lt;service&gt;.&lt;domain&gt; |
| `--zone` | string | — | आवंटित इंस्टॉल ज़ोन लेबल: स्टैक &lt;zone&gt;.&lt;domain&gt; से परोसा जाता है और होस्ट &lt;service&gt;.&lt;zone&gt;.&lt;domain&gt; होते हैं |

## stackkit address plan

अकाउंट-मुक्त पता पंजीकरण प्लान जारी करें।

```bash
stackkit address plan [flags]
```
