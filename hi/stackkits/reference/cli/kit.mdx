प्रकाशित StackKit रिलीज़ ऑपरेशन।

प्रकाशित StackKit रिलीज़ आर्टिफ़ैक्ट खोजें, सत्यापित करें और इंस्टॉल करें।

```bash
stackkit kit [flags]
```

उप-कमांड: [`stackkit kit list`](#stackkit-kit-list), [`stackkit kit prepare-source-generation`](#stackkit-kit-prepare-source-generation)

## stackkit kit list

GitHub से प्रकाशित StackKits रिलीज़ सूचीबद्ध करें।

वर्तमान ऑपरेटिंग सिस्टम और आर्किटेक्चर पर हर सार्वजनिक StackKit की सबसे नई प्रकाशित रिलीज़ रिज़ॉल्व करें। रिलीज़ इंडेक्स सार्वजनिक kombifyio/stackKits GitHub Releases रिपॉज़िटरी से लाया जाता है।

```text
Channels:
  stable  newest release that is not a prerelease
  beta    newest -beta.* prerelease
  edge    newest -edge.* prerelease
```

```bash
stackkit kit list [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--channel` | string | `stable` | रिलीज़ चैनल: stable, beta या edge। |
| `--json` | bool | — | stackkit.command-result/v1 JSON जारी करें। |

**उदाहरण**

```bash
# Show the newest stable release of every public StackKit for this OS and architecture
stackkit kit list

# Show beta prereleases as JSON
stackkit kit list --channel beta --json
```

## stackkit kit prepare-source-generation

संरक्षित जनरेशन बनाने वाली प्रमाणित रिलीज़ को कैश और सत्यापित करें।

```bash
stackkit kit prepare-source-generation [flags]
```

| फ़्लैग | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--json` | bool | — | प्रमाणित कैश तैयारी के बाद सोर्स-जनरेशन निरीक्षण का सीमित प्रमाण दिखाएँ। |
