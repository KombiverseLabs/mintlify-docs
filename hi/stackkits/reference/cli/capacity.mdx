चुने गए मॉड्यूल की माँग का देखी गई होस्ट क्षमता से आकलन करें।

वर्तमान CUE-बद्ध चयन को रिज़ॉल्व करें और उसका सलाहकारी क्षमता आकलन JSON के रूप में प्रिंट करें। अनुपस्थित माप unverified रहते हैं। कोई फ़ाइल या रनटाइम स्थिति नहीं बदलती; यह Apply admission का स्थान नहीं लेता।

```bash
stackkit capacity [spec-file] [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--inventory` | string | — | देखा गया Inventory; अनुपस्थित क्षमता unverified रहती है |
| `--module-root` | string | — | Architecture प्राधिकार root |
