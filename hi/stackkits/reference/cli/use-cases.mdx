वैकल्पिक kit यूज़ केस चुनें।

```bash
stackkit use-cases [flags]
```

उप-कमांड: [`stackkit use-cases add`](#stackkit-use-cases-add), [`stackkit use-cases pick`](#stackkit-use-cases-pick)

## stackkit use-cases add

मौजूदा स्वतंत्र इंस्टॉलेशन में कैटलॉग का यूज़ केस जोड़ें।

इंस्टॉल किए गए किट के CUE-स्वामित्व वाले विकल्प और मॉड्यूल प्रोफ़ाइल डिफ़ॉल्ट के साथ यूज़ केस जोड़ता है। मौजूदा वर्कलोड, रूट, प्लेसमेंट और स्टोरेज सुरक्षित रखता है। वर्तमान स्पेक हैश के आधार पर उम्मीदवार सहेजता है और केवल चुने गए यूज़ केस के स्थानीय सीक्रेट स्लॉट बनाता है। मौजूदा कस्टडी पुनः उपयोग होती है। कोई सेवा डिप्लॉय नहीं होती; सामान्य लाइफ़साइकिल से अद्यतन इंटेंट जनरेट और लागू करें। नेटिव stackkit/v2alpha2 और एक स्वतंत्र नोड/site आवश्यक हैं।

```bash
stackkit use-cases add <slug> [flags]
```

| फ़्लैग | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--expected-spec-hash` | string | — | इस कैनोनिकल वर्तमान स्पेक हैश की माँग करें; न देने पर बदलाव तैयार करने से पहले पढ़ा गया हैश उपयोग होता है |

**उदाहरण**

```bash
stackkit use-cases add mail
stackkit use-cases add mail --expected-spec-hash sha256:<current-hash>
```

## stackkit use-cases pick

वैकल्पिक यूज़ केस इंटरैक्टिव रूप से चुनें।

kit के वैकल्पिक यूज़ केस सूचीबद्ध करें और टर्मिनल में उन्हें टॉगल करें।

Arrow keys or j/k move the cursor. Space toggles the highlighted item. Enter confirms. Without `--kit`, the legacy Files, Photos and Vault selection is used.

With `--kit` (Basement or Cloud), choices and defaults come from the embedded CUE kit catalog. Each choice shows its standard profile minimum (CPU / RAM GiB / disk GiB). The running numeric preview includes required Core and selected default alternatives. It observes this host unless `--inventory` and `--node` select another target. Data budgets, add-ons, profile changes and resident policy need a resolved plan. This preview writes no configuration and grants no Apply admission.

`--print` writes the selected IDs as a comma-separated line on stdout so installers can pass them to stackkit init `--use-case`. Prompts go to stderr. When stdin is not a terminal, defaults are returned without a prompt; a kit preview is still printed to stderr. Unknown facts are shown as ?, never zero.

```bash
stackkit use-cases pick [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--inventory` | string | — | Read capacity from this Inventory instead of observing the local host; requires `--kit` and `--node` |
| `--kit` | string | — | Preview main use cases admitted by this kit at standard profiles; observe this host by default |
| `--node` | string | — | Explicit Inventory node for the kit capacity preview |
| `--print` | bool | — | चुनी गई यूज़-केस ID को stdout पर अल्पविराम-विभाजित पंक्ति के रूप में लिखें |

**उदाहरण**

```bash
# Choose optional use cases in the terminal
stackkit use-cases pick

# Print the selected IDs as one comma-separated line for stackkit init --use-case
stackkit use-cases pick --print

# Preview standard footprints and capacity on this target, from its kit catalog
stackkit use-cases pick --kit basement-kit --print

# Preview one explicitly selected Inventory node
stackkit use-cases pick --kit cloud-kit --inventory inventory.yaml --node cloud-node --print
```
