## stackkit use-cases pick

वैकल्पिक यूज़ केस इंटरैक्टिव रूप से चुनें।

kit के वैकल्पिक यूज़ केस सूचीबद्ध करें और टर्मिनल में उन्हें टॉगल करें।

ऐरो कीज़ या j/k कर्सर हिलाते हैं। Space हाइलाइट किए गए आइटम को टॉगल करता है। Enter पुष्टि करता है। Files, Photos और Vault पहले से चुने हुए शुरू होते हैं (kit L3 डिफ़ॉल्ट)।

`--print` चुनी गई ID को stdout पर अल्पविराम-विभाजित पंक्ति के रूप में लिखता है ताकि इंस्टॉलर उन्हें stackkit init `--use-case` को दे सकें। प्रॉम्प्ट stderr पर जाते हैं। जब stdin टर्मिनल नहीं होता, तो बिना प्रॉम्प्ट के वर्तमान डिफ़ॉल्ट लौटाए जाते हैं।

```bash
stackkit use-cases pick [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--print` | bool | — | चुनी गई यूज़-केस ID को stdout पर अल्पविराम-विभाजित पंक्ति के रूप में लिखें |

**उदाहरण**

```bash
# Choose optional use cases in the terminal
stackkit use-cases pick

# Print the selected IDs as one comma-separated line for stackkit init --use-case
stackkit use-cases pick --print
```
