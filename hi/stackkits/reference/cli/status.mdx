डिप्लॉयमेंट की स्थिति दिखाएँ।

StackKit डिप्लॉयमेंट की वर्तमान स्थिति दिखाएँ।

```text
Shows:
  • Deployment state (running, degraded, error)
  • Service statuses and health
  • Resource usage
  • URLs and endpoints
```

```bash
stackkit status [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--http` | bool | — | इस verifier होस्ट से सत्यापित सेवा रूट की जाँच करें |
| `--inventory` | string | — | कॉन्फ़िगर किए गए Standard प्रोसेस रनटाइम की पहचान के लिए उपयोग किया गया Architecture v2 observed Inventory |
| `--json` | bool | — | JSON के रूप में आउटपुट दें |
| `--resolved-plan` | string | — | कैनोनिकल Architecture v2 ResolvedPlan (डिफ़ॉल्ट: deploy/.stackkit/resolved-plan.json) |

**उदाहरण**

```bash
# Show status
stackkit status

# Output as JSON
stackkit status --json
```
