पोर्टेबल StackKits के साथ अपनी सेवाएँ सेट करें और उनकी देखभाल करें। ये पेज हर `stackkit` कमांड को उसके फ़्लैग और उदाहरणों के साथ सूचीबद्ध करते हैं। ये StackKits कमांड परिभाषाओं से जनरेट होते हैं; यदि आपका इंस्टॉल किया वर्ज़न पुराना है, तो उसके लिए `stackkit <command> --help` ही प्रामाणिक है।

## CLI इंस्टॉल करें

```bash
curl -sSL https://install.stackkit.cc | STACKKIT_CLI_ONLY=1 sh
```

`STACKKIT_CLI_ONLY=1` के साथ इंस्टॉलर `stackkit`, `stackkit-server`, `stackkit-mcp`, पैकेज्ड OpenTofu और सार्वजनिक kit कैटलॉग को कोई StackKit इंस्टॉल किए बिना `~/.stackkits` में रखता है। इसके बिना, इंस्टॉलर होस्ट पहचानता है और Basement Kit या Cloud Kit में आगे बढ़ता है।

## ग्लोबल फ़्लैग

ये फ़्लैग हर कमांड के साथ काम करते हैं।

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--chdir, -C` | string | `.` | चलाने से पहले डायरेक्टरी बदलें |
| `--correlation-id` | string | — | सत्यापित कॉलर सहसंबंध ID जो स्थानीय रोलआउट प्रमाण में दर्ज होती है |
| `--no-log` | bool | — | संरचित डिप्लॉय लॉगिंग अक्षम करें |
| `--progress-jsonl` | string | — | रेडैक्ट की गई मशीन-पठनीय रोलआउट प्रगति JSONL को किसी पथ पर लिखें, या stdout के लिए '-' |
| `--quiet, -q` | bool | — | गैर-ज़रूरी आउटपुट दबाएँ |
| `--spec, -s` | string | `stack-spec.yaml` | स्टैक स्पेसिफ़िकेशन फ़ाइल का पथ (डिफ़ॉल्ट न मिलने पर kombination.yaml स्वीकार की जाती है) |
| `--verbose, -v` | bool | — | विस्तृत आउटपुट सक्षम करें |
