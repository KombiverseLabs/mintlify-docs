ओनर-बद्ध स्थानीय सीक्रेट कस्टडी प्रबंधित करें।

```bash
stackkit secrets [flags]
```

उप-कमांड: [`stackkit secrets materialize`](#stackkit-secrets-materialize), [`stackkit secrets reveal`](#stackkit-secrets-reveal)

## stackkit secrets materialize

वर्तमान StackSpec के सीक्रेट संदर्भों के लिए कस्टडी स्थापित करें।

वर्तमान कैनोनिकल StackSpec के हर secret:// संदर्भ के लिए ओनर-बद्ध स्थानीय कस्टडी स्थापित करें या दोबारा उपयोग करें।

मौजूदा स्टैंडअलोन वर्कस्पेस में वर्कलोड जोड़ने के बाद और generate/apply से पहले यह स्पष्ट, आइडेम्पोटेंट चरण चलाएँ। यह कभी सीक्रेट संदर्भ या सामग्री प्रिंट नहीं करता और कभी अमान्य या बाहरी कस्टडी को नहीं बदलता।

```bash
stackkit secrets materialize [flags]
```

**उदाहरण**

```bash
# After adding a workload to stack-spec.yaml, create its secrets, then roll out
stackkit secrets materialize
stackkit generate
stackkit apply
```

## stackkit secrets reveal

स्थानीय ओनर कस्टडी से चुने गए वर्कलोड का एक सीक्रेट प्रिंट करें।

वर्तमान CUE-मान्य StackSpec में चुने गए वर्कलोड द्वारा घोषित एक सीक्रेट स्लॉट का मौजूदा मान प्रिंट करें। आउटपुट में सीक्रेट सामग्री होती है; इसे केवल निजी टर्मिनल या जानबूझकर बनाई गई पाइप में उपयोग करें। कोई मान डिप्लॉय लॉग या रसीदों में नहीं लिखा जाता।

```bash
stackkit secrets reveal [flags]
```

| Flag | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `--slot` | string | — | **आवश्यक।** घोषित वर्कलोड सीक्रेट स्लॉट |
| `--workload` | string | — | **आवश्यक।** चुना गया वर्कलोड ID |

**उदाहरण**

```bash
# Print the Photos database password from local owner custody
stackkit secrets reveal --workload photos --slot database-password
```
