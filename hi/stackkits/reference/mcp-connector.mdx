StackKits `stackkit` नाम का एक उपयोगकर्ता-सामने वाला MCP कनेक्शन उपलब्ध कराता है। स्थानीय एडाप्टर `stackkit-mcp` है; इंस्टॉलेशन के बाद यही कनेक्टर `stackkit-server` के संरक्षित `/mcp` एंडपॉइंट पर भी परोसा जा सकता है।

## स्थानीय क्लाइंट कॉन्फ़िगर करें

इंस्टॉल की गई रिलीज़ से क्लाइंट स्निपेट जनरेट करें:

```bash
stackkit agent mcp-config --client codex
```

डिफ़ॉल्ट स्थानीय रूप यह है:

```toml
[mcp_servers.stackkit]
command = "stackkit-mcp"
args = ["--mode", "docs,local,server"]
```

## सुरक्षा मॉडल

- रीड-ओनली डॉक्यूमेंटेशन और डायग्नोस्टिक टूल डिफ़ॉल्ट रूप से उपलब्ध हैं।
- लिखने में सक्षम टूल के लिए स्पष्ट राइट मोड और ऑपरेशन-विशिष्ट स्थानीय ओनर स्वीकृति चाहिए।
- दूर से पहुँचने योग्य एंडपॉइंट को जानबूझकर संरक्षित करना होगा; उसे सीधे सार्वजनिक इंटरनेट पर एक्सपोज़ न करें।
- कनेक्टर वही स्थानीय CLI लाइफ़साइकिल और प्रमाण कॉन्ट्रैक्ट उपयोग करता है जो टर्मिनल कमांड करते हैं।

## State Console

वैकल्पिक State Console स्थानीय स्थिति-समीक्षा और ऑपरेशन-स्वीकृति एडाप्टर है। यह चुना गया वर्कस्पेस, प्लान, स्थिति, लॉग और प्रमाण दिखा सकता है। यह kit की सिफ़ारिश नहीं करता और लाइफ़साइकिल एक्शन खुद लागू नहीं करता।
