यहाँ बताया गया है कि पता बन जाने के बाद आप उसके साथ क्या कर सकते हैं, और आगंतुक उसके बाद क्या
देखते हैं।

## आप क्या बदल सकते हैं

| बदलाव | संभव है? |
| --- | --- |
| पता कहाँ इंगित करता है (लक्ष्य) | हाँ |
| ऐप को चालू या बंद करना ("exposed") | हाँ |
| पते को रोकना या फिर चालू करना (स्थिति) | हाँ |
| विवरण | हाँ |
| नाम खुद | नहीं |

किसी नाम का नाम बदला नहीं जा सकता। दूसरा नाम पाने के लिए, अपने मनचाहे नाम के साथ नया पता जोड़ें,
अपने आगंतुकों को वहाँ ले जाएँ, फिर पुराना हटा दें।

बदलाव जल्दी लागू होते हैं। kombify.me लगभग 60 सेकंड का रूटिंग कैश रखता है और पता बदलने या
हटाने पर उसे साफ़ कर देता है।

## चरण

**ऐप को बंद करें:** उस ऐप के लिए "exposed" बंद करें। तब आगंतुकों को "not exposed" पेज (404)
मिलता है। इसे कभी भी फिर चालू करें।

**पते को रोकें:** उसकी स्थिति inactive पर सेट करें। आगंतुकों को 503 "inactive" जवाब मिलता
है। फिर शुरू करने के लिए उसे active पर सेट करें।

**उसे कहीं और इंगित करें:** लक्ष्य बदलें। नए लक्ष्य को पहले जैसे ही नियमों का पालन करना होगा।
सार्वजनिक पते को सार्वजनिक वेब पता चाहिए।

**पता हटाएँ:** उसे डिलीट करें। हटाने के बाद नाम काम करना बंद कर देता है।

## आगंतुक क्या देखते हैं

| स्थिति | आगंतुक क्या देखता है |
| --- | --- |
| ऐप बंद है | 404 "not exposed" |
| पता रोका गया है | 503 "inactive" |
| अस्थायी साझाकरण अवधि समाप्त हो गई | 410 "publication expired" |
| आपके सर्वर तक पहुँचा नहीं जा सकता | 502 "Bad Gateway" |
| निजी पता, सहायक ऑफ़लाइन | 503, थोड़ी देर में फिर कोशिश करें |

## निलंबित अकाउंट

अगर कोई सेल्फ़-होस्टेड अकाउंट निलंबित है, तो उसकी API कुंजी 403 "account suspended" संदेश
के साथ अस्वीकार की जाती है। kombify.me में रिपोर्ट या अवरुद्ध पतों के बारे में कोई अलग सार्वजनिक
पेज नहीं है। अगर आपको लगता है कि यह गलती से हुआ, तो नाम और समय के साथ
[info@kombify.io](mailto:info@kombify.io) को लिखें।

## अपनी कुंजी बदलना

सेल्फ़-होस्टेड अकाउंट अपनी API कुंजी बदल सकता है। पुरानी कुंजी तुरंत काम करना बंद कर देती है,
इसलिए उन सभी जगहों को अपडेट करें जहाँ वह इस्तेमाल होती है।

## अगर कुछ गलत हो

| आप क्या देखते हैं | क्या करें |
| --- | --- |
| बदलाव अस्वीकृत, "access denied" (403) | पता किसी दूसरे अकाउंट का है। |
| "subdomain not found" (404) | नाम जाँचें। हो सकता है वह पहले ही हटा दिया गया हो। |
| लक्ष्य अस्वीकृत | सार्वजनिक रास्ता केवल सार्वजनिक `http` या `https` पते स्वीकार करता है। |
| पुराना लक्ष्य अब भी दिख रहा है | लगभग एक मिनट प्रतीक्षा करें और फिर से लोड करें। |

और जानकारी के लिए [समस्या-निवारण](/hi/kombify-me/troubleshooting) देखें।
