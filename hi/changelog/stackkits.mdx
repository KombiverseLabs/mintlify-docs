## StackKits moves Coolify workloads between servers and adds an Early Access channel

StackKits ने [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) से [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) तक के संस्करण जारी किए। इनमें Coolify वर्कलोड को दूसरे सर्वर पर ले जाना, अब Early Access कहलाने वाला वैकल्पिक रिलीज़ चैनल, निजी AI बंडल और ऐप हटाने पर डेटा सुरक्षित रखना शामिल हैं।

### New features

- **Move Coolify workloads to another server.** [StackKits v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) adds `stackkit relocate plan`, `check`, `drain`, `send`, and `receive`. Drain stops your apps before the final send, so the backup is consistent, and `drain --undo` rolls the move back. See [`stackkit relocate` (English)](https://docs.kombify.io/stackkits/reference/cli/relocate).
- **Early Access रिलीज़ चैनल।** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) में एक वैकल्पिक रिलीज़ चैनल जोड़ा गया था। StackKits ने तब से इसे बंद कर दिया है और अब केवल Stable रिलीज़ करता है।
- **Preview footprint and capacity before you install.** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) shows the footprint and capacity of your selected use cases on the target with `stackkit use-cases pick --kit`. See [`stackkit use-cases`](/hi/stackkits/reference/cli/use-cases).
- **Private AI bundles by goal.** [v0.53.8](https://github.com/kombifyio/stackKits/releases/tag/v0.53.8) groups Private AI into bundles such as My private Chat and My local AI. It adds the LiteLLM model router for API access and a model manager setup action, and shows memory and GPU fit for each choice. See [Personal AI](/hi/guides/stackkits/use-cases/personal-ai).
- **OpenCloud for Files and an MQTT add-on.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) adds OpenCloud as a Files alternative and an MQTT add-on with authenticated messaging. See [Documents and files](/hi/guides/stackkits/use-cases/documents-and-files).
- **Household access per app.** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) adds per-app household access groups on your node, and completes native owner setup for Navidrome and Audiobookshelf. See [Media](/hi/guides/stackkits/use-cases/media).

### Updates

- **Removing an app keeps its data.** [StackKits v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) retains application volumes on ordinary removal. Deletion is an explicit choice.
- **Clearer install and upgrade guidance.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) resumes interrupted installs and explains unsupported Cloud or Modern upgrades with a supported route before anything changes.
- **Private DNS with AdGuard Home.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) activates private-client DNS through AdGuard Home, and [v0.53.8](https://github.com/kombifyio/stackKits/releases/tag/v0.53.8) backs up its configuration. See [Network](/hi/guides/stackkits/use-cases/network).
- **Smart Home notifications and MQTT.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) connects Home Assistant to kombify notify, [v0.53.6](https://github.com/kombifyio/stackKits/releases/tag/v0.53.6) installs ntfy live notifications, and [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) configures Home Assistant MQTT from your plan. See [Smart Home](/hi/guides/stackkits/use-cases/smart-home).
- **Bring your own AI provider.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) connects Private AI to an external OpenAI-compatible provider with a key from the kombify Wallet, and pulls selected model packs into Ollama during Apply.
- **Coolify and Dokploy are back.** [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) restores Coolify and Dokploy as optional application platforms. The default core still uses no PaaS. See [Coolify](/hi/stackkits/apps/coolify).

### Bug fixes

- **Coolify restores recover.** [StackKits v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) recovers interrupted Coolify application restores, and [v0.53.8](https://github.com/kombifyio/stackKits/releases/tag/v0.53.8) restores signed Coolify application data.
- **Restores are checked.** [v0.53.6](https://github.com/kombifyio/stackKits/releases/tag/v0.53.6) reads back restored volume content during live restore. See [Back up and restore](/hi/guides/stackkits/back-up-and-restore).
- **Friendlier install refusals.** [v0.53.6](https://github.com/kombifyio/stackKits/releases/tag/v0.53.6) fixes the non-root install path and explains a low-memory refusal. [v0.53.9](https://github.com/kombifyio/stackKits/releases/tag/v0.53.9) adds recovery guidance when a stored plan is rejected.
- **Stable capacity on Windows.** [v0.53.1](https://github.com/kombifyio/stackKits/releases/tag/v0.53.1) keeps Windows host capacity stable across working drives.

</Update>

## StackKits में गेम प्लेटफ़ॉर्म चुनें और मौजूदा इंस्टॉलेशन में उपयोग जोड़ें

StackKits v0.50.4–v0.52.6 में गेम प्लेटफ़ॉर्म का चुनाव, चल रहे इंस्टॉलेशन में उपयोग जोड़ना और सुरक्षित बहाली शामिल हैं। [v0.50.4](https://github.com/kombifyio/stackKits/releases/tag/v0.50.4) [v0.52.6](https://github.com/kombifyio/stackKits/releases/tag/v0.52.6)

### नई सुविधाएँ

- नए गेम इंस्टॉलेशन Calagopus इस्तेमाल करते हैं; Pelican और Pterodactyl भी उपलब्ध हैं। मालिक की कुंजी केवल पढ़ने, पावर, कंसोल और फ़ाइल संपादन की अनुमति देती है। stackkit setup game, game list, power और allow तीनों पर समान हैं; मौजूदा इंस्टॉलेशन अपना प्लेटफ़ॉर्म रखते हैं। [StackKits v0.52.0](https://github.com/kombifyio/stackKits/releases/tag/v0.52.0) [दस्तावेज़](/hi/guides/stackkits/use-cases/game)
- stackkit use-cases add से चल रहे इंस्टॉलेशन में mail जैसे उपयोग जोड़ें, बिना मौजूदा वर्कलोड, रूट या स्टोरेज बदले। यह StackKits MCP से भी उपलब्ध है। [v0.51.0](https://github.com/kombifyio/stackKits/releases/tag/v0.51.0) [`stackkit use-cases`](/hi/stackkits/reference/cli/use-cases)
- सर्वर को नए नेटवर्क पर ले जाने के बाद stackkit network उसके सेवा बाइंडिंग को नए पते पर बदलता है। [v0.51.7](https://github.com/kombifyio/stackKits/releases/tag/v0.51.7) [`stackkit network`](/hi/stackkits/reference/cli/network)

### अपडेट

- Home Assistant एजेंट कनेक्टर stackkit setup से जारी, दोबारा इस्तेमाल और रद्द किया जाता है तथा केवल नोड के एन्क्रिप्टेड स्थानीय स्टोरेज में रहता है। [StackKits v0.52.0](https://github.com/kombifyio/stackKits/releases/tag/v0.52.0) [दस्तावेज़](/hi/guides/stackkits/use-cases/smart-home)
- प्रमाणीकरण के साथ पुराने रिकवरी पॉइंट उपलब्ध हैं। [v0.52.5](https://github.com/kombifyio/stackKits/releases/tag/v0.52.5) [दस्तावेज़](/hi/guides/stackkits/back-up-and-restore)
- Paperless, Mosquitto, Stalwart, Zigbee2MQTT, SearXNG, Roundcube, Euro-Office, Navidrome, Audiobookshelf, ESPHome और Emby जैसे ऐप OpenTofu पर Compose रैपर के बिना चल सकते हैं। प्रत्येक ऐप के लिए नेटिव निष्पादन चुनना होता है। [v0.51.0](https://github.com/kombifyio/stackKits/releases/tag/v0.51.0)
- ऐप सीक्रेट फ़ाइलों के रूप में मिलते हैं, पर्यावरण चर में नहीं। Zigbee2MQTT का MQTT पासवर्ड और Pterodactyl की ऐप कुंजी अब डेटा वॉल्यूम में नहीं रखे जाते। [v0.51.0](https://github.com/kombifyio/stackKits/releases/tag/v0.51.0)
- Advanced मोड प्रबंधित kombify.me ओरिजिन के लिए Origin CA प्रमाणपत्र जारी करता है। [v0.51.7](https://github.com/kombifyio/stackKits/releases/tag/v0.51.7) [`stackkit advanced`](/hi/stackkits/reference/cli/advanced)

### सुधार

- बाधित बहाली प्रमाणित मूल रिलीज़ से पुनः शुरू होती है; बहाली कंटेनर फ़ाइलों का स्वामित्व सुरक्षित रखती है। [StackKits v0.52.6](https://github.com/kombifyio/stackKits/releases/tag/v0.52.6) [v0.52.5](https://github.com/kombifyio/stackKits/releases/tag/v0.52.5)
- ऑफ़साइट बैकअप खाली बकेट में अपना रिपॉज़िटरी बनाता है। [v0.51.2](https://github.com/kombifyio/stackKits/releases/tag/v0.51.2)
- Paperless-ngx का PocketID साइन-इन और Mosquitto ब्रोकर का पुनः चालू होना ठीक किया गया है। [v0.50.6](https://github.com/kombifyio/stackKits/releases/tag/v0.50.6)

</Update>

## StackKits में Private AI लैब, गेम सर्वर और हर इंस्टॉल पर MCP

StackKits ने [v0.33.0](https://github.com/kombifyio/stackKits/releases/tag/v0.33.0) से [v0.50.3](https://github.com/kombifyio/stackKits/releases/tag/v0.50.3) तक रिलीज़ किए: पूरी लोकल AI लैब, Game उपयोग केस, हर उपयोग केस में अधिक ऐप, Advanced मोड और हर इंस्टॉलेशन पर StackKits MCP।

### नई सुविधाएँ

- **Private AI अब एक लोकल AI लैब है।** [StackKits v0.48.0](https://github.com/kombifyio/stackKits/releases/tag/v0.48.0) आपको चैट के लिए Open WebUI या AnythingLLM चुनने देता है और वेब खोज, दस्तावेज़ पार्सिंग, Hermes सहायक, gVisor के भीतर OpenHands एजेंट और चित्र व वीडियो के लिए ComfyUI जोड़ता है। यह CPU या NVIDIA और AMD GPU पर चलता है। वैकल्पिक कनेक्टर आउटबाउंड कनेक्शन से आपके homelab मॉडल को kombify AI से जोड़ता है, इसलिए कोई इनबाउंड पोर्ट नहीं खुलता। देखें [Personal AI](/hi/guides/stackkits/use-cases/personal-ai)।
- **गेम सर्वर।** [v0.41.0](https://github.com/kombifyio/stackKits/releases/tag/v0.41.0) Pterodactyl Panel के साथ वैकल्पिक Game उपयोग केस जोड़ता है। `stackkit setup game` सुरक्षित डिफ़ॉल्ट के साथ Minecraft Java और Bedrock सर्वर बनाता है, और [v0.43.0](https://github.com/kombifyio/stackKits/releases/tag/v0.43.0) Paper, Terraria और Valheim जोड़ता है। सेटअप वास्तविक क्लाइंट से जुड़कर तत्परता जाँचता है और ऐसे सर्वर को अस्वीकार करता है जिसे होस्ट की मेमोरी संभाल नहीं सकती। देखें [Game](/hi/guides/stackkits/use-cases/game)।
- **हर उपयोग केस में अधिक ऐप।** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) डिफ़ॉल्ट के विकल्प के रूप में Nextcloud, Forgejo, Emby और Passbolt इंस्टॉल करता है। उपयोग केस के साथ ये ऐड-ऑन इंस्टॉल होते हैं: Paperless-ngx, Euro-Office, Navidrome, Audiobookshelf और ESPHome। देखें [उपयोग-केस कैटलॉग](/hi/stackkits/reference/use-case-catalog)।
- **मेल, आपके तरीके से।** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) आपके मौजूदा मेलबॉक्स के लिए Roundcube वेबमेल और समर्पित नोड पर वैकल्पिक Stalwart मेल सर्वर जोड़ता है। देखें [Mail](/hi/guides/stackkits/use-cases/mail)।
- **प्रबंधित घरों के लिए Advanced मोड।** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) Terramate के ज़रिए OpenTofu पर चेंज सेट, हर स्टैक के लिए ड्रिफ़्ट पहचान और समायोजन, समन्वित रोलबैक और रिस्टोर अभ्यास चलाता है। Basement इंस्टॉल अब डिफ़ॉल्ट रूप से OpenTofu इस्तेमाल करते हैं, और [v0.48.0](https://github.com/kombifyio/stackKits/releases/tag/v0.48.0) उसकी स्टेट और योजनाओं को एन्क्रिप्ट करता है। देखें [`stackkit advanced`](/hi/stackkits/reference/cli/advanced)।
- **हर इंस्टॉलेशन पर StackKits MCP।** [v0.46.0](https://github.com/kombifyio/stackKits/releases/tag/v0.46.0) हर Core पर टोकन-सुरक्षित `/mcp` एंडपॉइंट प्रकाशित करता है, ताकि AI एजेंट सीधे आपके सर्वर से जुड़ सके। अब हर सार्वजनिक CLI कमांड या तो MCP टूल है या सूचीबद्ध अपवाद; रहस्य उजागर कर सकने वाले कमांड केवल CLI में रहते हैं। देखें [MCP कनेक्टर](/hi/stackkits/reference/mcp-connector)।
- **CLI से OS अपडेट।** [v0.47.0](https://github.com/kombifyio/stackKits/releases/tag/v0.47.0) नोड पर OS अपडेट की योजना बनाता और लागू करता है तथा रीबूट निर्धारित करता है। देखें [`stackkit host`](/hi/stackkits/reference/cli/host)।
- **पहले से तैयार इमेज।** [v0.50.0](https://github.com/kombifyio/stackKits/releases/tag/v0.50.0) टूलचेन और कोर इमेज पहले से कैश करने के लिए `stackkit image plan`, `prepare` और `verify` जोड़ता है। हर इंस्टॉलेशन को पहली बूट पर अब भी अपनी ओनर कुंजियाँ और सीक्रेट मिलते हैं। देखें [`stackkit image`](/hi/stackkits/reference/cli/image)।

### अपडेट

- **अधिक ऐप के लिए साइन-इन।** [StackKits v0.48.0](https://github.com/kombifyio/stackKits/releases/tag/v0.48.0) Paperless-ngx, Media और Smart Home को PocketID के ज़रिए साइन इन कराता है और Files में घरेलू खाते प्रोविज़न करता है। [v0.38.0](https://github.com/kombifyio/stackKits/releases/tag/v0.38.0) ओनर पासकी के लिए `stackkit user owner status` और `activate` जोड़ता है। देखें [PocketID](/hi/stackkits/apps/pocketid)।
- **Smart Home का विस्तार।** [v0.47.1](https://github.com/kombifyio/stackKits/releases/tag/v0.47.1) ओनर द्वारा चुने गए LAN लिसनर और डिवाइस पासथ्रू के साथ Mosquitto और Zigbee2MQTT इंस्टॉल करता है, और [v0.50.0](https://github.com/kombifyio/stackKits/releases/tag/v0.50.0) मौजूदा Home Assistant की स्टेट बदले बिना उसे अपनाता है। देखें [Smart Home](/hi/guides/stackkits/use-cases/smart-home)।
- **हर ऐप्लिकेशन को एक रूट।** [v0.39.0](https://github.com/kombifyio/stackKits/releases/tag/v0.39.0) Media, Smart Home, AI, Dev और Documents को वही HTTPS रूट और डेटा बाइंडिंग देता है जो Photos, Files और Vault को मिलती है।
- **कवरेज समूह के अनुसार बैकअप।** [v0.37.0](https://github.com/kombifyio/stackKits/releases/tag/v0.37.0) `config`, `content` या `media` के अनुसार डेटा चुनता है। सेट न किया गया कवरेज `content` बनता है, इसलिए मीडिया हमेशा स्पष्ट विकल्प रहता है। देखें [बैकअप और रिस्टोर](/hi/guides/stackkits/back-up-and-restore)।

- **बिना प्लेसमेंट ब्लॉक वाले वर्कलोड बस काम करते हैं।** [v0.21.11](https://github.com/kombifyio/stackKits/releases/tag/v0.21.11) तब शासित प्लेसमेंट डिफ़ॉल्ट लागू करता है जब StackSpec लेखक `placement` ब्लॉक के बिना वर्कलोड चुनता है। देखें [StackSpec कॉन्फ़िगर करें](/hi/guides/stackkits/configure-stack-spec)।
- **विफल Apply बताता है कि आगे क्या करें।** [v0.22.0](https://github.com/kombifyio/stackKits/releases/tag/v0.22.0) विफल Product Apply को retry, `status` और `logs` मार्गदर्शन तथा Run-ID के साथ समाप्त करता है, और इंस्टॉलर मरने के बजाय मौजूदा वर्कस्पेस फिर शुरू करते हैं।

### अपडेट

- **`foundation`, `base` स्कीमा पैकेज की जगह लेता है।** [StackKits v0.18.22](https://github.com/kombifyio/stackKits/releases/tag/v0.18.22) साझा CUE स्कीमा पैकेज का नाम `base` से बदलकर `foundation` करता है और प्रकाशित आर्काइव में `foundation/stackkit.cue` की माँग करता है। प्रोडक्ट Kit अपरिवर्तित हैं और अब भी `#FoundationStackKit` को एक्सटेंड करते हैं।
- **`base-kit` इंस्टॉलर आर्गुमेंट रिटायर किया गया।** [v0.18.22](https://github.com/kombifyio/stackKits/releases/tag/v0.18.22) रिटायर किए `base-kit` स्लग को चुपचाप `basement-kit` में बदलने के बजाय अस्वीकार करता है। `basement-kit` उपयोग करें। देखें [Kit चुनें](/hi/guides/stackkits/choosing-a-kit)।

## StackKits v0.15.0 – v0.18.1: निर्देशित इंस्टॉलर, सेवा-नियंत्रित रोलआउट और प्रोवाइडर-निरपेक्ष Cloud कोर

StackKits इस सप्ताह v0.14.28 से [v0.18.1](https://github.com/kombifyio/stackKits/releases/tag/v0.18.1) तक पहुँचा। नया निर्देशित इंस्टॉलर तीन मोड में बिना तैयार मशीन को चलते होमलैब तक ले जाता है। Cloud Kit को प्रोवाइडर-निरपेक्ष Cloud कोर, सार्वजनिक TLS रूट स्वामित्व और वैकल्पिक ऑफ़साइट बैकअप मिले। `apply`, `status`, `verify` और `logs` हर नतीजे पर पूरी तरह मशीन-पठनीय हैं, और नया `stackkit service` कमांड पूर्ण apply के बीच अलग-अलग सेवाओं को नियंत्रित करता है।

### नई सुविधाएँ

- **निर्देशित इंस्टॉलर से चलते होमलैब तक।** [StackKits v0.17.0](https://github.com/kombifyio/stackKits/releases/tag/v0.17.0) तीन मोड और `--use-case`, `--platform` तथा `--enable` स्वीकार करने वाले `v2 init` प्रवाह के साथ पूर्ण निर्देशित इंस्टॉलेशन शिप करता है। इंस्टॉलर Docker और स्टोरेज रूट सीधे बूटस्ट्रैप करता है, `sudo` में सुरक्षित रूप से काम करता है, और सच्चे नेटिव क्रेडेंशियल प्रिंट करता है। देखें [क्विकस्टार्ट](/hi/stackkits/quickstart) और [Kit चुनना](/hi/guides/stackkits/choosing-a-kit)।
- **सार्वजनिक TLS रूट के साथ प्रोवाइडर-निरपेक्ष Cloud कोर।** [StackKits v0.15.0](https://github.com/kombifyio/stackKits/releases/tag/v0.15.0) `base`, `auth`, `id` और `coolify` के लिए आवश्यक `cloud-core` वर्कलोड हल करता है, एक digest-pinned Compose प्रोजेक्ट रेंडर करता है, और बाहर से दिए होस्ट पर बंद स्थानीय रनटाइम ओनर से चलाता है। [v0.18.0](https://github.com/kombifyio/stackKits/releases/tag/v0.18.0) Cloud Kit को सार्वजनिक TLS रूट का स्वामी बनाकर शुरू से अंत तक मटीरियलाइज़ करवाता है। Cloud रनटाइम कस्टडी केवल सेवा-स्कोप वाला PocketID, TinyAuth और Coolify मटीरियल रखती है। प्रोवाइडर क्रेडेंशियल, सर्वर क्रेडेंशियल, लीज़ और इन्वेंटरी StackKits के बाहर रहते हैं। देखें [Cloud Kit](/hi/stackkits/kits/cloud-kit)।
- **रोलआउट के बाद नियंत्रण के लिए `stackkit service` कमांड।** [v0.16.0](https://github.com/kombifyio/stackKits/releases/tag/v0.16.0) StackKits-प्रबंधित Cloud कोर सेवाओं के लिए `stackkit service start|stop|restart <service-key>` और `stackkit service logs <service-key>` जोड़ता है। बदलावों के लिए `--owner-approve` चाहिए, और `--json` संस्करणित एक्शन नतीजा लौटाता है। पूर्ण apply के बीच किसी एक सेवा को बाउंस या निरीक्षित करने के लिए इसका उपयोग करें। देखें [Day 2 ऑपरेशन](/hi/stackkits/reference/day-2-operations)।

```bash
stackkit service restart coolify --owner-approve --json
stackkit service logs auth --tail 100
```

- **apply, status, verify और logs पर पूर्ण मशीन-पठनीय आउटपुट।** [v0.15.8](https://github.com/kombifyio/stackKits/releases/tag/v0.15.8) `stackkit apply --json`, `stackkit status --json` और `stackkit verify --json` को सफलता, अस्वीकृति और विफलता पर पार्स करने योग्य रखता है। `stackkit logs` digest-बद्ध कर्सर और स्पष्ट ट्रंकेशन मेटाडेटा के साथ रिडैक्ट किए, सीमित पेज लौटाता है। MCP कनेक्टर वही संरचित प्रमाण उपलब्ध कराता है। देखें [MCP कनेक्टर](/hi/stackkits/reference/mcp-connector) और [StackKit संचालित करें](/hi/stackkits/reference/day-2-operations)।
- **प्रोडक्ट-स्वामित्व वाली एप्लिकेशन डिलीवरी के लिए Architecture v2 रनटाइम लिसनर।** [v0.15.3](https://github.com/kombifyio/stackKits/releases/tag/v0.15.3) Architecture v2 कैटलॉग प्रोजेक्शन पर रनटाइम लिसनर उपलब्ध कराता है ताकि एप्लिकेशन लाइफ़साइकल अधिकार को StackKits से बाहर ले जाए बिना अपनी डिलीवरी चला सकें। देखें [एप्लिकेशन डिलीवरी](/hi/guides/stackkits/application-delivery)।
