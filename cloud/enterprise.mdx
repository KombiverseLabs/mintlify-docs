## Enterprise SSO

kombify Cloud sign-in is built on Auth0, so enterprise SSO connects your existing identity provider to the standard kombify login:

- **Supported:** Okta, Azure Active Directory (Entra ID), Google Workspace, and any SAML 2.0 / OIDC provider.
- **Role mapping:** IdP groups map to kombify Cloud roles (Admin / Operator / Viewer).
- **Enforcement:** SSO can be enforced for your organization so password login is disabled.

Enterprise SSO connections are set up together with kombify during onboarding — [contact sales](mailto:enterprise@kombify.io) to start. Automatic user provisioning/deprovisioning (SCIM) is available as part of enterprise onboarding.
