The Tool Launcher provides one-click access to all kombify tools for your connected homelabs. No need to manage separate installations — everything runs in context of your selected stack.

## Launching tools

### From the dashboard

1. Select a homelab
2. Click the **Tools** dropdown
3. Choose the tool to launch

### From homelab details

1. Open a homelab's detail view
2. Use the toolbar icons to launch tools
3. Tool opens in a new tab with context

## kombify TechStack

Full-featured orchestration interface for managing your homelab.

### Features available

- Node management
- Service configuration
- Deployment pipeline
- Job monitoring
- Log viewer

### Launch options

| Option | Description |
|--------|-------------|
| **Read-only** | View configuration without changes |
| **Full access** | Complete management capabilities |
| **Specific node** | Open directly to a node |

### Context passed

When launched, TechStack receives:
- Homelab ID and connection details
- Your kombify Cloud authentication
- Role-based permissions

## kombify Simulate

Test changes in a simulated environment before deploying to production.

### Features available

- Create simulation from current config
- Test StackKit updates
- Validate configuration changes
- Network latency testing

### Workflow

<Steps>
  <Step title="Select homelab">
    Choose which homelab's config to simulate
  </Step>
  <Step title="Launch Simulate">
    Click **Launch Simulate** → opens in new tab
  </Step>
  <Step title="Create simulation">
    Simulate auto-creates environment from your config
  </Step>
  <Step title="Test changes">
    Modify and test safely
  </Step>
  <Step title="Apply to production">
    Export validated config back to kombify Cloud
  </Step>
</Steps>

### Simulation presets

| Preset | Description |
|--------|-------------|
| **Mirror** | Exact copy of production config |
| **Minimal** | Reduced resources for quick tests |
| **Stress** | Add latency/failures for resilience testing |

## On the roadmap

Two launcher surfaces are in development and will appear here as they roll out:

- **StackKits Studio** — a visual editor for StackKit configurations (service toggles, node topology, schema validation, spec export).
- **Web terminal** — browser-based SSH access to your nodes with audit logging.

Until they ship, use [`stackkit` CLI and TechStack](/guides/stackkits/deploy-with-cli-or-techstack) for spec editing and your own SSH client for node access.

## Tool permissions

Access depends on your team role:

| Role | TechStack | Simulate |
|------|-------|-----|
| **Owner** | ✅ Full | ✅ Full |
| **Admin** | ✅ Full | ✅ Full |
| **Operator** | ✅ Full | ✅ Full |
| **Viewer** | 👁️ View | ❌ |

## Troubleshooting

<Accordion title="Tool won't launch">
**Check:**
- Pop-up blocker disabled
- Agent connected (green status)
- Sufficient permissions

**Try:**
- Refresh the page
- Reconnect agent
- Contact team admin
</Accordion>

<Accordion title="Context not loading">
**Check:**
- Homelab selected before launch
- Agent has recent heartbeat

**Try:**
- Re-select the homelab
- Launch from homelab detail page
</Accordion>
