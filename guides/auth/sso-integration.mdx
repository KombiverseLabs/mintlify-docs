Integrate with enterprise identity providers.

<Note>
  All interactive sign-in flows go through the hosted **Auth0 Universal Login** page. Your enterprise IdP is federated behind it — users are redirected to Universal Login, which brokers the connection to your provider.
</Note>

## Supported providers

- **SAML 2.0:** Okta, Azure AD, Google Workspace
- **OAuth 2.0:** GitHub, GitLab, Bitbucket
- **OIDC:** Any OIDC-compliant provider

## Configuration

1. Configure provider in Auth0
2. Add redirect URIs
3. Map user attributes
4. Test authentication

## Example: Azure AD

```yaml
provider: azure-ad
client_id: your-client-id
client_secret: your-client-secret
tenant_id: your-tenant-id
```
