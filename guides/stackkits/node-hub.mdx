The StackKits Node Hub is the generated local service overview. After a successful rollout, open the `base.<domain>` address printed by the CLI or shown in the verified output.

## What to check

- The page identifies the current StackKits workspace.
- Only services selected by the validated configuration are visible.
- Each listed service uses the generated address for that rollout.

If the Node Hub does not open or a route looks incorrect, inspect the local evidence before changing configuration:

```bash
stackkit verify --json
stackkit status --json
stackkit logs list --json
```

Change the StackSpec and regenerate artifacts rather than editing the generated Node Hub or router configuration.

See [Released applications](/stackkits/apps/overview) for the public catalog.
