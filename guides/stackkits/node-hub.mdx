Node Hub is the post-rollout dashboard surface for current StackKits releases.

## Open Node Hub

Use the URL printed by your rollout output, typically `base.<domain>`.

## Verify

- Node Hub loads in the browser.
- Enabled services show a URL and guide reference.
- You can navigate to the linked service pages.
