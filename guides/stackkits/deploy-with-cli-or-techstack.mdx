Use only release-backed installer and CLI paths for executable instructions.

## Installer lanes

```bash
curl -sSL https://base.stackkit.cc | sh
curl -sSL https://cloud.stackkit.cc | sh
curl -sSL https://install.stackkit.cc | sh
```

## CLI lane

```bash
stackkit init basement-kit
stackkit prepare
stackkit generate
stackkit plan
stackkit apply
```

`cloud-kit` is the cloud counterpart for initialization where needed.

## Techstack note

Techstack is the open-core runtime/control-plane component and a Wave 2 blocker, but its current public distribution lane is dormant and is not required to complete Wave 1 StackKits OSS journeys.
