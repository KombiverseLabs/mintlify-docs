Stuck with StackKits? Pick the channel that fits your question. If you are not
sure, send an email.

### When email support answers

- Service hours are 08:00 to 22:00 (Europe/Berlin time), every day.
- You get a first answer within 4 service hours.
- Email that arrives after 22:00 is answered by 12:00 the next day.

### Report security problems privately

Report a security problem only through
[GitHub Security Advisories](https://github.com/kombifyio/StackKits/security/advisories/new).
Never open a public issue or discussion for it, because everyone can read
those.

## What to include

A good first message saves a round of questions. Include:

1. Your operating system and its version, for example Ubuntu 24.04.
2. Your hardware, for example "mini PC" or "virtual machine", and how much
   memory it has.
3. The kit you installed, for example Basement Kit.
4. The step where you got stuck, and what you expected to happen.
5. The output of these commands, run in your workspace folder, with secrets
   removed:

```bash
cd ~/my-homelab
stackkit version
stackkit logs latest --json
```

You can also attach a redacted support file. This command writes one rollout
log and its receipts to a new file, with secrets removed:

```bash
stackkit support export --output support-evidence.json
```

Read the file before you send it, and remove anything you do not want to share.

<Warning>
  Never post the contents of `.stackkit/access.json` or any password, in an
  email, a discussion or an issue. Also leave out passkey recovery material and
  private keys.
</Warning>
