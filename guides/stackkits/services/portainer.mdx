Portainer is a full-featured Docker management UI for inspecting and managing containers, images, volumes, and networks. The resolver enables it on the **high compute tier**; on smaller setups [Dockge](https://docs.kombify.io/guides/stackkits/services/dockge) is the lighter Compose-focused alternative.

Portainer is served at `portainer.<domain>`.

## Enable Portainer

```yaml stack-spec.yaml
stackkit: basement-kit

services:
  portainer:
    enabled: true
```

<Note>
  Portainer (full management) and Dockge (Compose-focused) overlap — pick the one that fits. See [tool alternatives](https://docs.kombify.io/stackkits/reference/tool-alternatives).
</Note>

## Steps

<Steps>
  <Step title="Open Portainer">
    Open `https://portainer.<domain>` and create the admin account on first launch.
  </Step>
  <Step title="Connect the local environment">
    Select the local Docker environment to manage the host's containers.
  </Step>
  <Step title="Manage workloads">
    Inspect containers, view logs, manage volumes, and redeploy stacks.
  </Step>
</Steps>

## Verify

- `portainer.<domain>` loads and lists the local environment.
- Containers, images, and volumes are visible.

## Troubleshooting

<AccordionGroup>
  <Accordion title="First-run admin timeout">
    Portainer locks new-admin creation a few minutes after start. Restart the container (`docker restart portainer`) and complete setup promptly.
  </Accordion>
</AccordionGroup>
