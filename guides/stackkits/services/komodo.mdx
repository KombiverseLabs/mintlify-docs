Komodo is a programmable, self-hosted PaaS for deploying Docker Compose stacks through API keys. It is an **alternative** app platform — the Base Kit ships [Coolify](/guides/stackkits/services/coolify) by default. Choose Komodo when you want API-driven Compose deployments.

Komodo is served at `komodo.<domain>`.

## Enable Komodo

```yaml kombination.yaml
stackkit: base-kit

services:
  komodo:
    enabled: true
```

<Note>
  Komodo, Coolify, and [Dokploy](/guides/stackkits/services/dokploy) are interchangeable app platforms — pick one. See [tool alternatives](/stackkits/reference/tool-alternatives).
</Note>

## Steps

<Steps>
  <Step title="Open Komodo">
    Open `https://komodo.<domain>` and complete the first-run setup.
  </Step>
  <Step title="Create an API key">
    Generate an API key for programmatic stack deployment.
  </Step>
  <Step title="Deploy a stack">
    Define a Compose stack and deploy it through the UI or API.
  </Step>
</Steps>

## Verify

- The Komodo UI is reachable at `komodo.<domain>`.
- A test stack deploys and its containers report healthy.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Komodo UI not reachable">
    Confirm `services.komodo.enabled: true`, re-run `stackkit generate && stackkit apply`, then check `docker logs komodo`.
  </Accordion>
</AccordionGroup>
