Dozzle is a real-time Docker container log viewer. It is **enabled by default** in the Basement Kit so you can tail any service's logs from the browser without SSH.

Dozzle is served at `logs.<domain>`.

## When you get it

Dozzle ships in the default Basement Kit profile across all compute tiers — no configuration needed.

```yaml stack-spec.yaml
stackkit: basement-kit
# Dozzle is on by default — open logs.<domain> after rollout.
```

## Steps

<Steps>
  <Step title="Open Dozzle">
    Open `https://logs.<domain>` to see all running containers.
  </Step>
  <Step title="Tail a service">
    Select a container (e.g. Traefik or your app platform) to stream its logs live.
  </Step>
  <Step title="Search and filter">
    Use the search box to filter log lines while debugging.
  </Step>
</Steps>

## Verify

- `logs.<domain>` lists your running containers.
- Selecting a container streams live log output.

## Troubleshooting

<AccordionGroup>
  <Accordion title="No containers listed">
    Dozzle needs the Docker socket. Verify it is mounted and that `docker logs dozzle` shows no permission errors.
  </Accordion>
</AccordionGroup>
