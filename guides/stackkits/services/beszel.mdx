Beszel is a lightweight server-monitoring tool with historical data and alerts. It is an **alternative** to the default [Netdata](/guides/stackkits/services/netdata) — ideal for low-resource nodes (e.g. a Raspberry Pi) where a full metrics agent is too heavy.

Beszel is served at `monitor.<domain>`.

## Enable Beszel

```yaml kombination.yaml
stackkit: base-kit
mode: pi          # low-resource intent favors lightweight tools

services:
  beszel:
    enabled: true
```

<Note>
  On `mode: pi` and low compute tiers the resolver already prefers lightweight metrics. Beszel and Netdata cover the same need — pick one. See [tool alternatives](/stackkits/reference/tool-alternatives).
</Note>

## Steps

<Steps>
  <Step title="Open Beszel">
    Open `https://monitor.<domain>` and create the first admin user.
  </Step>
  <Step title="Add agents">
    Register each node's Beszel agent so its metrics report to the hub.
  </Step>
  <Step title="Configure alerts">
    Set CPU, memory, and disk thresholds with a notification channel you watch.
  </Step>
</Steps>

## Verify

- The Beszel hub is reachable at `monitor.<domain>`.
- Each node reports CPU, RAM, disk, and network history.
