Media streams the films, music and home videos you own to the devices in your household. The release catalog calls this use case Media Library and delivers it as the optional `media` workload.

## Applications

<Card title="Jellyfin" icon="film" href="/stackkits/apps/jellyfin">

## Before you start

- Decide whether Jellyfin reads an existing media directory, which StackKits mounts read-only, or a library volume that the plan manages.
- StackKits does not back up your media files. Keep an independent copy of them.
- List the devices you want to watch on. A healthy container says nothing about playback on a particular TV or phone.

## Set it up

Set up Media after the baseline of your kit verifies. The [Jellyfin](/stackkits/apps/jellyfin) page covers the storage setting, owner setup and your first library, and ends with a playback test on a real client.

## Get the apps

Install an official Jellyfin client on the devices you want to watch on, then connect it to your generated Media URL and sign in with the account your household member registered.
