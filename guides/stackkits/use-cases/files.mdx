Files gives your household a private place to store and share files, on storage and a host you operate. The release catalog calls this use case File Storage and Documents and delivers it as the optional `files` workload.

## Applications

<Card title="Cloudreve" icon="folder-cloud" href="/stackkits/apps/cloudreve">

</Card>

The release catalog also lists Nextcloud as an alternative component. It has no guide yet.

## Plan storage first

- Choose an absolute primary data root with enough free space.
- Keep the backup root separate from primary data.
- Decide which clients may reach the generated Files route.
- Practice a restore before you place irreplaceable files in the library.

## Set it up

Files is a good first use case on a verified [Basement Kit](/stackkits/kits/basement-kit), because its standalone selection needs no secret reference. Select, deploy and verify it on the [Cloudreve](/stackkits/apps/cloudreve) page, then practice the recovery lifecycle in [Back up and restore](/guides/stackkits/back-up-and-restore).
