Photos gives your household one library for photos and videos on a host you operate. Immich runs the library, and its mobile apps upload pictures from your phones. The release catalog calls this use case Photos and Memories and delivers it as the optional `photos` workload.

## Choose the host

- Use [Basement Kit](/stackkits/kits/basement-kit) for local hardware and LAN-first access.
- Use [Cloud Kit](/stackkits/kits/cloud-kit) for an existing VPS or cloud host with a domain you control.

## Plan storage and recovery

Photos and videos often become the largest data set in a homelab. Plan storage and backups before you import a family library.

- Size primary and backup storage for photo and video growth.
- Recovery needs both the original photos and videos and the Immich database. Either part alone is not a complete restore.
- Practice a staged restore before the library is the only copy of your photos. See [Back up and restore](/guides/stackkits/back-up-and-restore).

## Set it up

Select the workload and complete first use on the [Immich](/stackkits/apps/immich) page. Then connect each phone with [Back up photos from your phone](/guides/stackkits/use-cases/photos/phone-backup) and check that a test photo arrives.
