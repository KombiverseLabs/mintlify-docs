This initial catalog snapshot is bound to the public [StackKits v0.16.0 release](https://github.com/kombifyio/StackKits/releases/tag/v0.16.0). Future releases that contain the immutable catalog assets replace this page automatically. The page contains only product purpose and declared components.

| Use case | Purpose | Declared components |
| --- | --- | --- |
| Smart Home | Home automation and local device adjacency | Home Assistant, Kombify Home Bridge, Mosquitto, Zigbee2MQTT |
| Photos and Memories | Family photo and video vault | Immich, Ente Photos |
| Media Library | Private household media streaming | Jellyfin |
| Password Vault | Owner-controlled password and secure-note vault | Vaultwarden |
| File Storage and Documents | Private storage, sharing, collaboration, and documents | Cloudreve, Nextcloud |
| Private AI | Local model serving and user-facing private AI | Ollama, Open WebUI |
| Developer Platform | Private source control and developer collaboration | Gitea |
| Private Mail | Private mail delivery and mailbox intent | Stalwart Mail Server |
| Game Server | Self-hosted multiplayer runtime | Game Server Runtime |
| Remote Desktop | Browser-accessible private workspace | Apache Guacamole |

The number of use cases is not fixed. A future catalog entry appears here only when StackKits explicitly registers it; an add-on or editorial guide does not create one.
