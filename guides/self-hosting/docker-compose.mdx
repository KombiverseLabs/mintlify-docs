Deploy the complete kombify self-hosted stack using Docker Compose.

<Note>
  **Self-hosting status:** The open-source mirror of kombify TechStack is **planned** but not yet published, and self-hosted kombify Simulate is **coming soon**. The repository referenced below is not yet publicly available — this guide describes the intended workflow.
</Note>

## Quick start

```bash
# Clone kombify-TechStack
git clone https://github.com/kombify/techstack
cd techstack

# Start services
docker compose up -d

# Access (from the host machine)
# kombify TechStack: http://127.0.0.1:5261
# kombify Simulate: http://127.0.0.1:5271
```

## Services

- kombify TechStack Core (API + PocketBase)
- kombify TechStack UI
- kombify Simulate API
- kombify Simulate UI
- Headscale (optional)
