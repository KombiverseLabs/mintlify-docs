# kombify documentation

These public docs cover the released StackKits homelab standard, the SpeechKit
voice framework, and the current Techstack product preview. Each product area
states which artifacts are publicly available and which capabilities remain a
preview.

<Info>
StackKits and SpeechKit both have standalone public releases. Techstack is
documented as a preview and does not yet have a public installer or anonymous
source distribution.
</Info>
