# kombify documentation

These public docs cover the released StackKits homelab standard, the SpeechKit
voice framework, and the current Techstack Alpha. Each product area
states which artifacts are publicly available and which capabilities remain a
preview.

<Info>

unsigned open-source Windows Alpha for account-free local orchestration.
</Info>
