# StackKits documentation

StackKits is the portable homelab standard from kombify. These public docs
cover the released StackKits specification, verified installers, the
standalone `stackkit` CLI and MCP server, local lifecycle operations, and
supported applications.

<Info>
StackKits works without a kombify account or hosted kombify service. The
standalone lifecycle remains the primary public path.
</Info>

## Release authority

Only capabilities backed by a public StackKits release belong in this site.
Release archives, checksums, SBOMs, notes, and known limitations remain
available from the
[StackKits GitHub releases](https://github.com/kombifyio/StackKits/releases).

<Note>
This documentation intentionally excludes internal development infrastructure
and product surfaces that have not been released for public use.
</Note>
