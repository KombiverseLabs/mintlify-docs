Basement Kit is the current local-first customer kit in StackKits `v0.5.x`.

<Note>
  **Compatibility identifier:** `base-kit` remains an accepted legacy alias in the current release line, but new docs and new stacks should use `basement-kit`.
</Note>

## What it is

Basement Kit deploys a single-environment homelab baseline with:

- local-first defaults,
- StackKits resolver-backed service composition,
- optional add-ons layered on top of the baseline.

It is the local counterpart to [Cloud Kit](/stackkits/kits/cloud-kit), both derived from the shared `base/` library.

## Install paths

Use one of the release-backed install lanes:

```bash
curl -sSL https://base.stackkit.cc | sh
```

Or install CLI-only and initialize explicitly:

```bash
curl -sSL https://install.stackkit.cc | sh
stackkit init basement-kit
```

## Operating mode alignment

Basement Kit maps to the **Local only** operating mode and can later bind to **Connect to Cloud** control-plane surfaces without requiring a separate kit switch.
