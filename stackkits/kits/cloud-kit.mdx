Cloud Kit is the current cloud/VPS customer kit in StackKits `v0.5.x`.

## What it is

Cloud Kit applies the shared `base/` library with cloud defaults:

- public-domain routing,
- ACME/TLS flow for internet-facing endpoints,
- cloud/VPS target assumptions.

It is paired with [Basement Kit](/stackkits/kits/basement-kit), which covers local-first deployment.

## Install paths

```bash
curl -sSL https://cloud.stackkit.cc | sh
```

Or CLI-only:

```bash
curl -sSL https://install.stackkit.cc | sh
stackkit init cloud-kit
```

## Release and availability truth

- Public stable latest: `v0.5.2` (verified 2026-07-10)
- Cloud graduation evidence remains from `v0.5.1` release validation
- This page describes product contract and release-backed commands; it is not itself proof of hosted SaaS availability

## Operating mode alignment

Cloud Kit participates in the same public operating-mode contract:

- **Local only**
- **Connect to Cloud**
- **Managed later**
