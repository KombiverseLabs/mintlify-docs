This reference covers the [v0.54.3 public release](https://github.com/kombifyio/StackKits/releases/tag/v0.54.3). It complements the generated [use-case catalog](/stackkits/reference/use-case-catalog) with the application choices and optional add-ons that its released modules declare. Start with the linked use-case guide; use [Configure the StackSpec](/guides/stackkits/configure-stack-spec) to change an existing workspace.

An application in this reference is a catalog choice, not a promise that it is selected in your installation. `executable` and `apply-ready` describe the released module contract. They do not certify installation, backup or recovery on your machine. Check [OS compatibility](/stackkits/reference/os-compatibility) and [application delivery compatibility](/stackkits/reference/application-delivery-compatibility) before applying.

The tables name the exact alternative or add-on and module, so you can match them to your generated plan. Add-ons are separate choices. A main application's supporting components are operated with their module, rather than installed one by one. Credentials stay in your own custody; follow the setup actions offered by your installed CLI and never edit generated deployment files.

## Source and limits

The choices, component kinds, `recorded` exclusions and compute-profile lists come from the v0.54.3 release catalog. The SpeechKit exclusion comes from the [same release's application image contracts](https://github.com/kombifyio/StackKits/blob/721b28cf58d148556aabcc6eec77161fc5a36f8d/foundation/architecture_v2_catalog.cue). A newer module, a private build or a planned application does not extend this release's public availability.
