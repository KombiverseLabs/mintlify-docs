This page lists the workload adapters in the `v0.16.0` compatibility matrix. Maturity describes the catalog contract, not observed health on your host.

| Choice | Current status | Use it when |
| --- | --- | --- |
| [Coolify](/stackkits/apps/coolify) | Supported | You already operate the generated application platform and accept that workload backup/restore is outside this adapter. |
| [Komodo](/stackkits/apps/komodo) | Beta | You deliberately accept the beta adapter maturity and validate it in your own workspace. |
| `standalone-compose` | Supported | You need the local workload path with declared backup/restore capability and no separate application platform. |

Use one delivery path for a workload and keep the selection within the installed release's validated configuration. Do not infer public support for a component that is not listed here.

Inspect the machine-readable matrix with `stackkit app compatibility --json`. See [Application delivery](/guides/stackkits/application-delivery) for configuration rules.
