This page lists the workload adapters in the released compatibility matrix. Maturity describes the catalog contract, not observed health on your host. Since v0.24.63, `standalone-compose` is the default for new selections and the default core installs no application platform.

| Choice | Current status | Use it when |
| --- | --- | --- |
| `standalone-compose` | Supported, default | You want the complete standalone product with declared backup/restore capability and no separate application platform. |
| [Coolify](/stackkits/apps/coolify) | Supported, explicit selection | You intentionally operate the Coolify platform and accept that workload backup/restore is outside this adapter. |
| [Komodo](/stackkits/apps/komodo) | Beta, explicit selection | You deliberately accept the beta adapter maturity and validate it in your own workspace. |

Use one delivery path for a workload and keep the selection within the installed release's validated configuration. Do not infer public support for a component that is not listed here.

Inspect the machine-readable matrix with `stackkit app compatibility --json`. See [Application delivery](/guides/stackkits/application-delivery) for configuration rules.
