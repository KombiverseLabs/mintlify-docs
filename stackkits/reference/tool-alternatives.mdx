This page intentionally lists only the application-platform choices that the `v0.16.0` StackKits catalog documents as current support.

| Choice | Current status | Use it when |
| --- | --- | --- |
| [Coolify](/stackkits/apps/coolify) | Default | You use the released default application platform for the selected StackKits configuration. |
| [Komodo](/stackkits/apps/komodo) | Supported alternative | You deliberately select the supported Komodo delivery path and validate it in your own workspace. |
| `standalone-compose` | Supported for selected application workloads | You need the supported local Compose delivery path without a separate application platform. |

Use one delivery path for a workload and let `stackkit validate` reject incompatible configuration. Do not infer public support for a component that is not listed here.

The application pages describe the currently released modules: [Applications](/stackkits/apps/overview).
