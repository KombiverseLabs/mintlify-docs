The initial snapshot is bound to [StackKits v0.16.0](https://github.com/kombifyio/StackKits/releases/tag/v0.16.0). Future releases that contain the immutable compatibility asset update this page automatically.

| Operating system | Version | Architecture | Status | Reason |
| --- | --- | --- | --- | --- |
| Debian | 12 | amd64/arm64 | `unverified` | OS policy is not yet admitted for this release. |
| Ubuntu | 24.04 | amd64/arm64 | `unverified` | No release-bound candidate receipt is attached. |

`unverified` is not a support claim. A positive status can appear only with a public receipt bound to the same release, source SHA, policy, and exported artifacts. `unsupported` can be emitted only by StackKits policy.
