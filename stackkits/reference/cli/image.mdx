Prepare and admit an owner-neutral golden image cache.

Prepare immutable core container caches from the embedded CUE catalog. This never initializes an Owner, starts services, creates volumes or prepares a provider VM. Ubuntu 26.04 is the default target; Ubuntu 24.04 remains compatible. The manifest is unsigned cache metadata, never host conformance or Apply authority. The existing packaged OpenTofu provider closure is verified and reused. Network access remains necessary for first-boot service integrations and optional workloads. Techstack owns machine sysprep, VM images and enrollment.

```bash
stackkit image [flags]
```

Subcommands: [`stackkit image plan`](#stackkit-image-plan), [`stackkit image prepare`](#stackkit-image-prepare), [`stackkit image verify`](#stackkit-image-verify)

## stackkit image plan

Print the authoritative neutral core cache profile.

```bash
stackkit image plan [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--profile` | string | `cloud-core-compose` | CUE neutral profile (cloud-core-compose, basement-core-compose, basement-core-lite-compose) |

## stackkit image prepare

Cache the exact running attested release and pull core images only.

```bash
stackkit image prepare [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--cache-root` | string | — | **Required.** Separate neutral release/cache metadata directory |
| `--profile` | string | `cloud-core-compose` | CUE neutral core cache profile |
| `--source-archive-sha256` | string | — | Independent exact selected candidate archive SHA256 |
| `--source-candidate-dir` | string | — | Selected candidate archive and complete offline trust material (preparation only) |
| `--source-cli-sha256` | string | — | Independent exact candidate CLI SHA256; must equal this process |
| `--source-index-sha256` | string | — | Independent exact private candidate index SHA256 |
| `--source-kind` | string | `public-release` | Authenticated source: public-release or preview-candidate |
| `--target` | string | — | **Required.** Empty future deployment directory; never an initialized stack |
