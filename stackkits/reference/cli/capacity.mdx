Assess selected module demand against observed host capacity.

Resolve the current CUE-bound selection and print its advisory capacity assessment as JSON. Missing measurements remain unverified. No files or runtime state are changed; this does not replace Apply admission.

```bash
stackkit capacity [spec-file] [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--inventory` | string | — | Observed Inventory; missing capacity remains unverified |
| `--module-root` | string | — | Architecture authority root |
