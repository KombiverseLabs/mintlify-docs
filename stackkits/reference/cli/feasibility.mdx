Check whether a proposed placement fits an exact node inventory.

Resolve a StackSpec, with the nodeRefs it pins, against the exact observed Inventory and report per workload whether it is feasible, infeasible or unknown, with the requested and resolved nodes and the reasons, plus the capacity verdict of every node. The operation is read-only: it attests no host facts, persists no plan or state, writes no .stackkit files and uses no network. It exits 0 whenever a report is produced, whatever the outcome, and 1 only when an input cannot be read or decoded.

```bash
stackkit feasibility [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--inventory` | string | — | Observed Inventory of the proposed nodes (required) |
| `--json` | bool | — | Emit stackkit.command-result/v1 JSON |
| `--module-root` | string | — | Architecture authority root |

**Examples**

```bash
stackkit feasibility --spec stack-spec.yaml --inventory inventory.yaml --json
```
