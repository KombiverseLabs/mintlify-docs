Prepare and import a verified Full Local artifact bundle.

Prepare owner-neutral release tools, provider packages, container images and a pinned local model. Install imports only the verified cache. Continue through the existing native init, generate and apply commands to create this host's own Owner and runtime custody.

```bash
stackkit bundle [flags]
```

Subcommands: [`stackkit bundle create`](#stackkit-bundle-create), [`stackkit bundle install`](#stackkit-bundle-install), [`stackkit bundle verify`](#stackkit-bundle-verify)

## stackkit bundle create

Prepare the complete neutral closure while online.

```bash
stackkit bundle create [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--model-cache` | string | — | Optional existing Ollama models directory; only manifest-pinned blobs are copied |
| `--profile` | string | `basement-full-local-compose` | Catalog Full Local profile |
| `--source-archive-sha256` | string | — | Independent exact selected candidate archive SHA256 |
| `--source-candidate-dir` | string | — | Selected candidate archive and complete offline trust material (preparation only) |
| `--source-cli-sha256` | string | — | Independent exact candidate CLI SHA256; must equal this process |
| `--source-index-sha256` | string | — | Independent exact private candidate index SHA256 |
| `--source-kind` | string | `public-release` | Authenticated source: public-release or preview-candidate |
| `--target` | string | — | Future native workspace, separate from the bundle (default current directory) |
| `--to` | string | — | **Required.** New owner-neutral bundle directory |
