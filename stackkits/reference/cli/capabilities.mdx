## stackkit capabilities configure

Enable or configure one declared Foundation capability.

Merge public settings, a provider and secret references into one capability. `--enable` explicitly adds an optional capability. Review the normal plan before apply. Advanced intent requires `--output` and capability-gated change-set dispatch. No runtime change occurs; existing applications and storage remain selected.

```bash
stackkit capabilities configure <id> [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--enable` | bool | — | Explicitly enable this kit-declared capability |
| `--expected-spec-hash` | string | — | Require the current canonical spec hash |
| `--json` | bool | — | Emit versioned authoring result; execution remains pending |
| `--output` | string | — | Write a new candidate file, retaining the active baseline; required for Advanced/multi-node intent |
| `--provider` | string | — | Explicit CUE provider; omission retains selection |
| `--secret-ref` | stringArray | — | Input key=secret://reference; never supply secret material |
| `--setting` | stringArray | — | Public setting key=JSON; repeat to merge named settings |
