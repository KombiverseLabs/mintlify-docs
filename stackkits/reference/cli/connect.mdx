Bind this server to your kombify account (a free account is enough).

Bind this server, which already runs the public package, to the kombify account that created the pairing in the kombify Homelab setup. The server shows its state in kombify Cloud afterwards; changes beyond that stay with the paid plans. Paste the one-time pairing at the hidden terminal prompt. Automation can use `--token-file` or KOMBI_TOKEN, never a token argument. The control plane origin comes from `--server` or KOMBI_SERVER (public default https://homelab.kombify.io). For a self-hosted control plane, copy the exact `--server` origin from its kombify Homelab own-server setup in kombify Cloud. A server that is already bound reports its binding and changes nothing. Run it as root on Linux.

```bash
stackkit connect [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--server` | string | — | control plane origin the pairing came from (KOMBI_SERVER, otherwise https://homelab.kombify.io); copy self-hosted origins from the kombify Homelab own-server setup |
| `--token-file` | string | — | private file holding the one-time pairing (otherwise KOMBI_TOKEN, then a hidden terminal prompt) |

**Examples**

```bash
sudo stackkit connect --server https://homelab.kombify.io
sudo stackkit connect --server https://your-techstack.example --token-file /root/kombify-pairing
```
