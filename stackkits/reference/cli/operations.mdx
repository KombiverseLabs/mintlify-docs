List the canonical standalone lifecycle operation contracts.

```bash
stackkit operations [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--json` | bool | — | Emit the operation contracts as JSON |

**Examples**

```bash

stackkit operations

# The same contracts as JSON
```
