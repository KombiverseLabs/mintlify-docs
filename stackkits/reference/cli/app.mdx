Inspect application delivery and run a Homelab own application.

Inspect the governed Architecture v2 application-delivery matrix for Coolify, Komodo, and standalone Compose.

Optional customer PaaS handoff metadata remains available only on the explicit v0.6 StackSpec compatibility line. StackKit-owned applications come from the CUE catalog. Customer-workload desired state belongs to Homelab: app own consumes its versioned one-container document on an installed Direct Compose Home node.

```bash
stackkit app [flags]
```

Subcommands: [`stackkit app compatibility`](#stackkit-app-compatibility), [`stackkit app own`](#stackkit-app-own)

## stackkit app compatibility

Show the governed application/adapter support matrix.

Show the immutable CUE-owned support rows for StackKits applications. This reports product capability, not the selected plan, live adapter availability, or deployment evidence.

```bash
stackkit app compatibility [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--json` | bool | — | Print the compatibility matrix as JSON |

**Examples**

```bash
# Show which applications each runtime adapter supports
stackkit app compatibility

# The same matrix as JSON
stackkit app compatibility --json
```

## stackkit app own

Render or operate one Homelab-owned container or Compose project on this node, or adopt an existing container (`--from-container`).

```bash
stackkit app own [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--action` | string | `render` | create, update, rollback, start, stop, restart, remove, status, logs, render or discard-checkpoint |
| `--allow-major` | bool | — | With `--image-tag`: admit a different major version, or a running image that names no version; never a downgrade or another variant |
| `--capability` | string | — | Managed node: Homelab capability (own-application.lifecycle) for an executed start, stop, restart, update or rollback |
| `--checkpoint` | string | — | Rollback: restore the data checkpoint this tag update operation took, then return to its prior image; discard-checkpoint: remove its retained copy |
| `--cpus` | float | — | Adoption: CPU limit (0.1..4; default the original's limit or 2) |
| `--decision-principal` | string | — | Acting principal the receipt is bound to, as &lt;person\|agent_instance&gt;:&lt;id&gt; |
| `--decision-receipt` | string | — | Compact decision receipt (JWS) that carries the person's confirmation of this exact operation, or @file to read it from a file |
| `--delete-data` | bool | — | Delete the named volume on remove; default retains it in backup |
| `--document` | string | — | Homelab own-application/v1, v2 or v3 JSON document (v2 outbound requires managed host firewall) |
| `--dry-run` | bool | — | Review inputs and render only; no Docker or custody writes |
| `--from-container` | string | — | Stack it: adopt this existing container (ID or name) StackKits did not install, rebuilt as an own application |
| `--http-port` | int | — | Adoption: the container's web port when it exposes several |
| `--image-tag` | string | — | Update only: move a one-container application to this newer version tag of its own image (re-resolved before stopping, data checkpoint, verify, automatic rollback of image and data) |
| `--installation-file` | string | — | Offline installation context; dry-run only |
| `--json` | bool | — | Return the versioned result as JSON |
| `--keep-secrets` | bool | — | On remove only: retain secrets with the retained named volume |
| `--memory-mib` | int | — | Adoption: memory limit (64..8192 MiB; default the original's limit or 2048) |
| `--name` | string | — | Application DNS name, without the reserved own- prefix |
| `--no-outbound` | bool | — | Adopt without outbound Internet; published host ports stay and only answer connections made to them |
| `--operation-id` | string | — | Stable identity of this exact reviewed mutation |
| `--owner-approve` | bool | — | Approve this exact local operation |
| `--phase` | string | — | Adoption phase: inspect, plan, adopt or verify |
| `--plan-digest` | string | — | Exact adoption plan digest returned by `--phase` plan; required for `--phase` adopt |
| `--release-original` | bool | — | Remove the stopped original of an adopted container (requires `--owner-approve`); never automatic |
| `--resolved-image` | string | — | Exact digest from dry review; required for executing a tagged image |
| `--resolved-images-file` | string | — | JSON object of service and digest pairs from dry review; required for executing a tagged project image |
| `--restore-original` | bool | — | Within 7 days of adoption: remove the rebuilt application and start the original again (requires `--owner-approve`) |
| `--review-digest` | string | — | Exact review digest returned by dry-run of this action |
| `--secret-env` | stringArray | — | Adoption: also classify this environment variable as a credential (repeatable); every value is hidden anyway |
| `--secrets-file` | string | — | Private JSON environment-key/value input for application-scoped custody (a project uses &lt;service&gt;.&lt;KEY&gt; slots) |
