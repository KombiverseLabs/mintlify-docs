Published StackKit release operations.

Discover, verify, and install published StackKit release artifacts.

```bash
stackkit kit [flags]
```

Subcommands: [`stackkit kit list`](#stackkit-kit-list), [`stackkit kit prepare-source-generation`](#stackkit-kit-prepare-source-generation)

## stackkit kit list

List published StackKits releases from GitHub.

Resolve the newest published release for every public StackKit on the current operating system and architecture. The release index is fetched from the public kombifyio/stackKits GitHub Releases repository.

```text
Channels:
  stable  newest release that is not a prerelease
  beta    newest -beta.* prerelease
  edge    newest -edge.* prerelease
```

```bash
stackkit kit list [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--channel` | string | `stable` | Release channel: stable, beta, or edge. |
| `--json` | bool | — | Emit stackkit.command-result/v1 JSON. |

**Examples**

```bash
# Show the newest stable release of every public StackKit for this OS and architecture
stackkit kit list

# Show beta prereleases as JSON
stackkit kit list --channel beta --json
```

## stackkit kit prepare-source-generation

Cache and verify the attested release that authored the retained generation.

```bash
stackkit kit prepare-source-generation [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--cache-only` | bool | — | Retain an exact attested public release independently of workspace lifecycle or Owner custody. |
| `--json` | bool | — | Emit bounded source-generation inspection proof after authenticated cache preparation. |
| `--release-cache` | string | — | Absolute persistent release cache directory for cache-only preparation. |
| `--source-arch` | string | — | Exact public source architecture. |
| `--source-archive-sha256` | string | — | Require the exact public source archive digest. |
| `--source-cli-sha256` | string | — | Require the installed source CLI digest to match the verified archive executable. |
| `--source-index-sha256` | string | — | Require the exact signed source release-index digest. |
| `--source-kit` | string | — | Exact public source kit for cache-only preparation. |
| `--source-os` | string | — | Exact public source operating system. |
| `--source-release` | string | — | Exact public source release tag, no newer than this CLI. |
