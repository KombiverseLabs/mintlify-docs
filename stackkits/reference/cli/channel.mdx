Show or set the release channel (stable or early-access).

Show which release channel this machine follows.

stable is the default. early-access is the opt-in channel: it gets builds the StackKits team switched live before they become the next stable release, and the newest stable release whenever that is newer. Early Access builds are unsigned prereleases. The choice is stored in ~/.stackkits/channel and read by the installer (install.sh), which fetches the newest release of that channel.

```bash
stackkit channel [flags]
```

**Examples**

```bash
# Show the current channel
stackkit channel

# Follow Early Access, then re-run the installer
stackkit channel set early-access
```

Subcommands: [`stackkit channel set`](#stackkit-channel-set)

## stackkit channel set

Choose the release channel.

```bash
stackkit channel set <stable|early-access> [flags]
```
