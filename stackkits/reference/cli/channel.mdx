Show or set the release channel (stable or preview).

Show which release channel this machine follows.

stable is the default. preview ("Nightly") is a prerelease built once a day from main when main changed; it is unsigned and opt-in. The choice is stored in ~/.stackkits/channel and read by the installer (install.sh), which fetches the newest release of that channel.

```bash
stackkit channel [flags]
```

**Examples**

```bash
# Show the current channel
stackkit channel

# Follow the Nightly prereleases, then re-run the installer
stackkit channel set preview
```

Subcommands: [`stackkit channel set`](#stackkit-channel-set)

## stackkit channel set

Choose the release channel.

```bash
stackkit channel set <stable|preview> [flags]
```
