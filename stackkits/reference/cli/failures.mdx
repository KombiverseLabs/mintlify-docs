Look up known failures and their resolutions offline.

Search the failure resolution snapshot shipped with this release. A resolution names its symptoms, where it applies, the root cause and the product procedures that fix it. It is advice: apply a fix only through the referenced procedure.

```bash
stackkit failures [flags]
```

Subcommands: [`stackkit failures lookup`](#stackkit-failures-lookup), [`stackkit failures snapshot`](#stackkit-failures-snapshot)

## stackkit failures lookup

Find resolutions by failure signature or description.

Look up promoted resolutions in the offline snapshot: an exact failure signature first, then the words of the description (FTS5). With a local Ollama serving bge-m3 (`--ollama-url` or STACKKIT_FAILURE_OLLAMA_URL) the description is also matched by meaning. Prints JSON; nothing leaves this host except the description sent to that local Ollama.

```bash
stackkit failures lookup [description] [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--ollama-url` | string | — | Ollama with bge-m3 on this host (localhost or a loopback address) for the semantic step |
| `--signature` | string | — | Failure signature (64 hex characters) from the failure normalizer |
| `--snapshot` | string | — | Snapshot file (default: STACKKIT_FAILURE_SNAPSHOT, then beside the stackkit binary) |
| `--text` | string | — | Error text or a description of the failure |
| `--top` | int | `5` | Number of results (1 to 20) |

## stackkit failures snapshot

Build or describe the failure resolution snapshot.

```bash
stackkit failures snapshot [flags]
```

Subcommands: [`stackkit failures snapshot build`](#stackkit-failures-snapshot-build), [`stackkit failures snapshot info`](#stackkit-failures-snapshot-info)

### stackkit failures snapshot build

Build the SQLite FTS5 snapshot from a resolution catalog.

Build the versioned snapshot from a catalog of promoted resolutions (kombify.failure-resolution-catalog/v1). The release build runs this over the catalog in internal/failureknowledge/data.

```bash
stackkit failures snapshot build [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--catalog` | string | — | Resolution catalog JSON |
| `--output` | string | — | Snapshot file to write |

### stackkit failures snapshot info

Print the version and size of the snapshot.

```bash
stackkit failures snapshot info [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--snapshot` | string | — | Snapshot file (default: STACKKIT_FAILURE_SNAPSHOT, then beside the stackkit binary) |
