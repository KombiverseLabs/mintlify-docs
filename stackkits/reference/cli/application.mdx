Adopt supported existing applications without replacing their accounts or data.

```bash
stackkit application [flags]
```

Subcommands: [`stackkit application adopt`](#stackkit-application-adopt), [`stackkit application control`](#stackkit-application-control), [`stackkit application inspect`](#stackkit-application-inspect), [`stackkit application release`](#stackkit-application-release), [`stackkit application verify`](#stackkit-application-verify)

## stackkit application adopt

Bind the reviewed existing application to its declared lifecycle.

```bash
stackkit application adopt [workload] [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--container-id` | string | — | Exact immutable 64-character Docker container ID |
| `--json` | bool | — | Emit the versioned secret-free application evidence |
| `--operation-id` | string | — | Stable operation identifier for idempotent resume |
| `--owner-approve` | bool | — | Approve this exact owner-bound application operation |
| `--owner-file` | string | `.stackkit/setup/home-assistant-owner.json` | Workspace-relative existing private owner grant file containing accessToken |
| `--plan-digest` | string | — | Exact reviewed source-bound adoption plan digest |
| `--workload` | string | — | Exact selected application workload (alternative to positional workload) |
