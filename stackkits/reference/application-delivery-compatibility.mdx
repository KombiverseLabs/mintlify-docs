This matrix is the product capability declared by [StackKits v0.16.0](https://github.com/kombifyio/StackKits/releases/tag/v0.16.0). It is not evidence that an adapter was deployed on a real host.

| Use cases | Adapter | Status | Deploy | Route/TLS | Status evidence | Backup/restore |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Files, Photos, Vault | Standalone Compose | `supported` | yes | yes | yes | yes |
| Files, Photos, Vault | Coolify | `supported` | yes | yes | yes | no |
| Files, Photos, Vault | Komodo | `beta` | yes | yes | yes | no |

The generated release projection expands these groups into exact use case/workload/adapter rows. Choose one delivery path for each workload; the [application delivery guide](/guides/stackkits/application-delivery) explains how to inspect the installed release.
