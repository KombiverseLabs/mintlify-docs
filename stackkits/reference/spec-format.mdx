`stack-spec.yaml` is the primary StackKits config contract.

## Current kit identifiers

- `basement-kit` (canonical local-first identifier)
- `cloud-kit` (canonical cloud identifier)

`base-kit` remains a compatibility alias in current releases and should be treated as legacy input.

## Minimal example

```yaml
version: "1.0"
stackkit: basement-kit
```
