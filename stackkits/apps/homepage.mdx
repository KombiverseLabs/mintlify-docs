Homepage is the default StackKits service start page. When enabled by the released configuration, it is available at the generated `home.<domain>` address and groups the services in that stack.

Use it for daily navigation. Use the Node Hub and CLI output for first-run state, recovery material, and verification details.

```bash
stackkit status --json
stackkit verify --json
```

If a service is missing, change the StackSpec, run `stackkit validate`, and regenerate the rollout instead of editing Homepage-generated configuration.
