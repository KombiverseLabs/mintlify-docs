Homepage ships as a released module contract, but it is not selected by the initial native v2 StackSpec. The Node Hub is the current generated core entrypoint.

## What it is

Homepage is a start page for your homelab: one web page with links to your services. A StackKit can include it as a friendly starting point. Its intended role is daily navigation.

## Which kits include it

The catalog defines Homepage as a default-maturity module that needs Traefik, but it is not selected by the initial native v2 StackSpec. Do not expect it in a fresh rollout.

## How you open it

If a released StackSpec selects it, the catalog gives the pattern `https://home.<domain>`, for example `https://home.lab.home` with the default domain. Copy the generated address instead of typing it.

## First use

1. Open the [Node Hub](/guides/stackkits/node-hub) at the `base.<domain>` address. Use the Node Hub and CLI output for first-run state, recovery material, and verification details.
2. If a future release lists Homepage, open its generated address.
3. Click a service tile to open that service.

## What to expect and what not to change

- Expect a page of links generated from your configuration. The catalog lets you set its title; the default is "My Homelab".
- Do not invent a Homepage module selection from an older schema. If a future StackSpec exposes it, use only the installed release's validated fields and generated route.
- Do not edit generated files by hand. Change the StackSpec and regenerate.

## If something goes wrong

- The address does not open: Homepage is probably not part of your rollout. Use the Node Hub instead.
- Another address does not open: compare it with the rollout output and see [Troubleshooting](/guides/stackkits/troubleshooting).
