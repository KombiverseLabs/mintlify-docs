Dozzle is a publicly released module contract for viewing container logs. The initial native v2 StackSpec does not expose a current public Dozzle selection, so archive presence is not an installation recipe.

Use it for quick inspection of a named container, then keep durable diagnosis in the StackKits evidence and logs:

```bash
stackkit logs list --json
stackkit verify --json
```

If a future released StackSpec selects it, Dozzle still does not replace the CLI verification result. Do not change StackKits-managed containers from the log viewer.
