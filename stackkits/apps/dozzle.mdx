Dozzle is a publicly released module contract for viewing container logs. The initial native v2 StackSpec does not expose a current public Dozzle selection, so archive presence is not an installation recipe.

If a future released StackSpec selects it, use Dozzle for quick inspection of a named container. It does not replace StackKits verification or durable evidence, and it must not be used to change StackKits-managed containers.
