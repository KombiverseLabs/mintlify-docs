Dozzle is an opt-in, publicly released StackKits module for viewing container logs. When it is included in your validated stack, open the generated service address from the Node Hub or rollout output.

Use it for quick inspection of a named container, then keep durable diagnosis in the StackKits evidence and logs:

```bash
stackkit logs list --json
stackkit verify --json
```

Dozzle does not replace the CLI verification result. Do not change StackKits-managed containers from the log viewer.
