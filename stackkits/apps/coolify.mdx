Coolify is the default application platform in the released StackKits `v0.16.0` catalog. When it is part of the validated configuration, the generated rollout owns its bootstrap and routes it at `coolify.<domain>`.

## Use it safely

1. Complete the StackKits lifecycle first: `validate`, `generate`, `apply`, then `verify`.
2. Open the generated Coolify URL from the Node Hub or the StackKits output.
3. Use one application delivery path per workload; do not create competing generated routes by hand.
4. Keep application credentials and recovery material under the local owner's control.

## Verify

- The generated Coolify route opens at the address reported by the rollout.
- The application platform and its configured routes show healthy after `stackkit verify --json`.
- The StackKits workspace remains the source of configuration intent.

For the supported alternative, see [Komodo](/stackkits/apps/komodo). For the public catalog, see [Applications](/stackkits/apps/overview).
