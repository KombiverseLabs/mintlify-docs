Coolify is an optional application platform and workload adapter. Select it explicitly when you want Coolify to manage your applications. The default standalone workspace uses Compose directly.

| Role | Released catalog behavior |
| --- | --- |
| Selection | Optional explicit integration; standalone Compose needs no application platform |
| Workload adapter | Supported for `files`, `photos`, and `vault` |
| Route and TLS evidence | Supported |
| Workload backup and restore | Not supplied by the Coolify adapter |

## Use it safely

1. Complete and verify the StackKits rollout before opening the application platform.
2. Open the generated Coolify URL from the Node Hub or the StackKits output.
3. Use one application delivery path per workload; do not create competing generated routes by hand.
4. Keep application credentials and recovery material under the local owner's control.
5. Use the StackKits backup path only where the selected adapter declares backup-and-restore support.

## Verify

- The generated Coolify route opens at the address reported by the rollout.
- StackKits verification reports the application platform and its configured routes as healthy.
- The StackKits workspace remains the source of configuration intent.

For the beta alternative, see [Komodo](/stackkits/apps/komodo). For the complete adapter matrix, see [Application delivery](/guides/stackkits/application-delivery).
