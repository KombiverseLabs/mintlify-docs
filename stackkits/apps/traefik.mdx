Traefik is the default reverse-proxy component in the released StackKits catalog. It routes generated service names such as `base.<domain>`, `auth.<domain>`, and application routes selected by your validated configuration.

Use the generated service URLs and CLI verification output to diagnose routing. Do not add labels, routers, or middleware directly to StackKits-managed containers.

```bash
stackkit verify --json
stackkit logs list --json
```

For a safe request-path check, use [Whoami](/stackkits/apps/whoami).
