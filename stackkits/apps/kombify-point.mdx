kombify Point DNS ships as a v0.16.0 module contract for a local DNS zone, but the initial native v2 StackSpec exposes no current public enablement how-to.

Use it only for a LAN resolver arrangement you operate. Public DNS remains the responsibility of your own DNS provider and domain setup.

Do not invent an enablement object from older examples. When a released StackSpec exposes the module, test generated names only from clients deliberately configured to use that resolver.
