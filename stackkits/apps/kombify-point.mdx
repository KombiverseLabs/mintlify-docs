kombify Point DNS is an opt-in StackKits module for a local DNS zone you control. It can resolve the local service names emitted by a StackKits rollout.

Use it only for a LAN resolver arrangement you operate. Public DNS remains the responsibility of your own DNS provider and domain setup.

After enabling it through a validated StackSpec, test a generated service name from a client that is configured to use the resolver. If it does not resolve, check the client or router DNS configuration before changing StackKits-generated files.
