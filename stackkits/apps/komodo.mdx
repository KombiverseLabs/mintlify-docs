Komodo is a beta adapter in the released workload compatibility matrix. Choose it only when you accept that maturity; standalone Compose and Coolify are the supported adapter paths.

Since v0.24.63, the default core installs neither Komodo nor Coolify. Komodo is an explicitly enabled integration that consumes the same workload, identity, routing, data, and evidence contracts as the standalone Compose default. Each workload keeps exactly one execution owner and one routing owner.

## Use it safely

- Select the beta `komodo` adapter explicitly in the workload intent for your installed release.
- Validate the workload intent before generating or applying the configuration.
- Use the generated Komodo URL and credentials from the rollout output.
- Keep one application delivery path per workload.

Do not copy an old configuration snippet or create a second platform route by hand. The installed release's CUE validation is authoritative.

See [Application delivery](/guides/stackkits/application-delivery) and [Released application platforms](/stackkits/reference/tool-alternatives).
