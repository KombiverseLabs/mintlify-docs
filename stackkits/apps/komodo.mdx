Komodo is the supported application-platform alternative in the released StackKits catalog. Choose it deliberately when its Compose and API-oriented operating model fits your environment; Coolify remains the default platform path.

## Use it safely

- Select the supported platform intent in the StackSpec for your installed release.
- Run `stackkit validate` before generating or applying the configuration.
- Use the generated Komodo URL and credentials from the rollout output.
- Keep one application delivery path per workload.

Do not copy an old configuration snippet or create a second platform route by hand. The installed release's CUE validation is authoritative.

See [Coolify](/stackkits/apps/coolify) and [Released application platforms](/stackkits/reference/tool-alternatives).
