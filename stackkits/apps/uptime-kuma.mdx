Uptime Kuma is the default uptime-monitoring component in the released StackKits catalog. When included in your stack, open the generated `kuma.<domain>` address from the Node Hub or rollout output.

Add monitors only for services you operate. For protected routes, use an intentional health endpoint or expect the configured authentication response; do not weaken route protection merely to make a monitor return HTTP 200.

Run `stackkit verify --json` after a change. The CLI result remains the source of StackKits lifecycle verification.
