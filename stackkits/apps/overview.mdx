StackKits applications are explicitly selected in your StackSpec. Check the
[release catalog](/guides/stackkits/use-cases/overview) and
[adapter capabilities](/stackkits/reference/application-delivery-compatibility)
for the installed release. Catalog presence, successful installation and a
completed recovery have different meanings.

## Current core runtime

- [PocketID](/stackkits/apps/pocketid) — local owner identity
- [TinyAuth](/stackkits/apps/tinyauth) — forward-auth entrypoint
- [Traefik](/stackkits/apps/traefik) — routing implementation in the generated core

Standalone Compose is the default. [Komodo](/stackkits/apps/komodo) and
[Coolify](/stackkits/apps/coolify) are explicitly selected platform integrations;
their lifecycle capabilities are listed in the adapter matrix.

## Optional native v2 workloads

- [Cloudreve](/stackkits/apps/cloudreve) — released `files` alternative
- [Immich](/stackkits/apps/immich) — released `photos` alternative
- [Vaultwarden](/stackkits/apps/vaultwarden) — released `vault` alternative
- [Jellyfin](/stackkits/apps/jellyfin) — `media` with an explicit library and native owner setup
- [Private AI](/guides/stackkits/use-cases/private-ai) — Ollama and Open WebUI with explicit model downloads
- Home Assistant — `smart-home` with native owner setup; HAOS and existing-instance contracts have separate execution paths

Choose the workloads you need during initialization or update the
[StackSpec](/guides/stackkits/configure-stack-spec). A base-only installation
remains valid. Applications that need credentials use the local owner's private
custody; follow their setup instructions before treating them as usable.

## Additional released module contracts

- [Homepage](/stackkits/apps/homepage), [Uptime Kuma](/stackkits/apps/uptime-kuma), [Whoami](/stackkits/apps/whoami), and [Dozzle](/stackkits/apps/dozzle) — visibility modules not selected by the initial native v2 StackSpec
- [kombify Point DNS](/stackkits/apps/kombify-point) — local DNS module without a current public native v2 how-to

Use `stackkit app compatibility --json` for the workload adapter matrix. Do not edit generated deployment files or infer enablement from archive presence.
