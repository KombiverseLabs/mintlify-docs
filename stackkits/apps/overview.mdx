This catalog contains only applications and platform components with current public support in the StackKits `v0.16.0` source and release catalog. The enabled set is determined by the validated StackSpec and the selected kit.

## Identity and routing

- [PocketID](/stackkits/apps/pocketid) — default local identity provider
- [TinyAuth](/stackkits/apps/tinyauth) — default forward-auth entrypoint
- [Traefik](/stackkits/apps/traefik) — default reverse proxy
- [Whoami](/stackkits/apps/whoami) — default routing diagnostic

## Platform and visibility

- [Coolify](/stackkits/apps/coolify) — default application platform
- [Komodo](/stackkits/apps/komodo) — supported application-platform alternative
- [Homepage](/stackkits/apps/homepage) — default service start page
- [Uptime Kuma](/stackkits/apps/uptime-kuma) — default uptime monitoring
- [Dozzle](/stackkits/apps/dozzle) — opt-in container log viewer
- [kombify Point DNS](/stackkits/apps/kombify-point) — opt-in local DNS component

## Applications

- [Immich](/stackkits/apps/immich) — default photo and video application
- [Vaultwarden](/stackkits/apps/vaultwarden) — default password-vault application
- [Jellyfin](/stackkits/apps/jellyfin) — opt-in media server

Use `stackkit validate` before changing application intent. Do not edit generated deployment files or treat an unlisted component as public support.
