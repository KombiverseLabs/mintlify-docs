Applications on StackKits are delivered as **add-ons and modules** on top of any kit — Basement Kit, Cloud Kit, or Modern Homelab. The catalog is grouped by **use case**: each use case ships a default application chosen by kombify, and most have alternatives you can switch to in your spec — see the [Tool alternatives](https://docs.kombify.io/stackkits/reference/tool-alternatives) reference.

## Use cases

| Use case | Applications |
|----------|--------------|
| **Photos** | [Immich](https://docs.kombify.io/stackkits/apps/immich) — default |
| **Media Streaming** | [Jellyfin](https://docs.kombify.io/stackkits/apps/jellyfin) — default |
| **Passwords & Secrets** | [Vaultwarden](https://docs.kombify.io/stackkits/apps/vaultwarden) — default |
| **Monitoring & Observability** | [Uptime Kuma](https://docs.kombify.io/stackkits/apps/uptime-kuma) — default uptime monitoring |
| **Login & SSO** | [PocketID](https://docs.kombify.io/stackkits/apps/pocketid) — identity (OIDC) · [TinyAuth](https://docs.kombify.io/stackkits/apps/tinyauth) — forward-auth gateway |
| **PaaS Platforms** | [Coolify](https://docs.kombify.io/stackkits/apps/coolify) — default · [Komodo](https://docs.kombify.io/stackkits/apps/komodo) — supported · [Dokploy](https://docs.kombify.io/stackkits/apps/dokploy) — draft · [Dockge](https://docs.kombify.io/stackkits/apps/dockge) — experimental |
| **Platform Core** | [Traefik](https://docs.kombify.io/stackkits/apps/traefik) · [Homepage](https://docs.kombify.io/stackkits/apps/homepage) · [Dozzle](https://docs.kombify.io/stackkits/apps/dozzle) · [whoami](https://docs.kombify.io/stackkits/apps/whoami) · [kombify Point](https://docs.kombify.io/stackkits/apps/kombify-point) |

More use-case groups are rolling out as their add-ons graduate: Files & Sync, Smart Home, Local AI, Developer Platform, Calendar & Contacts, Email, Remote Desktop, Tunnels, VPN Overlay, Backup, and Game Servers.

<Note>
  Defaults are context-resolved, never hard-locked — every default can be swapped for a documented alternative. The full default/alternative matrix lives in [Tool alternatives](https://docs.kombify.io/stackkits/reference/tool-alternatives). Browse the full catalog below.
</Note>
