PocketID is the default local identity provider in the released StackKits catalog. A Basement Kit rollout uses it for local owner custody and normally exposes it at `id.<domain>`.

After the rollout verifies successfully, open the generated address and create the first local owner passkey. Keep recovery material outside the server and do not use a shared identity for the owner.

TinyAuth uses the generated PocketID integration for protected StackKits routes. See [TinyAuth](/stackkits/apps/tinyauth) for the entrypoint behavior.
