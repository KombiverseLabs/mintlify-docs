Dokploy is currently a **draft/non-beta** app platform for StackKits. It is documented for preview and design alignment only.

For the public BaseKit beta, use Coolify as the default app platform or Komodo as the supported beta alternative. Dokploy must not be used as canonical beta evidence until its own released-content matrix graduates.

## Prerequisites

<Warning>
  Do not treat this page as an install path for the current public beta. The canonical beta E2E matrix excludes Dokploy.
</Warning>

## Steps

<Steps>
  <Step title="Open Dokploy">
    In a draft rollout, open `https://dokploy.<domain>` from the Node Hub.
  </Step>
  <Step title="Claim the admin account">
    Complete Dokploy's first-run setup and store recovery information outside the server.
  </Step>
  <Step title="Deploy an app">
    Add a project, choose the container or repository source, and route it through the StackKits domain.
  </Step>
</Steps>

## Verify

- Dokploy opens behind the StackKits auth layer.
- The first project can start a container.
- The app route resolves through Traefik.

These checks are preview diagnostics, not public beta release evidence.
