Jellyfin ships as a public v0.16.0 module contract, but the current native v2 workload catalog exposes only `files`, `photos`, and `vault`. The initial StackSpec has no released Jellyfin selector.

Do not add a guessed `application.media` or `workloads.jellyfin` object: the installed CUE contract rejects unsupported intent. A future released workload contract must define placement, storage, route, health, and lifecycle before this can become a public installation how-to.

The module archive remains useful release evidence for developers, but archive presence alone is not an operator-facing enablement path.
