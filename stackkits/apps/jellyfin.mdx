Jellyfin is an opt-in, publicly released StackKits media-server module. Include it only after you have planned the media path, available storage, and the clients that will use it.

After a verified rollout, open the generated Jellyfin address from the Node Hub or rollout output, create the application administrator, and add libraries that match the mounted storage path.

Do not modify generated mounts or service configuration directly. Change the StackSpec, validate it, and regenerate before applying changes.
