Whoami is the default StackKits routing diagnostic. Use its generated address to check the hostname, proxy headers, and expected authentication behavior before investigating a larger application.

If the result is unexpected, inspect the rollout first:

```bash
stackkit verify --json
stackkit status --json
stackkit logs list --json
```

Do not change generated router configuration in response to one diagnostic request. Update validated StackKits intent and regenerate the rollout instead.
