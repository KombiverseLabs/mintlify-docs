Use only the currently release-backed install and CLI commands.

## Fast install commands

```bash
curl -sSL https://base.stackkit.cc | sh
curl -sSL https://cloud.stackkit.cc | sh
```

## CLI-only flow

```bash
curl -sSL https://install.stackkit.cc | sh
mkdir my-stack && cd my-stack
stackkit init basement-kit
stackkit prepare
stackkit generate
stackkit plan
stackkit apply
stackkit status
```

<Note>
  `base-kit` is still accepted as a compatibility alias in current releases, but `basement-kit` is the canonical identifier for new stacks.
</Note>
