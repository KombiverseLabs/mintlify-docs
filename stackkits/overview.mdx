StackKits is the standalone, open homelab standard. It provides portable kit definitions, the `stackkit` CLI and MCP connector, and a local lifecycle for validating, generating, applying, and verifying a stack.

The public documentation currently describes the released `v0.16.0` catalog only. StackKits works against a host you already control; it does not require a kombify account or a hosted kombify endpoint.

Both kits are released through the public `v0.16.0` release index. Choose the kit by the environment you control, not by the number of services you want to run.

## Standalone lifecycle

```bash
stackkit init basement-kit --owner-source=local
stackkit validate
stackkit generate
stackkit apply
stackkit verify --json
```

`init` writes the initial StackSpec. `validate` checks it against the embedded CUE contract, `generate` creates disposable rollout artifacts, and `apply` changes the target. Review the generated plan and keep the StackKits workspace under your control; do not hand-edit generated artifacts.

## What StackKits does not do

- create or buy a server for you
- hold provider credentials or manage provider resources
- require a hosted control plane for Standard Mode
- replace the local owner and evidence produced by the standalone lifecycle
