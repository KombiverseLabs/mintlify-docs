StackKits is the Wave 1 OSS release surface for kombify infrastructure composition.

## Current public product tree

The current public customer kits are:

1. **Basement Kit** (`basement-kit`) for local-first environments.
2. **Cloud Kit** (`cloud-kit`) for cloud/VPS environments.

Both are derived from the shared `base/` library and follow the same operating-mode contract:

- **Local only**
- **Connect to Cloud**
- **Managed later**

<Note>
  Legacy `base-kit` exists as a compatibility identifier in current releases. New docs and new initialization flows use `basement-kit`.
</Note>

## Release truth

- Public repo: [github.com/kombifyio/stackKits](https://github.com/kombifyio/stackKits)
- Latest public stable at verification time: `v0.5.2` (verified 2026-07-10)
- Cloud Kit graduation evidence remains anchored in the `v0.5.1` release cycle

## Future concepts (not current deployable kits)

- **Modern Homelab Kit**: retained as future concept documentation only
- **High Availability Kit**: retained as future concept documentation only

These pages describe target architecture and do not represent current installable/public-release kits.

## Install lanes in current release

```bash
curl -sSL https://base.stackkit.cc | sh
curl -sSL https://cloud.stackkit.cc | sh
curl -sSL https://install.stackkit.cc | sh
```
