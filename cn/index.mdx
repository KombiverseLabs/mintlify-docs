# kombify 文档

这些公开文档涵盖已发布的 StackKits 家庭实验室标准、SpeechKit 语音框架和当前的
Techstack Alpha 版，包括 kombify.me 公共地址。每个产品区域都会说明哪些构件已公开
提供，以及哪些功能仍处于预览阶段。

<Info>
StackKits 和 SpeechKit 均已独立公开发布。Techstack 目前提供无需账户即可进行本地编排的
开源 Windows Alpha 版；该版本尚未签名。
</Info>

## 发布依据

有发布版本支持的说明会链接到当前公开构件，而不是固定的旧版本，因此下载链接始终指向
最新发布。当页面声明某个版本时，该行会根据已发布版本生成并自动核对。产品预览会单独
标记，也不会添加并不存在的下载或安装步骤。

本文档有意排除内部开发基础设施、私有实现细节和不受支持的产品声明。
